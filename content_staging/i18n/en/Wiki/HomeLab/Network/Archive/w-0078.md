# Hexo Installation and Prerequisite Environment Setup

> <img src='https://img.shields.io/badge/Status-Obsolete-red?style=for-the-badge&labelWidth=100' height='38' />

# Preface

Hexo is a very simple and easy-to-use static page generator, essentially requiring npm + Node.js.

## Related Tools

### Git

#### Linux

- **Arch Series**

```bash
sudo pacman -S git
```

- **Debian/Ubuntu Series**

```bash
sudo apt-get install git-core
```

> [!info] Updated 2026-11-27
> `git-core` is an early obsolete transitional package name; modern Debian/Ubuntu environments should use `sudo apt update && sudo apt install git` directly.

Since installing GitHub Desktop on Linux is somewhat cumbersome—especially without a VPN inside mainland China—it is recommended to just use Command Line `git`. If worst comes to worst, writing a script makes it very convenient anyway.

#### Windows

On Windows, it is recommended to directly download [GitHub Desktop](https://desktop.github.com/) for convenience, which can be downloaded and installed from the official website or installed via Chocolatey:

```bash
choco install github-desktop
```

### Node.js & npm

#### Linux

- **Arch Series**

```bash
sudo pacman -S nodejs npm
```

- **Debian/Ubuntu Series**

```bash
sudo apt-get install -y nodejs npm 
```

> [!info] Updated 2026-11-27
> The Node.js version provided by default in Debian/Ubuntu `apt` repositories is typically older and may not meet the requirements of newer Hexo versions or frontend tooling. In practice, it is recommended to install LTS versions using `nvm`, `fnm`, or NodeSource.

#### Windows

Similar to GitHub Desktop, you can download and install it from [Node.js](https://nodejs.org/en/), which includes npm bundled in, or install it via Chocolatey:

```bash
choco install nodejs
```

## Hexo Installation

Hexo is installed using npm. I have never installed it under Windows, but I assume it is the same:

```bash
npm install -g hexo-cli
```

It is installed once finished.
