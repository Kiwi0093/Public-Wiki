# Introduction to Hexo and GitHub Pages Blog Hosting Architecture

> <img src='https://img.shields.io/badge/Status-Obsolete-red?style=for-the-badge&labelWidth=100' height='38' />

## Objective

Set up a personal Blog + Wiki using [Hexo](https://hexo.io/) + [GitHub Pages](https://pages.github.com/).

## Basic Architecture

![Construction](https://raw.githubusercontent.com/Kiwi0093/graph/master/img/Blog_wiki_construction.PNG)

### Description

This leverages several features of GitHub Pages:

- Inside the `<Username>.github.io` repository's <span style="color:#e06c75"><del>master</del></span> *(Updated 2026-11-27: GitHub's default main branch is now `main`, and modern GitHub Pages also allows specifying arbitrary branches or deploying directly via GitHub Actions)* branch, the `index.html` file generates the valid URL `https://<Username>.github.io/`
- In other repositories, GitHub Pages generates the valid URL `https://<username>.github.io/<other-repo>/` from `index.html` within the `gh-pages` branch.

Therefore, you can generate the blog's web pages into the main branch of the `<username>.github.io` repository to serve as the primary website, and generate web pages using other desired themes into the `gh-pages` branch of other repositories to serve as sub-sites.

Although you can specify a particular `_config.yml` using Hexo commands to combine the two, the underlying principle is the same as the table above. However, doing so allows you to store the Hexo Wiki and Hexo Blog in the same directory, integrating Git synchronization management.
