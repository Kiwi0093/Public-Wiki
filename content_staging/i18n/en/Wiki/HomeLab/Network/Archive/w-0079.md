## Hexo Core Configuration

Hexo's core settings are all stored in `<folder>/_config.yml`. Most defaults can be kept as-is, which is very convenient, and only a few items need to be adjusted as needed.

Detailed [Hexo Configuration](https://hexo.io/docs/configuration.html)

### Site Section

```yaml
# Site
title: Kiwi's Blog
subtitle: 中年大叔的自言自語
description: ''
keywords:
author: Kiwi 
language: zh_TW
timezone: 
```

| Setting       | Description                                                  |
| :------------ | :----------------------------------------------------------- |
| `title`       | Site title                                                   |
| `subtitle`    | Site subtitle                                                |
| `description` | Site description                                             |
| `keywords`    | Site keywords. Supports multiple keywords.                   |
| `author`      | Your name                                                    |
| `language`    | Language used by the site; refer to [2-letter ISO-639-1 code](https://en.wikipedia.org/wiki/List_of_ISO_639-1_codes), defaults to `en` |
| `timezone`    | Site timezone. Hexo uses your computer's timezone by default; you can find an appropriate timezone in the [timezone list](https://en.wikipedia.org/wiki/List_of_tz_database_time_zones), such as `America/New_York`, `Japan`, and `UTC` |

### URL Section

If your site is hosted in a subdirectory, such as `http://example.org/blog`, set your `url` to `http://example.org/blog` and set `root` to `/blog/`.

```yaml
# URL
url: https://kiwi0093.github.io/
root: /
permalink: :year/:month/:day/:title/
permalink_defaults:
pretty_urls:
  trailing_index: true
  trailing_html: true
```

| Setting                      | Description                                                  | Default                     |
| :--------------------------- | :----------------------------------------------------------- | :-------------------------- |
| `url`                        | Site URL, must start with `http://` or `https://`            |                             |
| `root`                       | Root directory of the site                                   |                             |
| `permalink`                  | Format of post [permalinks](https://hexo.io/zh-tw/docs/permalinks) | `:year/:month/:day/:title/` |
| `permalink_defaults`         | Default values for each segment in `permalink`               |                             |
| `pretty_urls`                | Rewrites [`permalink`](https://hexo.io/zh-tw/docs/variables) values to beautify URLs |                             |
| `pretty_urls.trailing_index` | Whether to keep trailing `index.html` in permalinks; removed when set to `false` | `true`                      |
| `pretty_urls.trailing_html`  | Whether to keep trailing `.html` in permalinks; removed when set to `false` (*no effect on trailing `index.html`*) | `true`                      |

### Directory Section

```yaml
# Directory
source_dir: source
public_dir: public
tag_dir: tags
archive_dir: archives
category_dir: categories
code_dir: downloads/code
i18n_dir: :lang
skip_render:
```

| Setting        | Description                                                  | Default          |
| :------------- | :----------------------------------------------------------- | :--------------- |
| `source_dir`   | Source folder where your content is stored                   | `source`         |
| `public_dir`   | Public folder where generated static files are stored        | public           |
| `tag_dir`      | Tag directory                                                | `tags`           |
| `archive_dir`  | Archive directory                                            | `archives`       |
| `category_dir` | Category directory                                           | `categories`     |
| `code_dir`     | Include code directory                                       | `downloads/code` |
| `i18n_dir`     | Internationalization (i18n) directory                        | `:lang`          |
| `skip_render`  | Skip rendering for specified files; you can use [glob expressions](https://github.com/micromatch/micromatch#extended-globbing) to match paths |                  |

### Writing Section

```yaml
# Writing
new_post_name: :title.md
default_layout: post
titlecase: false
external_link:
  enable: true
  field: site
  exclude: ''
filename_case: 0
render_drafts: false
post_asset_folder: false
relative_link: false
future: true
highlight:
  enable: true
  line_number: true
  auto_detect: false
  tab_replace: ''
  wrap: true
  hljs: false
prismjs:
  enable: false
  preprocess: true
  line_number: true
  tab_replace: ''
```

| Setting                 | Description                                                  | Default     |
| :---------------------- | :----------------------------------------------------------- | :---------- |
| `new_post_name`         | Filename of new posts                                        | `:title.md` |
| `default_layout`        | Default layout                                               | `post`      |
| `auto_spacing`          | Add spaces between Western and East Asian characters         | `false`     |
| `titlecase`             | Transform titles into title case                             | `false`     |
| `external_link`         | Open external links in a new tab                             | `true`      |
| `external_link.enable`  | Open external links in a new tab                             | `true`      |
| `external_link.field`   | Applies to the whole `site` or `post` only                   | `site`      |
| `external_link.exclude` | Exclude hostname. Specify subdomain when applicable, including `www` | `[]`        |
| `filename_case`         | Transform filenames to: `1` lowercase or `2` uppercase       | `0`         |
| `render_drafts`         | Render drafts                                                | `false`     |
| `post_asset_folder`     | Enable [Asset Folder](https://hexo.io/zh-tw/docs/asset-folders) | `false`     |
| `relative_link`         | Make links relative to the root folder                       | `false`     |
| `future`                | Display future posts                                         | `true`      |
| `highlight`             | Code block settings, see [Highlight.js](https://hexo.io/docs/syntax-highlight#Highlight-js) section for usage guide |             |
| `prismjs`               | Code block settings, see [PrismJS](https://hexo.io/docs/syntax-highlight#PrismJS) section for usage guide |             |

### Homepage Section

```yaml
# Home page setting
# path: Root path for your blogs index page. (default = '')

# order_by: Posts order. (Order by date descending by default)

  path: ''
  per_page: 10
  order_by: -date
```

### Date & Time Section

```yaml

## Hexo uses Moment.js to parse and display date
## You can customize the date format as defined in
## http://momentjs.com/docs/#/displaying/format/
```

### Pagination Section

```yaml
# Pagination
per_page: 10
pagination_dir: page
```

| Setting          | Description                                      | Default |
| :--------------- | :----------------------------------------------- | :------ |
| `per_page`       | Amount of posts displayed per page (`0` = disable pagination) | `10`    |
| `pagination_dir` | Pagination directory                             | `page`  |

### Include / Exclude Section

```yaml
# Include / Exclude file(s)
## include:/exclude: options only apply to the 'source/' folder
include:
exclude:
ignore:
```

| Setting   | Description                                                  |
| :-------- | :----------------------------------------------------------- |
| `include` | Hexo ignores hidden files and folders by default, but files listed here will still be processed by Hexo |
| `exclude` | Files listed here will be ignored by Hexo                    |
| `ignore`  | Ignore files/folders                                         |

### Extension Section

```yaml

```

| Setting  | Description                                        |
| :------- | :------------------------------------------------- |
| `theme`  | Theme name; set to `false` to disable theming      |
| `deploy` | Deployment settings                                |

### Update 2021-08-16

Due to GitHub's policy changes, logging in with a username/password over HTTPS is no longer supported, so the `deploy` configuration must be updated to the following:

```yaml
# Deployment
## Docs: https://hexo.io/docs/one-command-deployment
deploy:
  type: git
  repo: https://<token>@github.com/Kiwi0093/Kiwi0093.github.io
  branch: master
```

Note that with this setting, `hexo d -g` no longer prompts for a username/password, but if this token ever leaks it can be a serious security issue. The simplest mitigation is to make the entire repo private to reduce exposure.

> [!info] Updated 2026-11-27
> GitHub has completely deprecated HTTPS password authentication, and storing a Personal Access Token in plaintext inside `_config.yml` (`https://<token>@github.com/...`) still poses a credential leak risk. Modern practice is to use an SSH deploy key (`git@github.com:...`), a system credential manager, or GitHub Actions with the built-in `GITHUB_TOKEN` to automatically deploy to GitHub Pages.

## Hexo Usage

```bash
#清除建立好的資料
hexo clean
#建立靜態網頁
hexo g
#啟動Local Server
hexo s
#Deploy到Server上
hexo d
```

### Pages to Create Manually Right After Initializing Hexo

- Add a categories main page: `hexo new page categories`

- Add a tags main page: `hexo new page tags`

  Edit `source/tags/index.md`:

  ```yaml
  ---
  type: "tags"
  ---
  ```

### Using Other `config.yml` Files with Hexo

```bash
# 使用自訂的 'custom.yml' 取代預設的 '_config.yml'
$ hexo server --config custom.yml

# 使用多個配置檔, 有衝突時優先使用 'custom2.json'
$ hexo server --config custom.yml,custom2.json
```

When this error message pops up, the solution is as follows:

```yaml
# /under/your/web/_config.yml
---------------------------------------------------------------------------------------------------------------------------------
....
html_minifier:  
  collapseBooleanAttributes: true
  collapseWhitespace: true
  # Ignore '<!-- more -->' https://hexo.io/docs/tag-plugins#Post-Excerpt
  #ignoreCustomComments: [ !!js/regexp /^\s*more/]		#把這行Mark掉就好了
  removeComments: true
  removeEmptyAttributes: true
  removeScriptTypeAttributes: true
  removeStyleLinkTypeAttributes: true
  minifyJS: true
  minifyCSS: true
...
```

> [!info] Updated 2026-11-27
> This error was mainly caused by Hexo upgrading to `js-yaml` v4, which removed support for the unsafe `!!js/regexp` YAML tag by default (newer versions of Hexo / NexT have removed that syntax).
