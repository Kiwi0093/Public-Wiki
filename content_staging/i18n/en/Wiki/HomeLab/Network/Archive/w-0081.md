## Preface

The NexT theme is a very beautiful blog theme/style and is very simple to install. You can install it directly using `npm`.

## Installation

There are two installation methods on the [NexT Theme Official Website](https://github.com/next-theme/hexo-theme-next):

+ Install directly via `npm` (requires Hexo version 5.0 or above)

  ```bash
  # Inside the Hexo directory
  npm install hexo-theme-next
  ```

  After installation, directly modify the `theme` section in the Hexo directory's `_config.yml` to use it:

  ```yaml
  theme: next
  ```

+ <span style="color:#e06c75"><del>Clone the entire theme directly into Hexo's theme directory using Git commands</del></span> Since V8, `npm` installation is essentially used.

  ```bash
  # Inside the Hexo directory
  git clone https://github.com/next-theme/hexo-theme-next themes/next
  ```

  After installation, you still need to modify the Hexo directory's `_config.yml`:

  ```yaml
  theme: next
  ```

## Configuration

### Theme Setting

Copy the Theme's `_config.yml` as `_config.[Theme_name].yml` (e.g., `_config.next.yml`).

For detailed instructions, refer to the [Official Documentation](https://theme-next.js.org/docs/getting-started/configuration.html).

Basically, you only need to modify the following main parameters:

### Choosing Scheme

```yaml
# ---------------------------------------------------------------
# Scheme Settings
# ---------------------------------------------------------------

# Schemes
#scheme: Muse
scheme: Mist
#scheme: Pisces
#scheme: Gemini

# Dark Mode
darkmode: true
```

There are four schemes to choose from, with examples available on the official website: [Muse](https://theme-next.js.org/muse/), [Mist](https://theme-next.js.org/mist/), [Pisces](https://theme-next.js.org/pisces/), [Gemini](https://theme-next.js.org/). You can choose one and modify the configuration to enable it.

Additionally, NexT now natively supports Dark Mode. It is `false` by default; changing it to `true` enables dark mode.

#### Manual Toggle for Dark Mode

##### References

[Clay's Technical Blog](https://www.techgrow.cn/posts/abf4aee1.html)

#### Configuration Method

##### Install Plug-in

```bash
$ npm install hexo-next-darkmode --save
```

##### Configuration

```bash
#_config.next.yml
---------------------------------------------------------------------------------------------------------------------------------
# disable default Darkmode
darkmode: false
# add below

# Darkmode JS
# For more information: https://github.com/rqh656418510/hexo-next-darkmode, https://github.com/sandoche/Darkmode.js
darkmode_js:
  enable: true
  bottom: '64px' # default: '32px'
  right: 'unset' # default: '32px'
  left: '32px' # default: 'unset'
  time: '0.5s' # default: '0.3s'
  mixColor: 'transparent' # default: '#fff'
  backgroundColor: 'transparent' # default: '#fff'
  buttonColorDark: '#100f2c' # default: '#100f2c'
  buttonColorLight: '#fff' # default: '#fff'
  isActivated: false # default false
  saveInCookies: true # default: true
  label: '🌓' # default: ''
  autoMatchOsTheme: true # default: true
  libUrl: # Set custom library cdn url for Darkmode.js
```

* `isActivated: true`: Use Dark Mode by default; recommended to pair with `saveInCookies: false`, `autoMatchOsTheme: false`.

## Menu

```yaml
# ---------------------------------------------------------------
# Menu Settings
# ---------------------------------------------------------------

menu:
  home: / || fa fa-home
  #about: /about/ || fa fa-user
  tags: /tags/ || fa fa-tags
  categories: /categories/ || fa fa-th
  archives: /archives/ || fa fa-archive
  #schedule: /schedule/ || fa fa-calendar
  #sitemap: /sitemap.xml || fa fa-sitemap
  #commonweal: /404/ || fa fa-heartbeat
  wiki: https://kiwi0093.github.io/Wiki-site/ || fa fa-sitemap

# Enable / Disable menu icons / item badges.
menu_settings:
  icons: true
  badges: false
```

Editing this section can easily create a menu within the blog framework. The official documentation also introduces hierarchical menu syntax, as follows:

```yaml
menu:
  home: / || fa fa-home
  archives: /archives/ || fa fa-archive
  Docs:
    default: /docs/ || fa fa-book
    Getting Started:
      default: /getting-started/ || fa fa-flag
      Installation: /installation.html || fa fa-download
      Configuration: /configuration.html || fa fa-wrench
    Third Party Services:
      default: /third-party-services/ || fa fa-puzzle-piece
      Math Equations: /math-equations.html || fa fa-square-root-alt
      Comment Systems: /comments.html || fa fa-comment-alt
```

For other detailed settings, refer to the official documentation.

## Comment Functionality

After trying around, I ultimately chose to use self-hosted Isso instead of <span style="color:#e06c75"><del>Disqus+DisqusJS</del></span>.

### <span style="color:#e06c75"><del>References</del></span>

* [Laoqingcai](https://laoqingcai.com/)
* [DisqusJS Github](https://github.com/SukkaW/DisqusJS)

### <span style="color:#e06c75"><del>Applying for a Disqus Account</del></span>

<span style="color:#e06c75"><del>Apply for this on the official website. After applying, remember to set up the API as well (refer to the approach in [DisqusJS Github](https://github.com/SukkaW/DisqusJS))</del></span>

### <span style="color:#e06c75"><del>Configuration File</del></span>

```bash
#_config.next.yml
---------------------------------------------------------------------------------------------------------------------------------
# Disqus
disqus:
  enable: true
  shortname: ${your_shortname}
  count: true

# DisqusJS
# Alternative Disqus - Render comment component using Disqus API.
# Demo: https://suka.js.org/DisqusJS/
# For more information: https://github.com/SukkaW/DisqusJS
disqusjs:
  enable: true
  # API Endpoint of Disqus API (https://disqus.com/api/).
  # Leave api empty if you are able to connect to Disqus API. Otherwise you need a reverse proxy for it.
  # For example:
  # api: https://disqus.skk.moe/disqus/
  api:
  apikey: ${Your_API_KEY} # Register new application from https://disqus.com/api/applications/
  shortname: ${your_shortname} # See: https://disqus.com/admin/settings/general/
```

<span style="color:#e06c75"><del>Once done, run `hexo clean` and `hexo d -g`</del></span>
