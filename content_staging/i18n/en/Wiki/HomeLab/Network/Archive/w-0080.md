# Hexo Plugin Installation, Updates, and Common Configuration

> <img src='https://img.shields.io/badge/Status-Obsolete-red?style=for-the-badge&labelWidth=100' height='38' />

## Plugin Installation Methods

Hexo Plugin Official Website: [https://hexo.io/plugins/](https://hexo.io/plugins/)

### Basic Commands

```bash
# Install
npm install <plugin> --save
# Uninstall
npm uninstall <plugin> --save
# Update plugins & framework (under Hexo Dir)
npm update
```

### Additional Commands

First, install `npm-check-updates`:

```bash
# Manjaro Environment
pacman -S npm-check-updates
```

Useful commands:

```bash
# Check which packages are outdated
npm outdated

# Check for the latest packages
npm-check-updates
# Update package.json
ncu -u
# Update packages
npm install
```

Additionally, when `git clone` is used to fetch the entire blog (including `package.json`), you do not need to re-run installation commands:

```bash
# Update the entire node_modules according to package.json
npm update
```

> [!info] Updated 2026-11-27
> The historical commands above contain several errors and outdated syntax; they are retained for archival reference:
> 1. The package name should be `npm-check-updates` (with a trailing `s`), and since it is typically not included in official Arch/Manjaro repositories, it should be installed via `npm install -g npm-check-updates`.
> 2. The npm subcommand to check for outdated packages is `npm outdated` (misspelled as `npm outdate` in the original text).
> 3. When restoring a project from `git clone` without an existing `node_modules`, you should run `npm install` (or `npm ci`) to install dependencies based on `package.json` / `package-lock.json`, rather than `npm update`.

## Related Configuration

#### Render-markdown-it-plus Section

```yaml
markdown_it_plus:
    highlight: true
    html: true
    xhtmlOut: true
    breaks: true
    langPrefix:
    linkify: true
    typographer:
    quotes: “”‘’
    pre_class: highlight
```

#### Deployment Section

```yaml
deploy:
  type: git
  repo: https://github.com/<Username>/<username>.github.io
  branch: <branch_name>
```

#### Hexo-html-minifier

```yaml
html_minifier:  
  collapseBooleanAttributes: true
  collapseWhitespace: true
  # Ignore '<!-- more -->' https://hexo.io/docs/tag-plugins#Post-Excerpt
  ignoreCustomComments: [ !!js/regexp /^\s*more/]
  removeComments: true
  removeEmptyAttributes: true
  removeScriptTypeAttributes: true
  removeStyleLinkTypeAttributes: true
  minifyJS: true
  minifyCSS: true
```
