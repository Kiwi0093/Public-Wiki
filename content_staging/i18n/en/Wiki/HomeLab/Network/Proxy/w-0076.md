### Three-Domain Configuration Comparison Table

| Independent Domain Plan | External Port | Traefik Routing Tier | TLS Certificate Handler | 3X-UI Internal Listen Port | Internal Protocol | CDN Proxy Status |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **`panel.yourdomain.com`** | `443` | Layer 7 HTTP | Traefik (Let's Encrypt) | `2053` | Plain HTTP | Grey Cloud (DNS Only) or Orange Cloud |
| **`reality.yourdomain.com`** | `443` | Layer 4 TCP | **No Decryption Passthrough** (Xray handles it) | **`44300`** | VLESS-Reality | **Strict Grey Cloud (DNS Only)** |
| **`cdn.yourdomain.com`** | `443` | Layer 7 HTTP/WS | Traefik (Let's Encrypt) | **`44301`** | Plain WebSocket (Cleartext) | **Orange Cloud Enabled (Proxied)** |

## 2. DNS Resolution and Critical Cloudflare Configuration

Add three A records pointing to the VPS public IP in your domain registrar (using Cloudflare as an example):

```text
panel.yourdomain.com   A   <VPS_IP>   DNS Only (or Proxied with Full SSL)
reality.yourdomain.com A   <VPS_IP>   DNS Only (Must disable orange cloud, otherwise TCP native handshake breaks)
cdn.yourdomain.com     A   <VPS_IP>   Proxied  (Enable orange cloud to hide real IP)
```

### Cloudflare Console Checklist

- **SSL/TLS Mode**: Switch to **Full** or **Full (Strict)** (prevents Cloudflare from returning 520/521 errors when connecting to Traefik port 443).
- **Network**: Ensure **WebSockets** is enabled.

## 3. Docker Compose Deployment Configuration

Configure in `/opt/3x-ui/docker-compose.yml`, attaching 3X-ui to the external bridge network `proxy-network` where Traefik resides:

```yaml
services:
  3x-ui:
    image: ghcr.io/mhsanaei/3x-ui:latest
    container_name: 3x-ui
    restart: unless-stopped
    environment:
      - XRAY_VMESS_AEAD_FORCED=false
    volumes:
      - /opt/3x-ui/db:/etc/x-ui
      - /opt/3x-ui/cert:/root/cert
    networks:
      - proxy-network
    labels:
      - "traefik.enable=true"

      # =========================================================================
      # 1. 3X-UI Web Panel (Independent domain panel.yourdomain.com -> Internal 2053)
      # =========================================================================
      - "traefik.http.routers.xui-panel.rule=Host(`panel.yourdomain.com`)"
      - "traefik.http.routers.xui-panel.entrypoints=websecure"
      - "traefik.http.routers.xui-panel.tls=true"
      - "traefik.http.routers.xui-panel.tls.certresolver=myresolver"
      - "traefik.http.services.xui-panel.loadbalancer.server.port=2053"

      # =========================================================================
      # 2. VLESS-Reality Direct Connection (Independent domain reality.yourdomain.com -> Internal 44300)
      # =========================================================================
      # Key: HostSNI matches connection name; passthrough=true prevents Traefik from decrypting
      - "traefik.tcp.routers.xui-reality.rule=HostSNI(`reality.yourdomain.com`)"
      - "traefik.tcp.routers.xui-reality.entrypoints=websecure"
      - "traefik.tcp.routers.xui-reality.tls.passthrough=true"
      - "traefik.tcp.services.xui-reality.loadbalancer.server.port=44300"

      # =========================================================================
      # 3. VLESS-WS + CDN Rescue (Independent domain cdn.yourdomain.com -> Internal 44301)
      # =========================================================================
      # Traefik handles TLS termination, forwarding cleartext WebSocket traffic to Xray
      - "traefik.http.routers.xui-ws.rule=Host(`cdn.yourdomain.com`)"
      - "traefik.http.routers.xui-ws.entrypoints=websecure"
      - "traefik.http.routers.xui-ws.tls=true"
      - "traefik.http.routers.xui-ws.tls.certresolver=myresolver"
      - "traefik.http.services.xui-ws.loadbalancer.server.port=44301"

networks:
  proxy-network:
    external: true
```

Start the container:

```bash
docker compose -f /opt/3x-ui/docker-compose.yml up -d
```

## 4. 3X-UI Inbounds Configuration Details

Open `https://panel.yourdomain.com` in a browser to log in to the panel, navigate to **Inbounds**, and add two nodes:

### 4.1 Inbound 1: VLESS-Reality (Internal Port 44300)

- **Remark**: `Reality-Direct-44300`
- **Protocol**: `vless`
- **Listening IP**: `0.0.0.0`
- **Port**: **`44300`** (Matches the port declared in the Compose TCP service)
- **Flow**: `xtls-rprx-vision`
- **Security**: `Reality`
- **uTLS**: `chrome`
- **Dest**: <span style="color:#e06c75"><del>`reality.yourdomain.com:443` (or `swdist.apple.com:443`)</del></span> *(Updated 2026-11-27: The Reality `Dest` / newer 3X-UI `Target` must not point to `reality.yourdomain.com:443` which routes back to the local `44300` port via the same `HostSNI`, otherwise unvalidated probe connections will form a loop; point it to an external real website supporting TLS 1.3 and HTTP/2 such as `swdist.apple.com:443`, or another local independent virtual host HTTPS port)*
- **Server Names (SNI)**: **`reality.yourdomain.com`** (**Must match the `HostSNI` in Traefik Labels exactly**)
- **Private Key / Public Key**: Click generate and record the public key
- **Short IDs**: Click generate

### 4.2 Inbound 2: VLESS-WS + CDN Rescue (Internal Port 44301)

- **Remark**: `WS-CDN-Rescue-44301`
- **Protocol**: `vless`
- **Listening IP**: `0.0.0.0`
- **Port**: **`44301`** (Matches the port declared in the Compose HTTP service)
- **Network**: `ws`
- **Path**: `/ray-ws-stream`
- **Security**: **`none`** (**Key: Traefik boundary has already performed TLS certificate decryption; enabling TLS inside the container is strictly prohibited**)

## 5. Client Configuration Reference

Regardless of whether the internal listening port is `44300` or `44301`, **the server port filled in by external clients is always standard `443`**.

### 5.1 Reality Client Settings (Direct High-Speed Connection)

```text
vless://<UUID>@reality.yourdomain.com:443?type=tcp&security=reality&pbk=<PUBLIC_KEY>&fp=chrome&sni=reality.yourdomain.com&sid=<SHORT_ID>&flow=xtls-rprx-vision#Reality-Direct
```

- **Address**: `reality.yourdomain.com`
- **Port**: `443`
- **Security**: `reality`
- **SNI**: `reality.yourdomain.com`
- **Flow**: `xtls-rprx-vision`

### 5.2 WS + CDN Client Settings (Anti-Blocking Rescue)

```text
vless://<UUID>@cdn.yourdomain.com:443?type=ws&security=tls&sni=cdn.yourdomain.com&path=%2Fray-ws-stream#CDN-Rescue
```

- **Address**: `cdn.yourdomain.com` (Can be replaced with Cloudflare preferred IPs if blocked)
- **Port**: `443`
- **Security**: `tls`
- **SNI / Host**: `cdn.yourdomain.com`
- **Path**: `/ray-ws-stream`

## 6. Troubleshooting Core Verifications

1. **Reality Handshake Timeout**:
   - Check if Cloudflare mistakenly enabled the orange cloud for `reality.yourdomain.com`; this domain **must remain grey cloud (DNS Only)**.
   - Verify that the SNI entered on the client matches the `HostSNI` in the Traefik Label exactly.
2. **WS Node Throws 502 Bad Gateway**:
   - Check whether the `Security` setting for the 3X-UI backend port 44301 inbound was mistakenly set to `tls`. Since the outer layer already has Traefik terminating certificates, the container side must be set to `none`.
3. **Panel Fails to Login**:
   - Check Traefik's ACME certificate application status and confirm that `panel.yourdomain.com` has successfully issued a Let's Encrypt certificate.
