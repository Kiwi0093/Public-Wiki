## 1. Shell Special Control Characters Quick Reference

| **Symbol** | **Name** | **Core Function & Behavior Analysis** | **Practical Command Examples** |
| :--- | :--- | :--- | :--- |
| **`$`** | Variable Value Symbol | Extracts the value corresponding to a variable, also used for environment variables or special variables (e.g., `$?`, `$$`). | `echo $USER`<br />`echo $?` _(Returns the exit status code of the previous command)_ |
| **`#`** | Comment Symbol | A `#` at the beginning of a line or after a space denotes a comment; the shell directly ignores everything after it. | `# This is a comment`<br />`mkdir app # Create a directory` |
| **`\`** | Escape Character | Removes the special semantics of the immediately following single character, restoring it to literal text; or acts as a line continuation character. | `echo \$PATH`<br />`rm -f filename\ with\ space.txt` |
| **`\|`** | Pipe Symbol | Redirects the "standard output (stdout)" of the left-hand command into the "standard input (stdin)" of the right-hand command. | `cat access.log \| grep "404" \| wc -l` |
| **`;`** | Command Separator | Executes multiple commands sequentially in a row (the next command executes regardless of whether the previous one succeeded). | `cd /opt; ls -la; df -h` |
| **`&`** | Background Execution Job Control | Moves a command to run in the background, immediately releasing the current terminal prompt. | `python3 server.py &`<br />`nohup ./backup.sh &` |
| **`/`** | Directory Path Separator | The directory level separator in the Linux virtual file system tree structure; a single `/` at the very top represents the root directory. | `/var/log/docker.log` |
| **`>`** | Output Redirection (Overwrite) | Redirects and writes standard output to the specified file, **overwriting it directly if the file already exists**. | `echo "token=123" > config.env` |
| **`>>`** | Output Redirection (Append) | Redirects and writes standard output to the specified file, **appending to the very end of the file** without overwriting. | `date >> /var/log/deploy.log` |
| **`<`** | Input Redirection | Uses the contents of the specified file as the standard input for a command (replacing keyboard input). | `mysql -u root -p db < backup.sql` |
| **`<<`** | Here-Document | Defines a multi-line text block as standard input until a custom delimiter tag (such as `EOF`) is encountered. | `cat << 'EOF' > test.txt`<br />`hello`<br />`EOF` |
| **`' '`** | Single Quotes (Strong Quoting) | **Completely maintains literal characters**, internal variables and escape sequences are not evaluated at all. | `echo '$USER'` _(Output: `$USER`)_ |
| **`" "`** | Double Quotes (Weak Quoting) | Preserves most text, but **allows evaluation of variables (`$`), command substitution (`$()`), and escapes (`\`)**. | `echo "Hi, $USER"` _(Output: `Hi, admin`)_ |
| **`$( )`** or **`` ` ` ``** | Command Substitution | Evaluates the commands inside the brackets first and substitutes their execution result (stdout) back into the original location. | `TODAY=$(date +%F)`<br />`tar -czvf "backup-$TODAY.tar.gz" /data` |
| **`( )`** | Subshell | Executes a group of commands in an independently forked sub-process; directory changes or variable assignments inside it will not pollute the outer layer. | `(cd /tmp && rm -rf *)` _(Current shell remains in the original directory after execution completes)_ |
| **`{ }`** | Command Group / Expansion | 1. Groups and executes commands in the current shell (requires spaces and semicolons).<br />2. Batch expands sequences/strings. | `{ echo 1; echo 2; }`<br />`mkdir -p /opt/{app,db,config}`<br />`cp app.yml{,.bak}` |

## 2. Wildcards / Globbing Quick Reference

Wildcards are primarily expanded by the shell before executing commands (Pathname Expansion), used for **matching filenames and paths**:

| **Wildcard** | **Matching Rule** | **Precise Behavior Analysis** | **Practical Examples** |
| :--- | :--- | :--- | :--- |
| **`*`** | 0 to arbitrary characters | Matches strings of arbitrary length in a filename (excluding leading dots `.` for hidden files). | `ls *.log` _(Lists all files ending in .log)_<br />`rm -rf /tmp/cache*` |
| **`?`** | **Exactly 1 arbitrary character** | Must and can only match 1 character (cannot be 0, cannot exceed 1). | `ls file?.txt` _(Matches `file1.txt`, `fileA.txt`, but does not match `file10.txt`)_ |
| **`[abc]`** | Any character within the set | Matches any single character listed inside the brackets. | `ls report_[abc].pdf` _(Matches `report_a.pdf`, `report_b.pdf`, etc.)_ |
| **`[0-9]`** | Any character within an encoded range | Matches any character within a continuous ASCII / character encoding range. | `ls img_[0-9].png` _(Matches single digits 0 through 9)_<br />`ls [a-z]*.md` _(Files starting with a lowercase letter)_ |
| **`[!abc]`**<br />_(or `[^abc]`)_ | Excluded set (Negation) | Any single character **excluding** those specified inside the brackets. | `ls file[!0-9].txt` _(Matches `fileA.txt`, excludes `file1.txt`)_ |

## 3. Essential Tips for Senior Engineers: Confusing Boundary Details

### 3.1 Logical Operators `&&` and `||`

- **`cmd1 && cmd2` (AND)**: Executes `cmd2` only if `cmd1` **executes successfully (Exit Code = 0)**.
- **`cmd1 || cmd2` (OR)**: Executes `cmd2` only if `cmd1` **fails to execute (Exit Code ≠ 0)**.
- **Classic Example**:

    ```bash
    docker compose pull && docker compose up -d || echo "Deployment update failed!"
    ```

### 3.2 Differences Between Wildcards and Regular Expressions (Regex)

- **Shell Wildcards (Globbing)**: Evaluated by the shell, mapped directly to **filenames** on disk.
    - `*` represents "arbitrary string".
    - `?` represents "single character".
- **Regular Expressions (Regex)**: Evaluated by specific tools (`grep`, `sed`, `awk`, `python`), used for matching **text content**.
    - `*` represents "the preceding character repeated 0 or more times".
    - `.` represents "any single character".
    - `.*` The combination of both equals the wildcard `*`.

### 3.3 High-Efficiency Usage of Brace Expansion

Generate batch continuous strings or files directly without writing loops:

```bash
# 1. Batch create directories numbered 1 through 10
mkdir -p node_{01..10}

# 2. Quickly create a backup file (equivalent to cp nginx.conf nginx.conf.bak)
cp nginx.conf{,.bak}

# 3. Two-dimensional matrix expansion (generates a1, a2, b1, b2)
echo {a,b}{1,2}
```
