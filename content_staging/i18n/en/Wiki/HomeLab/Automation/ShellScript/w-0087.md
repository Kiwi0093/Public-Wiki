## 1. Core Implementation: Robust Arrow Key Menu Function (`select_option`)

This improved version adopts **Relative Cursor Movement**, avoiding the `\E[6n` coordinate queries that are vulnerable to terminal scrolling. It is much more stable and compatible with major terminal environments (macOS Terminal, Windows Terminal, iTerm2, Linux Console).

```bash
#!/usr/bin/env bash

# ==============================================================================
# Interactive Arrow Key Menu Function
# Arguments: List of options (strings or array expansion)
# Returns: Index value of the option selected by the user (0, 1, 2...)
# ==============================================================================
select_option() {
    local -a options=("$@")
    local num_options=${#options[@]}

    # Return error directly if no options are passed
    [[ $num_options -eq 0 ]] && return 1

    # ANSI control code definitions
    local ESC=$'\033'
    local CURSOR_OFF="${ESC}[?25l"
    local CURSOR_ON="${ESC}[?25h"
    local CLEAR_LINE="${ESC}[2K"
    local TEXT_INVERT="${ESC}[7m"
    local TEXT_RESET="${ESC}[0m"

    # Trap interrupt signals (Ctrl+C) to ensure terminal cursor and attributes are properly restored
    trap 'printf "${CURSOR_ON}"; stty echo; printf "\n"; exit 130' INT TERM

    # Disable cursor blinking
    printf "%s" "${CURSOR_OFF}"

    local selected=0

    # Initial render of the list
    local i
    for ((i=0; i<num_options; i++)); do
        if [[ $i -eq $selected ]]; then
            printf "  ${TEXT_INVERT} > %s ${TEXT_RESET}\n" "${options[i]}"
        else
            printf "    %s \n" "${options[i]}"
        fi
    done

    # Keyboard input listening loop
    while true; do
        # Read 3 characters to capture arrow key escape sequences (\033[A, \033[B)
        IFS= read -rsn1 key
        if [[ $key == "${ESC}" ]]; then
            read -rsn2 -t 0.1 rest
            key="${key}${rest}"
        fi

        case "$key" in
            "${ESC}[A"|k|K) # Up arrow (or Vim key 'k')
                ((selected--))
                [[ $selected -lt 0 ]] && selected=$((num_options - 1))
                ;;
            "${ESC}[B"|j|J) # Down arrow (or Vim key 'j')
                ((selected++))
                [[ $selected -ge $num_options ]] && selected=0
                ;;
            "") # Enter key to confirm selection
                break
                ;;
        esac

        # Move cursor back up to the start of the list and overwrite the entire menu
        printf "${ESC}[%dA" "${num_options}"
        for ((i=0; i<num_options; i++)); do
            printf "${CLEAR_LINE}"
            if [[ $i -eq $selected ]]; then
                printf "  ${TEXT_INVERT} > %s ${TEXT_RESET}\n" "${options[i]}"
            else
                printf "    %s \n" "${options[i]}"
            fi
        done
    done

    # Restore cursor and environment
    printf "%s" "${CURSOR_ON}"

    # Output the selected index value
    echo "$selected"
}
```

## 2. Basic Usage Example: Fixed Option Menu

```bash
echo "Use [Up/Down Arrow Keys] to move, [Enter] to confirm selection:"
echo

MENU_ITEMS=("Start all Docker containers" "Stop Nextcloud service" "Execute database backup" "Exit script")

# Call function and capture the selected index
CHOICE_INDEX=$(select_option "${MENU_ITEMS[@]}")

echo "----------------------------------------"
echo "Selected item index: ${CHOICE_INDEX}"
echo "Selected item content: ${MENU_ITEMS[CHOICE_INDEX]}"

case "${CHOICE_INDEX}" in
    0) echo "Starting containers..." ;;
    1) echo "Stopping service..." ;;
    2) echo "Starting backup execution..." ;;
    3) echo "Exiting program."; exit 0 ;;
esac
```

> [!info] Updated 2026-11-27
> The `select_option` above outputs both the menu screen `printf` and the final index `echo "$selected"` to standard output (`stdout`). If used with command substitution like `CHOICE_INDEX=$(select_option ...)`, the menu's ANSI control codes will be intercepted together by the variable and fail to display properly in the terminal. In practice, please redirect the menu drawing and cursor control inside the function to `>&2` (`stderr`) or `/dev/tty`, keeping only the final `echo "$selected"` output to `stdout`; additionally, it is recommended to use `trap '...' RETURN` or restore `INT TERM` signal handling before the function ends to avoid overriding the main script's `trap`.

## 3. Solving Dynamic Directory Blank Line Pain Points: Combining Dynamic Arrays

The original notes used `DATE1=$(ls ... | sed -n '1p')` to hardcode 5 variables, which produced blank lines when actual directories were fewer than 5.

**Standard Solution**: Use `mapfile` (or `readarray`) to **dynamically read existing directories into an array**, and dynamically append an `Exit` option:

```bash
#!/usr/bin/env bash

BACKUP_DIR="/storage/backup"

# 1. Check if directory exists
if [[ ! -d "${BACKUP_DIR}" ]]; then
    echo "Error: Backup directory ${BACKUP_DIR} does not exist!" >&2
    exit 1
fi

# 2. Dynamically read all "subdirectory names" under the directory into an array
# Method A: Use find (most precise, excludes regular files)
mapfile -t BACKUP_LIST < <(find "${BACKUP_DIR}" -mindepth 1 -maxdepth 1 -type d -exec basename {} \; | sort -r)

# 3. Check if there is backup data
if [[ ${#BACKUP_LIST[@]} -eq 0 ]]; then
    echo "Notice: No backup directories available at present."
    exit 0
fi

# 4. Dynamically append the "Exit" option at the end of the array
BACKUP_LIST+=("Cancel and Exit")

# 5. Render menu
echo "Please select the backup snapshot directory to restore:"
SELECTED_IDX=$(select_option "${BACKUP_LIST[@]}")

# 6. Determine user selection
LAST_IDX=$((${#BACKUP_LIST[@]} - 1))

if [[ "${SELECTED_IDX}" -eq "${LAST_IDX}" ]]; then
    echo "User cancelled operation, script exiting safely."
    exit 0
fi

CHOSEN_BACKUP="${BACKUP_LIST[SELECTED_IDX]}"
echo "--------------------------------------------------"
echo "Successfully selected backup directory: ${CHOSEN_BACKUP}"
echo "Full path: ${BACKUP_DIR}/${CHOSEN_BACKUP}"
echo "Preparing restoration process..."
```

## 4. Key Technical Details and Pitfall Quick Reference

| **Item** | **Traditional Hardcoded Approach** | **Dynamic Array Best Practice** |
| :--- | :--- | :--- |
| **Directory Capture** | `DATE1=$(ls \| sed -n '1p')` | `mapfile -t LIST < <(find ... -type d)` |
| **Blank Options** | Blank lines inevitably appear when directories are fewer than declared variables | Renders as many lines as there are items in the array, zero blank lines |
| **Exception Exit (Ctrl+C)** | Cursor disappears, terminal does not echo text | Add `trap` to restore `stty echo` and cursor upon interruption |
| **Cursor Overwrite Mechanism** | `\E[6n` relies on terminal absolute coordinates (prone to scrolling misprints) | `\033[NA` relative line rollback paired with `\033[2K` to clear entire line |
