## 5. Cross-Service Integration Guide (Internal Communication Configuration Standards)

Because all services (except qBittorrent which is attached to Gluetun) are within the same `media_net` custom network, **containers can communicate directly via DNS using service names**, eliminating the need to fill in host IPs or set up additional static IPs.

### 5.1 Prowlarr Integrating FlareSolverr

- In Prowlarr, go to **Settings** -> **Indexers** -> click to add **FlareSolverr**.

- For **Host**, enter: `http://flaresolverr:8191`

- For **Tag**, enter: `flaresolverr` (subsequently, when encountering sites protected by Cloudflare, simply tag this Tag on that Indexer).

### 5.2 Prowlarr Automatic Synchronization to Sonarr / Radarr / Lidarr

Go to **Settings** -> **Apps** -> click add:

- **Sonarr**:

  - **Prowlarr Server**: `http://prowlarr:9696`

  - **Sonarr Server**: `http://sonarr:8989`

  - **ApiKey**: Enter Sonarr's API Key.

- **Radarr** and **Lidarr** follow the same pattern, entering the corresponding container names and ports. After saving, all torrent sites in Prowlarr will be automatically synchronized into each application.

### 5.3 Sonarr / Radarr Integrating qBittorrent

Go to **Settings** -> **Download Clients** -> select **qBittorrent**:

- **Host**: Enter `gluetun` (**Note: Because qBittorrent uses Gluetun's network, its exposed hostname is `gluetun`**).

- **Port**: `4080`

- **Username / Password**: Enter the account and password set in qBittorrent WebUI.

- **Category**:

  - For Sonarr, enter: `tv`

  - For Radarr, enter: `movies`

  - For Lidarr, enter: `music`

### 5.4 Bazarr Integrating Sonarr and Radarr

- Go to **Settings** -> **Sonarr**:
  - **Address**: `sonarr`, **Port**: `8989`, enter API Key.
- Go to **Settings** -> **Radarr**:
  - **Address**: `radarr`, **Port**: `7878`, enter API Key.

## 6. Common Troubleshooting

### 6.1 qBittorrent Default Password Cannot Login (Invalid Credentials)

For security, new LinuxServer qBittorrent containers no longer use the default `adminadmin`:

- **Initial Password Retrieval**: Run `docker compose logs qbittorrent`, and the logs will print a one-time randomly generated administrator password.

- **Manually Reset Password**: If login fails, you can run the following command to reset it to `adminadmin`:

  ```bash
  # Stop qbittorrent
  docker compose stop qbittorrent
  # Edit /opt/appdata/qbittorrent/qBittorrent/qBittorrent.conf
  # Delete the WebUI\Password_PBKDF2 setting line and restart the container
  docker compose start qbittorrent
  ```

### 6.2 Lidarr Cannot Add Music, Cannot Find Artists (MusicBrainz Error)

- **Cause**: If old configurations placed Lidarr inside Gluetun, requests often timed out due to VPN nodes being blocked by the MusicBrainz API or Gluetun DNS anomalies.

- **Remedy**: Follow the Rev 2.0 architecture, ensuring Lidarr connects to the standard Docker network using local broadband externally, which resolves artist metadata query freezes.

### 6.3 Files Repeatedly Occupying Space, Hard Drive Rapidly Filling Up

- **Cause**: Sonarr / Radarr download directory mapping is inconsistent with qBittorrent, causing the hardlink mechanism to fail and fall back to "Copy".

- **Remedy**: Check the volume settings of each container, confirm that mapped paths are globally identical root directories (e.g., all using `/data:/data`), and confirm that **Use Hardlinks instead of Copy** is enabled in Sonarr/Radarr's **Settings -> Media Management**.
