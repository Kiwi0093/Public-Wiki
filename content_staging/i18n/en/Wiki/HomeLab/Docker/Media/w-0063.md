## 1. Architecture Overview and Modern Evolution

![](https://raw.githubusercontent.com/kiwi0093/graph/master/img/pasted-1789707582359-rxf342.png)

### Key Updates and Selection Highlights (Breaking Changes & Best Practices)

1. **Image Name Update**:
   The official Docker image has been officially renamed to `ghcr.io/suwayomi/suwayomi-server:stable` (the old `ghcr.io/suwayomi/tachidesk` still has an alias, but full adoption of the new standard is recommended to receive the latest fixes).
2. **Network Integration with FlareSolverr**:
   Many manga sites (such as CopyManga, DM5, etc.) employ Cloudflare's 5-second shield anti-scraping mechanism. By sharing a custom Docker bridge network, Suwayomi can directly call FlareSolverr via `http://flaresolverr:8191` to bypass verification without exposing FlareSolverr to the host or external routing.
3. **Storage Planning and CBZ Packaging**:
   Default downloads are stored as scattered image directories; enabling the environment variable `DOWNLOAD_AS_CBZ=true` automatically compresses each chapter into a single `.cbz` file, significantly reducing the consumption of host inodes by small files and making it convenient to directly import into professional comic servers like Kavita or Komga later.

## 2. Docker Compose Complete Deployment Template

This configuration integrates **Suwayomi** and **FlareSolverr**, while setting log rotation limits and common environment parameters:

```yaml
services:
  suwayomi:
    image: ghcr.io/suwayomi/suwayomi-server:stable
    container_name: suwayomi
    restart: unless-stopped
    ports:
      # Direct WebUI default port; can be commented out if exclusively using Traefik / NPM
      - "4567:4567"
    environment:
      - TZ=Asia/Taipei
      # Core: Enable FlareSolverr to penetrate Cloudflare
      - FLARESOLVERR_ENABLED=true
      - FLARESOLVERR_URL=http://flaresolverr:8191
      # Automated download and update settings
      - AUTO_DOWNLOAD_CHAPTERS=true           # Automatically download when new chapters are detected
      - DOWNLOAD_AS_CBZ=true                  # Automatically package downloaded chapters into .cbz archives
      - UPDATE_INTERVAL=12                    # Check for global updates automatically every 12 hours
      # Built-in authentication (strongly recommended to enable if exposed to public network)
      - AUTH_MODE=none                        # Can be changed to basic_auth or ui_login
      # - AUTH_USERNAME=admin
      # - AUTH_PASSWORD=your_super_password
    volumes:
      # Persistent directory for manga database, extensions, and downloaded chapters
      - /opt/suwayomi/data:/home/suwayomi/.local/share/Tachidesk
    depends_on:
      - flaresolverr
    logging:
      driver: "json-file"
      options:
        max-size: "50m"
        max-file: "3"
    networks:
      - manga_net
      # To connect to Traefik / NPM, add the proxy network
      - proxy-network

  flaresolverr:
    image: ghcr.io/flaresolverr/flaresolverr:latest
    container_name: flaresolverr
    restart: unless-stopped
    environment:
      - LOG_LEVEL=info
      - TZ=Asia/Taipei
    # Internal communication only, no need to expose external port
    networks:
      - manga_net

networks:
  manga_net:
    name: manga_net
    driver: bridge
  proxy-network:
    external: true
```

## 3. Reverse Proxy Integration (Traefik v3 / NPM)

### 3.1 Via Traefik v3 (Labels Declaration)

When using Traefik v3, add Labels directly to the `suwayomi` service block (ports `4567:4567` can be uncommented/removed):

```yaml
    labels:
      - "traefik.enable=true"
      - "traefik.http.routers.suwayomi.rule=Host(`manga.example.com`)"
      - "traefik.http.routers.suwayomi.entrypoints=websecure"
      - "traefik.http.routers.suwayomi.tls=true"
      - "traefik.http.routers.suwayomi.tls.certresolver=myresolver"
      - "traefik.http.services.suwayomi.loadbalancer.server.port=4567"
```

### 3.2 Via Nginx Proxy Manager (NPM)

1. Ensure Suwayomi and NPM are on the same external Docker network (e.g., `proxy-network`).
2. Add a Proxy Host in the NPM UI:
   - **Domain Names**: `manga.example.com`
   - **Forward Hostname / IP**: `suwayomi` (enter the container name directly)
   - **Forward Port**: `4567`
   - Check **Websockets Support** (required for real-time reader progress synchronization and terminal logs).

## 4. Extension Repositories and Source Settings

Since the original Tachiyomi official extension repository was shut down, the community is currently maintained primarily by open-source teams such as **Keiyoushi**. The new version of Suwayomi requires manually adding third-party extension repositories before searching and installing sources.

### Step 1: Add Extension Repositories

1. Open `http://<Host_IP>:4567` in your browser to enter the Suwayomi Web interface.
2. Click the left menu **Settings** -> **Browse** -> **Extension repositories**.
3. Paste the mainstream community **Keiyoushi** repository index URL:

   ```
   https://raw.githubusercontent.com/keiyoushi/extensions/repo/index.min.json
   ```

4. Click **Add** to save.

### Step 2: Search and Install Manga Sources

1. Click **Browse** on the left -> Switch to **Extensions** at the top.
2. Check **Chinese (ZH)** and other preferred languages in the top-right language filter.
3. Search for common sources and click **Install**:
   - **CopyManga**: Comprehensive collection and great image quality.
   - **Manhuagui**: Classic, long-standing source.
   - **Bilibili / Tencent official sources** (some non-paid chapters readable).
4. After installation, switch to the **Sources** tab to search for manga and click **Add to Library**.

## 5. Recommended Cross-Platform Clients and Connection Setup

Suwayomi can be viewed not only in web browsers but also supports various client connections:

| **Client Name** | **Supported Platforms** | **Core Features** | **Connection Method** |
|---|---|---|---|
| **Native WebUI** | Any device with a browser (PC / Phone / E-reader) | Zero-install, out-of-the-box, supports webhooks and keyboard page-turning shortcuts | Open URL directly |
| **Sorayomi** (Tachidesk-Sorayomi) | **Android / Windows / Linux / macOS** | Official dedicated client built with Flutter, minimalist UI, smooth fluidity, offline caching support | Set Server URL: `https://manga.example.com` |
| **Mihon (formerly Tachiyomi)** | **Android** | Install the `Tachidesk` extension to directly integrate Suwayomi as a single source into mobile Mihon | Install extension and enter Server IP |
| **Tachimanga** | **iOS / iPadOS** | Excellent reader on iOS compatible with the Tachiyomi extension protocol | Integrate via external sources or use as a standalone reader |

## 6. Common Troubleshooting

### 6.1 Sources fail to load, keep spinning, or throw `HTTP 403 / Cloudflare` errors

- **Cause**: The source site has enabled strict Cloudflare shields or Turnstile verification.
- **Action**:
  1. Check whether `FLARESOLVERR_ENABLED=true` and `FLARESOLVERR_URL` are correctly defined in Compose.
  2. Enter the Suwayomi container to test communication with FlareSolverr:

     ```bash
     docker compose exec suwayomi curl -I http://flaresolverr:8191
     ```

  3. If a specific source (like CopyManga) frequently times out, enter its extension settings page to switch to a different API mirror site.

### 6.2 Host Disk Space Exhausted

- **Cause**: Tracking multiple serialized manga with auto-download enabled, accumulating dozens of GBs quickly from tens of high-res images per chapter.
- **Action**:
  1. Set `DOWNLOAD_AS_CBZ=true` to reduce scattered directory files.
  2. Configure **Download limit** in WebUI "Settings -> Downloads", e.g., limiting cache to the first 5 unread chapters and auto-clearing read caches.

### 6.3 Directory Permission Error (Permission Denied)

- **Cause**: The container runs internally as the `suwayomi` user by default. If the mounted host directory was created by root, it will cause database write failures or image download blocks.
- **Action**:
  Relax or correct the ownership of the mounted directory on the host:

  ```bash
  sudo chown -R 1000:1000 /opt/suwayomi/data
  sudo chmod -R 755 /opt/suwayomi/data
  ```

## 7. Maintenance and Data Backup

All bookshelf records, chapter progress, installed extensions, and downloaded files in Suwayomi are centralized in a single directory:

```bash
# 1. Back up data directory (excluding downloads significantly reduces backup size)
sudo tar --exclude='downloads' -czvf /opt/backups/suwayomi-config-$(date +%F).tar.gz -C /opt/suwayomi data

# 2. Full backup (including downloaded manga)
sudo tar -czvf /opt/backups/suwayomi-full-$(date +%F).tar.gz -C /opt/suwayomi data

# 3. Restoration method
sudo tar -xzvf /opt/backups/suwayomi-*.tar.gz -C /opt/suwayomi/
docker compose restart suwayomi
```
