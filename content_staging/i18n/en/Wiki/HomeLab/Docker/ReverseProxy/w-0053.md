## 1. Core Concepts and Architecture Analysis

Traefik's data flow and configuration logic consist of three core abstractions:

```text
[External Request (Client)]
        │ (Port 80 / 443)
        ▼
   [EntryPoints]   ─── (web / websecure: Defines listened protocols and ports)
        │
        ▼
    [Routers]      ─── (Resolves requests based on Rules such as Host(`app.example.com`))
        │
        ├─► [Middlewares] ─── (Intermediate processing: HTTP to HTTPS, Basic Auth, Rate Limit, etc.)
        │
        ▼
    [Services]      ─── (Forwards to corresponding container IP and internal Port)
        │
        ▼
  [Backend Container (Backend App)]
```

- **Static Configuration**: Defines global infrastructure (EntryPoints, Providers, ACME certificate resolvers). Loaded at startup, supports CLI arguments (`command:`) or static configuration files (`traefik.yml`).

- **Dynamic Configuration**: Defines routing rules (Routers, Services, Middlewares), dynamically injected by Providers (Docker Labels in this case). When containers restart or change, Traefik itself does not need to be restarted.

- **SSL Certificate Storage (`acme.json`)**: Traefik integrates the ACME client, and all private keys and certificates issued by Let's Encrypt are stored in a single JSON file. **The permissions of this file must be strictly restricted to `600`**, otherwise Traefik will refuse to load it for security reasons.

## 2. Traefik v3 Core Configuration (Docker Compose)

Compared to the older v2.5, **Traefik v3** brings several modern and simplified improvements:

1. **EntryPoints Native Support for HTTP to HTTPS**: No longer requires declaring tedious `hostregexp` catch-all and RedirectScheme middlewares in Routers; enabling `redirections` directly on the EntryPoint applies it globally.

2. **ACME Challenge Mutual Exclusivity**: You cannot enable `httpChallenge` and `tlsChallenge` simultaneously; choose one (generally `tlsChallenge` is recommended, using port 443 for maximum simplicity).

3. **Security Hardening**: The Dashboard by default must be protected with explicit middleware validation (such as BasicAuth) and is not allowed to be exposed unprotected.

### Step 1: Create Dedicated Network and Mount Directories

To prevent interference between project containers and the Traefik network, create a global shared Docker Bridge network:

```bash
# Create Traefik dedicated shared external network
docker network create proxy-network

# Create directory for certificates and initialize acme.json permissions (must be 600)
mkdir -p /opt/traefik/letsencrypt
touch /opt/traefik/letsencrypt/acme.json
chmod 600 /opt/traefik/letsencrypt/acme.json

# Create BasicAuth username and password (using admin / secret123 as an example, requires apache2-utils or openssl/htpasswd)
# Format: username:hashed_password (Note: $ must be written as $$ in YAML to avoid escaping)
echo $(htpasswd -nb admin secret123)
# Output example: admin:$apr1$xyz123... -> When writing to label, convert to admin:$$apr1$$xyz123...
```

### Step 2: Traefik Main `docker-compose.yml` (v3 Configuration)

Configure in `/opt/traefik/docker-compose.yml`:

```yaml
services:
  traefik:
    image: traefik:v3.1
    container_name: traefik
    restart: unless-stopped
    security_opt:
      - no-new-privileges:true
    networks:
      - proxy-network
    ports:
      - "80:80"
      - "443:443"
      # To directly access debug/dashboard, port 8080 can be opened; in production, accessing via internal Router and closing port 8080 mapping is recommended
      # - "8080:8080"
    volumes:
      - /etc/localtime:/etc/localtime:ro
      - /var/run/docker.sock:/var/run/docker.sock:ro
      - /opt/traefik/letsencrypt/acme.json:/letsencrypt/acme.json
    command:
      #### 1. API and Dashboard ####
      - --api.dashboard=true
      - --api.insecure=false

      #### 2. Logging and Debug Records ####
      - --log.level=INFO
      - --accesslog=true

      #### 3. Docker Provider Settings ####
      - --providers.docker=true
      - --providers.docker.exposedbydefault=false # Do not expose by default, must explicitly add label to proxy
      - --providers.docker.network=proxy-network # Explicitly specify default communication network

      #### 4. EntryPoints (Port Definitions) ####
      # HTTP (Port 80) - v3 natively built-in global redirect to HTTPS
      - --entrypoints.web.address=:80
      - --entrypoints.web.http.redirections.entrypoint.to=websecure
      - --entrypoints.web.http.redirections.entrypoint.scheme=https
      - --entrypoints.web.http.redirections.entrypoint.permanent=true

      # HTTPS (Port 443)
      - --entrypoints.websecure.address=:443

      #### 5. Certificate Resolver (Let's Encrypt ACME) ####
      # Use TLS-ALPN-01 challenge (verifies directly on port 443, no extra file directory opening required)
      - --certificatesresolvers.myresolver.acme.tlschallenge=true
      - --certificatesresolvers.myresolver.acme.email=your-email@example.com
      - --certificatesresolvers.myresolver.acme.storage=/letsencrypt/acme.json
    labels:
      - "traefik.enable=true"

      # --- Dashboard Routing Configuration (HTTPS) ---
      - "traefik.http.routers.traefik-dashboard.rule=Host(`traefik.example.com`)"
      - "traefik.http.routers.traefik-dashboard.entrypoints=websecure"
      - "traefik.http.routers.traefik-dashboard.service=api@internal"
      - "traefik.http.routers.traefik-dashboard.tls=true"
      - "traefik.http.routers.traefik-dashboard.tls.certresolver=myresolver"

      # --- Dashboard Security Defense (BasicAuth Middleware) ---
      - "traefik.http.routers.traefik-dashboard.middlewares=auth"
      # Note: $ symbols in password strings must be escaped as $$ in compose
      - "traefik.http.middlewares.auth.basicauth.users=admin:$$apr1$$xyz123...YourHash..."

networks:
  proxy-network:
    external: true
```

## 3. Configuration Specification for Upstream Containers

When deploying any web service, **there is no need to declare `ports` to expose to the Host**, you only need to meet two conditions:

1. Join the shared external network `proxy-network`.

2. Annotate `labels` to tell Traefik the service's domain name and target Port.

### Syntax Structure Logic

The hierarchical rules of Traefik Labels follow:

```
traefik.<protocol>.<component_type>.<custom_identifier>.<specific_parameter>=<value>
```

### Example: Deploying Whoami Test Service and Independent Applications (e.g., V2ray / Web App)

```yaml
services:
  whoami:
    image: traefik/whoami
    container_name: test-whoami
    restart: unless-stopped
    networks:
      - proxy-network
    # No need to write ports: ["80:80"], container resides entirely in internal network, enhancing host security
    labels:
      # 1. Enable Traefik awareness
      - "traefik.enable=true"

      # 2. Define HTTPS Router rule
      - "traefik.http.routers.whoami.rule=Host(`whoami.example.com`)"
      - "traefik.http.routers.whoami.entrypoints=websecure"

      # 3. Enable automatic TLS certificate request
      - "traefik.http.routers.whoami.tls=true"
      - "traefik.http.routers.whoami.tls.certresolver=myresolver"

      # 4. Specify internal forwarding Port (mandatory if the image exposes multiple ports or uses a custom port)
      - "traefik.http.services.whoami.loadbalancer.server.port=80"

networks:
  proxy-network:
    external: true
```

## 4. Common Useful Middlewares Configuration Examples

In Docker Labels, various security and filtering middlewares can be mounted in front of applications:

### 4.1 Security Headers / HSTS

```yaml
labels:
  - "traefik.http.middlewares.sec-headers.headers.sslredirect=true"
  - "traefik.http.middlewares.sec-headers.headers.stsseconds=31536000"
  - "traefik.http.middlewares.sec-headers.headers.browserxssfilter=true"
  - "traefik.http.middlewares.sec-headers.headers.contenttypenosniff=true"
  - "traefik.http.routers.myapp.middlewares=sec-headers"
```

> [!info] Updated 2026-11-27
> `headers.sslredirect` was officially removed in **Traefik v3**; keeping this parameter in v3 configuration files will cause startup failure. For HTTP to HTTPS redirection, please instead use the EntryPoints global redirection configuration demonstrated in Section 2 (`--entrypoints.web.http.redirections.entrypoint.*`) or use the `redirectScheme` middleware. Additionally, `browserxssfilter` (`X-XSS-Protection`) has also been deprecated by modern browsers.

### 4.2 Rate Limit

Prevent brute-force attacks on APIs or login endpoints:

```yaml
labels:
  # Average 100 requests per second, maximum burst of 50
  - "traefik.http.middlewares.my-ratelimit.ratelimit.average=100"
  - "traefik.http.middlewares.my-ratelimit.ratelimit.burst=50"
  - "traefik.http.routers.myapp.middlewares=my-ratelimit"
```

### 4.3 StripPrefix

Automatically strip `/api` when forwarding `example.com/api/*` to the container:

```yaml
labels:
  - "traefik.http.routers.myapi.rule=Host(`example.com`) && PathPrefix(`/api`)"
  - "traefik.http.middlewares.api-strip.stripprefix.prefixes=/api"
  - "traefik.http.routers.myapi.middlewares=api-strip"
```

## 5. Important Architecture Principles and Troubleshooting

### 5.1 SSL Offloading

- Backend containers (such as Nextcloud, WordPress, V2ray, etc.) **should run HTTP internally**, and self-signing certificates or running HTTPS inside containers is strictly prohibited.

- All certificate encryption and decryption are completed at the Traefik boundary (SSL Offloading). Communication between containers and Traefik runs over pure HTTP via internal Docker networks, greatly reducing computing overhead and avoiding certificate conflicts.

### 5.2 Certificate Request Failure Troubleshooting Focus

| **Common Error Phenomenon**                                       | **Root Cause**                     | **Troubleshooting Action**                                                                                             |
| ----------------------------------------------------------------- | ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `permissions of /letsencrypt/acme.json are too open`              | File permissions are not 600       | Run `chmod 600 /opt/traefik/letsencrypt/acme.json` and restart Traefik.                                                  |
| `Cannot obtain certificates: 403 / 400 urn:ietf:params:acme:error`| External Port 80/443 closed or DNS not effective | Verify external firewall/router maps 80/443 to the host, and Public DNS A record fully points to the local public IP.  |
| `Bad Gateway (502)`                                               | Traefik cannot reach backend container | 1. Check if backend container joined `proxy-network`.<br />2. Check if `loadbalancer.server.port` matches container internal listening port. |
| Forwarding confusion when container has multiple ports            | Image defines multiple EXPOSE ports| Must explicitly lock down via `traefik.http.services.<name>.loadbalancer.server.port=<port>`.                           |
