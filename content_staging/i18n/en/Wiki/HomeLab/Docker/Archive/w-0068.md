> [!info] Updated 2026-11-27
> This article is an archival note on early experimentation with Node-RED. Below is a comparison with modern Docker and Node-RED:
> 1. Docker Compose v2 has dropped the top-level `version: '3.3'` field, and recommends using `compose.yaml` and the `docker compose` command.
> 2. It is not recommended to run `chmod 777` directly on mounted directories; a safer practice is to run `chown -R 1000:1000 /var/lib/docker/volumes/node-red` to align with the container's default UID 1000.
> 3. The correct filename for the Node-RED configuration file is the lowercase plural `settings.js` (not `Setting.js`); the built-in command in newer official containers is `node-red admin hash-pw`, eliminating the need to install global `node-red-admin`.

# Installation

Actually, the installation part is the easiest part...

## docker-compose.yml

```bash
version: '3.3'
services:
  node-red:
    image: nodered/node-red
    container_name: node-red
#    ports:
#      - '1880:1880'
    environment:
      - TZ=Asia/Taipei
    volumes:
      - /var/lib/docker/volumes/node-red:/data
    restart: unless-stopped
    labels:
      traefik.enable: true
      traefik.http.routers.node-red.rule: Host(`<Domain>`)
      traefik.http.routers.node-red.tls: true
      traefik.http.routers.node-red.tls.certresolver: myresolver
      traefik.http.services.node-red.loadbalancer.server.port: 1880

networks:
  default:
    external: true
    name: traefik_backend
```

### Key Points

* Volumes Permissions
  Because the default UID permission is 1000, creating the container as root will cause it to fail to run properly due to write permission issues. The solution is to define it as root or directly change the directory permissions (I changed them to 777).
* `settings.js` (written as `Setting.js` in the original text) Configuration
  Since I use Traefik to handle SSL, only the login permission part needs attention.
  Basically, enabling login settings is very easy:

  ```bash
  adminAuth: {
   type: "credentials",
   users: [
       {
           username: "admin",
           password: "$2a$08$zZWtXTja0fB1pzD4sHCMyOCMYz2Z6dNbM6tl8sJogENOMcxWV9DN.",
           permissions: "*"
       },
       {
           username: "george",
           password: "$2b$08$wuAqPiKJlVN27eF5qJp.RuQYuy6ZYONW7a/UWYxDTtwKFCdB8F19y",
           permissions: "read"
       }
   ]
  }
  ```

  Just change the `username` part to your preferred ID,
  then via `docker exec -it <NodeRed_container_name> bash`
  run `node-red-admin hash-pw`,
  and it will let you enter your desired password and generate the hash string. Copy and paste it into the configuration above.
