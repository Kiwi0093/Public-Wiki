## Basic Setting

Users who do not plan to use a GUI basically only need this section:

### Archlinux-keyring

```bash
# Initialize keyring
sudo pacman-key --init
# Populate keyring
sudo pacman-key --populate
# Apply and update (if mirrorlist adjustment is needed, modify /etc/pacman.d/mirrorlist first)
sudo pacman -Syu
```

This step is essential for ArchWSL; otherwise, nothing can be installed without a proper keyring.

### `/etc/wsl.conf`

```bash
# Use systemd
[boot]
systemd=true
# Set default user
[users]
default=<username>
```

> [!info] Updated 2026-11-27
> The `[users]` section name in the configuration above is incorrect and will be ignored by WSL; the correct syntax requires the singular `[user]`:
> ```ini
> [user]
> default=<username>
> ```

### yay

```bash
# Requires go, git, and base-devel to be installed first
cd <what ever you like>
git clone https://aur.archlinux.org/yay.git
cd yay
makepkg -si
```

`yay` is currently the most convenient tool for installing from the `AUR`, so it is strongly recommended.

## GUI (WSLg)

### X server

References:

- [Bug of WSL Preview - Empty /mnt/wslg/.X11-unix & /tmp/.X11-unix Directory](https://github.com/microsoft/wslg/issues/782)

```bash
# Check Display is :0
echo $DISPLAY
:0

# Check if /mnt/wslg/.X11-unix exists, and whether /tmp/.X11-unix -> /mnt/wslg/.X11-unix
ls -la /mnt/wslg
ls -la /tmp

# If /mnt/wslg/.X11-unix exists but is not linked to /tmp/.X11-unix
sudo rm -r /tmp/.X11-unix
ln -s /mnt/wslg/.X11-unix /tmp/.X11-unix
```

Then test whether your GUI software runs correctly. If it runs, proceed to the next step; if not... check the documentation...

```bash
/etc/tmpfiles.d/wslg.conf
---

# TYPE    PATH        Mode    UID    GID Age    Argument
L+    /tmp/.X11-unix    -        -    -    -    /mnt/wslg/.X11unix
```

> [!info] Updated 2026-11-27
> 1. `sudo` should be added when creating the symbolic link manually (`sudo ln -s /mnt/wslg/.X11-unix /tmp/.X11-unix`).
> 2. The target path in the last column of the `wslg.conf` snippet above is missing a hyphen; it should be `/mnt/wslg/.X11-unix` (instead of `.X11unix`). Also, the file content should not include the leading filename and `---`.
> 3. Newer WSL/WSLg versions have fixed this issue where `systemd` startup cleans up `/tmp/.X11-unix`, so manually creating this configuration file is generally no longer necessary.

Run `wsl --shutdown` in PowerShell and re-enter WSL.

### dolphin + breeze (Optional)

Dolphin is the KDE file manager (similar to Windows Explorer). Installing Dolphin alone results in missing icons, so installing the KDE theme `breeze` is required for proper appearance:

```bash
yay -S breeze dolphin
```

### Remmina + freerdp (Optional)

This is a very useful RDP client, but Remmina is only a frontend interface; `freerdp` must be installed to RDP into other RDP servers:

```bash
yay -S remmina freerdp
```

### Brave (Optional)

A browser is necessary... otherwise what is the GUI for:

```bash
yay -S brave-bin
```
