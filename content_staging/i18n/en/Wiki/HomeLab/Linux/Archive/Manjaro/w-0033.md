> [!info] Updated 2026-11-27
> This article is an early historical archive note regarding Manjaro Linux:
> - `pacman-mirrors` is a tool exclusive to Manjaro and is not applicable to standard Arch Linux. If you are on an Arch Linux environment, please use `reflector` instead (e.g., `sudo reflector --country Taiwan,Japan --latest 10 --sort rate --save /etc/pacman.d/mirrorlist`).
> - The `<County Name>` in the original command should be `<Country Name>`; after changing mirrors in Manjaro, it is also recommended to run `sudo pacman -Syyu` to forcibly synchronize the package repository index.

##### Select By Country

```Bash
sudo pacman-mirrors --country <Country Name>
```

This command checks the speeds of servers in the selected country list to build a mirror-list.

##### Select By Speed

```Bash
sudo pacman-mirrors --fasttrack <count>
```
