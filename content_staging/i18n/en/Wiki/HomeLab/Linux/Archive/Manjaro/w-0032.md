## Tweak

### Environment

* Manjaro KDE 21.0.7

#### Changing the Mirror-list

Where Manjaro is more user-friendly than Arch is that it provides a tool to directly update the Mirror-list without having to edit configuration files manually (though some people might find editing the file cleaner, simpler, and faster).

```bash
# 依照國別選擇
sudo pacman-mirrors --country <Country Name>
# 依照速度選擇
sudo pacman-mirrors --fasttrack <數量>
```

Previously when I was living in China, I used to set the Mirror-list to China to save a lot of hassle caused by the Great Firewall.

Now that I'm back in Taiwan, I'll likely switch to selecting mirrors by speed—or even skip selecting one altogether.

#### Installing the VGA Driver

```bash
sudo mhwd -a [pci or usb connection] [free or nonfree drivers] 0300
```

This will automatically detect, download, and install the driver.

#### VM Guest OS

##### Installer ISO Fails to Boot

This happened in version 21.0.6, likely because Manjaro adjusted the VM Guest drivers, causing the default `driver=free` boot option to fail to initialize display output and get stuck at `mhwd` detection.

The workaround was to manually edit the GRUB boot parameter in the boot menu:

```bash
# 將原先預設參數中的
driver=free
# 改成
driver=mesa
```

Switching to `mesa` for display output allowed it to boot, though this issue was fixed again by version 21.0.7.

##### Unable to Resize Resolution or Auto-Fit Screen After Entering the VM

This is a quirk in version 21 right now (earlier versions like 20 or 19 didn't have this issue; not sure if future releases will fix it), caused by missing VM display drivers.

```bash
# 安裝需要的 Package
sudo pacman -S open-vm-tools virtualbox-guest-utils
```

While this isn't an official fix—since the `video-virtualmachine` driver still couldn't be installed (every attempt failed; maybe a later release will fix it)—

at least the display started resizing properly, so I just left it at that.

##### yakuake

This is a drop-down console. I used to remove it, but recently I found it actually very handy, so I kept it. There's nothing special about the settings—basically just:

* Adjust the drop-down width; I prefer 90%
* Adjust the drop-down height; I prefer 80%
* Set the shell to `/bin/zsh` (you can also just use `chsh` to change your default shell)

When you want to use it, just press `F12` (it can probably be rebound to another key, though I personally find `F12` pretty good). When you focus another GUI app, it automatically retracts out of the way.

As long as you haven't exited, pressing `F12` again brings you right back to your running console, which is super convenient.

## Application

Since I only use Manjaro as a desktop, I don't use anything overly fancy.

### Networking

#### Browser

Right now I use Brave as my primary browser, and since Brave is in the AUR, it needs to be installed with `yay`:

```bash
yay -S brave-bin
```

Make sure to use `brave-bin`, otherwise waiting for it to compile will take forever.
That's it; I also usually remove Firefox since I don't use it.

#### FTP Client

```bash
yay -S filezilla
```

FileZilla also supports SFTP and `.ppk` files, making it quite convenient. However, nowadays everyone transfers files via web cloud services, so traditional FTP/SFTP is used less and less—you can skip installing it if you don't need it.

#### RDP

```bash
yay -S remmina freerdp
```

This lets you remotely control other Windows machines over RDP.

#### GitHub Desktop (Optional)

```bash
yay -S github-desktop
```

Although you can use git in the console, ~~sometimes a GUI is nicer to use~~ the CLI is still better to use.

#### Hexo (Optional)

```bash
yay -S nodejs npm
```

Since I basically only install Hexo for my own Blog/Wiki, if you just want to try it, pick any directory:

```bash
sudo npm install -g hexo-cli
```

And you're ready to get started.

> [!info] Updated 2026-11-27
> In practice, globally installing packages with `sudo npm install -g` is not recommended (as it easily causes permission issues); consider using a version manager such as NVM or fnm instead. Furthermore, this site has since migrated from Hexo to Docusaurus.
