Here we still use the universal `bash <(curl -L URL/script)` syntax to run it. Trying `curl -L URL/script | bash` resulted in issues with user prompts inside the script. I don't fully understand the technical details, but basically, try to avoid running shell scripts via pipes to prevent issues.

### Content Overview

The purpose of this script is to quickly port my active **Manjaro** environment to a newly installed machine or VM, reducing the repeated work of setting up and adjusting the development environment. This document will first outline what gets installed and generated, and the detailed script will be explained section by section below.

- **_Terminator_** :

  A console application supporting tabbed usage. I saw the terminal used in Garuda previously and it looked pretty nice; if I find other more intuitive ones, I will replace it.

- **_PowerLevel10k_** :

  This is basically a terminal customization tool. Since we use the terminal so often under Linux, why not make it look gorgeous and pleasing to the eye? Basically it's **powerlevel10k** combined with some Nerd Fonts, and sometimes **neofetch**.

- **_V2ray Series_** :

  Living behind the Great Firewall makes this a must-install program (though machines used only in the dorm might not need it since it's already handled at the gateway). It mainly installs **Qv2ray** and **V2ray** for GUI control.

  - Actually, if you want to be more nerdy, you could ditch the GUI and just run pure v2ray + `config.json` with `systemd`... but for a desktop environment, having a GUI feels more appropriate.

  However, several test runs showed that installing **Qv2ray** is a huge waste of time... and frequently errors out... If I lose patience after a few more tries, I might remove it (or make it optional!?).

- **_Rambox_** :

  As a person with friends (undoubtedly...), I still need some IM and Mail clients. Rambox currently works as a smooth unified interface (YES, it just integrates various web interfaces).

- **_Brave_** :

  Since I am not that fond of **Firefox**, I use **Brave** instead.

- **_Blog/Wiki Writing Suite_** :

  This includes **Typora** (my current favorite Markdown editor), **Git & GitHub Desktop** (I know CLI `git` should be enough, but GUI **GitHub Desktop** is actually very handy, especially for someone like me who isn't super fluent in `git` CLI commands...), plus **PicGo** which is needed for uploading images in **Typora**.

- **_PuTTY_** :

  To some degree, running the SSH client directly from the terminal is better than the Linux version of **PuTTY**, but `.ppk` keys cannot be used directly that way, and opening SSH Tunnels is more convenient with pre-configured **PuTTY**, so I always install it, though I probably only use it when connecting back home.

- **_Remmina_** :

  This actually requires **freerdp** to run RDP directly. I basically use this + SSH Tunnel to connect back to my home P2P Windows.

- **_FileZilla_** :

  This tool is mostly useless now because the need to perform **FTP/SFTP** transfers has decreased... but I still install it out of habit just in case.

- **_gnome-pie_** :

  This is a launcher, but it looks flashy so I like it now, and it's kept in the mandatory installation list.

- **_fcitx Series_** :

  As a non-native English speaker, I definitely need non-English input methods... so I generally use this to install **Chewing** and **Mozc** to handle my Chinese and Japanese typing needs...

- **_TeamViewer_** :

  Actually I don't use **TeamViewer** very often, I just habitually install it just in case.

- **_VMware Workstation Pro (optional)_** :

  I made this an option because some of my machines are already running inside VMs, so I don't play the "VM inside a VM" game...

- **_KDE Fun Widgets (optional)_** :

  This basically installs some widgets or boot animations... and might include multiple-boot themes later on...

## Conclusion

Although it started as a private script for myself, I still try to write it to be general (though somewhat pointless), and make things with strong personal taste optional.
