> [!tip]
> For reasons unknown, Manjaro 21 KDE exhibits the following two issues when installed inside VMware Workstation:
> * ~~Failure to boot using free drivers & non-free drivers~~ (Fixed in 21.0.7)
> * Missing VM display drivers after installation, leading to display issues.

# Boot from USB/ISO

Although the issue has been resolved, here is a record of the workaround used at the time:

```bash
# Enter the grub editor during boot and change:
driver=free to driver=mesa
```

That resolves it.

# Display Issue Fix

Essentially, it lacks the installation of `video-virtualmachine`, a driver compatible with both VMware and VirtualBox:

```
# First install the required packages
sudo pacman -S virtualbox-guest-utils open-vm-tools
sudo mhwd -i pci video-virtualmachine
sudo systemctl enable vmtoolsd.service
sudo systemctl start vmtoolsd.service
```

In theory, this should suffice.

> [!info] Updated 2026-11-27
> Manjaro 21 is an outdated version (the `driver=mesa` boot issue was fixed after 21.0.7). Additionally, in VMware VMs, you only need to install `open-vm-tools` (omitting `virtualbox-guest-utils`, which is strictly for VirtualBox) and enable `vmtoolsd.service` (along with `vmware-vmblock-fuse.service` if needed). Modern Linux/Manjaro kernels and Mesa already include built-in `vmwgfx` support, eliminating the need for the aforementioned legacy GRUB parameters or `mhwd` workarounds.
