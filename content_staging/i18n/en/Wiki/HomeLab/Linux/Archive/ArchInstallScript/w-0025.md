## Architecture Explanation

Since the installation logic of **_Arch Linux_** is as follows:

> First, perform operations on the HDD within the Live CD OS, then install the new Arch Linux system onto the HDD over the network. Next, chroot into the new system to perform initial configuration and bootloader setup using the new system's environment, and finally exit completely and reboot into the HDD, completing the installation of a new system.

Therefore, in the script design, all options executed after `arch-chroot` were structured as independent scripts, as illustrated in the architecture diagram below:
