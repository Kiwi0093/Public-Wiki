> This script documents an early personal automated deployment setup for an Arch Linux dual-NIC gateway. It is now unmaintained and superseded by the official `archinstall` tool. For modern Arch Linux environments, it is recommended to use `systemd-networkd` or `NetworkManager` instead of `netctl`, and `nftables` instead of legacy manual `iptables` scripts. #### Timezone and Hardware Clock Setup

```bash
#change Timezone to CTS(Taipei)
echo -e "${COLOR1}Please select your time zone\n1)Taipei\n2)Shanghai\n*)Whatever..I don't care\n${NC}"
while :
do
	read ZONE
	case $ZONE in
		1)
			echo -e "${COLOR1}Set Time Zone to Asia/Taipei${NC}"

			ln -sf /usr/share/zoneinfo/Asia/Shanghai /etc/localtime
			hwclock --systohc --utc
			break
			;;
		*)
			echo -e "${COLOR1}Nobody cares the local time!!${NC}"
			hwclock --systohc --utc
			break
			;;
	esac
done
echo -e "${COLOR2}Completed${NC}"
```

##### Naming NICs by MAC Address

```bash
#Set Mac Address
echo -e "${COLOR1}Define your NIC by Mac address${NC}"
echo -e "${COLOR1}Please input your EXT Mac Address:\n${NC}"
read OUTSIDE
echo 'SUBSYSTEM=="net", ACTION=="add", ATTR{address}=="'${OUTSIDE}'", NAME="EXT0"' > /etc/udev/rules.d/10-network.rules
echo -e "${COLOR1}Please input your INT Mac Address:\n${NC}"
read INSIDE
echo 'SUBSYSTEM=="net", ACTION=="add", ATTR{address}=="'${INSIDE}'", NAME="INT0"' >> /etc/udev/rules.d/10-network.rules
echo -e "${COLOR2}Completed${NC}"
```

* This configuration binds fixed **MAC addresses** to name the external and internal network interfaces **`EXT0`** and **`INT0`**, respectively.

##### Internal Static IP Setup

```bash
# Set INT network
echo -e "${COLOR1}Setting your INT0${NC}"
echo "Description='INT0 IP SETTING'" > /etc/netctl/INT0.service
echo "Interface=INT0" >> /etc/netctl/INT0.service
echo "Connection=ethernet" >> /etc/netctl/INT0.service
echo "IP=static" >> /etc/netctl/INT0.service
echo -e "${COLOR1}Please input your INT IP:\n${NC}"
read INT_IP
echo "Address=('${INT_IP}/24')" >> /etc/netctl/INT0.service
echo -e "${COLOR2}Enable INT0${NC}"
netctl enable INT0.service
echo -e "${COLOR2}Finished.${NC}"
```

* Please configure the IP within the `192.168.0.0/16` private subnet range.

> [!info] Updated 2026-11-27
> The original script writes to `/etc/sysctl/30-ipforward.conf`, which is an incorrect path; Arch Linux and `systemd-sysctl` read configuration files from `/etc/sysctl.d/30-ipforward.conf`.

##### iptables Setup and systemd

```bash
# iptable script
echo -e "${COLOR1}Create Iptable start script${NC}"
echo "#Natd" > /etc/iptables/iptable.sh
echo "iptables -t nat -A POSTROUTING -s 192.168/16 -j MASQUERADE" >> /etc/iptables/iptable.sh
chmod 750 /etc/iptables/iptable.sh
echo -e "${COLOR2}Finished.${NC}"

# systemd
echo -e "${COLOR1}Create Systemd Service${NC}"
echo "[Unit] > /etc/systemd/system/iptables.service
echo "Description=iptables rules >> /etc/systemd/system/iptables.service
echo " " >> /etc/systemd/system/iptables.service
echo "[Service]" >> /etc/systemd/system/iptables.service
echo "ExecStart=/bin/sh /etc/iptables/iptable.sh" >> /etc/systemd/system/iptables.service
echo " " >> /etc/systemd/system/iptables.service
echo "[Install]" >> /etc/systemd/system/iptables.service
echo "WantedBy=multi-user.target" >> /etc/systemd/system/iptables.service
systemctl enable iptables.service
echo -e "${COLOR2}Finished.${NC}"
```

> [!info] Updated 2026-11-27
> 1. In the original script, both `echo "[Unit]` and `echo "Description=iptables rules` are missing closing double quotes `"`, which causes syntax errors at runtime.
> 2. On modern Arch Linux, it is recommended to use `nftables` (with `nftables.service`) directly instead of a custom `iptables` shell script, and to replace `netctl` with `systemd-networkd` or `NetworkManager`.

#### Changing the root Password and Creating Another Account

```bash
#Root Password
echo -e "${COLOR1}設定你的root密碼${NC}"
passwd
chsh -s /bin/zsh
echo -e "${COLOR2}Completed${NC}"

#add User
echo -e "${COLOR1}Add user account:${NC}"
echo -n "${COLOR1}What ID you want:${NC}"
read YOURID
useradd -m -g root -s /bin/zsh ${YOURID}
passwd ${YOURID}
echo -e "${COLOR2}Completed${NC}"

echo -e "${COLOR1}Add $YOURID into sudo list${NC}"
pacman -Syu sudo
echo "${YOURID} ALL=(ALL) ALL" >> /etc/sudoers
echo -e "${COLOR2}Completed${NC}"
```

> [!info] Updated 2026-11-27
> `useradd -m -g root` sets the regular user's primary group to `root`, which is not recommended in practice; normally you should omit `-g root`, add the user to the `wheel` group with `-G wheel`, and enable `%wheel` permissions via `visudo` (or `/etc/sudoers.d/`).

#### Installing Packages

```bash
#install Tools
echo -e "${COLOR1}Install Packages${NC}"
echo -e "${COLOR1}screen${NC}"
pacman -Sy screen v2ray
echo -e "${COLOR2}Completed${NC}"
```

> [!info] Updated 2026-11-27
> Arch Linux does not support partial upgrades. When installing packages, you should use `pacman -Syu <packages>` (or perform a full system upgrade first and then run `pacman -S`), avoiding `pacman -Sy` to prevent dependency breakage.

#### Installing the Bootloader

```bash
#install Bootloader
echo -e "${COLOR1}Install grub Boot Loader into /dev/sda${NC}"
grub-install --target=i386-pc /dev/sda
grub-mkconfig -o /boot/grub/grub.cfg
echo -e "${COLOR2}Completed${NC}"
```

> [!info] Updated 2026-11-27
> `grub-install --target=i386-pc /dev/sda` only applies to legacy BIOS + MBR setups on `/dev/sda`; on modern UEFI systems, you must use `--target=x86_64-efi --efi-directory=/boot --bootloader-id=GRUB` (along with a GPT partition table and an EFI System Partition).

#### Syncing and Exiting Arch-chroot

```bash
#Finished install
sync
sync
sync
exit
```
