> [!info] Updated 2026-11-27
> This document covers a historical archived script. The following practices are outdated or considered anti-patterns in modern Arch Linux environments (the original script block below is preserved as-is for reference only):
> 1. **Installation Method**: Official media now includes `archinstall`; writing and using manual chroot installation scripts like this is no longer recommended.
> 2. **Package Management**: The snippet containing `pacman -Sy screen` represents a "partial upgrade" anti-pattern forbidden in Arch Linux; updates should be completed before installation or packages installed via `pacstrap`.
> 3. **Users & Permissions**: `useradd -m -g root -s /bin/zsh` sets the default group of a regular user to `root` without ensuring `zsh` is installed first; appending rules directly into `/etc/sudoers` lacks syntax checking. Modern best practices recommend `-G wheel` combined with `/etc/sudoers.d/` (with permissions `0440`) and `visudo -c`.
> 4. **Network & Bootloader**: `netctl` has been superseded by `systemd-networkd` / `NetworkManager`; `grub-install --target=i386-pc /dev/sda` applies only to legacy BIOS/MBR disks, whereas modern UEFI systems should use `--target=x86_64-efi` or `systemd-boot`.
> 5. **Discrepancy Between Sections**: The step-by-step breakdown installs `screen`, whereas the "Full Script" at the bottom installs `tmux`.

#### Setting Timezone and Hardware Clock

```bash
#change Timezone
echo -e "${COLOR1}Please select your time zone\n${NC}${COLOR_H1}1)Taipei\n2)Shanghai\n*)Whatever..I don't care\n${NC}"
while :
do
	read ZONE
	case $ZONE in
		1)
			echo -e "${COLOR1}Set Time Zone to Asia/Taipei${NC}"
			ln -sf /usr/share/zoneinfo/Asia/Taipei /etc/localtime
			hwclock --systohc --utc
			break
			;;
		2)
			echo -e "${COLOR1}Set Time Zone to Asia/Shanghai${NC}"
			ln -sf /usr/share/zoneinfo/Asia/Shanghai /etc/localtime
			hwclock --systohc --utc
			break
			;;
		*)
			echo -e "${COLOR1}Nobody cares the local time!!${NC}"
			hwclock --systohc --utc
			break
			;;
	esac
done
echo -e "${COLOR2}Completed${NC}"
```

#### Setting Locales and Ensuring Terminal Uses UTF-8 (Otherwise Tmux Fails to Function Properly)

```bash
#locale-gen to add en_US & zh_TW
echo -e "${COLOR1}Setting local file${NC}"
echo "en_US.UTF-8 UTF-8" >> /etc/locale.gen
echo "zh_TW.UTF-8 UTF-8" >> /etc/locale.gen
echo -e "${COLOR1}Generate locale.conf${NC}"
locale-gen
echo -e "${COLOR1}Setting locale.conf${NC}"
echo LANG=en_US.UTF-8 > /etc/locale.conf
export LANG=en_US.UTF-8
echo -e "${COLOR2}Completed${NC}"
```

#### Network Configuration

```bash
#Hostname
echo -e "${COLOR1}Please input your hostname\n${NC}"
read HOSTNAME
echo ${HOSTNAME} > /etc/hostname
echo "127.0.0.1 localhost ${HOSTNAME}" >> /etc/hosts
echo -e "${COLOR2}Completed${NC}"

echo -e "${COLOR1}Define your NIC by Mac address${NC}"
echo -e "${COLOR1}Please input your MAC Address(need to be lowcase):\n${NC}"
read OUTSIDE
echo 'SUBSYSTEM=="net", ACTION=="add", ATTR{address}=="'${OUTSIDE}'", NAME="EXT0"' > /etc/udev/rules.d/10-network.rules
echo -e "${COLOR2}Completed${NC}"

echo -e "${COLOR1}Define your IP for EXT0:${NC}"
echo "Description='EXT0 IP SETTING'" > /etc/netctl/EXT0.service
echo "Interface=EXT0" >> /etc/netctl/EXT0.service
echo "Connection=ethernet" >> /etc/netctl/EXT0.service
echo "IP=static" >> /etc/netctl/EXT0.service
echo -n "${COLOR1}Please input your IP address:\n${NC}"
read EXT_IP
echo "Address=('${EXT_IP}/24')" >> /etc/netctl/EXT0.service
echo -n "${COLOR1}Please input your Gateway IP address:\n${NC}"
read GATE_IP
echo "Gateway='${GATE_IP}'" >> /etc/netctl/EXT0.service
echo -n "${COLOR1}Please input your DNS IP address:\n${NC}"
read DNS_IP
echo "DNS=('${DNS_IP}')" >> /etc/netctl/EXT0.service
echo -e "${COLOR2}Enable EXT0${NC}"
netctl enable EXT0.service
echo -e "${COLOR2}Finished.${NC}"
```

* This configuration utilizes a fixed **_MAC Address_** to name the **_NIC Interface_** as **_EXT0_**.
* Make sure the MAC Address is entered in **lowercase**, otherwise it will fail.
* This configuration relies on `netctl`.

#### Changing Root Password and Creating Regular User Accounts

```bash
#Root Password
echo -e "${COLOR1}Set your root password${NC}"
passwd
chsh -s /bin/zsh
echo -e "${COLOR2}Completed${NC}"

#add User
echo -e "${COLOR1}Add user account:${NC}"
echo -n "${COLOR1}What ID you want:${NC}"
read YOURID
useradd -m -g root -s /bin/zsh ${YOURID}
passwd ${YOURID}
echo -e "${COLOR2}Completed${NC}"

echo -e "${COLOR1}Add $YOURID into sudo list${NC}"
pacman -Syu sudo
echo "${YOURID} ALL=(ALL) ALL" >> /etc/sudoers
echo -e "${COLOR2}Completed${NC}"
```

#### Installing Packages

```bash
#install Tools
echo -e "${COLOR1}Install Packages${NC}"
echo -e "${COLOR1}screen${NC}"
pacman -Sy screen
echo -e "${COLOR2}Completed${NC}"
```

Since this is Simple Arch, only `screen` is installed by default (the full script at the bottom uses `tmux` instead).

#### Installing Bootloader

```bash
#install Bootloader
echo -e "${COLOR1}Install grub Boot Loader into /dev/sda${NC}"
grub-install --target=i386-pc /dev/sda
grub-mkconfig -o /boot/grub/grub.cfg
echo -e "${COLOR2}Completed${NC}"
```

#### Syncing and Exiting arch-chroot

```bash
#Finished install
sync
sync
sync
exit
```
