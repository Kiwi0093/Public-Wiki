# Preface

In the world of Linux, my favorite systems are Arch-based, but installing Arch Linux is not very user-friendly, so I decided to write my own installation script.

## Scope of Application

This is a general-purpose **Arch Linux** installation script designed for **_VMware ESXi_**, with the following basic default conditions:

* ~~Intel CPU~~ (The script includes AMD-ucode)
* 1~2GB RAM
* 20GB+ HDD space

This version performs the following optional items:

*Update 2021/06/15: Since I moved back to Taiwan and no longer use it, Ver.K has been deleted and this entry is no longer maintained.*

* Simple Arch Linux
  - Basic Arch Linux, installing only essential system tools
  - Single NIC with static MAC Address & Static IP
  - Copy zsh configuration from Live CD
* V2Ray Server
  - Arch Linux with V2Ray without V2Ray configuration
  - Single NIC with static MAC Address & Static IP
  - Copy zsh configuration from Live CD
* V2Ray Client Gateway
  - Arch Linux with V2Ray without V2Ray configuration
  - No iptables configuration
  - Dual NIC with static MAC Address
  - External network optional PPPoE or Static IP
  - Internal network with static IP
  - Copy zsh configuration from Live CD
* ~~V2Ray Client Gateway Kiwi private version~~
  - ~~Arch Linux with V2Ray with Kiwi's existing settings (encrypted, private use)~~
  - ~~Directly apply Kiwi's existing iptables (encrypted, private use)~~
  - ~~Dual NIC with static MAC Address~~
  - ~~External network optional PPPoE or Static IP~~
  - ~~Internal network with static IP~~
  - ~~Copy zsh configuration from Live CD~~
* Nextcloud Server (Later found that Docker is actually faster)
  - Arch Linux With Nextcloud from package
  - Single NIC with static MAC Address & Static IP
  - Copy zsh configuration from Live CD

## Usage

Boot with the Live CD, ensure the network is connected, and run:

```bash
zsh <(curl -L -s https://Kiwi0093.gitub.io/script/Arch/arch.sh)
```

> [!info] Updated 2026-11-27
> The URL in the historical command above contains a typo (`gitub.io` should be `github.io`), and this custom installation script is now deprecated and unmaintained. The official Arch Linux Live ISO now includes the guided installation tool `archinstall`; it is recommended to use `archinstall` for installation directly.

* The Great Firewall blocks `https://raw.githubusercontent.com/` via DNS pollution, so if used behind the firewall, you can configure `/etc/hosts` first to see if it can be overcome.
* Later I switched to `https://Kiwi0093.github.io` to host my scripts directly.
