> [!info] Updated 2026-11-27
> Below is the original script content retaining historical context, which contains several outdated practices and syntax issues. **Do not run it directly in modern environments**:
> 1. **Shebang Position and Shell**: The full script placed `#` comments before `#!/bin/zsh`, which causes the Linux kernel to ignore the shebang (`#!` must be on the very first line). Furthermore, the Arch ISO / chroot default environment does not pre-install `zsh`; `#!/bin/bash` should normally be used.
> 2. **Timezone Abbreviation Typo**: The comment `CTS(Taipei)` is a typo; Taiwan Standard Time should be `CST` (UTC+8).
> 3. **Network Management Tool**: `netctl` combined with udev custom network interface naming `EXT0` is an early approach. Modern Arch Linux recommends using `systemd-networkd` or `NetworkManager`.
> 4. **Accounts and Sudo Privileges**: `useradd -m -g root` sets the regular user's primary group to `root`, and directly appending writes to `/etc/sudoers` risks configuration corruption. The standard practice is `useradd -m -G wheel` and enabling the `%wheel` group via `visudo`.
> 5. **Dangerous Partial Upgrade**: `pacman -Sy <package>` only synchronizes databases without updating existing packages, which easily causes system library conflicts and corruption on Arch Linux. Installing packages should use `pacman -Syu <package>`. In addition, practice has largely shifted to replacing old `v2ray` and `screen` with `xray` / `sing-box` and `tmux`.
> 6. **Bootloader Mode**: `grub-install --target=i386-pc /dev/sda` is only applicable to legacy BIOS / MBR; modern UEFI machines require `--target=x86_64-efi` with an ESP partition mounted.

## Script Content

### Script Content Description

#### Basic Definitions

```bash
#!/bin/zsh
#Parmeter Pre-Define
COLOR1='\e[94m'
COLOR2='\e[32m'
NC='\e[0m'
```

Defines terminal colors for output strings in the script.

#### Setting Timezone and Hardware Clock

```bash
#change Timezone to CTS(Taipei)
echo -e "${COLOR1}Please select your time zone\n1)Taipei\n2)Shanghai\n*)Whatever..I don't care\n${NC}"
while :
do
	read ZONE
	case $ZONE in
		1)
			echo -e "${COLOR1}Set Time Zone to Asia/Taipei${NC}"
			ln -sf /usr/share/zoneinfo/Asia/Taipei /etc/localtime
			hwclock --systohc --utc
			break
			;;
		2)
			echo -e "${COLOR1}Set Time Zone to Asia/Shanghai${NC}"
			ln -sf /usr/share/zoneinfo/Asia/Shanghai /etc/localtime
			hwclock --systohc --utc
			break
			;;
		*)
			echo -e "${COLOR1}Nobody cares the local time!!${NC}"
			hwclock --systohc --utc
			break
			;;
	esac
done
echo -e "${COLOR2}Completed${NC}"
```

#### Network Configuration

```bash
#Hostname
echo -e "${COLOR1}Please input your hostname\n${NC}"
read HOSTNAME
echo ${HOSTNAME} > /etc/hostname
echo "127.0.0.1 localhost ${HOSTNAME}" >> /etc/hosts
echo -e "${COLOR2}Completed${NC}"

echo -e "${COLOR1}Define your NIC by Mac address${NC}"
echo -e "${COLOR1}Please input your MAC Address:\n${NC}"
read OUTSIDE
echo 'SUBSYSTEM=="net", ACTION=="add", ATTR{address}=="'${OUTSIDE}'", NAME="EXT0"' > /etc/udev/rules.d/10-network.rules
echo -e "${COLOR2}Completed${NC}"

echo -e "${COLOR1}Define your IP for EXT0:${NC}"
echo "Description='EXT0 IP SETTING'" > /etc/netctl/EXT0.service
echo "Interface=EXT0" >> /etc/netctl/EXT0.service
echo "Connection=ethernet" >> /etc/netctl/EXT0.service
echo "IP=static" >> /etc/netctl/EXT0.service
echo -n "${COLOR1}Please input your IP address:\n${NC}"
read EXT_IP
echo "Address=('${EXT_IP}/24')" >> /etc/netctl/EXT0.service
echo -n "${COLOR1}Please input your Gateway IP address:\n${NC}"
read GATE_IP
echo "Gateway='${GATE_IP}'" >> /etc/netctl/EXT0.service
echo -n "${COLOR1}Please input your DNS IP address:\n${NC}"
read DNS_IP
echo "DNS=('${DNS_IP}')" >> /etc/netctl/EXT0.service
echo -e "${COLOR2}Enable EXT0${NC}"
netctl enable EXT0.service
echo -e "${COLOR2}Finished.${NC}"
```

- This configuration names the network interface as **`EXT0`** using a fixed **MAC Address**.
- This configuration uses `netctl` for static IP management.

#### Changing Root Password and Creating Other Accounts

```bash
#Root Password
echo -e "${COLOR1}Set your root password${NC}"
passwd
chsh -s /bin/zsh
echo -e "${COLOR2}Completed${NC}"

#add User
echo -e "${COLOR1}Add user account:${NC}"
echo -n "${COLOR1}What ID you want:${NC}"
read YOURID
useradd -m -g root -s /bin/zsh ${YOURID}
passwd ${YOURID}
echo -e "${COLOR2}Completed${NC}"

echo -e "${COLOR1}Add $YOURID into sudo list${NC}"
pacman -Syu sudo
echo "${YOURID} ALL=(ALL) ALL" >> /etc/sudoers
echo -e "${COLOR2}Completed${NC}"
```

#### Installing Programs

```bash
#install Tools
echo -e "${COLOR1}Install Packages${NC}"
echo -e "${COLOR1}screen${NC}"
pacman -Sy screen v2ray certbot certbot-nginx nginx
echo -e "${COLOR2}Completed${NC}"
```

Installs `screen`, `v2ray`, `certbot`, `certbot-nginx`, and `nginx`. Because back then I didn't want to directly put a `config.json` or copy someone else's *one-click install* script, I only installed the basic packages and manually completed the rest of the configuration referencing other materials.

#### Installing Bootloader

```bash
#install Bootloader
echo -e "${COLOR1}Install grub Boot Loader into /dev/sda${NC}"
grub-install --target=i386-pc /dev/sda
grub-mkconfig -o /boot/grub/grub.cfg
echo -e "${COLOR2}Completed${NC}"
```

#### Sync and Exit Arch-chroot

```bash
#Finished install
sync
sync
sync
exit
```
