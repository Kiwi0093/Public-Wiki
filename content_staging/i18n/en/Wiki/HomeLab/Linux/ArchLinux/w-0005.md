## Archinstall: The Modern Standard for Arch Linux Installation

If you are still manually typing `pacstrap` and writing `fstab` by hand, you've earned my respect. Installing Arch Linux now requires only one core prerequisite: confirming that network connectivity works. As long as the network is connected, a single command `archinstall` lets you experience the thrill of "automated installation".

It is not just a script; it is a menu-driven interactive installer (TUI). Compared to bloated Calamares GUI interfaces like Ubuntu or Manjaro, `archinstall` is faster, more stable, and most importantly: it gives you complete control over your system without wasting time on repetitive grunt work.

### 🛠 Core Workflow: Boot, Connect, Execute

After entering the Arch Live environment, don't rush to partition; follow these three steps:

1. **Check Network**: Run `ping google.com` to check. If using Wi-Fi, connect using `iwctl`; if this step fails, there's no need to discuss the rest.

2. **Launch the Magic Tool**: Simply enter the following in the Shell:

   ```bash
   archinstall
   ```

3. **Multiple-Choice Quiz Time**: A series of menus will appear. This isn't an exam, just fill them out according to your intuition (see advanced configuration below for details).

### ⚡ Advanced Configuration Key Points (Don't Fill Randomly, Look Here)

Although it's automated, choosing the right options will make your Arch truly "take off":

#### 1. Disk Layout —— Recommended to select Btrfs

Stop using traditional ext4. Select "Wipe all selected drives" and specify Btrfs as the filesystem. It supports compression and subvolumes, making future snapshot backups (like Timeshift) super convenient.

<img src='https://img.shields.io/badge/Kiwi-%E4%BD%86%E6%98%AF%E6%88%91%E9%81%93%E7%94%A8ext4-A8FF24?style=social&logo=kiwix&logoColor=EA7500' height='40' />

#### 2. Kernels —— A Must-Choose for Performance Enthusiasts

- For stability: select `linux`.
- For rocket speed: select `linux-zen`. For desktop users, the responsiveness and scheduling optimization of the Zen kernel are genuinely noticeable.

#### 3. Profiles —— A Lazy Person's Blessing

This step is the best. After selecting Desktop, you can directly pick KDE, GNOME, Sway, or Hyprland. It will automatically bundle the relevant Display Manager (such as SDDM or GDM) and base drivers for you.

#### 4. Graphics Drivers

It automatically detects hardware. If you are an NVIDIA user, select proprietary drivers; if AMD or Intel, selecting open-source drivers is sufficient. It installs more accurately than you could manually fetch them.

### 💾 Magic Trick: The "Heirloom" Mode for Configuration Files

This is why I think `archinstall` completely defeats `Calamares`.

Before finishing the installation, it will ask if you want to save the User Configuration. This generates a JSON file. Be sure to save it!

- **Its Benefits:** Next time you get a new computer or need to deploy an identical environment in another virtual machine, you won't even need to click through menus.

How to use it: Put that JSON onto a flash drive, and run after booting:

```bash
archinstall --config my_favorite_setup.json
```

> [!info] Updated 2026-11-27
> Newer versions of `archinstall` have separated account and password settings into `user_credentials.json`. For fully unattended deployments, both the configuration file and credentials file need to be passed simultaneously: `archinstall --config user_configuration.json --creds user_credentials.json`.

Then you can go grab a cup of coffee. This is true "Infrastructure as Code", turning your installation habits into code.

### ⚖️ Why Abandon GUI Installers?

- **Speed:** Calamares frequently hangs on loading graphical interfaces or strange decompression processes. `archinstall` runs underlying Python logic, and its plain text interface responds extremely fast.
- **Cleanliness:** Many GUI installers force a bunch of default software on you. `archinstall` gives you official, authentic Arch, installing only what you select.
- **Automation Flexibility:** You can modify its `config.json` at any time; this level of customizability is something GUI interfaces can never provide.

## Conclusion

> Installing Arch used to be about proving technical prowess; installing Arch now is about efficiency. If you pursue "speed, precision, and stability", `archinstall` is currently the most perfect solution, hands down.
