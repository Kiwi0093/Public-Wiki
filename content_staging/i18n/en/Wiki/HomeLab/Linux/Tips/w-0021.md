## I. First Step: Understanding apk and Alpine's Minimalist Philosophy

Alpine Linux became the king of Docker base images because it discards bulky GNU toolchains (such as `glibc`) in favor of the ultra-lightweight `musl libc` and `BusyBox`. A pristine Alpine image is under 5MB!

Its accompanying tool, `apk`, features very intuitive operation logic and extremely fast execution speed. Configuration files are primarily located at `/etc/apk/repositories`.

## II. Basic Maintenance: Routine System Installation and Updates

If you are maintaining Alpine as a standalone VM or LXC container, the basic commands are as follows:

**1. System Update** Similar to `apt`, updating the local index directory is required before running upgrades:

```bash
# Update package index
apk update

# Upgrade all installed packages
apk upgrade

# Or do it in one line
apk update && apk upgrade
```

**2. Search and Query**

```bash
# Search for packages
apk search <keyword>

# Query detailed information of an installed package
apk info <package_name>

# List all installed packages
apk info
```

## III. Essential Dockerfile Skill: Ultimate Image Slimming

If you are writing a Dockerfile, **forget** the `apk update` trick mentioned above. In container packaging best practices, we have smarter parameters to compress image sizes to the minimum.

**1. God-tier parameter: `--no-cache` (Replacing update and cache cleanup)** When writing Dockerfiles in Debian/Ubuntu, we are often forced to write long, ugly commands to avoid residual caches: `apt-get update && apt-get install -y xxx && rm -rf /var/lib/apt/lists/*`

In Alpine, you only need to append `--no-cache`. It automatically fetches the latest index from the server, installs the software, and **leaves zero cache or index files on the local disk**, all in one line:

```dockerfile
# Perfect, clean, and trace-free installation method
RUN apk add --no-cache curl nginx
```

## IV. Package Uninstall and "Orphan" Cleanup

`apk` automatically checks and removes "orphan packages no longer depended on by any software" by default during uninstallation, so frequent `autoremove` commands like in other systems are rarely needed.

**1. Remove Package**

```bash
apk del <package_name>
```

**2. Force Orphan Cleanup (For Insurance)** If you manually deleted files or want to ensure extreme system cleanliness, although there is no native autoremove command, you can root out unrecorded orphans with this trick:

```bash
# Fix and clean all system dependencies (packages not belonging to the world list will be purged)
apk fix
```

## V. Advanced: Repository Management

Alpine repositories are primarily divided into `main` (core support) and `community` (community maintained). Many great open-source software packages are in `community` by default, but the repository might not be enabled.

**1. Enable Community Repository** Edit `/etc/apk/repositories`:

```bash
vi /etc/apk/repositories
```

You will see content similar to this; remove the `#` comment in front of the line starting with `community`:

```bash
http://dl-cdn.alpinelinux.org/alpine/v3.18/main
http://dl-cdn.alpinelinux.org/alpine/v3.18/community
```

> [!info] Updated 2026-11-27
> Alpine Linux v3.18 reached End-of-Life (EOL) on May 9, 2025. When configuring `/etc/apk/repositories`, please match the active version branch currently used by the host (such as `v3.21` or `latest-stable`), and it is recommended to switch entirely to the `https://` protocol.

Remember to run `apk update` once after modifying.

**2. Temporarily Targeting Edge Repository for a Single Package** If you urgently need the latest version of a software but do not want to upgrade the entire system to an unstable testing branch, you can cross-repository install temporarily with this command:

```bash
# Temporarily use the edge repository to install the latest version of a specific software
apk add --no-cache <package_name> --repository=http://dl-cdn.alpinelinux.org/alpine/edge/community
```

> [!info] Updated 2026-11-27
> In modern Alpine environments, it is recommended to update the URL above to `https://dl-cdn.alpinelinux.org/alpine/edge/community` to ensure transmission security.
