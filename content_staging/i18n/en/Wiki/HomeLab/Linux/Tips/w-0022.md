## chage Command Set and Parameter Details

Linux system account password expiration policies are controlled by the `shadow` file and most commonly adjusted using the `chage` command. Below are core parameters and practical examples:

- **View Full Account Status (`-l`)**

    ```bash
    sudo chage -l john
    ```

    The output will include: last password change date, password expiration date, number of warning days before password invalidation, account deactivation date, and minimum/maximum password change intervals.

- **Set Maximum Password Validity Days (`-M`)**

    ```bash
    sudo chage -M 90 john
    ```

    Forces the user to change their password every 90 days. Setting it to `-1` means the user's password never expires.

- **Set Minimum Password Change Days (`-m`)**

    ```bash
    sudo chage -m 7 john
    ```

    Requires users to wait at least 7 days after changing their password before modifying it again, preventing users from bypassing password history restrictions through consecutive changes.

- **Set Password Expiry Warning Days (`-W`)**

    ```bash
    sudo chage -W 14 john
    ```

    When there are 14 days remaining before the password expires, the user will receive a warning message every time they log into the terminal.

- **Set Absolute Account Expiration Date (`-E`)**

    ```bash
    sudo chage -E 2026-12-31 john
    ```

    Specifies the final deadline the account can be used (formatted as `YYYY-MM-DD`). After this day, the account will be locked directly, regardless of password validity.

## Password Complexity Configuration (pwquality.conf)

Modern Linux distributions typically use `libpwquality` to verify password strength. Modify the `/etc/security/pwquality.conf` file to define password strength policies:

| **Parameter Setting** | **Default or Recommended Value** | **Description** |
| --- | --- | --- |
| `minlen` | `12` | Minimum allowed total password length. |
| `minclass` | `3` | Required number of different character classes (uppercase, lowercase, numbers, special symbols). |
| `dcredit` | `-1` | Negative numbers indicate the minimum required count of digits (e.g., `-1` means at least 1). |
| `ucredit` | `-1` | Minimum required count of uppercase letters. |
| `lcredit` | `-1` | Minimum required count of lowercase letters. |
| `ocredit` | `-1` | Minimum required count of special symbols. |
| `maxrepeat` | `3` | Maximum allowed consecutive repetitions of the same character. |
