## bsnmp

FreeBSD has built-in `bsnmp`.

1. **`vi /etc/rc.conf`**

```bash
# /etc/rc.conf
--------------------------------------------------------------------------------------------------------------------------------
bsnmpd_enable="YES"
```

2. **`pkg install bsnmp-ucd`**
3. **`vi /etc/snmpd.conf`**

```bash
# Append the following contents to /etc/snmpd.conf
--------------------------------------------------------------------------------------------------------------------------------
begemotSnmpdModulePath."ucd" = "/usr/local/lib/snmp_ucd.so"
%ucd
updateInterval = 500
extCheckInterval = 100
extUpdateInterval = 3000
extTimeout = 60

memMinimumSwap = 1600
memSwapErrorMsg = "No free swap!"

laConfig.1 = "6.0"
laConfig.2 = "5.0"
laConfig.3 = "4.0"

laErrMessage.1 = "1min load average is high!"
laErrMessage.2 = "5min load average is high!"
laErrMessage.3 = "15min load average is high!"

# Process table

prNames.0 = "httpd"
prMin.0 = 3
prMax.0 = 100

prErrFix.0 = 1
prErrFixCmd.0 = "/usr/local/etc/rc.d/apache22 restart"

# Extension commands (extTable)

extNames.0 = "uname"
extCommand.0 = "/usr/bin/uname -a"

extNames.1 = "uptime"
extCommand.1 = "/usr/bin/uptime"

# example of extension with fix command
extNames.2 = "apache"
extCommand.2 = "/usr/local/etc/rc.d/apache status"
extErrFix.2 = 1
extErrFixCmd.2 = "/usr/local/etc/rc.d/apache restart"
```

4. **`/etc/rc.d/bsnmpd restart`**
5. **`bsnmpwalk -v 2c -c public`**

If data is retrieved successfully, it is okay.

> [!info] Updated 2026-11-27
> 1. `apache22` in the example has been deprecated in FreeBSD Ports (modern versions use `apache24`).
> 2. On modern FreeBSD, it is recommended to use `service bsnmpd restart` instead of directly executing `/etc/rc.d/bsnmpd restart`.
> 3. FreeBSD's built-in `bsnmpwalk(1)` does not support `net-snmp`'s `-c` flag; specifying the community and target host should be done via `-s`: `bsnmpwalk -v 2c -s public@localhost` (v2c is the default and can also be abbreviated as `bsnmpwalk -s public@localhost`).

## check_mk_agent

### pre-install needed

```bash
pkg install bash ipmitool libstatgrab git
```

Because `check_mk_agent` needs to run with bash, it will not work without bash.

### Install and setup

1. **`Fetch check_mk_agent & grant execution permissions`**

```bash
git clone https://github.com/librenms/librenms-agent.git
cp librenms-agent/check_mk_agent_freebsd /usr/local/bin/check_mk_agent
chmod +x /usr/local/bin/check_mk_agent
```

The method above is outdated... because it is now supported in ports.

`/usr/ports/net-mgmt/check_mk_agent/`

```bash
cd /usr/ports/net-mgmt/check_mk_agent/
make install clean
```

> [!info] Updated 2026-11-27
> In addition to compiling via Ports, modern FreeBSD can also install precompiled binary packages directly: `pkg install check_mk_agent` (which automatically installs dependencies such as `bash` and `libstatgrab`).

2. **`vi /etc/services`**

```bash
# /etc/services
--------------------------------------------------------------------------------------------------------------------------------
check_mk        6556/tcp   #check_mk agent
```

This is added.

3. **`vi /etc/inetd.conf`**

```text
# /etc/inetd.conf
--------------------------------------------------------------------------------------------------------------------------------
check_mk  stream  tcp nowait  root  /usr/local/bin/check_mk_agent check_mk_agent
```

This is also added.

4. **`vi /etc/rc.conf`**

```bash
# /etc/rc.conf
--------------------------------------------------------------------------------------------------------------------------------
inetd_enable=yes
inetd_flags=-wW
```

This is also added.

5. **`vi /etc/hosts.allow`**

```bash
# /etc/hosts.allow
--------------------------------------------------------------------------------------------------------------------------------
# Allow nagios server to access us
check_mk_agent : 192.168.56.3 : allow
check_mk_agent : ALL : deny
```

This is also added.

6. **`/etc/rc.d/inetd start`**
7. **`Confirm with telnet`**

```bash
telnet bsdhost 6556
<<<check_mk>>>
Version: 1.1.13i1
AgentOS: freebsd
```

This is all set.

> [!info] Updated 2026-11-27
> Standard syntax for `/etc/rc.conf` should include double quotes (`inetd_enable="YES"`, `inetd_flags="-wW"`), starting the service should preferably use `service inetd start`, and verifying port connectivity can use `nc bsdhost 6556` instead of `telnet`.

### Conclusion

Although I don't really like enabling `inetd` to run this, these machines and ports are basically restricted by firewalls, and LibreNMS is deployed internally, so the risk should not be that high.

It can still barely be used this way.
