# Basic Concepts

Unlike `Linux` which uses a single package manager to update the entire system and packages, FreeBSD uses different commands for updating the system and packages.

### Linux Approach

```bash
# Debian/Ubuntu
apt update && apt upgrade
# Arch
pacman -Syu
```

One command solves everything.

# FreeBSD System Update

## Update System

```bash
# Update patches for existing version
freebsd-update fetch && freebsd-update install
# Upgrade to x.y-RELEASE
freebsd-update upgrade -r x.y-RELEASE && freebsd-update install
```

> [!info] Updated 2026-11-27
> When performing cross-version upgrades using `freebsd-update upgrade -r x.y-RELEASE`, the first execution of `freebsd-update install` only installs the new kernel. You must first reboot (`shutdown -r now`) and then run `freebsd-update install` a second time to complete the userland update. If third-party packages were rebuilt after removing old libraries, you must run `freebsd-update install` one final time at the end.

## Update Package - pkg

Actually, if you don't need to compile yourself, using `pkg` is much more convenient.

<img src="https://img.shields.io/badge/Kiwi-%E7%B0%A1%E5%96%AE%E7%9A%84%E8%AA%AA%E5%B0%B1%E6%98%AF%E6%87%B6%E7%9A%84%E7%AD%89port%20make%20install-A8FF24?style=social&logo=kiwix&logoColor=EA7500" height="40" />

```bash
# Install
pkg install <pkg_name>

# Remove
pkg delete <pkg_name>

# Autoremove
pkg autoremove

# Check pkgs version
pkg version

# Update repo
pkg update

# Update pkg
pkg upgrade
```

## Port Update

In the past, most software in FreeBSD was compiled using ports. Nowadays, unless special compilation parameters are required, `pkg` is basically used for installation.

### Port Tree Update

```bash
cd /usr/ports
# First time use
portsnap fetch && portsnap extract && portsnap update
# Subsequent use
portsnap fetch && portsnap update
```

> [!info] Updated 2026-11-27
> The `portsnap` tool has been deprecated since FreeBSD 13 and **officially removed starting from FreeBSD 14.0** (the Ports Tree is now fully hosted via Git). Modern FreeBSD environments should install `git` (e.g., `pkg install git`), initially acquire the Ports Tree via `git clone https://git.FreeBSD.org/ports.git /usr/ports`, and subsequently update using `git -C /usr/ports pull`.

### Port Software Update

```bash
portmaster -a
```
