## 1. General CJK Fonts Installation

Regardless of the operating system used, the primary step is to install general fonts capable of properly rendering Chinese, Japanese, and Korean characters:

- **Arch Linux / Manjaro:**

    ```bash
    sudo pacman -S noto-fonts-cjk
    ```

- **Debian / Ubuntu / Linux Mint:**

    ```bash
    sudo apt install fonts-noto-cjk
    ```

- **RHEL / CentOS / Fedora:**

    ```bash
    sudo dnf install google-noto-sans-cjk-fonts
    ```

- **FreeBSD:**

    ```bash
    sudo pkg install noto-fonts-cjk
    ```

> [!info] Updated 2026-11-27
> The FreeBSD `pkg` repository does not contain a package named `noto-fonts-cjk`. Please install specific language fonts as needed (e.g., `noto-tc` for Traditional Chinese, `noto-jp` for Japanese) or the complete meta-port `noto`: for example, `sudo pkg install noto-tc noto-jp`.

## 2. Input Method Framework and Engine Installation (Commands by Distribution)

It is strongly recommended to fully adopt the modern **Fcitx5** family to achieve optimal performance, Wayland compatibility, and Japanese/Zhuyin candidate selection experience.

### 1. Arch Linux Family

```bash
sudo pacman -S fcitx5 fcitx5-mozc fcitx5-chewing fcitx5-configtool fcitx5-qt fcitx5-gtk
```

### 2. Debian / Ubuntu Family

```bash
sudo apt install fcitx5 fcitx5-frontend-qt5 fcitx5-frontend-gtk3 fcitx5-module-quickphrase fcitx5-config-qt fcitx5-mozc fcitx5-chewing
```

> [!info] Updated 2026-11-27
> Newer Ubuntu 24.04+ / Debian 13+ have merged `fcitx5-module-quickphrase` into the `fcitx5-modules` core package. If you encounter package-not-found errors, install `fcitx5-modules` instead, and optionally install `fcitx5-frontend-gtk4` and `fcitx5-frontend-qt6` depending on your desktop environment.

### 3. RHEL / Fedora Family (Fedora 34+)

```bash
sudo dnf install fcitx5 fcitx5-gtk fcitx5-qt fcitx5-config-qt fcitx5-mozc fcitx5-chewing
```

> [!info] Updated 2026-11-27
> The configuration interface package name in the official Fedora repositories is `fcitx5-configtool` (rather than `fcitx5-config-qt` in the Debian family). You can also optionally install `fcitx5-gtk4`, `fcitx5-qt6`, and `fcitx5-autostart` as needed.

### 4. FreeBSD

```bash
sudo pkg install fcitx5 fcitx5-configtool fcitx5-gtk4 fcitx5-gtk3 fcitx5-qt fcitx5-chewing fcitx5-mozc
```

> [!info] Updated 2026-11-27
> FreeBSD `pkg` actual package names include language and shared component prefixes/suffixes: Chewing is `zh-fcitx5-chewing`, GTK common is `fcitx5-gtk-common`, Qt common is `fcitx5-qt-common` (or corresponding Qt5/Qt6 packages). Also, official binary package repositories typically do not provide `fcitx5-mozc` directly; for Japanese input, you can install `ja-fcitx5-anthy` or compile Mozc via Ports.

## 3. System Environment Configuration and Runtime Scenarios

Depending on your "desktop environment" and "display server (X11 vs. Wayland)", the configuration method varies:

### Scenario A: Modern Wayland + KDE Plasma (e.g., Arch Linux with Plasma 5.27/6)

Under this combination, Fcitx5 offers extremely high integration, requiring **almost no manual environment variable configuration**:

1. Ensure all aforementioned packages are installed, then re-login.
2. The system will automatically launch `fcitx5` in the background via XDG.
3. Open KDE System Settings (**Regional Settings -> Input Method**), and add Chewing and Mozc to the list to start using them out-of-the-box.

### Scenario B: Traditional X11 or XFCE / GNOME / Minimal Desktop Environments (e.g., WSL)

If you are not running Wayland + KDE, or if the system fails to load modules automatically, you need to configure environment variables manually:

- **Global Environment Variables (`/etc/environment`):**

    ```bash
    GTK_IM_MODULE=fcitx
    QT_IM_MODULE=fcitx
    XMODIFIERS=@im=fcitx
    SDL_IM_MODULE=fcitx
    GLFW_IM_MODULE=fcitx
    ```

- **FreeBSD Environment Variables and Autostart:**

    - Add the following to your shell configuration file (`~/.xprofile` or `~/.bashrc`):

        ```bash
        export GTK_IM_MODULE=fcitx5
        export QT_IM_MODULE=fcitx5
        export XMODIFIERS=@im=fcitx5
        ```

        > [!info] Updated 2026-11-27
        > For compatibility, Fcitx5's GTK/Qt IM module and XIM identifier names remain `fcitx` (not `fcitx5`). The correct settings should be `export GTK_IM_MODULE=fcitx`, `export QT_IM_MODULE=fcitx`, and `export XMODIFIERS=@im=fcitx`.

    - Add the background startup command to your window manager startup script (`~/.xinitrc`):

        ```bash
        fcitx5 -d &
        ```
