## 2. Modern Mainstream: `tmux` and `oh-my-tmux` Practice

### 1. Basic Installation

- **Arch Linux:**

  ```bash
  sudo pacman -S tmux
  ```

- **Debian / Ubuntu:**

  ```bash
  sudo apt install tmux
  ```

- **FreeBSD:**

  ```bash
  sudo pkg install tmux
  ```

### 2. oh-my-tmux Configuration (Aesthetics and Quick Setup)

Quickly build a professional and aesthetically pleasing interface via the well-known configuration project:

```bash
cd
git clone https://github.com/gpakosz/.tmux.git
ln -s -f .tmux/.tmux.conf
cp .tmux/.tmux.conf.local .
```

### 3. tmux Common Shortcuts Reference Table (Default Prefix is `Ctrl+a` or `Ctrl+b`)

### 4. Startup and Connection Management Commands

- **List all running Sessions:**

  ```bash
  tmux ls
  ```

- **Reattach to a specified Session:**

  ```bash
  tmux attach -t $number
  # or abbreviated
  tmux at -t 0
  ```

- **Smart startup command (combining auto-attachment and creation):**

  ```bash
  tmux -u attach || tmux -u
  ```

### 5. Advanced Configuration: Default Shell and WSL Automatic Takeover

- **Set Default Shell to zsh:**

  Add the following to `~/.tmux.conf`:

  ```bash
  set -g default-shell /usr/bin/zsh
  ```

- **WSL Automatic Session Attachment:**

  Add the following snippet to `~/.zshrc` or `~/.bashrc`. This is extremely useful in WSL environments: closing and reopening the terminal window will automatically reattach to the original Session:

  ```bash
  if command -v tmux &> /dev/null && [ -z "$TMUX" ]; then
    tmux attach-session -t default || tmux new-session -s default
  fi
  ```

## 3. The Classic Forefather: GNU `screen`

Although `tmux` has become mainstream, `screen` remains the best pre-installed rescue tool in many lightweight container images or legacy servers.

### Common Commands

- **Start a new Session:**

  ```bash
  screen -S mysession
  ```

- **List background Screen Sessions:**

  ```bash
  screen -ls
  ```

- **Reattach to a specified Screen:**

  ```bash
  screen -r mysession
  ```

- **Keyboard Shortcuts:**
  - Detach (leave and send to background): Press `Ctrl+a` then `d`
  - Create new window: Press `Ctrl+a` then `c`
  - Switch windows: Press `Ctrl+a` then `n` (Next) or `p` (Previous)

## 4. Modern Rust Terminal Rising Star: `zellij`

`zellij` is a terminal multiplexer written in Rust. It simplifies layout concepts to the extreme, providing a bottom status bar and pane menu by default, with excellent mouse support.

### 1. Installation Methods

- **Arch Linux:**

  ```bash
  sudo pacman -S zellij
  ```

- **Cargo (Rust Package Manager):**

  ```bash
  cargo install zellij
  ```

### 2. Basic Usage and Operations

- **Start a new session:**

  ```bash
  zellij
  ```

- **List and manage Sessions:**

  ```bash
  zellij list-sessions
  ```

- **Reattach to a specified Session:**

  ```bash
  zellij attach <SESSION_NAME>
  ```

- **Core Operational Features:**
  - Upon startup, shortcut prompts (Shortcut Bar) are permanently stationed at the bottom of the screen. You can use arrow keys or the mouse for intuitive operation via `Ctrl+p` (control panel) and `Ctrl+n` (new pane) without needing to memorize complex Prefix combinations.
