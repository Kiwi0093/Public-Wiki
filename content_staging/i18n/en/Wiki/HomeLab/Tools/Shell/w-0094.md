## Zsh Installation

This is very simple and essentially relies on your system's package manager:

```shell
# Arch Linux family
sudo pacman -S zsh
# or
yay -S zsh
# Yum family
yum install zsh
# FreeBSD
pkg install zsh
```

> [!info] Updated 2026-11-27
> Modern RHEL, Rocky Linux, AlmaLinux, and Fedora distributions have replaced `yum` with `dnf`; please use `sudo dnf install zsh` instead. On FreeBSD, execute `sudo pkg install zsh` (or as `root`).

## Manjaro-zsh-config @ Arch Linux

Since `manjaro-zsh-config` is available in the AUR, installing this package automatically pulls in all related dependencies, so it's straightforward:

```shell
# Arch Linux family
# Since this is in the AUR:
git clone https://aur.archlinux.org/manjaro-zsh-config.git
cd manjaro-zsh-config && makepkg -si
# Or simpler:
yay -S manjaro-zsh-config
```

<span style="color:#e06c75"><del>Remember to copy `/etc/zsh/zshrc-manjaro/.zshrc` to `~/.zshrc` for it to take effect</del></span> *(Updated 2026-11-27: The template provided by the AUR package `manjaro-zsh-config` is located at `/etc/skel/.zshrc` (which sources `/usr/share/zsh/manjaro-zsh-config`). If following the manual script copy method below, you should copy `/etc/zsh/zshrc-manjaro` as `~/.zshrc`.)*

## Other Operating Systems

### Packages for manjaro-zsh-config

- `zsh-completions`
- `zsh-autosuggestions`
- `zsh-history-substring-search`
- `zsh-syntax-highlighting`
- `zsh-theme-powerlevel10k`
- `ttf-noto-nerd` (Noto Nerd Fonts)

### zsh-theme-powerlevel10k Installation

```shell
# Arch Linux family
sudo pacman -S zsh-theme-powerlevel10k
# or
yay -S zsh-theme-powerlevel10k
# Other systems - Manual Installation
sudo git clone --depth=1 https://github.com/romkatv/powerlevel10k.git /usr/share/
# The installation path is fixed to match Manjaro's configuration later.
```

> [!info] Updated 2026-11-27
> Directly running `git clone` into an existing and non-empty `/usr/share/` will fail. Manual installation requires specifying the target directory name:
> ```shell
> sudo git clone --depth=1 https://github.com/romkatv/powerlevel10k.git /usr/share/zsh-theme-powerlevel10k
> ```
> Also note that upstream `romkatv/powerlevel10k` has entered a limited maintenance state, with features mostly frozen but still fully functional.

### gitstatus Installation

```shell
sudo git clone --depth=1 https://github.com/romkatv/gitstatus.git /usr/share/zsh-theme-powerlevel10k/
# The installation path is fixed to match Manjaro's configuration later.
```

> [!info] Updated 2026-11-27
> If the `/usr/share/zsh-theme-powerlevel10k/` directory already exists, you must append the subdirectory name `gitstatus` (i.e., `/usr/share/zsh-theme-powerlevel10k/gitstatus`). Actually, `powerlevel10k` also automatically downloads the corresponding `gitstatusd` binary by default.

### Manjaro-zsh-config Configuration Files

Since there is no directly installable package, please run the following script:

```shell
git clone https://github.com/Chrysostomus/manjaro-zsh-config
sudo cp -Rv manjaro-zsh-config/manjaro-zsh-prompt /usr/share/zsh/
sudo cp -Rv manjaro-zsh-config/zsh-maia-prompt /usr/share/zsh/
sudo cp -Rv manjaro-zsh-config/p10k.zsh /usr/share/zsh/
sudo cp -Rv manjaro-zsh-config/p10k-portable.zsh /usr/share/zsh/
sudo cp -Rv manjaro-zsh-config/command-not-found.zsh /usr/share/zsh/functions/
sudo cp -Rv manjaro-zsh-config/.zshrc /etc/zsh/zshrc-manjaro
sudo cp -r manjaro-zsh-config/base16-shell /usr/share/zsh/scripts/
sudo chmod a+x /usr/share/zsh/scripts/base16-shell/
```

> [!info] Updated 2026-11-27
> The original GitHub repository `Chrysostomus/manjaro-zsh-config` has been migrated/archived; it is recommended to obtain it from official Manjaro repositories or the AUR. Additionally, before executing the copy commands above on non-Arch systems, you need to first create the target directories by running `sudo mkdir -p /usr/share/zsh/functions /usr/share/zsh/scripts /etc/zsh`.

Then copy `manjaro-zsh-config/.zshrc` (or `/etc/zsh/zshrc-manjaro`) as `~/.zshrc` and restart `zsh`.

## Windows Terminal Nerd Fonts Display

### Installing Nerd Fonts

Since this is `WSL`, besides installing Noto Nerd Font inside the Linux system, you must also install Nerd Fonts on the host Windows system; otherwise, icons will not display correctly.

[Nerd Fonts](https://www.nerdfonts.com) web page collecting various Nerd Fonts:
[![Nerd Fonts](https://raw.githubusercontent.com/Kiwi0093/graph/master/img/nerd_font.png)](https://www.nerdfonts.com)

Go to `Download` and pick your favorite version to download.

I personally like using <span style="color:#e06c75"><del>[noto-nerd-font](https://github.com/ryanoasis/nerd-fonts/releases/download/v3.1.1/Noto.zip)</del></span> *(Updated 2026-11-27: v3.1.1 is an older link; it is recommended to download from the [Nerd Fonts latest release `Noto.zip`](https://github.com/ryanoasis/nerd-fonts/releases/latest/download/Noto.zip))*
[![Noto Nerd Font](https://raw.githubusercontent.com/Kiwi0093/graph/master/img/noto-nerd-fonts.png)](https://github.com/ryanoasis/nerd-fonts/releases/latest/download/Noto.zip)

After downloading, remember to extract the Zip file and install the fonts.

### Configuring Windows Terminal Font

![Windows Terminal Setting 1](https://raw.githubusercontent.com/Kiwi0093/graph/master/img/windows_terminal_archwsl_setting1.png)

In settings, select your ArchWSL option and choose appearance:

![Windows Terminal Setting 2](https://raw.githubusercontent.com/Kiwi0093/graph/master/img/windows_terminal_archwsl_setting2.png)

Change the font to the `Nerd Font` you downloaded and remember to save your changes.
