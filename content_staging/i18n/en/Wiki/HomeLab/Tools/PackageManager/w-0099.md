## 1. Traditional Core Tool: `du` (Disk Usage)

`du` is a POSIX-standard tool natively built into all Unix-like systems (Linux, FreeBSD, macOS). It calculates occupied space by sequentially reading filesystem metadata, making it ideal for standard shell script automation troubleshooting.

### Platform Support

- **Support Status:** Both (built-in natively on both Linux and FreeBSD).

### Core Commands and Practical Examples

- **Limit directory display depth (most commonly used for troubleshooting space):**

    ```bash
    du -h --max-depth=1
    # or abbreviated as
    du -h -d 1
    ```

- **Specify output in MB units and list the total sum of a specified directory:**

    ```bash
    du -m -s /var/log/
    ```

- **Practical Classic: Find the top 5 largest subdirectories or files in the current directory**

    ```bash
    du -m --max-depth=1 | sort -nr | head -n 5
    ```

> [!info] Updated 2026-11-27
> `--max-depth=1` is a long parameter specific to GNU coreutils `du` (Linux); BSD `du` on FreeBSD and macOS does not support `--max-depth`. For cross-platform compatibility, use `-d 1` instead (e.g., `du -m -d 1 | sort -nr | head -n 5`).

## 2. Terminal Interactive Pioneer: `ncdu` (NCurses Disk Usage)

Created to overcome the shortcomings of plain-text `du` results being difficult to inspect layer by layer. It introduces an `ncurses` text user interface, allowing administrators to intuitively navigate directories in the terminal just like a file manager.

### Platform Support

- **Support Status:** Both (installable via each system's package repository).

### Installation and Operation

- **Installation Command:**

    ```bash
    # Linux (Ubuntu / Debian / RHEL)
    sudo apt install ncdu

    # FreeBSD (via pkg or Ports)
    sudo pkg install ncdu
    ```

- **Launch and Interaction:**

    ```bash
    # Scan current directory and enter interactive interface
    ncdu

    # Scan specified directory
    ncdu /var/log
    ```

- **Interactive Shortcuts:** Use up and down arrow keys to navigate, press `Enter` to enter a subdirectory, and press `d` directly on a target to delete space-hogging bulky files.

## 3. Modern Disk Partition Viewer: `duf` (Disk Usage/Free Utility)

Although the name contains `du`, its core functionality focuses more on replacing the traditional `df` command, presenting the health status and remaining capacity of overall disk partitions (mount points) with excellent visual formatting.

### Platform Support

- **Support Status:** Both (cross-platform support).

### Installation and Usage

- **Installation Command:**

    ```bash
    # Install via package repository or binary
    sudo apt install duf  # Some Linux distributions
    ```

- **Execution:**

    ```bash
    duf
    ```

## 4. Blazing-Fast Parallel Computation Rising Star: `gdu` (Go Disk Usage)

A high-performance disk analysis tool written in Go, specifically optimized for modern SSD drives and multi-core CPU architectures, capable of fully utilizing hardware performance for parallel scanning.

### Platform Support

- **Support Status:** Both (cross-platform support).

### Advantages and Core Operations

- **Blazing Fast:** Significantly faster than traditional `du` or `ncdu` when scanning directories containing millions of small files (such as `node_modules`).

- **Common Operation Commands:**

    ```bash
    # Interactive scan of current directory
    gdu

    # Display space status of all mount points only
    gdu -d

    # Start web server mode to remotely view scan results directly via browser
    gdu --web /path/to/scan
    ```
