When writing technical blogs (such as Docusaurus, Obsidian, or Typora), Markdown serves as the core syntax for recording notes and knowledge bases. Beyond standard formatting rules, mixing HTML tags allows for many advanced visual effects. This article provides a comprehensive overview ranging from basic syntax to advanced HTML techniques.

## I. Basic Syntax

Most modern Markdown editors (such as Typora) support real-time preview and shortcuts, but mastering native markup ensures stable rendering across any Wiki platform.

### 1. Headings

Corresponding to HTML `<h1>` through `<h6>`, there are six size hierarchies:

# `#` H1 Heading

## `##` H2 Heading

### `###` H3 Heading

#### `####` H4 Heading

##### `#####` H5 Heading

###### `######` H6 Heading

### 2. Dividers

You can use three or more asterisks, hyphens<span style="color:#e06c75"><del>, or plus signs</del></span> *(Updated 2026-11-27: The CommonMark standard specifies underscores `_`; plus signs `+++` are not standard divider syntax)* to create horizontal rules:

```markdown
---
***
+++
```

> [!info] Updated 2026-11-27
> Standard CommonMark / GFM only supports three or more hyphens (`---`), asterisks (`***`), or underscores (`___`); `+++` in static site generators is typically reserved for TOML Frontmatter and cannot be rendered as a horizontal divider.

### 3. Links

Standard anchor text and URL link syntax:

```markdown
[Title](httpURL)
```

_Result:_ [Kiwi's Wiki](https://blog.kiwireich.com/docs "WIKI Knowledge Base")

### 4. Text Styles

Supports italics, bold, strikethrough, and combinations thereof:

|Syntax 1|Syntax 2|Result|
|:-:|:-:|:-:|
|\*Italic\*|\_Italic\_| *Italic*|
|\*\*Bold\*\*|\_\_Bold\_\_|**Bold**|
|\*\*\*Bold Italic\*\*\*|\_\_\_Bold Italic\_\_\_|***Bold Italic***|
|\~~Strikethrough\~~||~~Strikethrough~~|

### 5. Lists

- **Unordered Lists** (using `*`, `-`, or `+` yields identical results):

    ```markdown
    * First item
    * Second item
    * Third item
    ```

- **Ordered Lists**:

    ```markdown
    1. First item
    2. Second item
    3. Third item
    ```

    _(Note: Even if numbering is out of order, most editors will automatically sequence them)_

### 6. Images and Media Links

- **Standard Image:**

    ```markdown
    ![Alt text](/path/to/img.jpg)
    ```

- **Nested Media Link (e.g., wrapping a YouTube thumbnail into a clickable hyperlink):**

    ```markdown
    [![Video Title](http://img.youtube.com/vi/SlzBMJvtGHo/0.jpg)](https://www.youtube.com/watch?v=SlzBMJvtGHo "Video Tooltip")
    ```

    _Result (YouTube Example):_

    [![Dr. Berg's Fasting Explanation](http://img.youtube.com/vi/SlzBMJvtGHo/0.jpg)](https://www.youtube.com/watch?v=SlzBMJvtGHo "Fasting Body Changes")

> [!info] Updated 2026-11-27
> The thumbnail URLs above should preferably use HTTPS (`https://img.youtube.com/vi/SlzBMJvtGHo/0.jpg`) to avoid triggering browser mixed content blocks or warnings on modern HTTPS sites.

## II. Advanced Usage: Mixing Markdown with HTML

Markdown's core design allows embedding **HTML syntax** directly. When finer layout control, color customization, or special markers are needed, HTML tags can be used alongside Markdown.

> **⚠️ Note:** When writing content inside HTML `<>` tags, it is recommended to adopt HTML formatting internally (e.g., using `<font>` or `<del>` instead of `**`) to avoid parser conflicts.

### 1. Text Decoration and Underline

Native Markdown does not directly support underlines (to avoid confusion with links), which require HTML's `<u>` tag:

| Syntax | Result |
| :---: | :---: |
| \<u>Underline\</u> | <u>Underline</u> |
| \<del>Strikethrough\</del> | <del>Strikethrough</del> |

### 2. Custom Font Colors (`<font>`)

Using `<font color="...">` allows free adjustment of font colors, ideal for highlighting key points in technical notes:

| Syntax | Result | Syntax | Result |
| :---: | :---: | :---: | :---: |
| `<font color="#800000">Maroon</font>` | <font color="#800000">Maroon</font> | `<font color="#FF0000">Red</font>` | <font color="#FF0000">Red</font> |
| `<font color="#FF6600">Orange</font>` | <font color="#FF6600">Orange</font> | `<font color="#FFD700">Gold</font>` | <font color="#FFD700">Gold</font> |
| `<font color="#FFFF00">Yellow</font>` | <font color="#FFFF00">Yellow</font> | `<font color="#00FF00">Green</font>` | <font color="#00FF00">Green</font> |
| `<font color="#008000">Dark Green</font>` | <font color="#008000">Dark Green</font> | `<font color="#00FFFF">Cyan</font>` | <font color="#00FFFF">Cyan</font> |
| `<font color="#0000FF">Navy Blue</font>` | <font color="#0000FF">Navy Blue</font> | `<font color="#FF00FF">Pink</font>` | <font color="#FF00FF">Pink</font> |
| `<font color="#800080">Purple</font>` | <font color="#800080">Purple</font> | `<font color="#808080">Gray</font>` | <font color="#808080">Gray</font> |

> [!info] Updated 2026-11-27
> The `<font>` tag is deprecated in HTML5 specifications; modern standards recommend using CSS inline styles `<span style="color: #FF0000">Text</span>` (or `style={{color: '#FF0000'}}` in Docusaurus MDX v2/v3).

### 3. Superscript and Subscript (`<sup>` / `<sub>`)

Suitable for mathematical formulas, chemical equations, or version labeling:

| Syntax | Result |
| :---: | :---: |
| 3\<sup>2\</sup>=9 | 3<sup>2</sup>=9 |
| H\<sub>2\</sub>O | H<sub>2</sub>O |

### 4. Special Math and Common Entity Symbols

Directly insert special symbols via HTML Entity References:

| Target | Syntax | Result |
| :---: | :---: | :---: |
| Trademark | \&reg; | Trademark&reg; |
| Function ƒ(x) | \&fnof;(X)=X+1 | &fnof;(X)=X+1 |
| Square Root | \&radic;2 | &radic;2 |
| Degree | 45\&deg; | 45&deg; |

### 5. Ruby Annotations (`<ruby>`)

Leverage HTML5 `<ruby>`, `<rt>` (ruby/pinyin annotation), and `<rp>` (parentheses for unsupported browsers) tags to create ruby text:

```markdown
<ruby>
Kanji<rp>(</rp><rt>かんじ</rt><rp>)</rp>
</ruby>
```

_Result:_ <ruby>Kanji<rp>(</rp><rt>かんじ</rt><rp>)</rp></ruby>

**Practical Example (Dual-Layer Technical Semantics):** Combine colors and strikethroughs within annotations for dual-layer semantic effects:

```markdown
I really like <ruby><font color="blue"><del>my fleet</del></font><rp>(</rp><rt><font color="red">VMware ESXi</font></rt><rp>)</rp></ruby>
```

_Result:_ I really like <ruby><font color="blue"><del>my fleet</del></font><rp>(</rp><rt><font color="red">VMware ESXi</font></rt><rp>)</rp></ruby>
