## 1. Basic Operations and Save & Quit

<span style="color:#e06c75"><del>All commands are entered under **Command Mode**</del></span> *(Updated 2026-11-27: Strictly speaking, operations like `i`, `a`, `o`, `dd`, `u`, and `p` belong to **Normal Mode**, whereas colon-prefixed instructions like `:w`, `:q`, and `:%s/...` belong to **Command-line Mode**)*, and pressing the `Esc` key will return you to Normal Mode at any time.

| **Command** | **Effect Description** |
|---|---|
| `:q` | Quit without saving (blocked if there are unsaved changes) |
| `:q!` | Force quit without saving (discard all unsaved modifications) |
| `:w` | Write and save current file |
| `:wq` or `ZZ` | Save and quit |
| `:wq!` | Force save and quit (applies to overriding when permissions allow) |

## 2. Keyboard Editing and Navigation Shortcuts

Common shortcuts for switching from Normal Mode to Insert Mode or performing block operations:

| **Command / Key Action** | **Effect Description** |
|---|---|
| `i` | Enter insert mode (Insert) at current cursor position |
| `a` | Enter insert mode **after** the cursor position |
| `o` | Open a blank line **below** the current line and enter insert mode |
| `dd` | Delete (cut) the entire line |
| `[number]dd` | Delete specified `[number]` of lines starting from the current line (e.g., `5dd`) |
| `u` | Undo previous action |
| `p` | Paste (content buffered by `dd` or `yy`) |

## 3. Advanced Search and Global Replacement Commands

Utilize Ex commands in Command-line mode for powerful string searching and batch replacement.

### 1. Basic Search

- Type `/` in Normal Mode followed by the keyword to search downwards (press `n` for next, `N` for previous).

### 2. Global String Replacement Syntax

- **Global replacement across the entire file:**

  ```vim
  :%s/search_from/replace_to/g
  ```

- **Interactive confirmation with user prior to each replacement:**

  ```vim
  :%s/search_from/replace_to/gc
  ```

  *(When prompted, press `y` to confirm replacement, `n` to skip, `a` to replace all, `q` to quit)*

- **Ignore English case differences:**

  ```vim
  :%s/search_from/replace_to/gi
  ```

- **Replace only on the "current line":**

  ```vim
  :s/search_from/replace_to/g
  ```

- **Specify a target line number range for replacement:**

  ```vim
  :[start_line],[end_line]s/search_from/replace_to/gc
  ```

  *(e.g., `:10,50s/foo/bar/gc` means perform confirmed replacement only between line 10 and line 50)*
