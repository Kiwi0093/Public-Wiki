## I. Prerequisites: Powerline Fonts and Core Installation

To ensure special icons and arrows render correctly in the status bar, ensure terminal fonts and packages are in place.

### 1. Install Powerline Patched Fonts

- **Arch Linux / Manjaro:**

    ```bash
    sudo pacman -S powerline-fonts ttf-jetbrains-mono-nerd
    ```

- **Debian / Ubuntu:**

    ```bash
    sudo apt install fonts-powerline
    ```

- **FreeBSD:**

    ```bash
    sudo pkg install powerline-fonts
    ```

*(After installation, remember to switch your terminal emulator font setting to a font with Powerline support, such as `JetBrainsMono Nerd Font`)*

### 2. Install Vim and Powerline Core

Taking Arch Linux / Manjaro systems as an example:

```bash
sudo pacman -S vim powerline python-powerline
```

> [!info] Updated 2026-11-27
> The official Arch Linux repository has split the Vim integration plugin into `vim-powerline` (providing `powerline-vim`). It is recommended to install `sudo pacman -S vim powerline vim-powerline`. Once `vim-powerline` is installed, it is automatically mounted to the Vim runtime path; typically only `set laststatus=2` needs to be configured without manually writing `python3` load scripts.

## II. Powerline Status Bar Customization

Drive the dynamic status bar via embedded Python modules.

### 1. Initialize Configuration File

Copy the system-built-in Vim sample configuration to your home directory:

```bash
cp /usr/share/vim/vim90/vimrc_example.vim ~/.vimrc
```

*(Note: Depending on the actual Vim version, `vim90` in the path may be a version number like `vim91`)*

### 2. Write Powerline Startup Settings

Open `~/.vimrc` with an editor and add the following configuration at the end:

```vim
" Powerline status bar customization
set laststatus=2           " Always show the bottom status bar

" Load Powerline framework via embedded Python 3
python3 from powerline.vim import setup as powerline_setup
python3 powerline_setup()
python3 del powerline_setup
```

## III. Code Folding and Marker Configuration

Faced with hundreds of lines of code, using Marker tags and `foldmethod` allows you to collapse temporarily ignored logic blocks effectively.

### 1. Append Folding Configuration in `~/.vimrc`

Add the following folding parameters to the same `~/.vimrc` file:

```vim
syntax on
set foldmarker={{{,}}}
set foldmethod=marker
set foldlevel=0          " Collapse all blocks by default upon startup
let php_folding = 1      " Additional dependent folding support for PHP syntax
set foldnestmax=3        " Limit maximum nested folding levels to 3 layers
```

### 2. Practical Writing Example

After configuration, add `{{{` and `}}}` inside code comments to create folded blocks:

```php
// Database connection and initialization module {{{
function init_connection() {
    // Implementation details...
}
// }}}
```

## IV. Folding Control High-Frequency Shortcut Reference Table (Folding Commands)

Common shortcuts for operating folding states in Vim:

|**Shortcut Command**|**Effect and Description**|
|---|---|
|`zi`|**Enable / Disable** file-wide folding functionality|
|`zo`|**Open** the folding block at the current cursor|
|`zc`|**Close** the folding block at the current cursor|
|`zO`|**Recursively open** all folding blocks at and below the current cursor level|
|`zC`|**Recursively close** all folding blocks at and below the current cursor level|
|`zm`|Decrement `foldlevel` by 1 (tighten overall folding level further)|
|`zM`|Set `foldlevel` to 0 (**force all blocks folded**)|
|`zr`|Increment `foldlevel` by 1 (loosen overall folding level further)|
|`zR`|Set `foldlevel` to maximum (**fully expand all blocks**)|
|`zx`|Update folding state (re-apply rules for all blocks except the one under the cursor)|
|`zf`|Select a range via Visual Mode to dynamically create start and end folding markers|
