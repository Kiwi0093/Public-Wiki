# BattleTech Ammo System Architecture and Custom Ammo Box JSON Modification Guide

> <img src='https://img.shields.io/badge/Status-Active-A8FF24?style=for-the-badge&labelWidth=100' height='38' />

:::tip
Ammunition is also worth modifying; at the very least, ammo quantity is crucial.
:::

In BattleTech's underlying architecture, the ammunition system adopts a rigorous "three-layer" mapping logic. To successfully fire a single bullet, you must ensure that the JSON configurations of the **Weapon**, **AmmunitionBox**, and **Ammunition** are perfectly linked together.

## 1. Ammo Pairing and Trigger Logic (System Logic)

When a Mech attempts to fire in combat, the system sequentially executes the following checks:

1. **Layer 1 [Weapon End]**: Reads the `AmmoCategory` parameter in the `Weapon` JSON (e.g., `"AC20"`), confirming what caliber of bullet the weapon consumes.
2. **Layer 2 [Mech Inventory]**: Scans all equipment on the Mech, looking for physical ammo boxes where `ComponentType` is `AmmunitionBox`, and verifies whether the box can provide ammo of the `"AC20"` category.
3. **Layer 3 [Bullet Definition]**: The `AmmoID` inside the ammo box points to an independent `Ammunition` JSON file (e.g., `Ammunition_AC20.json`). This underlying file truly defines the attributes of this bullet (such as armor-piercing or incendiary effects).

> 💡 **Safe Modding Rule**
>
> If your sole purpose is to "expand ammunition capacity", **only modify the `Capacity` parameter of the AmmunitionBox**, while keeping `AmmoID` pointing to the factory-default bullet file. This ensures the system will never encounter loading errors.

## 2. AmmunitionBox Core Parameter Dictionary

The ammo box is the "physical equipment" that players actually install onto Mechs in the refitting interface.

| **Parameter Name (Key)** | **Setting Impact & Description** |
| :--- | :--- |
| `AmmoID` | **Core Link Point**: Specifies the bullet type contained in this ammo box. Must exactly match the underlying Ammunition file name (e.g., `"Ammunition_AC20"`). **Must not be entered incorrectly, otherwise the weapon will show no ammunition.** |
| `Capacity` | **Ammunition Capacity**: Total firing times provided by this ammo box. For example, setting it to `100` means this box allows a weapon consuming 1 ammo per shot to fire 100 times. |
| `ComponentType` | **Main Component Classification**: Must be set to `"AmmunitionBox"`. Tells the system to judge it as an ammo container rather than a weapon or heat sink. |
| `ComponentSubType` | **Sub-Component Classification**: Must be set to `"Ammunition"`. |
| `InventorySize` | **Slots Occupied**: Space occupied in a Mech location (such as legs, torso). Factory ammo typically occupies 1 slot. |
| `Tonnage` | **Equipment Weight (Tons)**: Consumes part of the Mech's total weight allowance. Factory ammo is typically 1 ton. |
| `Description.Id` | **Object ID**: Must be exactly identical to the JSON file name of this ammo box. |

## 3. Ammunition Core Parameter Dictionary (Advanced)

If you want to create special bullets (e.g., high-explosive incendiary rounds that increase heat upon hit, or depleted uranium armor-piercing rounds with higher damage), you need to create a brand-new `Ammunition` JSON file and point the ammo box's `AmmoID` to it.

_File Example: You can copy the factory `Ammunition_AC20.json` to modify._

| **Parameter Name (Key)** | **Setting Impact & Description** |
| :--- | :--- |
| `AmmoCategory` | **Ammunition Caliber Category**: Must match the weapon's `AmmoCategory` (e.g., `"AC20"`). Tells the system who this bullet is for. |
| `WeaponEffectID` | **Exclusive Visual Effects**: Optional. If this is a special bullet, you can specify different firing visual effects or tracer colors. |
| `HeatGeneratedModifier` | **Heat Generation Modifier**: Alters heat generated when firing this ammo. For example, `1.2` means weapon heat increases by 20% when firing this ammo. |
| `ArmorDamageModifier` | **Armor Damage Modifier**: Alters destructive power against armor. For example, `1.5` means 1.5x extra damage dealt to enemy armor. |
| `ISDamageModifier` | **Internal Structure Damage Modifier**: Alters destructive power against unarmored parts (Internal Structure). For example, `2.0` means extremely easy to destroy internal Mech components. |
| `InstabilityModifier` | **Instability Modifier**: Alters the multiplier for reducing target stability upon hit. |
