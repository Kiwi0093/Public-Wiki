> This article compiles the definitions and actual impacts of various parameters in PC game **BattleTech** weapon and equipment JSON files, categorized into four main groups.

## 1. Base Weapon Stats

Controls the weapon's hardware classification, range, and operational basis.

| **Parameter Name (Key)** | **Setting Impact & Description** |
|---|---|
| `Category` | Major weapon category: e.g., `Ballistic`, `Energy`, `Missile`. Determines the Mech hardpoints applicable to the weapon. |
| `Type` | Weapon type: e.g., `Autocannon`, `Laser`, used for internal system logic identification. |
| `WeaponSubType` | Weapon sub-type: e.g., `UAC20`, further subdividing types, affecting ammo bin matching and pilot skill bonuses. |
| `RangeSplit` | Range thresholds: Formatted as `[Short, Medium, Long]`. Defines hit rate reduction determination points across different distance intervals. |
| `AmmoCategory` | Ammo category: e.g., `AC20`. The Mech must have the corresponding category of ammunition box installed to fire. |
| `HeatGenerated` | Heat generated per firing: Increases the Mech's heat level each time it fires. |

## 2. Damage & Combat Mechanics

Defines destructive power and supplemental combat effects caused when weapons fire.

| **Parameter Name (Key)** | **Setting Impact & Description** |
|---|---|
| `Damage` | Base damage per single shot: Armor or internal structure value deducted when each ammunition round/beam hits. |
| `ShotsWhenFired` | Shots fired: Number of shots fired in a single attack command. Total damage = Base damage × Shots fired (if `ProjectilesPerShot > 1`, total damage is `Damage × ShotsWhenFired × ProjectilesPerShot`). |
| `ProjectilesPerShot` | Projectiles per shot: For scatter weapons (LBX) or missiles, how many independently calculated hitting projectiles a single ammo round splits into. |
| `Instability` | Stability damage: Deducts target stability upon hit. Accumulating enough leads to enemy Mech knockdown. |
| `AccuracyModifier` | Accuracy modifier: **Negative values** represent increased accuracy, positive values represent decreased accuracy. |
| `AttackRecoil` | Attack recoil: Hit penalty generated from continuous-round firing (UAC category is usually set higher). |
| `IndirectFireCapable` | Indirect fire capability: Boolean (`true`/`false`). Whether it can attack across obstacles ignoring Line of Sight (LoS). |

## 3. Mech Specs

Defines space occupancy and installation restrictions in the refit screen.

| **Parameter Name (Key)** | **Setting Impact & Description** |
|---|---|
| `InventorySize` | Critical Slots: The amount of space occupied when installed in a Mech body part. |
| `Tonnage` | Equipment weight (tons): Occupies quota of the Mech's total weight capacity. |
| `AllowedLocations` | Allowed mounting locations: `All` means installable on the entire machine; can also restrict to e.g., `MechHead`. |

## 4. UI & Description

| **Parameter Name (Key)** | **Setting Impact & Description** |
|---|---|
| `Description.Id` | **Most core parameter**. Must match the JSON filename exactly. |
| `BonusValueA / B` | Special effect hint: Green bonus text (e.g., `+ 50 Dmg.`). _Note: This is strictly a UI string; actual effects must be modified in Damage or statusEffects._ |
| `ComponentTags` | Component tags: Affects store generation. Tagging `BLACKLISTED` prevents it from appearing in stores or salvage. |
