# OS Installation

I used to put quite a few installation scripts on my wiki, but this time I realized a lot of them aren't needed anymore (or don't need to be written like that).

## Archlinux

Ever since `Archlinux` introduced the `archinstall` automated install script.. I haven't needed to write my own Archlinux install scripts anymore (of course, if you need to deploy many hosts with specialized configs you still can...). Mainly, Docker is so convenient now that I don't need so many VMs running individual Archlinux hosts, so the ROI of writing automated install scripts has dropped dramatically...

## Windows

Ever since Windows 10, installing Windows hasn't taken much time or effort anyway. Now, possibly because it's leaning closer to Linux (not sure if that's the reason), Windows's CLI tools have gotten pretty nice too. So nowadays I install apps directly with `winget`—not because it's cooler, just because apps installed via winget can easily be updated with `winget`.

```bash
# Search for app XXX
winget search XXX

# Install app XXX
winget install XXX

# Uninstall app XXX
winget uninstall XXX

# Update all apps
winget update --all
```

## PhotonOS

There's really nothing special to configure for this. For version 5.0 that I installed this time, as long as the initial IP setup is fine, at most you just

add the NFS folder to mount in `/etc/fstab`, remember to install `docker-compose` (now you can just install it via `yum install docker-compose`), and run `systemctl enable docker.service` plus `systemctl enable remote-fs.target` so the machine starts Docker and mounts the NFS folder automatically on boot.

### Docker

After testing, no matter how I tried, `nfs-volume` still kept failing on me. So for now I'm sticking to the old-school method: creating Docker volumes locally and using a script to automatically back them up to the NFS folder, which is simpler.
