# What Happened

Actually, what happened is pretty simple: after my PhotonOS rebooted, I noticed the forum wouldn't start up properly. Looking closer, the Docker volume mapping had failed. On top of just rebooting,

because the original config didn't have a restart policy set and it didn't come back up automatically after the reboot, my itchy fingers ran `docker-compose up -d`.

And then Docker very smoothly went ahead and recreated the container for me....

And then all the data was gone and blown up.....

# Root Cause

The post-mortem investigation result left me completely speechless, pasted below:

## Excerpt from my original docker-compose.yml

```yaml
...    
    volumes:
      - /var/lib/docker/volumes/phpbb/mariadb:/bitnami/mariadb'
...
```

## Excerpt from my fixed, working docker-compose.yml

```yaml
...    
    volumes:
      - /var/lib/docker/volumes/phpbb/mariadb:/bitnami/mariadb
...
```

See it? All because of one single `'` character....
