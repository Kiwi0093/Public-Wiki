# Introduction

For security reasons, starting August 13 of this year, GitHub no longer accepts logging in via HTTPS with a username and password...

For details, please see [this article](https://github.blog/2020-12-15-token-authentication-requirements-for-git-operations/)

<!--truncate-->

## Changing the Login Method

Maybe because I found setting up SSH keys and all that too tedious, I had always been using a username/password to update my Blog/Wiki

And today it finally broke

## Token

Using a token isn't really a big deal—after all, pico also uses a token to upload...

But in order to use a token, I now have to switch both my Blog and Wiki to Private to prevent the data written in _config.yml from leaking out...

What a hassle....
