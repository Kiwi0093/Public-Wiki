# A Certain Magical Project

## Origin

This whole thing started when the boss assigned me to support the IT department on a certain project (company confidential, so no details..).

The key point is that my assigned role was to act as the project's PM, except a meddlesome guy like me... still stuck his hands into the project's server architecture anyway....

## The Main Offense

Because this project needed `SQL-Server + JDK environment + Samba` on the company side,

right as our IT team was about to wheel out their heirloom Windows Server to handle everything, I ran my mouth and dropped:

`Couldn't all of this be done directly with Penguins + Containers, and be easier to back up too?`

And because my show-off personality had already bragged about my home setup to the IT folks before... I got hit with:

`We think so too, except we don't know how—could you help get the environment up and running?`

## Result

### Amazon Linux 2

Since this machine will eventually run directly on AWS... the Linux distro was locked to Amazon Linux.

I have to say, testing this thing locally on VMware Workstation is a real buzzkill....

Installing it is fussy and annoying (well, maybe not actually that hard—mostly my own lack of skill where a single network config nearly killed me).

Once installed, using it actually feels very similar to `Oracle Linux` (obviously—they're practically forked from the exact same upstream...).

### MS SQL-Server on Docker

Credit to M$ for being generous enough to provide an official Docker image for SQL-Server 2019, so all I had to do was install it...

(Yep, what I call "development" was just cranking out a working `docker-compose.yml` and calling it a day.)
