### Upgrade Details

Put simply, the workflow is:

* Stop and disable the service in systemd
* Use `rm` to wipe out the previously installed binaries and related files
* Use `mv` to move the config file from the old default */etc/v2ray/* to */usr/local/etc/v2ray/*. As for why they changed the path? I guess maybe ~~they were charmed by FreeBSD~~ they wanted to separate v2ray configs from the system's main config directory
* Install using the new script (if you don't want to change the default path, you'd have to manually edit the script, which makes putting it in crontab a pain~~)
* Enable `v2ray.service`
* Start `V2ray.service` and call it a day

If you want to switch to **VLESS**, you just add the v2ray account configuration, handle the certbot keys (or generate keys another way, though I don't know how yet), and finally update `config.json`.

The detailed steps are pretty clearly documented in the [official documentation](https://github.com/v2fly/fhs-install-v2ray/wiki/Migrate-from-the-old-script-to-this).

#### If your server runs Arch Linux....

Then all it takes is one line:

```bash
pacman -Syu
```

And your V2ray upgrades to the latest version.... zero drama.. super effortless....

I really hate how VPS providers never offer Arch as a default OS option... so annoying.

## Client Selection

As for clients, honestly the one I use most heavily is V2ray on Arch Linux—best compatibility (since it's the exact same binary as the server) and high stability. Still, as mentioned before, other clients need to be considered too.

#### Android

Lately I've really taken a liking to **V2RayNG**, though it's also the only client I ran into where the 4.33 core couldn't connect to a 4.23 server.... Between the previous release (1.33) and the newly updated version, there's a real difference in VLESS support and speed. In the future, whenever the server's V2Ray-Core gets upgraded, we might have to upgrade this immediately too for things to stay smooth..... (I hope it won't be like that...)

#### Windows

Since I use QV2Ray + V2Ray-Core on Linux Desktop, it works smoothly with no issues. On Windows, I ~~have to switch to something else~~ just use QV2ray as well... (this thing is cross-platform.. works on Windows/Linux/macOS).

Download links: [QV2Ray](https://github.com/Qv2ray/Qv2ray/releases), paired with [V2Ray-Core](https://github.com/v2fly/v2ray-core/releases).
