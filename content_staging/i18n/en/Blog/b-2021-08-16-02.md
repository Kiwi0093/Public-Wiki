# Annoyance B - Automated Media Stack

## Backstory

I saw an awesome automated media-bingeing stack on some blog, so I wanted to build one myself... and then... and then everything blew up.

## Docker Network

For some reason when I spun up Emby, its default network was `192.168.0.0/16`, which collided directly with my internal network architecture... For a moment I freaked out thinking I had completely broken my `pf` config.... So I had to tear down a bunch of containers just to pinpoint where the issue was.... Afterward I went and learned how Docker container network configs are actually written.

## RAM & Disk....

This one really was....

Simply put, I was way too naive before... How could anything video-related possibly run smoothly on tiny RAM and a barely-there disk space?!

The bottom line was my PhotonOS had too little RAM and not enough default disk, and then I botched the online disk expansion.

So Saturday became a full reinstall....

## Reinstalling PhotonOS
