## Recent Updates

Lately I've basically been a couch potato. After returning to Taiwan and facing the baptism of raising kids, I basically have zero time to spend tons of hours playing with new toys like before (actually, it's also because at work I have to work seriously instead of writing blog posts on the clock like I used to....).

### Server

Since I'm back in Taiwan, my focus naturally shifted from ~~wall-hopping~~ "scientific internet access" back in Suzhou to focusing purely on the services themselves without having to worry about the network environment. Consequently, the server OS naturally switched back from Arch Linux—which is friendly to bypass tools—to FreeBSD, which I've used for ages but was a nightmare to deal with over on the mainland.

##### Server OS

There's still a bit of a transition period, though when reinstalling I noticed it really is way easier to set up than Arch.

Just boot from the disc, pick the items you want to install, and basically without needing to use your brain at all, you can finish the installation in no time.

Then just drop the old server's config files back in:

* /etc/rc.conf
* /usr/local/etc/screenrc
* /etc/csh.cshrc
* /etc/pf.conf
* /etc/ipfw.conf

Put them back and reboot.... done.... seriously way too easy.

##### ESXi

Due to certain issues (yep, those twice-a-week power outages), one of my ESXi servers died...

Fortunately, because that machine had ESXi installed on a USB drive, I was able to reinstall it and get it back up and running very quickly.

This time I chose to switch from ESXi 5.1 to the ESXi 6.5U2 custom ISO for HPE (since my Gen8 can only run up to the 6.5 pre-Gen9 ISO).

The best part after switching is that I finally don't need to install a separate client anymore. Since the old vSphere Client only supported up to 6.0 and I couldn't find the installer anyway, I switched over to the HTML5 web client, which actually works pretty nicely.

However, if you don't get passthrough configured right on the first try, you'll run into trouble... and have to reinstall (since I don't have the desktop client to modify it).

Cost me a whole morning....
