# Useful Tools - Android Related

Most of these were also things I saw on Ivon's Blog and decided to try out... So I won't write too much, just list a few that I actually find useful.

### Obtainium

This app that can automatically check and update APKs installed from GitHub is seriously awesome... If they ever release a Windows version I'd definitely install it...
(Wait, don't you already use `Winget`?)

### Innertune & Pipepipe

Both of these are basically ad-free YouTube clients—one for watching videos, and the other for listening to YouTube Music...
Although my inner data hoarder usually tries to save everything somewhere I control and stream it myself, for the few things I want to listen to without hoarding a giant collection, this is super handy (for example, I really like Simyee's Cantonese cover of *Blue and White Porcelain*, even though I don't collect Chinese songs...).

### Pairdrop

This one is genuinely great... It's basically an open-source AirDrop... I also tried self-hosting it `via docker` though I didn't get it working properly yet, so I'm using the official service for now and will tinker with it again later.
