# V2Ray on Cloudflare

After leaving China, I haven't spent much effort or skill points on anti-censorship wall-circumvention tools anymore...
However, while watching YouTube last time, I discovered that you can set up a serverless V2Ray server using free `Cloudflare Workers`, and it even comes with multiple IPs that can be refreshed and changed...
I can only say it is truly a blessing...

## Edgetunnel

[Edgetunnel from cmliu](https://github.com/cmliu/edgetunnel)

Actually, the moment I found this project, 90% of the setup was already done. The remaining part is having a `Cloudflare` account—though you might not even need one since CF Workers automatically generate a URL like `worker_name.User_name.workers.dev` for you. However... as someone who has previously set up V2Ray WebSockets over TLS myself, hosting on a custom domain under CF can be considered a standard setup... so none of these should be an issue, unless someone starts completely from scratch with nothing at all, in which case they might really need to put in some effort to get a domain...

Next, just create a free Worker project, paste the code from GitHub into the Worker editor, ~~go to an [online UUID generator](https://www.uuidgenerator.net/) to get a pleasing UUID~~ put any arbitrary string as a token into the 4th line `let userID = '<uuid you like>';`, and deploy it.

Then go to the Worker's Settings -> Domains and Routes to configure your domain, or resign yourself to using the `workers.dev` link (though I only tested that it connects; not sure what might happen if actually used), and visit `https://your.domain.or.workers.dev/UUID` to see a screen similar to the one below:

![](https://raw.githubusercontent.com/Kiwi0093/graph/master/img/螢幕擷取畫面%202025-01-03%20171436.png)

## Client

### Windows

Basically `V2RayN` works. Just import the subscription group, refresh, and you're good to go.

### Android

Unfortunately, `V2RayNG` does not support group subscription features, so I had to test [ClashMeta for Android](https://github.com/MetaCubeX/ClashMetaForAndroid) instead. I installed it directly from GitHub using `Obtainium`...
Detailed configuration methods... too lazy to write them out. Basically anyone who knows how to use `V2RayNG` will know how to configure it themselves from a subscription URL, just by filling in `https://your.domain.or.workers.dev/UUID` into the URL field.....
