# WFH = \ = WTF

Since I've been working from home lately, I can spend a bit of time pretending to work while actually messing around with some fun toys.

So I went ahead and tidied up my home server even further (previously it was just an emergency recovery; now it's entertainment disguised as expansion).

<!--truncate-->

## Tmux

Honestly, I discovered this thing while watching YouTube (see how slacker I am—I had to browse YouTube just to learn `tmux` exists).

Now it has become part of my standard setup (replacing `screen`).

This thing supports powerline, though it's pretty pointless since powerline only really works in an X environment (at least I haven't found a way for the console to render the relevant fonts properly).

Still, even saying that, its features are slightly stronger than `screen`, so I've started transitioning over to `tmux`.

## Nextcloud

This one is a bit of reheating old leftovers... I actually played with it back when I was in Suzhou, though it wasn't very usable at the time (honestly, it hasn't gotten much better now either...).

However, this time I did find Nextcloud Apps rather interesting.

#### Nextcloud Music

The basic feature of this app is that you can play music in a Nextcloud folder directly from a web browser, and after building it into a media library, you can stream it out as well.

Paired with Subsonic-series apps (like [Ultrasonic](https://play.google.com/store/apps/details?id=org.moire.ultrasonic&hl=zh_TW&gl=US)), it can stream playback and even supports album covers and such—making it a media server you can use even without Emby.

(Though if this turns out to be the only useful feature left, I'll probably still go find another streaming server to use.)

#### Nextcloud Deck

This is a Kanban/Deck app. Truth be told, I only use it because there isn't really a Google alternative (actually, I just wanted a free Milanote to use...).

## Docker

This isn't unfamiliar either, though honestly I never spent time properly using Docker because I've always just spun up VMs directly on VMware ESXi, rarely running multiple Docker containers on a single machine.

But Docker is getting more and more convenient these days—for many things you can just grab an image and spin it up, saving the hassle of installation and configuration.

#### [Webtop](https://docs.linuxserver.io/images/docker-webtop)

Honestly, this is something that looks cool and sounds cool, yet when it comes to actually using it I really can't think of a use case....

Put simply, it lets you run a desktop environment remotely through a browser. Currently it supports Alpine/Ubuntu with Xfce/KDE/MATE/IceWM/i3/Openbox (no Manjaro, which I like... =-=!!).

Sounds pretty nice, right? Wait—if you already have a browser to use, that means you're already in a GUI environment, and you're opening *another* DE inside it... Aside from setting it up so a locked-down company computer can escape through a browser to breathe the air of freedom, I really can't think of what else it's good for.
