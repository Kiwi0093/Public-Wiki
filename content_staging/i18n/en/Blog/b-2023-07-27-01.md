## WSL

### Dilemma

This Windows installation is super weird—I actually couldn't install the new version of WSL from anywhere... it kept throwing `error code  0x80070490`.
Running `wsl --update` just told me element not found....
The price of that is... WSL Distros can't properly use `systemd` (which is absurd, since one of Windows 11's selling points is built-in `systemd` support in the new WSL).

### Workaround and Result

I basically switched to [ArchWSL2 from Sileshn](https://github.com/sileshn/ArchWSL2) because that version is actively maintained...
As for the systemd issue, the only reason I actually needed systemd inside WSL was for `systemd-resolved.service` for `Wireguard`, so switching `resolvconf` to `oopenresolv` solved it.

### Little Discovery

I really love the default customized zsh theme in `Manjaro KDE`. Previously I always copied the customization files directly from `/usr/share/zsh/`, until I recently discovered that `AUR` actually has `manjaro-zsh-config`. After installing it, you just need to make sure `~/.zshrc` has the right contents. The only minor downside is that its console color is `Manjaro green` instead of `Arch blue`.
