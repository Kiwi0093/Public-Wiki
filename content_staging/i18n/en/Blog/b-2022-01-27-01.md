# Preface

After a recent system update, I suddenly noticed a "BUY License" prompt popping up whenever I used Typora... After looking into it, I found out Typora is going paid...

<!--truncate-->

# Free Alternatives

### MarkText

* Marktext - [Hompage](https://marktext.app/) , [Github]([GitHub - marktext/marktext: 📝A simple and elegant markdown editor, available for Linux, macOS and Windows.](https://github.com/marktext/marktext))

This is an MIT-licensed Markdown editor. In fact, this article is already being written with it.

## Differences from Typora

* Different hotkeys
  
  I was used to Typora's `ctl+/` to toggle between source code mode and preview mode. Here the default is changed to `alt+ctrl+s`, which takes some getting used to.

* Interface changes
  
  That's understandable, though the biggest issue is its borderless design and the lack of a hotkey to zoom in—the editing area looks pretty small, so I'll need to get used to it.

* Built-in GitHub image uploader
  
  This is genuinely generous. Previously Typora relied on PicGo (`pico-go`) to upload images; having this as a built-in feature is really nice, and it only needs a GitHub repo token.

# Conclusion

There's definitely an awkward adjustment period when switching software, but compared to paying 14.9 USD, my stingy nature will probably drive me to get used to this editor very quickly.
