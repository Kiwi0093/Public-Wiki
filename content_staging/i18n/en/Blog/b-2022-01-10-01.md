# Preface

While browsing around casually, I noticed Oracle has an Always Free Cloud tier, so on an impulse I signed up.

[Oracle Cloud](https://www.oracle.com/cloud/)

<!--truncate-->

# Basic Overview

The free tier comes with a huge pile of DB-related services (classic Oracle) that I have no use for. For me, only the following perks are really useful:

* You can create two VMs - the free OS options are only Ubuntu/CentOS/Oracle Linux.. (no Arch-based distros and no Debian...)
* An outdated CPU + 1GB RAM
* 486Mb/s network with unlimited bandwidth
* Supposedly 100GB of storage combined across the two

# Current Usage

Honestly, something like this is great for setting up a proxy/tunnel (as long as the direct connection speed from behind the firewall is good enough...), though this time I prioritized running Calibre-Web on it because I noticed there are actually quite a few light novel fans at my company too.

So it felt more practical to spin up an e-book library for everyone to use (of course, I'll probably also put V2Ray on the same machine later on).

# Service Stack

* Basic OS - Ubuntu 21.0 mini
* Docker Conainers
  * Traefik  - Proxy/Redirect
  * Portainer - Docker GUI
  * watchtower - Auto Updater
  * Calibre-web - Ebook library 

# Conclusion

Aside from the otaku-friendly utility mentioned above, what's actually even more important is using this to practice working with Traefik. From the looks of it, the next major overhaul of my home setup will probably replace my current Nginx Proxy Manager with Traefik—after all, it's awesome that it doesn't even require port mapping.
