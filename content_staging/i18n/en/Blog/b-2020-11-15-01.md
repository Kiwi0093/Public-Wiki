Originally, I wanted to use some Markdown note-taking software, such as [Obsidian](https://obsidian.md/), to take fragmented notes for collecting and organizing new things and new approaches I encounter later on.

<!--truncate-->

However, after browsing around for a while, I felt that rather than using a local note-taking app, it would be better to build it in the form of a Wiki so I can easily look things up myself. As I kept exploring, I decided to switch my existing Hugo + GitHub Pages setup to Hexo + GitHub Pages paired with two different themes to create a new Blog + Wiki website.

I'm using GitHub Desktop so that Blog/Wiki articles can be conveniently synced and version-controlled through GitHub to achieve the desired workflow. For the detailed setup, you can refer to the already written <span style="color:#e06c75"><del>[Wiki entry](https://kiwi0093.github.io/Wiki-site/wiki/Network/Hexo/1-introduce/)</del></span> *(Updated 2026-11-27: [Wiki entry](https://blog.kiwireich.com/docs/HomeLab/Network/Archive/w-0077))*.

Next, I'll probably set up a web page clipping/recording feature to save things I come across, and slowly get used to writing short, fragmented Markdown posts to build a personal knowledge base of my own.
