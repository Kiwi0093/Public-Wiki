# The Game Itself

Actually, I haven't even reached Chapter 2 yet—after all, I only get to play in short bursts at night after the kids fall asleep, connecting to my GL-73 via Moonlight. Still, you can tell this installment feels much more like a complete game compared to the previous *Pathfinder: Kingmaker*. As for the story so far, even though it's a classic heroic tale, it's relatively dark... feels pretty great.

# Moonlight

It's actually very useful, though it still has the following issues:

* Insufficient frame smoothness
* Needs `MSTSC.EXE` to simulate a desktop to work properly
* Colors sometimes look weird and require reconnecting

First, regarding the frame smoothness issue: my test environment uses a 1Gb wired home network, configured at around 20M bitrate with 1080p 30fps, yet it still feels stuttery at times...

Not sure where the bottleneck is.

Next is desktop simulation: this is mainly because Steam Big Picture isn't very smooth, so I have to launch it this way. Honestly, I could also just launch the game directly, but since I need to do desktop tasks like browsing Nexus Mods, using the desktop directly is still more convenient (maybe in the future if I really stream from a TV box, I'll handle it differently).

Finally, the color issue: there's no real fix for this either—I don't know which setting needs tweaking—but reconnecting fixes it, so it doesn't really matter.

After listing the issues, I still have to praise it: even with Intel integrated graphics, it plays smoothly... (So far in testing, only VMs on ESXi can't run smoothly, because they lack basic VP9 or HEVC support...)

# Heavy Modding

Okay, I admit the real reason my progress is so slow is that I keep restarting and heavily modding the game....

The mod selection isn't as rich as *Kingmaker* yet (though most of the essential ones are already out). Since there are already plenty of classes, I've only seen one Class Mod so far, though I imagine more and more will appear later, including mods for other rideable mounts and such.

However, there is something I already modded back in my *Kingmaker* days—making a follower with a mercenary's appearance (basically treating a humanoid as an animal companion).

I figured out how to mod that this time too.... See my Wiki for details.

I guess that's about it.... I'll finish playing through it whenever I have time later....
