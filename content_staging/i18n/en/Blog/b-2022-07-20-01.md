# Introduction

Because of annoying ads... I set up AdGuard at home, but for the past few days, for some reason, my home internal network has been failing because DNS went down....

<!--truncate-->

# Simple Debugging

This section is basically nonsense..

Seeing a DNS error whenever there's no internet connection.... it's definitely something fishy with DNS.

# Workaround

Currently, I pointed the DNS specified in DHCPd to another dnsmasq instance (since I need to map a bunch of internal DN services). And, lo and behold, it worked like magic—the home network is super smooth now (except for seeing ads).

# Root Cause Analysis

* AdGuard is running normally

* The disconnections are intermittent

* The same machine is also running `tdarr`

My guess (the irresponsible version with no evidence) is that the machine is overloaded, causing AdGuard to hang on by a thread and trigger the issue...

# Conclusion...

Buy a new server, a beefier one.. (just kidding)

In the future, I'll probably need more Docker hosts to split up resources and ensure core backbone services have enough resources to run.
