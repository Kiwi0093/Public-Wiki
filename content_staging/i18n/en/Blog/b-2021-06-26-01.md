# Upgrading ESXi

## References

This upgrade mainly referenced [Master's experience](https://roidintw.kaienroid.com/2020/09/vmware-esxi-upgrade-from-60-to-65-with.html).

Though he lived dangerously and ran it without entering maintenance mode—I at least entered maintenance mode before executing it.

## Getting the Files

First, log into your My VMware account and look for the VMware vSphere Hypervisor download. Although 6.X currently has 6.7 out, all I saw were ISOs, so I just downloaded the 6.5 **VMware vSphere Hypervisor (ESXi) Offline Bundle**.

It's a zip file; once downloaded, just drop it into ESXi's datastore.

## Upgrade Sequence

### Maintenance Mode

This part is easy: connect to ESXi using the existing client and select Maintenance Mode.

### Verify File Location

Use PuTTY to SSH into your ESXi host:

```bash
ls /vmfs/volume/
```

You'll see your datastore, and the ZIP file you just uploaded will be inside.

### Verify the Profile Image

```bash
esxcli software sources profile list -d /vmfs/volumes/$(your_volume)/$(your_file.zip)
```

This lets you see its profile image.

### Upgrade

```bash
esxcli software profile update -d /vmfs/volumes/$(your_volume)/$(your_file.zip) -p $(profile-image)
```

It will start installing a bunch of VIBs and then prompt for a reboot (this part is annoying because its shell wouldn't accept `reboot` or `shutdown` commands, so I went to the client UI and clicked Reboot Host).

### After the Upgrade Reboot

Log in through the web interface instead, remember to exit Maintenance Mode, and then power back on whichever VMs need to be running.
