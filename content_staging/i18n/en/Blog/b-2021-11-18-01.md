# Basic Architecture

This has probably been explained in many places already: Traefik is a great tool that ~~automatically~~ relies on Label definitions in `Docker-compose.yml` to automatically generate the corresponding Virtual Host for each container.

# Comparison with Nginx Proxy Manager

1. NPM is ultimately just a proxy—you still have to expose/map the container ports yourself.
2. NPM's SSL certificates are stored in `/etc/letscrypt` just like Certbot, whereas Traefik stores them directly inside `ACME.json` in a different format.
3. NPM is more intuitive to operate, while Traefik requires understanding `Docker-compose.yml` label definitions.

# Results

Honestly, it's quite nice. You don't need to define ports or anything like that—basically you just define your Hostname in `docker-compose.yml` and it automatically generates everything.

It's very suitable for people who want a fully automated migration.

Although there are also features like load balancing, I don't need them yet, so....

# Drawbacks

When using Traefik, you basically don't use your main domain directly; instead, you isolate every container by assigning subdomains.
