## [Phoenix OS](http://www.phoenixos.com/)

This is a Chinese-customized Android system based on [Android X86](https://www.android-x86.org/)

Its highlights include a UI tailored for PC environments, wired Ethernet support, and a default installation method that lets you use an `.exe` file directly under Windows to set up a dual-boot



## Conclusion

#### Day 1 

* Even when forcing USB boot on the ASUS T100, it just stops at

  ```bash
  grub>
  ```

  At this point you have to manually type this to boot

  ```bash
  configfile /efi/boot/grub.cfg
  ```

* If you choose install, the keyboard stops working as soon as it enters the HDD selection screen.. so you can't proceed to the next step
* If you try using the `.exe` installer inside Windows instead, no matter how you run it, it always fails to install...

#### Day 2

After tinkering for a whole day, I finally discovered that the T100 is actually an odd relic of a bygone era that boots with 32-bit UEFI...

Because of this, I had to go redownload and make a 32-bit Windows 10 installation USB to reinstall the OS I had messed up

Then I downloaded the 32-bit version of Phoenix OS (based on Android 5)

After reinstalling Windows 10 and running the `.exe` installer, pressing `esc` at boot brings up the menu where selecting Phoenix OS boots right into the newly installed Phoenix OS

What? You ask why not just use the x86 ISO to install Phoenix OS by itself?

I wanted to, too, but the darn keyboard still wouldn't work~~~~
