# The Beginning

Actually it wasn't entirely because of G-Suite; it was mainly that I was wondering whether I should further integrate and upgrade the services I host at home in the future, so I gave OnlyOffice Workspace a try. Turns out it was quite a hassle.

# OnlyOffice Workspace

## Overview

It's basically a free version of Office 365. Workspace includes:

* Mail
  
  * Web Client
  
  * SMTP server
  
  * Custom Domain

* Document
  
  * Word
  
  * Excel
  
  * PowerPoint

* Project
  
  * Task
  
  * Gantt chart

* CRM

* People

* Calendar

## Docker-compose

Unsurprisingly, this is also installed using `docker-compose`. As usual, I'll put the detailed steps on the Wiki.

However, there's a big gap in this installation setup.

Unlike other Docker setups, its SQL initialization scripts and MySQL configs aren't baked into the image—you have to add them manually beforehand. Because of that, there were tons of issues right from the start.

## Server Resources

Even though it stated the requirements right at the beginning, I foolishly tried running it first on my low-resource Oracle Cloud instance. The result was that it completely exhausted system resources and still couldn't start.... Later I could only recover by rebooting and frantically killing the containers during the brief window while the system was still responsive... before things went back to normal...

Afterward, running it on my machine at home, it definitely does consume quite a bit of resources (though my binge-watching stack already takes up a good chunk of RAM—around 60% RAM usage), yet it's still within a workable range.
