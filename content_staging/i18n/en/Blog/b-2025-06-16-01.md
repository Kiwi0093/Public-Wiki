# The Crash

I used to see people say that if you use Arch Linux, you need to be mentally prepared for it to randomly die after an update. Having used it for nearly 10 years (Wait!! Am I really that old already? I started using it in 2015...), honestly, I had never once experienced a crash from an update, so I had a hard time understanding why anyone would refuse to update just to avoid breaking things....

Until last week, when I casually hit my remote desktop with a `yay -Syu --noconfirm` and then discovered... there was no "then". The machine looked powered on, yet remote connections failed. I went into ESXi to check the Console and it was a completely black screen.... It... bricked..

# Root Cause

How would I know what the root cause is... I don't even know how to code..

However, I ran the following tests:

* Installed Manjaro with sddm + KDE plasma - Works normally
* Installed EndeavourOS with KDE - LiveDVD boots, but black screen after a fresh install
* Re-install
	* Tried options like `linux-6.14`, `linux-lts-6.12`, etc., and it still booted to a black screen after installation and reboot
    * Switched to gdm + KDE Plasma - Works, though inside ESXi only Wayland works normally

And all of these issues also occurred when tested under VMWare Workstation 17 Pro....

## Suspected Causes

1. sddm does not get along with VMware—aside from Manjaro, anything using sddm gives a black screen on boot
2. X11 does not get along with gdm—even though using gdm shows a display, trying to log into a plasma-x11 session runs into issues

Based on the two points above, ~~Broadcom forgot to pray to the gods~~ VMware has been disliked by everyone ever since its change of ownership...

# Conclusion

My current setup is `gdm+KDE Plasma`, but because wayland-plasma doesn't support VNC and this machine is mainly used as my `VDI`, I used `systemd` to run `vncserver@:1.service` so the machine starts a plasma-x11 session over VNC on boot.
So far it hasn't had any issues, though it looks like I'll eventually have to migrate from ESXi to PVE.

On a side note, this incident didn't affect my other console-only Arch Linux machines, so strictly speaking it doesn't really count as Arch Linux bricking. Great!! My confidence in Arch Linux didn't drop—it actually went up (wait, what??)
