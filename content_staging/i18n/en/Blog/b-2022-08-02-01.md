# Preface

I've long had the habit of using `calibre` + the `kindle app` to read e-books <ruby><font color="lightblue"><del>freely provided by kind souls</del></font><rp>(</rp><rt><font color="red">freeloaded</font></rt><rp>)</rp></ruby>. A while ago, Amazon announced that the long-standing `mobi` format was being phased out in favor of `epub`...

<!--truncate-->

# Main Changes

I've always used `calibre-web` to <ruby><font color="lightblue"><del>manage</del></font><rp>(</rp><rt><font color="red">show off</font></rt><rp>)</rp></ruby> the e-books I have on hand. After checking, thankfully the newer version supports this feature.

So I happily swapped out the image... (Besides, the converter bundled with the image I used before isn't needed under the new rules anyway, and I never even used it back in the old version...

## Calibre-web

```json
version: '3'
services:
  calibre-web:
    image: lscr.io/linuxserver/calibre-web:latest
    container_name: calibre-web
    environment:
      - PUID=1000
      - USE_CONFIG_DIR=true
      - OAUTHLIB_RELAX_TOKEN_SCOPE=1
      - DOCKER_MODS=linuxserver/calibre-web:calibre
    volumes:
      - /Books/lib/location:/books
      - /var/lib/docker/volumes/calibre/config:/config
    labels:
      traefik.enable: true
      traefik.http.routers.calibre-web.rule: Host(`$Your_Domain`)
      traefik.http.routers.calibre-web.tls: true
      traefik.http.routers.calibre-web.tls.certresolver: myresolver
    restart: unless-stopped
```

Yep, I switched to the more frequently updated image from `linuxserver.io`.

## Result

![](https://raw.githubusercontent.com/Kiwi0093/graph/master/img/calibre-web-epub.PNG)

Only one format shows up for me because I already cleared out all the `mobi` files; otherwise there would be a dropdown menu to pick from.

# Bonus Effect

Honestly, not needing two formats is great. Previously I had to convert downloaded books using desktop `calibre` and upload both formats to the server, taking up nearly double the storage.. Now it saves both effort and disk space.

Killing two birds with one stone—very nice.

# Conclusion

Actually, I don't really know what the difference is between `mobi` and `epub`... Still, unifying on a single format is definitely more convenient....
