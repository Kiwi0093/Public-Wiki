## All Complaints Below

* `https://raw.githubusercontent.com` is blocked

  I really want to curse... Putting things on GitHub was supposed to ensure that ~~the Great Firewall~~ the Celestial Empire wouldn't target GitHub, making it very convenient to use, but alas... the Celestial Empire still delivered a DNS pollution strike.. truly frustrating.

* `pacstrap /mnt base` did not install the kernel

  Looking at the new [Archlinux Installation Guide](https://wiki.archlinux.org/index.php/installation_guide), it says running `mkinitcpio` is not needed, which is true, ~~but it didn't mention that running `pacstrap` wouldn't conveniently install the kernel package along with it, so `mkinitcpio` naturally wouldn't run, and `grub-mkconfig` wouldn't build the boot menu either...~~ and booting turns into a tragedy....

* Correction: Well, I was just being blind. The latest Installation Guide explicitly requires:

  ```bash
  pacstrap /mnt base linux linux-firmware
  ```

  This was my own foolishness.. but I'm still going to complain anyway...

* `netctl` became something that needs to be installed separately

  Actually, I forgot whether it needed separate installation before. The original default network interface configuration instructions used `netctl`, but now it has changed to the `ip` command, though it can still be installed as a package and used.

* `pacman-mirrors` is surprisingly not an Arch Linux package

  Since I like using Manjaro for Linux Desktop, and Manjaro is almost identical to Arch Linux (well, aside from the logo, there are some differences), I didn't expect that following `yay`, there would be packages not found in Arch Linux... So during installation, I could only use `sed` commands to filter out desired locations in the mirrorlist... Let me check later if AUR supports installing it...

* Postscript: Checked Arch's AUR, `pacman-mirrors` is not in there... (crying)

## After the Complaints

Although I love Arch, thinking about it carefully, I actually love Manjaro....

I would probably only use Arch Linux on servers or gateways... though it seems possible to use Manjaro and directly install a GUI-less version for server use...

However, I am a bit picky, and my requirements for servers and desktops differ. Servers are best kept as clean and minimalist as possible, while desktops prioritize convenience as long as they remain within the Arch family...
