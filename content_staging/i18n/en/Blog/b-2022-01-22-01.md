# Preface

After experimenting with Traefik and other tools on another VPS recently, I felt that my existing home architecture wasn't that great, so I decided to reorganize the services currently running at home.

<!--truncate-->

# Original Architecture and Services

## Original Services

### Infrastructure

* Nginx Proxy Manager - Front-end reverse proxy server
* Mariadb - Primary DB
* Portainer - Docker Web GUI
* Watchtower - Tool for automatically updating Containers/Images

### Services
#### Basic Network Services
* Wireguard - VPN to Home
* Guacamole - Web terminal to Home
#### Multimedia Network Services
* Navidrome - Music Streaming
* Calibre-web - E-Book Library 
##### Binge-Watching Bundle
* qbittorent - Major BT downloader
* Emby - Media Front-end
* Sonarr - Automatic tool for Drama/Anime
* Radarr - Automatic tool for Movie
* Lidarr - Automatic tool for Music
* Chinesesubfinder - Automatic tool for Chinese Sub file
* Jackett - RSS feed interface
* Flaresovlerr - Tool for supporting Jackett
#### Others
* Librenms - Monitoring 
* phpBB - BBS
* Heimdall - Dashboard
