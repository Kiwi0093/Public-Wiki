# Preface

Recently I spent some time revisiting and digging into some fundamental tools.. I didn't expect `vim` to have such an awesome successor..

This `NeoVim` fork supports all kinds of plugins and features, and paired with the pre-built `NvChad`, it's basically insanely good.

<!--truncate-->

# NeoVim + NvChad

## Neovim

[Official Neovim Website](https://neovim.io/)

This thing is actually pretty much the same as Vim, except it supports `lua` configuration files and a huge variety of plugins.

Still, just for all the new tricks it supports, it's well worth replacing the `vim` I've been using for ages with it.

## NvChad

[NvChad · Neovim with lua is cool](https://nvchad.com/)

Honestly, this thing is ridiculously awesome....

By writing basic configurations in Lua for Vim plugins supported by Neovim, it transforms it into something that feels almost like a completely different editor (yep, you can basically make it look just like VS Code).

With your own customization, you can even use it to replace a markdown editor... (I even saw a corresponding plugin for picgo... it even has image hosting upload support... why would you even need any other editor...)

## Customization

To be honest, customizing this requires knowing a few things:

* Lua syntax

* How to install and configure Vim plugins

Basically, under the framework already set up by NvChad, you use its override mechanism to swap out certain definitions... (Of course, you can also fork its git repo and rewrite your own version from scratch...)

Right now, the only thing I've customized myself is the key mapping part (since the default ones were a bit sparse). Later on, I'll put it into my Ansible setup to apply it across all my clients.
