# はじめに

セキュリティ上の理由から、今年の8月13日より GitHub は HTTPS 経由でのユーザー名／パスワードによるログインを受け付けなくなりました……

詳細は[こちらの記事](https://github.blog/2020-12-15-token-authentication-requirements-for-git-operations/)をご覧ください。

<!--truncate-->

## ログイン方法の変更

SSH 方式だと SSH キーの作成などが必要で面倒だと感じていたため、これまでずっとアカウント／パスワード方式で自分の Blog/Wiki を更新してきました。

ところが、今日ついに動かなくなってしまいました。

## Token

トークンを使うこと自体は特に大したことではありません。なにしろ pico もアップロードにトークンを使っていますし……

ただ、トークンを使うにあたって、_config.yml に記載された情報が流出するのを防ぐため、今は Blog/Wiki をすべて Private に変更しなければならなくなりました……

本当に面倒くさい話です……
