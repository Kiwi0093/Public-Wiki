## [Phoenix OS](http://www.phoenixos.com/)

[Android X86](https://www.android-x86.org/) をベースに中国でカスタマイズされた Android OS です。

特徴は PC 環境向けに UI が調整されている点や、有線ネットワーク接続に対応している点、そして標準のインストール方法として Windows 上から exe ファイルを実行してそのままデュアルブート環境を構築できる仕組みが用意されている点です。



## 結論

#### Day 1 

* ASUS T100 では USB から強制ブートしても、以下の画面で止まってしまいます。

  ```bash
  grub>
  ```

  このとき、手動で以下のように入力しないと起動できません。

  ```bash
  configfile /efi/boot/grub.cfg
  ```

* インストールを選択して HDD 選択画面に入ると、キーボードが効かなくなり……次のステップへ進めません。
* Windows 画面から exe を使ってインストールする方法に切り替えても、どうやってもインストール失敗になります……。

#### Day 2

丸一日格闘してようやく判明したのですが、T100 は「32bit UEFI ブート」という、なんとも不思議な旧時代の代物だったのです……。

このため、やむなく Windows 10 の 32bit 版インストーラーをダウンロードしてインストール USB を作り直し、自分が壊してしまったシステムをリカバリしました。

そのうえで 32bit 版の Phoenix OS（Android 5 ベースのバージョン）をダウンロードしました。

Windows 10 を再インストールしてから exe でインストールを実行し、起動時に `esc` を押してブートメニューから Phoenix OS を選択すれば、新しく入れた Phoenix OS で起動できるようになりました。
