# メールアドレスの変更

## 最終期限

### G-Suite 無料版は 2022/6/30 をもって正式にサービス終了予定

## 影響

連携しているサービスは多いのですが、最も影響が大きいはずの銀行系はむしろ変更が一番簡単でした（結局は本人確認に紐づいているので、国が私のマイナンバー相当の身分証番号を変えない限り詰むことはありません）。

レンタルしている VPS のアカウントなどはどれも面倒ですが、ほとんどのサーバーはもう更新しないので実はそこまで困りません（というか変更し忘れているだけですが……）。ただし、以下を除いては……。

# Cloudflare

ひとまずアカウントのメールアドレス変更は完了し、別のメールアドレスで紐づけられるようにはなったのですが、その過程で対応する大量の SSL KEY 周りをやらかしてしまいました。

SSL key の自動アップデート機能はまさに諸刃の剣で、DNS 設定が整っていなかったドメインに対応する SSL key が一瞬で死んでしまいました……。解放されて再び使えるようになるまで 1 週間から 3 か月ほど待たないといけないようです……=_=!!

しかも、Proxy 機能を有効にしているドメインは階層が深すぎると問題が起きることにもちょうど気づいてしまい……こちらは現在、保留中の課題リスト行きです。

# Oracle Cloud

こればかりはどうにも変更できない悲劇です……パスワードを絶対に忘れないようにしながら使い続けるしかなさそうです……。

# Zoho Mail

代替手段として今のところ見つけられたのがこれで、独自ドメインが使えるメールサービスで、無料枠でも 5 アカウントまで利用できます……。

ただ、この無料プランがいつまで無料のままでいてくれるかは神のみぞ知る、といったところですが……。

# おわりに

ともあれ、まだ無料で使えるものがあるうちはそれを使っておき、本当にどうにもならなくなったら自分で Mail Server を立てるしかありません。幸い、今は Docker を使えば構築自体はとても手軽なので、あとはサーバーさえあればなんとかなりますね……。
