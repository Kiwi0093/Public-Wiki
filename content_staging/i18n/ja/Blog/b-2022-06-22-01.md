# はじめに

以前使っていた Typora が有料化したため、その後は TextMark を新しい Markdown Editor として使っていました。特に不満があったわけではありませんが、Obsidian でメモを取っている人を見かけて、私も一緒に乗り換えてみようかと思い立ちました。

<!--truncate-->

# 基本的な使い方

仕組みはとてもシンプルで、Obsidian はクロスプラットフォームのノートアプリなので、どの OS でもそのままインストールでき、既存のディレクトリを開いて現在の Git repo の場所を指定するだけで使えます。

# 感動した点

正直なところ……今のところはまだ見当たりません……おそらく一番の強みであるバックリンク機能をまだ使いこなせていないからでしょうか？

また、Obsidian のグラフビュー（ナレッジグラフ）を気に入って、たくさんの Node がつながっている様子を見ながら「自分の知識もつながっているな」と実感するのが好きだという人もいます。

ただ、以前書いたメモをそのまま Obsidian で開いてみたところ……すべてが独立した Node になっていて何もつながっていませんでした……。

あとで別途設定が必要なのかもしれませんが、私は Obsidian 上で直接メモを読むのではなく、Hexo で静的 Web サイトに変換して GitHub に上げていることを考えると……この機能はあまり出番がなさそうです……。
