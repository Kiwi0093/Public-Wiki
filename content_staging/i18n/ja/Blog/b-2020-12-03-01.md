## 以下、すべて愚痴

* `https://raw.githubusercontent.com` がブロックされている

  本当に悪態をつきたくなります……GitHub に置いておけば、まさか~~壁の国~~お上も GitHub には手を出さないだろうから便利に使えると思っていたのに、結局 DNS 汚染を食らうとは……本当に勘弁してほしいです。

* `pacstrap /mnt base` でカーネルが入らない

  新しい [Archlinux installation Guide](https://wiki.archlinux.org/index.php/installation_guide) を見ると `mkinitcpio` を手動で叩く必要はないと書いてあり、それ自体は事実なのですが、~~`pacstrap` を走らせたときにカーネルパッケージが一緒に入らなくなっていることには触れておらず、当然 `mkinitcpio` も走らず、`grub-mkconfig` でもブートメニューが作られず……~~そして起動しようとしたら大惨事になりました……。

  訂正：すみません、完全に自分の不注意でした。最新版の Installation Guide ではこう指定されています。

  ```bash
  pacstrap /mnt base linux linux-firmware
  ```

  これは完全に自分の確認不足ですが……それでも一言文句は言わせてください……。

* `netctl` が別パッケージになった

  もともと別インストールだったかどうか忘れてしまいましたが、以前はネットワークインターフェースの設定手順が `netctl` だったのに、今は `ip` コマンドを使うようになっています。まあパッケージとして入れれば引き続き使えますが。

* `pacman-mirrors` がそもそも Arch Linux のパッケージではない

  普段 Linux デスクトップでは Manjaro を好んで使っており、Manjaro はほぼ Arch Linux と同じ（まあロゴ以外にも多少の違いはありますが）だと思っていたのですが、`yay` に続いて Arch Linux には存在しないパッケージがあるとは思いませんでした……。おかげでインストール時には `sed` コマンドを使って `mirrorlist` から目当てのロケーションを絞り込むしかありません。あとで AUR から入れられないか調べてみようと思います……。

  追記：Arch の AUR を確認しましたが、`pacman-mirrors` はありませんでした……（泣）

## 愚痴を吐き終えて

Arch が好きとは言いつつ、よく考えてみれば自分が本当に好きなのは Manjaro のほうかもしれません……。

Arch Linux を使うのはおそらくサーバー用途かゲートウェイ用途くらいでしょう……もっとも、GUI なしの Manjaro をそのまま入れるという手もありそうですが。

ただ自分は少しこだわりが強く、サーバーとデスクトップで求めるものが違います。サーバーは極力シンプルでクリーンな状態が一番で、デスクトップは同じ Arch 系であれば扱いやすさ重視で構わないと思っています……。
