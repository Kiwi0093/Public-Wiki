# はじめに

なんとなくネットを眺めていたら Oracle に永久無料の Cloud があるのを見かけて、つい手が滑って申し込んでしまった。

[Oracle Cloud](https://www.oracle.com/cloud/)

<!--truncate-->

# 基本紹介

無料枠には DB 関連のサービスが山ほどある（さすが Oracle）ものの私には使い道がなく、自分にとって便利そうなのはだいたい以下の点くらいだ。

* VM を 2 台作成可能 - 無料の OS は Ubuntu/CentOS/Oracle Linux のみ……（Arch 系も Debian もない……）
* 時代遅れの CPU + 1GB RAM
* 486Mb/s で通信量無制限のネットワーク
* 2 台合わせて合計 100GB のストレージ（とのこと）

# 現在の用途

正直なところ、こういう環境はプロキシ（壁越え）を立てるのに向いている（中国国内からの直結速度が十分であればだが……）。ただ今回は、社内に意外とライトノベル好きが多いことに気づいたので、まずは Calibre-Web を動かすのに使うことにした。

みんなで使える電子書籍ライブラリを立てる方が実用的だからだ（もちろん後から同じマシンに V2Ray も載せるつもりではある）。

# Service 構成

* Basic OS - Ubuntu 21.0 mini
* Docker Conainers
  * Traefik  - Proxy/Redirect
  * Portainer - Docker GUI
  * watchtower - Auto Updater
  * Calibre-web - Ebook library 

# まとめ

上で書いたようにオタク仲間を増やす用途以外にも、実は Traefik の使い方を練習するという重要な目的がある。今のところ、次回の自宅環境の大規模刷新では現在使っている Nginx Proxy Manger を Traefik に置き換えることになりそうだ。何しろ Port Mapping すら不要になる優れものだから。
