# 事の経緯

実は経緯はとても単純で、PhotonOS を再起動したあと掲示板が正常に起動しなくなり、よく確認してみると Docker の volume マウントに失敗していました。しかも再起動しただけでなく、

元の設定に `restart` を書いていなかったせいで再起動後に自動起動しなかったため、つい余計な手を出して `docker-compose up -d` を叩いてしまいました。

すると Docker がとてもスマートにコンテナを再作成（recreate）してくれて……

そのままデータが吹き飛んで終わりました……。

# Root cause

事後に調査した結果はあまりにも衝撃的だったので、下に貼っておきます。

## 元の `docker-compose.yml` からの抜粋

```yaml
...    
    volumes:
      - /var/lib/docker/volumes/phpbb/mariadb:/bitnami/mariadb'
...
```

## 修正後の正常な `docker-compose.yml` からの抜粋

```yaml
...    
    volumes:
      - /var/lib/docker/volumes/phpbb/mariadb:/bitnami/mariadb
...
```

わかりましたか？たった 1 文字、`'` 記号のせいです……。
