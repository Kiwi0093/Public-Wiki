# はじめに

鬱陶しい広告対策として自宅に AdGuard を入れていたのですが、ここ数日、原因不明のまま自宅の内部ネットワークが DNS 障害で繋がらなくなってしまいました……。

<!--truncate-->

# 簡易デバッグ

ここは完全に蛇足ですが……

接続できないときに確認して DNS に異常が出ていれば……原因は間違いなく DNS にあります。

# 対処方法

とりあえず DHCPd で指定する DNS を別の dnsmasq（内部サービス用のドメイン名を大量にマッピングする必要があるため）へ向けたところ、なんとまあ不思議なことに自宅のネットワークがとても快適になりました（広告が表示されるようになった以外は）。

# 根本原因（Root Cause）の分析

* AdGuard 自体は正常に起動している
* 通信断は起きたり直ったり不安定
* 同じマシン上で `tdarr` も稼働している

推測（根拠も証拠もない仮説）ですが、マシンの負荷（Loading）が高すぎて AdGuard が虫の息になり、問題を引き起こしていたのではないかと思います……。

# 結論……

新しい Server を買うこと。もっとパワフルなやつを……（大嘘）

今後は基幹サービスを動かすのに十分なリソースを確保するため、より多くの docker host を用意してリソースを分割する必要がありそうです。
