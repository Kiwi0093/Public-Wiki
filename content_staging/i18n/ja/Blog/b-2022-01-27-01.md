# はじめに

最近システムを更新したところ、Typora を使おうとした際に突然「BUY License」の画面が表示されるようになった……調べてみると、Typora が有料化されたとのこと……。

# 無料の代替ソフト

### MarkText

* MarkText - [Homepage](https://marktext.app/) , [GitHub](https://github.com/marktext/marktext)

これは MIT ライセンスベースの Markdown エディタであり、現在この記事もこれに乗り換えて書いている。

## Typora との違い

* ホットキーが異なる
  
  Typora の `ctrl+/` でソースコードモードと表示モードを切り替える操作に慣れていたが、こちらはデフォルトで `alt+ctrl+s` に変わっているので慣れが必要。

* インターフェースの変更
  
  これは仕方のないことだが、一番の問題はフレームレスな設計になっており、ズームイン（zoom in）できるホットキーがなく、編集エリアが小さく見えるため慣れが必要だ。

* GitHub 画像アップローダーを内蔵
  
  これは本当にありがたい。以前の Typora では画像をアップロードするのに PicGo に頼っていたが、内蔵機能になったのはとても素晴らしい。こちらも GitHub のリポジトリトークンさえあれば使える。

# まとめ

ソフトの移行期間は確かに慣れないものだが、14.9 USD を払うことに比べれば、私のケチな性格がすぐにこのエディタへ適応させてくれるだろう。
