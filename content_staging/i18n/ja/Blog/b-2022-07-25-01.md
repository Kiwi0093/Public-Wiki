# 概要

<span style="color:#e06c75"><del>[私のWiki](https://kiwi0093.github.io/wiki/wiki/Network/Ansible/Install%20&%20Configuration/1-Intro/)</del></span> *(Updated 2026-11-27: [Kiwi Wiki](https://blog.kiwireich.com/docs)、Ansible 記事は現在整理中です)* に書いているとおり、これは Red Hat 製の便利なサーバー管理ツールです。Python + SSH を通じて、management node 側の playbook やコマンドを client 側で実行し、client の制御や管理を行うことができます。最大の利点は、client の状態（たとえば特定の package がインストールされているかどうかなど）を確認できる多数の module が用意されており、client 側の構成管理を実現できる点にあります。

## 制約事項

* 基本的にスムーズに接続するには、パスフレーズなしの SSH private key を用意して接続する必要があります

* 実行速度はスクリプトを直接走らせるほど速くありません

* 大量の反復的な設定作業が前提でない限り、汎用的な shell script より速くも便利にもなりません

## おおよその構造

基本的には `inventory` を使って接続対象を管理し、`動作定義.yml` を使って自動化の動作を定義します。

この `動作定義.yml` は最上位の playbook にもなれますし、roles 内のメイン tasks にもなれますし、tasks 内で `inculde_tasks` によって呼び出される別の `動作定義.yml` にもなれます。そのため、記述する際は独立した object を一つずつ作り、あとから上位の playbook で全部を繋ぎ合わせて変数による条件分岐を組み合わせることで、最終的に汎用的なサーバー管理フレームワークへと仕上げることができます（その段階で `inventory` に戻って異なるグループごとに別々の処理を行うよう定義できます）。
