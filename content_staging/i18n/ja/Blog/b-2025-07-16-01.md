# はじめに

前回、Archlinux が逝ったと勘違いした一件に続いて、またも KDE Plasma に一本取られる形になってしまった……。

<!--truncate-->

# 悲劇再び！？

背後霊がクズ男なある偉人が言っていた。「人は同じ過ちを繰り返す..まったく..！」
そう、今回もつい手癖で `yay -Syu --noconfirm` に続いて `sync` を叩き、`sudo reboot` を実行してしまったのだ。
すると、また VNC に繋がらなくなった……。確認してみると、`plasma-x11` の選択肢が消えていた……。

# 真実はいつも一つ！

そう、犯人は KDE Plasma だった……。いろいろ記事を漁ってみると、plasma 6.4 以降からデフォルトで x11 session が外されるようになったらしい……。
そこで再び `KDE + Wayland` でのリモートデスクトップ手段を探し始めた。

ところが、`krdp` を試そうとしてそのパフォーマンスに不満を感じていた矢先……ある事実に気づいた。

## `実は手動で X11 セッションを入れられるんですよね～～～～`

というわけで、迷わずマシンに `yay -S  plasma-x11-session --noconfirm` を叩き込んだ。
これで問題は~~解決~~ Plasma 7 以降まで先延ばしにできるようになった。

# 独り言

コミュニティ全体で Xorg が古すぎるから徐々に wayland へ移行しようという声が上がっているのは分かっているのだが、
今のところ `vnc` より効率的なリモートデスクトップ方式を体感できていない……。そう遠くない将来、
`moonlight/sunshine` 構成へ全面的に乗り換えることになるかもしれない。何しろ現状の Linux の `rdp` 環境はどれも動作がもっさりしていて、
Windows のような滑らかさには及ばないのだから……。
