# トラブル B - 自動ドラマ視聴セット

## 経緯

ある Blog でめちゃくちゃ素晴らしい自動ドラマ視聴セットを見かけたので、自分でも組んでみようと思ったのですが...そして...そして爆発しました。

## Docker Network

なぜか Emby を立ち上げて動かしたとき、デフォルトの Network が 192.168.0.0/16 になってしまい、私の社内（宅内）ネットワーク構成と競合してしまいました...一瞬、自分の pf 設定が壊れたのかと思って肝を冷やしました...結局 container を大量に削除してようやくどこが問題だったか特定できたので....その後 docker container の Network の書き方を勉強しました。

## RAM & Disk....

これに関しては本当に....

簡単に言うと、私が甘すぎました...Video に関わる処理が、わずかな RAM と大して大きくもない Disk space でなんとかなるはずがなかったのです...

結論から言うと、私の PhotonOS は RAM が少なすぎたうえ、デフォルトで割り当てた disk も足りず、さらに online で容量拡張しようとして失敗してしまいました。

その結果、土曜日は丸ごと再インストールする羽目に....

## PhotonOS の再インストール

実はこれ自体は厳密にはトラブルとは言えず、これまでの PhotonOS と Docker に対する習熟度を試す良い機会になりました....

だいたい1時間ほどですべての container を元の状態に戻せましたが、唯一嫌だったのが...

## SSL

`/etc/letsencrypt` ディレクトリをバックアップしてはいたものの、`live` ディレクトリ内の link をそのまま cp することができず、結局後から手動で一つずつ link を張り直す羽目になって..本当に苦痛でした...
