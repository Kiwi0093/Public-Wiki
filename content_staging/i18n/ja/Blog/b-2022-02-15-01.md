# きっかけ

実は完全に G-suite のせいというわけでもなく、主な理由は「今後の自宅のサービスをさらに統合・強化できないか」と考えていたことでした。そこで OnlyOffice Workspace を試験的に導入してみたのですが、これが思った以上に面倒でした。

# OnlyOffice Workspace

## 概要

要するに無料版の Office 365 のようなもので、Workspace には以下が含まれています。

* Mail
  * Web Client
  * SMTP server
  * Customize Domain
* Document
  * Word
  * Excel
  * Powerpoint
* Project
  * Task
  * Gantt chart
* CRM
* People
* Calander

## Docker-compose

案の定、こちらも `docker-compose` を使ってインストールする仕組みです。細かい手順はいつもの通り Wiki の方にまとめます。

ただ、このインストール方法にはかなり大きな落とし穴がありました。

他の Docker イメージのように SQL の初期化コマンドや MySQL の設定があらかじめイメージ内に組み込まれておらず、事前に手動で追加しておかなければなりません。そのせいで最初のうちはトラブル続きでした。

## Server Resource

最初から要件に書かれていたにもかかわらず、私は無謀にもリソースの乏しい Oracle Cloud 上で試験運用してしまいました。結果、システムリソースを完全に食い尽くした挙句、結局起動すらしないという羽目に……。最後は再起動直後のまだギリギリ操作できるタイミングを狙って、強引にコンテナを叩き落としてようやく復旧させました……。

その後自宅のマシンで動かしてみたところ、確かにかなりのリソースを消費します（もともと「ドラマ鑑賞セット」で RAM 使用率の 60% ほどを消費しているため余力は少なめですが、一応実用範囲内には収まっています）。

## 残課題

* Document が開けない
  * ネットで調べた限り、Traefik V2 の middlewares 設定が正しくないのが原因のようです。
* Traefik Middleware の設定方法がわからない
  * まあ……上記の件と合わせると、要するに現時点では私には対処できていないということです～～。
* 繁体字中国語 UI がない
  * これも解決しようがありません。

# まとめ

結果だけ見ればなかなかワクワクする内容ではあるのですが、一方で無料の Office や Google Docs がまだ使える現状を考えると……独自ドメインのメールアドレス、Project 機能、そしてファイルを直接ダウンロードできる点以外には、あらゆる困難を乗り越えてまで無理に導入する動機があまり見当たらない気もします……。
