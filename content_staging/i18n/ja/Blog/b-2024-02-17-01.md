## Arch Linux

`Archlinux` が `archinstall` という自動インストールスクリプトを提供してくれるようになってからは、自分で Arch Linux のインストールスクリプトを書く必要がまったくなくなりました（もちろん、特化した設定で何台も構築するなら書いてもいいのですが……）。主に今は Docker がとても便利になり、個別の Arch Linux ホストごとに何台も VM を立てる必要がなくなったため、自動設定スクリプトを作るコスパが大きく下がったというのもあります。

## Windows

もともと Windows 10 以降は Windows のインストール自体にそれほど時間や手間がかからなくなっていましたが、最近は Linux に寄せてきたのか（それが理由かはわかりませんが）Windows の CLI ツールもかなり使いやすくなりました。そのため、今はアプリを入れるときも `winget` で直接インストールしています。別にその方がカッコいいからというわけではなく、単に `winget` で入れたアプリなら `winget` で手軽にアップデートできるからです。

```bash
# XXX プログラムを検索
winget search XXX

# XXX プログラムをインストール
winget install XXX

# XXX プログラムをアンインストール
winget uninstall XXX

# すべてのプログラムを更新
winget update --all
```

## PhotonOS

こちらは特に凝った設定をする必要がありません。今回入れた 5.0 で言えば、基本的に最初の IP 設定さえ問題なければ、あとは `/etc/fstab` にマウントしたい NFS フォルダを追記し、`docker-compose` をインストールして（今は `yum install docker-compose` でそのまま入ります）、`systemctl enable docker.service` と `systemctl enable remote-fs.target` を有効にして、起動時に自動で Docker の起動と NFS フォルダのマウントが行われるようにしておくだけです。

### Docker

いろいろ試してみたのですが、現状 `nfs-volume` はどうテストしても失敗してしまうため、今は昔ながらの方法で素直にローカルに Docker volume を作成し、スクリプトで自動的に NFS フォルダへバックアップする形にしています。こちらのほうがシンプルで確実です。
