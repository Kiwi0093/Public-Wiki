# V2Ray on Cloudflare

中国を離れてからは、壁越え用のプロキシ（梯子）にあまり時間やスキルポイントを割かなくなっていました……。
ただ先日 YouTube を見ていたとき、無料の `cloudflare worker` を使ってサーバーレスの V2Ray サーバーを立てられるうえに、複数 IP をリフレッシュして切り替えられる方法があることを知りました。
本当に太っ腹すぎる仕組みですね……。

## Edgetunnel

[Edgetunnel from cmliu](https://github.com/cmliu/edgetunnel)

実のところ、このプロジェクトを見つけた時点で構築の 90% は終わったようなものです。あとは `cloudflare` のアカウントを用意するだけ。実際には CF Worker が `worker_name.User_name.workers.dev` のような URL を自動生成してくれるので独自ドメインがなくても動きますが、自分で V2Ray WebSocket over TLS を組んだことがある身としては、CF で管理しているドメインを使うのは定番中の定番です。なのでこのあたりは何も問題ないはず（完全にゼロから始める人の場合はドメインを用意するのに少し手間がかかるかもしれませんが……）。

あとは無料の Worker プロジェクトを作成し、GitHub のコードを Worker のエディタに貼り付け、~~[online UUID generator](https://www.uuidgenerator.net/) で好みの UUID を生成して~~任意の文字列をトークンとして 4 行目の `let userID = '<uuid you like>';` に設定してデプロイするだけです。

続いて Worker の「設定 → ドメインとルート」で自分のドメインを設定するか、あるいは素直に `workers.dev` のリンクを使うことにします（私は接続テストだけ試した状態なので、実際に本格運用した場合にどうなるかは分かりません）。あとは `https://your.domain.or.workers.dev/UUID` にアクセスすれば、下のような画面が表示されます。

## Client

### Windows

基本的には `V2RayN` でそのまま使えます。サブスクリプション（グループ）をインポートして更新すれば利用可能です。

### Android

残念ながら `V2Rayng` はグループ購読機能に対応していないため、代わりに [ClashMeta for Android](https://github.com/MetaCubeX/ClashMetaForAndroid) を試しました（`Obtainium` を使って GitHub から直接インストールしました）。
詳しい設定方法は……書くのが面倒なので省略します。基本的に `V2rayng` を使える人なら URL からの設定方法はすぐ分かるはずなので、`https://your.domain.or.workers.dev/UUID` を URL 欄に入力するだけです……。
