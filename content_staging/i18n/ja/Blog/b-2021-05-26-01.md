家庭の事情により、蘇州での駐在生活を終えて台湾に戻り、落ち着いた日々を送ることにしました。

## 近況報告

実はここ最近はずっとダメ人間のような状態で、台湾に戻って子どもの洗礼を受けてからは、以前のように新しいおもちゃ（技術）をいじるために大量の時間を割く余裕がほとんどなくなりました（もっとも、仕事中も真面目に働かなければならなくなり、以前のように仕事中にこっそりブログを書くわけにはいかなくなったのもありますが……）。

### Server

台湾に戻ってきたことで、これまでの蘇州でのような~~壁越え~~「科学的インターネット（GFW回避）」中心の運用から、ネットワーク環境を気にする必要のないサービス内容重視の運用へと自然と軸足が移りました。サーバーの OS も、GFW 回避に相性の良い Arch Linux から、長年使い慣れていたものの向こう（中国大陸）ではどうしようもないほど使いにくかった FreeBSD に戻しました。

##### Server OS

移行期間それなりに手間はかかりましたが、再インストールしてみると、実際のところ Arch よりインストールが圧倒的に楽だと感じました。

ディスクから起動してインストールする Item を選ぶだけで、あとはほとんど頭を使うこともなくあっという間にインストールが終わります。

あとは元のサーバーの設定ファイルである

* /etc/rc.conf
* /usr/local/etc/screenrc
* /etc/csh.cshrc
* /etc/pf.conf
* /etc/ipfw.conf

を戻して再起動するだけ……完了……あまりにも簡単すぎます。

##### Esxi

ちょっとしたトラブル（そう、例の週2回の停電のせいです）で、手元の ESXi Server が1台落ちてしまいました……。

ただ、そのマシンは USB メモリに ESXi をインストールしていたおかげで、すぐに再インストールして元通り動かせる状態に戻せました。

今回は ESXi 5.1 から ESXi 6.5U2 for HPE のカスタム ISO に変更しました（私の Gen8 サーバーは 6.5 の pre-Gen9 ISO までしか対応していないためです）。

乗り換えて感じたのは、ようやく別途クライアントをインストールしなくて済むようになったことです。以前使っていた vSphere Client も 6.0 までしか対応しておらず、インストーラーも見つからなかったので HTML5 の Web Client に切り替えましたが、使い勝手はなかなか良好です。

ただ、passthrough（パススルー）の設定を一度でうまく決められないと厄介で……再インストールする羽目になります（編集できるクライアントが手元にないため）。

これで一朝丸々潰れました……。

##### PCHome 24 ~~H~~ D

作業の途中で、自宅の NAS の HDD が1台壊れていることに気づきました。以前ならクレジットカードを取り出して HDD を4台ポチり、届くのを待てば解決する話でした。

しかしあいにく今回は10年に一度レベルの「PCHome 24D（24時間ならぬ24日遅延）事件」にぶつかり、HDD の到着を待つのが一番つらく時間のかかる作業になってしまいました（結局最後はすべて Momo で買い直しましたが……）。
