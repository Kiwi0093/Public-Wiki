最近ほかの VPS 上で Traefik などを試してみたところ、今の自宅環境アーキテクチャがあまり良くないと感じるようになったため、現在自宅で動かしている関連サービスを整理し直すことにしました。

# 従来の構成とサービス

## 従来のサービス

### インフラ系

* Nginx Proxy Manager - フロントエンドの Reverse proxy server
* Mariadb - メイン DB
* Portainer - Docker Web GUI
* Watchtower - コンテナ／イメージ自動更新ツール

### サービス系
#### 基本ネットワークサービス
* Wireguard - 自宅向け VPN
* Guacamole - 自宅向け Web ターミナル
#### マルチメディア・ネットワークサービス
* Navidrome - 音楽ストリーミング
* Calibre-web - 電子書籍ライブラリ
##### ドラマ・アニメ鑑賞セット（bundle）
* qbittorent - メインの BT ダウンローダー
* Emby - メディアフロントエンド
* Sonarr - ドラマ／アニメ自動管理ツール
* Radarr - 映画自動管理ツール
* Lidarr - 音楽自動管理ツール
* Chinesesubfinder - 中国語字幕ファイル自動取得ツール
* Jackett - RSS フィードインターフェース
* Flaresovlerr - Jackett 補助ツール
#### その他
* Librenms - 監視ツール
* phpBB - 掲示板（BBS）
* Heimdall - ダッシュボード
