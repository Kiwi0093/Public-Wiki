# ESXi のアップグレード

## 参考資料

今回のアップグレードは主に[師匠の経験記事](https://roidintw.kaienroid.com/2020/09/vmware-esxi-upgrade-from-60-to-65-with.html)を参考にしました。

ただ、師匠はメンテナンスモードに入らずにそのまま実行するというなかなかの荒業をしていましたが、私は念のためメンテナンスモードに入れてから実行しました。

## ファイルの取得

まずは My VMware にログインして VMware vSphere Hypervisor のダウンロードページを探します。6.x 系ではすでに 6.7 も出ていましたが、見たところ ISO ばかりだったため、今回は 6.5 の **VMware vSphere Hypervisor (ESXi) Offline Bundle** をダウンロードしました。

これは ZIP ファイルになっており、ダウンロードしたらそのまま ESXi のデータストア（datastorage）に放り込んでおけば OK です。

## アップグレード手順

### メンテナンスモード（maintenance mode）

これは簡単で、既存のクライアントから ESXi に接続し、メンテナンスモードを選択するだけです。

### ファイルの場所を確認

PuTTY を使って ESXi ホストに SSH ログインします。

```bash
ls /vmfs/volume/
```

するとデータストアが表示されるので、先ほどアップロードした ZIP ファイルがその中に入っているはずです。

### Profile Image の確認

```bash
esxcli software sources profile list -d /vmfs/volumes/$(your_volume)/$(your_file.zip)
```

これでプロファイルイメージ（profile image）の一覧を確認できます。

### アップグレード

```bash
esxcli software profile update -d /vmfs/volumes/$(your_volume)/$(your_file.zip) -p $(profile-image)
```

すると大量の VIB のインストールが始まり、最後に再起動となります（ここが少し面倒で、シェルから `reboot` や `shutdown` コマンドが通らないため、クライアント画面から「Reboot Host」を押して再起動しました）。

### アップグレード再起動後

Web インターフェースからログインし直し、メンテナンスモードを解除するのを忘れずに確認してから、起動すべき VM を立ち上げれば完了です。

# 今後の計画

今回のアップグレードの主な目的は、自宅のいくつかのサービスを個別の Linux VM で動かす構成から、Photon OS 上で直接 Docker コンテナとして動かす構成へ移行し始めることです。こうすることでディスク容量やマシンリソースを節約できます。

また、サービスを動かすたびに Linux を一からインストールしたりチューニングしたりする手間も減らせます。

そのため、今後はいくつか時間を取って以下のテーマを勉強していく必要があります。

* Photon OS の使い方
  * Photon OS でのマルチ IP 設定
  * Photon OS のシェル変更および関連ツールの導入・チューニング（さんざん迷った挙げ句、結局 Arch から Photon OS に乗り換えることに）
* Docker の使い方
  * 基本構文
  * Docker の実践的な活用方法
* そもそも自宅でどのサービスを統合運用するのかの整理
