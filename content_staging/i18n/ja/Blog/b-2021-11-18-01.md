# はじめに

自分で Mail Server を構築したかったのですが、自宅の Server には手を入れたくなかったため、Traefik + V2ray を試してみました……

効果はなかなか良好です。

<!--truncate-->

# 基本構成

これについてはすでに多くの場所で解説されていると思いますが、Traefik とは、Docker-compose.yml 内の Label 定義に基づいてコンテナに対応する Virtual host を~~自動~~で生成してくれる優れものです。

# Nginx Proxy Manager との比較

1. NPM はあくまで Proxy に過ぎないため、自分でコンテナの Port を expose / mapping する必要があります。
2. NPM の SSL 証明書は Certbot と同様に `/etc/letscrypt` に保存されますが、Traefik は直接 `ACME.json` 内に保存されるため形式が異なります。
3. NPM は操作が直感的ですが、Traefik は `Docker-compose.yml` の定義を理解する必要があります。

# 使用感

率直に言ってかなり良いです。Port などをいろいろ定義する必要がなく、基本的には `docker-compose.yml` 内に Hostname を定義しておくだけで、残りのすべてを自動的に生成してくれます。

完全自動での移行をしたい人にとても向いています。

ロードバランシング（load balance）などの機能もありますが、今のところ使う予定はないので……。

# デメリット

Traefik を使う場合、基本的にはメインの Domain をそのまま使うのではなく、Subdomain を付与する形ですべてのコンテナを独立して公開することになります。
