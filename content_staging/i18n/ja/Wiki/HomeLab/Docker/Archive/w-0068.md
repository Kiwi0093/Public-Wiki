> [!info] Updated 2026-11-27
> 本記事は初期に Node-RED を実験した際のアーカイブメモです。以下は現在の Docker および Node-RED との対照補足です：
> 1. Docker Compose v2 ではトップレベルの `version: '3.3'` フィールドが廃止されており、`compose.yaml` と `docker compose` コマンドの使用が推奨されます。
> 2. マウントディレクトリに対して直接 `chmod 777` を実行することは推奨されません。より安全な方法は `chown -R 1000:1000 /var/lib/docker/volumes/node-red` を実行し、コンテナのデフォルト UID 1000 に合わせることです。
> 3. Node-RED の設定ファイルの正しいファイル名は小文字複数形の `settings.js`（`Setting.js` ではない）です。新しい公式コンテナには `node-red admin hash-pw` コマンドが内蔵されており、別途グローバルに `node-red-admin` をインストールする必要はありません。

# インストール

実のところ、インストールの部分が一番簡単なパートでした⋯⋯

## docker-compose.yml

```bash
version: '3.3'
services:
  node-red:
    image: nodered/node-red
    container_name: node-red
#    ports:
#      - '1880:1880'
    environment:
      - TZ=Asia/Taipei
    volumes:
      - /var/lib/docker/volumes/node-red:/data
    restart: unless-stopped
    labels:
      traefik.enable: true
      traefik.http.routers.node-red.rule: Host(`<Domain>`)
      traefik.http.routers.node-red.tls: true
      traefik.http.routers.node-red.tls.certresolver: myresolver
      traefik.http.services.node-red.loadbalancer.server.port: 1880

networks:
  default:
    external: true
    name: traefik_backend
```

### 注意点

* Volumes の権限
  デフォルトの UID 権限が 1000 であるため、root で container を作成すると書き込み権限の問題で正常に動作しません。解決策は root として実行するよう定義するか、ディレクトリの権限を変更することです（私は 777 に変更しました）。
* `settings.js`（原文では `Setting.js` と記載）の設定
  私は Traefik で SSL を処理しているため、注意すべきなのはログイン権限の部分だけです。
  基本的にログイン設定を有効にするのはとても簡単です：

  ```bash
  adminAuth: {
   type: "credentials",
   users: [
       {
           username: "admin",
           password: "$2a$08$zZWtXTja0fB1pzD4sHCMyOCMYz2Z6dNbM6tl8sJogENOMcxWV9DN.",
           permissions: "*"
       },
       {
           username: "george",
           password: "$2b$08$wuAqPiKJlVN27eF5qJp.RuQYuy6ZYONW7a/UWYxDTtwKFCdB8F19y",
           permissions: "read"
       }
   ]
  }
  ```

  `username` の部分を好みの ID に書き換えて、
  `docker exec -it <NodeRed_container_name> bash` 経由で
  `node-red-admin hash-pw` を実行すると、
  設定したいパスワードの入力を求められた後に hash 文字列を生成してくれるので、それを上記の設定にコピー＆ペーストするだけです。
