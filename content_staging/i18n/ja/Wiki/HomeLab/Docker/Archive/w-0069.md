# 手順

## docker-compose.yml の内容

*2022/7/26 更新*

```bash
services:
  isso:
    image: ghcr.io/isso-comments/isso:latest
    container_name: isso
    environment:
      - PUID=1000
    volumes:
      - /var/lib/docker/volumes/isso/config:/config
      - /var/lib/docker/volumes/isso/data:/db
    restart: unless-stopped
    networks:
      - traefik
    labels:
      traefik.enable: true
      traefik.http.routers.isso.rule: Host(`$domain_you_like`)
      traefik.http.routers.isso.tls: true
      traefik.http.routers.isso.tls.certresolver: myresolver

networks:
  traefik:
    external: true
    name: web-service
```

この書き方では、あらかじめ `touch` で `isso.conf` ファイルを作成しておく必要があり、また指定した `PUID` から読み取れるようにパーミッションを設定しておくことを忘れないでください。

## isso.conf の内容

```bash
[general]
dbpath = /db/$(databasename).db        #このファイル名は自由に定義できます
host = https://$(your_Blog_domain)        #ここにブログのURLを設定します
[server]
listen = http://0.0.0.0:8080            #ここで設定するポートはdocker-compose.yml内で定義するコンテナ内のポートです
[guard]
enabled = true
ratelimit = 2
direct-reply = 3
reply-to-self = false
require-author = true
require-email = true
[moderation]                            #公開前に事前承認が必要かどうか。必要な場合はtrueに変更
enabled = false
purge-after = 30d
[admin]                                     #管理者機能を有効にするかどうか
enabled = false
password = strong-password
```

## NexT の設定

`_config.next.yml` に以下を追記します：

```bash
# ---------------------------------------------------------------
# Comments Settings
# See: https://theme-next.js.org/docs/third-party-services/comments
# ---------------------------------------------------------------

# Multiple Comment System Support
comments:
  # Available values: tabs | buttons
  style: tabs
  # Choose a comment system to be displayed by default.
  # Available values: disqus | disqusjs | changyan | livere | gitalk | utterances
  active: isso 
  # Setting `true` means remembering the comment system selected by the visitor.
  storage: true
  # Lazyload all comment systems.
  lazyload: false
  # Modify texts or order for any naves, here are some examples.
  nav:
    #disqus:
    #  text: Load Disqus
    #  order: -1
    #gitalk:
    #  order: -2
.....
.....
# Isso
# For more information: https://posativ.org/isso/
isso: https://$domain_you_like/
```

あとは `hexo d -g` を実行するだけです。

# 注意事項

* Traefik で `https` を動かしている場合、`data-isso` にはチュートリアル記載の `//$domain_you_like/` ではなく `https://$domain_you_like/` を指定してください。
* ローカルで `hexo s` を実行しているときはコメント欄が表示されません……必ず `hexo g -d` で GitHub 上にプッシュしないと表示されないので注意してください……。
