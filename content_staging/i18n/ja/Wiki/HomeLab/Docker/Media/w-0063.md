### 主なアップデートと選定のポイント (Breaking Changes & Best Practices)

1. **イメージ名の更新**：
   公式により Docker イメージ名が正式に `ghcr.io/suwayomi/suwayomi-server:stable` へ移行されました（旧版 `ghcr.io/suwayomi/tachidesk` にもエイリアスは残っていますが、最新の修正を受け取るためにも新標準の採用を強く推奨します）。
2. **FlareSolverr とのネットワーク連携**：
   多くの漫画サイト（CopyManga、動漫之家など）は Cloudflare の 5 秒待機（アンチスクレイピング機構）を導入しています。共有の Docker カスタム Bridge ネットワークを使用することで、Suwayomi は FlareSolverr をホストに公開したり外部ルーティングを経由したりすることなく、`http://flaresolverr:8191` 経由で直接呼び出して認証をバイパスできます。
3. **ストレージ設計と CBZ パッケージ化**：
   デフォルトではダウンロードした画像はバラバラのディレクトリとして保存されますが、環境変数 `DOWNLOAD_AS_CBZ=true` を有効にすると各話が自動的に単一の `.cbz` ファイルに圧縮されます。これによりホスト側の Inode 消費を大幅に削減でき、将来的に Kavita や Komga といった専門の漫画サーバーへ直接インポートする際にも非常に便利です。

## 2. Docker Compose 完全デプロイテンプレート

本構成では **Suwayomi** と **FlareSolverr** を統合し、同時にログローテーション上限と主要な環境変数を設定しています：

```yaml
services:
  suwayomi:
    image: ghcr.io/suwayomi/suwayomi-server:stable
    container_name: suwayomi
    restart: unless-stopped
    ports:
      # WebUI 直結用のデフォルトポート。Traefik / NPM のみを使う場合はコメントアウト可
      - "4567:4567"
    environment:
      - TZ=Asia/Taipei
      # コア設定：Cloudflare 突破のため FlareSolverr を有効化
      - FLARESOLVERR_ENABLED=true
      - FLARESOLVERR_URL=http://flaresolverr:8191
      # 自動ダウンロードおよび更新設定
      - AUTO_DOWNLOAD_CHAPTERS=true           # 新しいチャプター検出時に自動ダウンロード
      - DOWNLOAD_AS_CBZ=true                  # ダウンロードしたチャプターを自動的に .cbz 圧縮ファイル化
      - UPDATE_INTERVAL=12                    # 12 時間ごとに全体の更新を自動チェック
      # 組み込み認証（インターネットに公開する場合は有効化を強く推奨）
      - AUTH_MODE=none                        # basic_auth または ui_login に変更可能
      # - AUTH_USERNAME=admin
      # - AUTH_PASSWORD=your_super_password
    volumes:
      # 漫画データベース、拡張機能、ダウンロード済みチャプターの永続化ディレクトリ
      - /opt/suwayomi/data:/home/suwayomi/.local/share/Tachidesk
    depends_on:
      - flaresolverr
    logging:
      driver: "json-file"
      options:
        max-size: "50m"
        max-file: "3"
    networks:
      - manga_net
      # Traefik / NPM と連携する場合は proxy ネットワークを追加
      - proxy-network

  flaresolverr:
    image: ghcr.io/flaresolverr/flaresolverr:latest
    container_name: flaresolverr
    restart: unless-stopped
    environment:
      - LOG_LEVEL=info
      - TZ=Asia/Taipei
    # 内部通信専用のため、外部ポートの公開は不要
    networks:
      - manga_net

networks:
  manga_net:
    name: manga_net
    driver: bridge
  proxy-network:
    external: true
```

## 3. リバースプロキシ連携 (Traefik v3 / NPM)

### 3.1 Traefik v3 を使用する場合 (Labels 宣言)

Traefik v3 を使用している場合は、`suwayomi` サービスセクションに Labels を直接追加します（ports `4567:4567` はコメントアウトまたは削除できます）：

```yaml
    labels:
      - "traefik.enable=true"
      - "traefik.http.routers.suwayomi.rule=Host(`manga.example.com`)"
      - "traefik.http.routers.suwayomi.entrypoints=websecure"
      - "traefik.http.routers.suwayomi.tls=true"
      - "traefik.http.routers.suwayomi.tls.certresolver=myresolver"
      - "traefik.http.services.suwayomi.loadbalancer.server.port=4567"
```

### 3.2 Nginx Proxy Manager (NPM) を使用する場合

1. Suwayomi と NPM が同じ Docker 外部ネットワーク（例：`proxy-network`）に所属していることを確認します。
2. NPM の UI で新しい Proxy Host を追加します：
   - **Domain Names**：`manga.example.com`
   - **Forward Hostname / IP**：`suwayomi`（コンテナ名を直接入力）
   - **Forward Port**：`4567`
   - **Websockets Support** にチェックを入れます（リーダーのリアルタイム進捗同期やターミナルログ表示に必要）。

## 4. 拡張機能リポジトリ (Extensions) とソース設定

元の Tachiyomi 公式リポジトリが閉鎖されて以降、コミュニティは現在 **Keiyoushi** などのオープンソースチームが中心となって維持しています。新しい Suwayomi では、検索してソースをインストールする前にサードパーティ製リポジトリを手動で追加する必要があります。

### ステップ 1：拡張機能リポジトリ (Extension Repositories) の追加

1. ブラウザで `http://<Host_IP>:4567` を開き、Suwayomi Web インターフェースにアクセスします。
2. 左側のメニューから **Settings** -> **Browse** -> **Extension repositories（拡張機能リポジトリ）** を選択します。
3. 現在コミュニティで最も主流となっている **Keiyoushi** リポジトリのインデックス URL を貼り付けます：

   ```
   https://raw.githubusercontent.com/keiyoushi/extensions/repo/index.min.json
   ```

4. **Add** をクリックして保存します。

### ステップ 2：漫画ソースの検索とインストール

1. 左側の **Browse（参照）** をクリックし、上部のタブを **Extensions（拡張機能）** に切り替えます。
2. 右上の言語フィルターで **中文 (ZH)** やその他の希望言語にチェックを入れます。
3. よく使うソースを検索して **Install** をクリックします：
   - **CopyManga (拷貝漫畫)**：作品数が豊富で高画質。
   - **Manhuagui (漫畫櫃)**：古くからある定番ソース。
   - **Bilibili / 騰訊などの公式ソース**（一部無料チャプターの閲覧が可能）。
4. インストール完了後、**Sources（ソース）** タブに切り替えると漫画の検索が可能になり、「**Add to Library（ライブラリに追加）**」で書棚に登録できます。

## 6. よくあるトラブルシューティング (Troubleshooting)

### 6.1 ソースが読み込めない、無限ロードする、または `HTTP 403 / Cloudflare` エラーが出る

- **原因**：ソースサイトが厳格な Cloudflare シールドまたは Turnstile 認証を有効にしています。
- **対処法**：
  1. Compose ファイル内で `FLARESOLVERR_ENABLED=true` と `FLARESOLVERR_URL` が正しく定義されているか確認します。
  2. Suwayomi コンテナ内に入って FlareSolverr との通信をテストします：

     ```bash
     docker compose exec suwayomi curl -I http://flaresolverr:8191
     ```

  3. 特定のソース（CopyManga など）でタイムアウトが頻発する場合は、該当拡張機能の設定画面から別の API ミラーサイトに切り替えてみてください。

### 6.2 ホスト側のディスク容量が圧迫される

- **原因**：複数の連載漫画をフォローして自動ダウンロードを有効にすると、1 話あたり数十枚の高画質画像が急速に蓄積し、数十 GB に達することがあります。
- **対処法**：
  1. `DOWNLOAD_AS_CBZ=true` を設定してディレクトリ内の細かなファイルを減らします。
  2. WebUI の「Settings -> Downloads」で **Download limit（ダウンロード上限）** を設定し、例えば未読の先頭 5 話のみをキャッシュし、既読分は自動的にキャッシュを削除するように制限します。

### 6.3 ディレクトリ権限エラー (Permission Denied)

- **原因**：コンテナ内部はデフォルトで `suwayomi` ユーザーとして実行されます。ホスト側でマウントしたディレクトリが root によって作成されていると、データベースへの書き込みや画像のダウンロードに失敗します。
- **対処法**：
  ホスト側でマウントディレクトリの所有権を緩和または修正します：

  ```bash
  sudo chown -R 1000:1000 /opt/suwayomi/data
  sudo chmod -R 755 /opt/suwayomi/data
  ```

## 7. メンテナンスとデータバックアップ

Suwayomi のライブラリ記録、既読進捗、インストール済み拡張機能、ダウンロード済みファイルはすべて単一のディレクトリに集約されています：

```bash
# 1. データディレクトリのバックアップ（downloads を除外することでバックアップ容量を大幅に削減可能）
sudo tar --exclude='downloads' -czvf /opt/backups/suwayomi-config-$(date +%F).tar.gz -C /opt/suwayomi data

# 2. フルバックアップ（ダウンロード済み漫画を含む）
sudo tar -czvf /opt/backups/suwayomi-full-$(date +%F).tar.gz -C /opt/suwayomi data

# 3. リストア方法
sudo tar -xzvf /opt/backups/suwayomi-*.tar.gz -C /opt/suwayomi/
docker compose restart suwayomi
```
