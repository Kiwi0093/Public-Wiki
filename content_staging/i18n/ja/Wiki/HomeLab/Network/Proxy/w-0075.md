## クイック接続情報の対照表（前回の構成を基準）

- **Reality 直接接続ノード**：

    - ドメイン：`reality.yourdomain.com`、ポート：`443`

    - トランスポート：`TCP`、セキュリティ：`Reality`、フロー制御：`xtls-rprx-vision`

    - SNI：`reality.yourdomain.com`、Fingerprint：`chrome`

    - 必須パラメータ：`UUID`、`Public Key`、`Short ID`

- **WS+TLS+CDN レスキューノード**：

    - ドメイン：`cdn.yourdomain.com`（または Cloudflare 最適化 IP）、ポート：`443`

    - トランスポート：`WebSocket (WS)`、パス：`/ray-ws-stream`

    - セキュリティ：`TLS`、SNI / Host：`cdn.yourdomain.com`

    - 必須パラメータ：`UUID`

## 1. Android クライアントの推奨と設定

### 推奨クライアント

- **第一候補：v2rayNG**（直感的な UI、Xray コアへの対応が最も完全で、Reality/Vision の全機能に対応）

- **高度な代替案：sing-box (Android 公式版)**（強力なルールベースルーティング、非常に低い消費電力）

### v2rayNG の設定手順

#### 最速インポート方法（クリップボードからのインポート）

1. 3X-UI パネルでノードの `vless://` リンクをコピーします。

2. v2rayNG を開き、右上の **`+`** ボタン -> **「クリップボードからインポート」** を選択します。

3. 右下の V アイコンをタップして接続し、下部のステータスバーをタップして遅延テストを行います。

#### VLESS-Reality の手動設定

1. 右上の **`+`** -> **「手動入力 [VLESS]」** をタップします。

2. 順番に入力します。

    - **備考 (Remarks)**：`Reality-Direct`

    - **アドレス (Address)**：`reality.yourdomain.com`

    - **ポート (Port)**：`443`

    - **ユーザー ID (id)**：自分の `UUID` を入力

    - **フロー制御 (flow)**：`xtls-rprx-vision` を選択

    - **トランスポートプロトコル (network)**：`tcp`

    - **トランスポートセキュリティ (streamSecurity)**：`reality` を選択

    - **SNI**：`reality.yourdomain.com`

    - **Fingerprint (uTLS)**：`chrome`

    - **PublicKey**：3X-UI で生成された `Public Key` を入力

    - **ShortId**：対応する `Short ID` を入力

3. 右上のチェックマークをタップして保存します。

#### VLESS-WS+TLS+CDN の手動設定

1. 右上の **`+`** -> **「手動入力 [VLESS]」** をタップします。

2. 順番に入力します。

    - **備考 (Remarks)**：`WS-CDN-Rescue`

    - **アドレス (Address)**：`cdn.yourdomain.com`（または Cloudflare 最適化 IP）

    - **ポート (Port)**：`443`

    - **ユーザー ID (id)**：自分の `UUID` を入力

    - **フロー制御 (flow)**：空欄のまま

    - **トランスポートプロトコル (network)**：`ws` を選択

    - **WebSocket -> path**：`/ray-ws-stream`

    - **WebSocket -> host**：`cdn.yourdomain.com`

    - **トランスポートセキュリティ (streamSecurity)**：`tls` を選択

    - **SNI**：`cdn.yourdomain.com`

3. 右上のチェックマークをタップして保存します。

## 2. iPhone (iOS) クライアントの推奨と設定

### 推奨クライアント

- **第一候補：Shadowrocket**（コスパ最強、買い切り型、互換性が高く Reality と uTLS に対応）

- **代替／上級者向け：Loon** または **Sing-box** または **Stash (Clash for iOS)**

### Shadowrocket の設定手順

#### 最速インポート方法（QR コードスキャン／リンク）

1. 3X-UI パネルでノードの QR コードアイコンをクリックします。

2. Shadowrocket を開き、左上の**スキャンボタン**で画面を読み取るか、`vless://` をコピーした状態でアプリを開くと自動追加のプロンプトが表示されます。

#### VLESS-Reality の手動設定

1. 右上の **`+`** をタップします。

2. **タイプ (Type)**：`VLESS` を選択します。

3. 順番に入力します。

    - **サーバー (Address)**：`reality.yourdomain.com`

    - **ポート (Port)**：`443`

    - **パスワード (UUID)**：`UUID` を入力

    - **暗号化／セキュリティ (Security)**：`Reality` を選択

    - **PublicKey**：`Public Key` を入力

    - **Short ID**：`Short ID` を入力

    - **Peer (SNI)**：`reality.yourdomain.com`

    - **アルゴリズム (Flow)**：`xtls-rprx-vision` を選択

    - **Fingerprint**：`chrome` を選択

4. 右上の **保存** をタップします。

#### VLESS-WS+TLS+CDN の手動設定

1. 右上の **`+`** をタップします。

2. **タイプ (Type)**：`VLESS` を選択します。

3. 順番に入力します。

    - **サーバー (Address)**：`cdn.yourdomain.com`

    - **ポート (Port)**：`443`

    - **パスワード (UUID)**：`UUID` を入力

    - **トランスポート方式 (Transport)**：`websocket` を選択

    - **Path**：`/ray-ws-stream`

    - **Host**：`cdn.yourdomain.com`

    - **TLS**：オンにチェック

    - **SNI**：`cdn.yourdomain.com`

4. 右上の **保存** をタップします。

## 3. Windows クライアントの推奨と設定

### 推奨クライアント

- **第一候補（直感的な GUI）：v2rayN**（Xray コア対応、標準状態で Reality をサポート）

- **第一候補（ルール分流）：Clash Verge Rev**（Mihomo / Clash Meta コアベース、UI が非常に美しく、サブスクリプションやカスタムルールに対応）

### 方式 A：v2rayN (Xray コア)

#### クイックインポート

`vless://` ノード文字列をコピーし、v2rayN のメインウィンドウ上でショートカットキー `Ctrl + V` を押すと自動追加されます。

#### VLESS-Reality の手動追加

1. 上部の **サーバー (Servers)** -> **VLESS サーバーを追加** をクリックします。

2. パラメータを合わせます。

    - **サーバーアドレス (Address)**：`reality.yourdomain.com`

    - **ポート (Port)**：`443`

    - **ユーザー ID (id)**：自分の `UUID`

    - **フロー制御 (flow)**：`xtls-rprx-vision`

    - **トランスポートプロトコル (network)**：`tcp`

    - **トランスポートセキュリティ (streamSecurity)**：`reality` を選択

    - **SNI**：`reality.yourdomain.com`

    - **uTLS**：`chrome`

    - **PublicKey**：Public Key を貼り付け

    - **ShortId**：Short ID を貼り付け

3. 確定をクリックします。タスクバー右下のアイコンを右クリックし、「システムプロキシ」を **システムプロキシの自動設定 (PAC／グローバル)** に切り替えます。

### 方式 B：Clash Verge Rev (Mihomo コア)

設定ファイル内の Proxies セクションに以下のスニペットを手動で追加します。

```yaml
proxies:
  # 1. Reality 直接接続ノード
  - name: "Reality-Direct"
    type: vless
    server: reality.yourdomain.com
    port: 443
    uuid: YOUR_UUID_HERE
    network: tcp
    flow: xtls-rprx-vision
    tls: true
    udp: true
    servername: reality.yourdomain.com
    client-fingerprint: chrome
    reality-opts:
      public-key: YOUR_PUBLIC_KEY_HERE
      short-id: YOUR_SHORT_ID_HERE

  # 2. WS+TLS+CDN レスキューノード
  - name: "CDN-Rescue"
    type: vless
    server: cdn.yourdomain.com       # 遮断された場合は Cloudflare 最適化 IP に変更可能
    port: 443
    uuid: YOUR_UUID_HERE
    cipher: auto
    tls: true
    udp: true
    servername: cdn.yourdomain.com   # SNI はドメインのまま維持
    network: ws
    ws-opts:
      path: "/ray-ws-stream"
      headers:
        Host: cdn.yourdomain.com
```

> [!info] Updated 2026-11-27
> 2 番目の `VLESS` ノード例にある `cipher: auto` は VMess プロトコル用のパラメータであり、VLESS 自体では `cipher` の指定は不要です（Mihomo コアでは通常無視されますが、VLESS 設定では省略することを推奨します）。

## 4. Linux (デスクトップ／サーバー／Photon OS) クライアントの推奨と設定

### 推奨クライアント

- **デスクトップ環境 (GUI)**：**Clash Verge Rev (AppImage / .deb / .rpm)**

- **サーバー / コマンドライン (CLI 第一候補)**：**sing-box (単一バイナリ実行ファイルまたは Systemd サービス)**

### sing-box CLI 設定手順 (Debian/Ubuntu/Photon OS 共通)

#### ステップ 1：sing-box のインストール

```bash
# 公式バイナリをダウンロード（amd64 の例）
bash -c "$(curl -fsSL https://sing-box.app/deb-install.sh)" 2>/dev/null || \
curl -Lo /usr/local/bin/sing-box https://github.com/SagerNet/sing-box/releases/latest/download/sing-box-linux-amd64.tar.gz
chmod +x /usr/local/bin/sing-box
```

> [!info] Updated 2026-11-27
> 上記のフォールバック用ダウンロードコマンドには 2 つの誤りがあります。`SagerNet/sing-box` の GitHub Releases のアーカイブファイル名にはすべてバージョン番号が含まれるため（例：`sing-box-<VERSION>-linux-amd64.tar.gz`）、`sing-box-linux-amd64.tar.gz` を直接リクエストすると 404 になります。また、`.tar.gz` は先に `tar -xzf` で展開して中の `sing-box` バイナリを取り出してから `/usr/local/bin/` へ移動する必要があります。Debian/Ubuntu 環境では、公式の `deb-install.sh` または公式 APT リポジトリを使用してインストールすることを推奨します。

#### ステップ 2：`/etc/sing-box/config.json` の設定

設定ファイルを作成し、ローカルで <span style="color:#e06c75"><del>SOCKS5 (Port 10808) と HTTP プロキシ (Port 10809)</del></span> *(Updated 2026-11-27: 以下の設定では実際には単一の `mixed` インバウンドを使用しており、Port `10809` のみで HTTP と SOCKS5 の両方のプロキシを提供しています。`10808` は有効化されていません)* を待ち受けます。

```json
{
  "log": {
    "level": "info",
    "timestamp": true
  },
  "inbounds": [
    {
      "type": "mixed",
      "tag": "mixed-in",
      "listen": "127.0.0.1",
      "listen_port": 10809
    }
  ],
  "outbounds": [
    {
      "type": "vless",
      "tag": "reality-out",
      "server": "reality.yourdomain.com",
      "server_port": 443,
      "uuid": "YOUR_UUID_HERE",
      "flow": "xtls-rprx-vision",
      "network": "tcp",
      "tls": {
        "enabled": true,
        "server_name": "reality.yourdomain.com",
        "utls": {
          "enabled": true,
          "fingerprint": "chrome"
        },
        "reality": {
          "enabled": true,
          "public_key": "YOUR_PUBLIC_KEY_HERE",
          "short_id": "YOUR_SHORT_ID_HERE"
        }
      }
    },
    {
      "type": "vless",
      "tag": "cdn-out",
      "server": "cdn.yourdomain.com",
      "server_port": 443,
      "uuid": "YOUR_UUID_HERE",
      "network": "ws",
      "tls": {
        "enabled": true,
        "server_name": "cdn.yourdomain.com"
      },
      "transport": {
        "type": "ws",
        "path": "/ray-ws-stream",
        "headers": {
          "Host": "cdn.yourdomain.com"
        }
      }
    }
  ],
  "route": {
    "rules": [
      {
        "outbound": "reality-out"
      }
    ]
  }
}
```

> [!info] Updated 2026-11-27
> `sing-box` 1.11 以降のバージョンでは、ルーティングルールが正式に明示的な `"action": "route"` 構文へ変更されました。デフォルトアウトバウンドのみを設定したい場合は、無条件の空ルールオブジェクトを使う代わりに、`"route"` 内で `"rules": [], "final": "reality-out"` のように記述することを推奨します。

#### ステップ 3：起動とバックグラウンド実行

```bash
# 設定ファイルの構文チェック
sing-box check -c /etc/sing-box/config.json

# 直接起動して実行
sing-box run -c /etc/sing-box/config.json

# 接続テスト
curl -x http://127.0.0.1:10809 https://ip.sb
```
