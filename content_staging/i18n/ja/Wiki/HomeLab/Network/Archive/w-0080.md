# Hexo プラグインのインストール、更新およびよくある設定

> <img src='https://img.shields.io/badge/Status-Obsolete-red?style=for-the-badge&labelWidth=100' height='38' />

## Plugin のインストール方法

Hexo Plugin 公式ページ：[https://hexo.io/plugins/](https://hexo.io/plugins/)

### 基本コマンド

```bash
# インストール
npm install <plugin> --save
# アンインストール
npm uninstall <plugin> --save
# プラグインおよびフレームワークを更新 (Hexo ディレクトリ配下で実行)
npm update
```

### 追加コマンド

先に `npm-check-update` をインストールします

```bash
# Manjaro 環境
pacman -S npm-check-update
```

便利なコマンド：

```bash
# 古くなっているパッケージを確認
npm outdate

# 最新版のパッケージがあるか確認
npm-check-update
# package.json を更新
ncu -u
# パッケージを更新
npm install
```

また、Blog 全体（`package.json` を含む）を `git clone` してきた場合は、インストールコマンドを打ち直す必要はありません：

```bash
# package.json に従って node_module 全体を更新
npm update
```

> [!info] Updated 2026-11-27
> 上記の過去のコマンドにはいくつか誤りと古い記述が含まれていますが、アーカイブ対照用として原文のまま残しています：
> 1. 正しいパッケージ名は `npm-check-updates`（末尾に `s` が付く）であり、Arch／Manjaro の公式リポジトリには収録されていないため、通常は `npm install -g npm-check-updates` でインストールします。
> 2. 古いパッケージを確認する npm サブコマンドは `npm outdated` です（原文では `npm outdate` と誤記されています）。
> 3. `git clone` でプロジェクトを復元し、まだ `node_modules` が作られていない状態では、`npm update` ではなく `npm install`（または `npm ci`）を実行して `package.json` / `package-lock.json` に従い依存関係をインストールする必要があります。

## 関連設定

#### Render-markdown-it-plus Section

```yaml
markdown_it_plus:
    highlight: true
    html: true
    xhtmlOut: true
    breaks: true
    langPrefix:
    linkify: true
    typographer:
    quotes: “”‘’
    pre_class: highlight
```

#### Deployment Section

```yaml
deploy:
  type: git
  repo: https://github.com/<Username>/<username>.github.io
  branch: <branch_name>
```

#### Hexo-html-minifier

```yaml
html_minifier:  
  collapseBooleanAttributes: true
  collapseWhitespace: true
  # Ignore '<!-- more -->' https://hexo.io/docs/tag-plugins#Post-Excerpt
  ignoreCustomComments: [ !!js/regexp /^\s*more/]
  removeComments: true
  removeEmptyAttributes: true
  removeScriptTypeAttributes: true
  removeStyleLinkTypeAttributes: true
  minifyJS: true
  minifyCSS: true
```
