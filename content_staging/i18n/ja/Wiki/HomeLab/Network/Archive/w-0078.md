# Hexo のインストールと事前環境構築

> <img src='https://img.shields.io/badge/Status-Obsolete-red?style=for-the-badge&labelWidth=100' height='38' />

# はじめに

Hexo はとてもシンプルで使いやすい静的サイトジェネレーターで、基本的には npm + Node.js があれば動きます。

## 関連ツール

### Git

#### Linux

- **Arch 系**

```bash
sudo pacman -S git
```

- **Debian/Ubuntu 系**

```bash
sudo apt-get install git-core
```

> [!info] Updated 2026-11-27
> `git-core` は初期の古い移行用パッケージ名です。現在の Debian／Ubuntu 環境では `sudo apt update && sudo apt install git` をそのまま使用してください。

GitHub Desktop の Linux 版はインストールがやや面倒で、特に~~強国~~天朝（中国本土）内で VPN（壁越え）なしの状態だとインストールが大変なので、コマンドライン版の `git` だけで済ませるのがおすすめです。必要ならスクリプトを書いてしまえば十分便利です。

#### Windows

Windows 環境では [GitHub Desktop](https://desktop.github.com/) を直接ダウンロードするのが手軽です。公式ページからダウンロードしてインストールできるほか、Chocolatey 経由でもインストールできます。

```bash
choco install github-desktop
```

### Node.js & npm

#### Linux

- **Arch 系**

```bash
sudo pacman -S nodejs npm
```

- **Debian/Ubuntu 系**

```bash
sudo apt-get install -y nodejs npm 
```

> [!info] Updated 2026-11-27
> Debian／Ubuntu 標準の `apt` リポジトリで提供される Node.js はバージョンが古いことが多く、新しい Hexo やフロントエンドツールの要件を満たさない場合があります。実運用では `nvm`、`fnm`、または NodeSource を使って LTS 版をインストールすることをおすすめします。

#### Windows

GitHub Desktop と同様に、[Node.js](https://nodejs.org/en/) からインストーラーをダウンロードして入れれば npm も同時にインストールされます。Chocolatey を使ってインストールすることも可能です。

```bash
choco install nodejs
```

## Hexo のインストール

Hexo は npm を使ってインストールします。Windows 環境では試したことがありませんが、手順は同じはずです。

```bash
npm install -g hexo-cli
```

コマンドの実行が終わればインストール完了です。
