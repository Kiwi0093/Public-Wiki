## Hexo 本体の設定

Hexo 本体の設定はすべて `<folder>/_config.yml` に記述されており、ほとんどの項目はデフォルトのまま流用できて非常に便利です。必要に応じて一部の項目のみ調整します。

詳細な [Hexo Configuration](https://hexo.io/docs/configuration.html)

### Site セクション

```yaml
# Site
title: Kiwi's Blog
subtitle: 中年大叔的自言自語
description: ''
keywords:
author: Kiwi 
language: zh_TW
timezone: 
```

| 設定          | 説明                                                         |
| :------------ | :----------------------------------------------------------- |
| `title`       | サイトタイトル                                               |
| `subtitle`    | サイトサブタイトル                                           |
| `description` | サイトの説明                                                 |
| `keywords`    | サイトのキーワード（複数指定に対応）                         |
| `author`      | 著者名                                                       |
| `language`    | サイトで使用する言語。[2-letter ISO-639-1 code](https://en.wikipedia.org/wiki/List_of_ISO_639-1_codes) を参照。デフォルトは `en` |
| `timezone`    | サイトのタイムゾーン。Hexo のデフォルトは使用中の PC のタイムゾーンです。[タイムゾーン一覧](https://en.wikipedia.org/wiki/List_of_tz_database_time_zones)から `America/New_York`、`Japan`、`UTC` などを指定できます |

### URL セクション

サイトをサブディレクトリ（例：`http://example.org/blog`）に配置する場合は、`url` を `http://example.org/blog` に、`root` を `/blog/` に設定してください。

```yaml
# URL
url: https://kiwi0093.github.io/
root: /
permalink: :year/:month/:day/:title/
permalink_defaults:
pretty_urls:
  trailing_index: true
  trailing_html: true
```

| 設定                         | 説明                                                         | デフォルト値                |
| :--------------------------- | :----------------------------------------------------------- | :-------------------------- |
| `url`                        | サイトの URL。`http://` または `https://` で始まる必要があります |                             |
| `root`                       | サイトのルートディレクトリ                                   |                             |
| `permalink`                  | 記事の[パーマリンク](https://hexo.io/zh-tw/docs/permalinks)形式 | `:year/:month/:day/:title/` |
| `permalink_defaults`         | `permalink` 内の各セグメントのデフォルト値                   |                             |
| `pretty_urls`                | [`permalink`](https://hexo.io/zh-tw/docs/variables) の値を書き換えて URL を整形します |                             |
| `pretty_urls.trailing_index` | パーマリンク末尾に `index.html` を残すかどうか。`false` にすると除去されます | `true`                      |
| `pretty_urls.trailing_html`  | パーマリンク末尾に `.html` を残すかどうか。`false` にすると除去されます（*末尾の `index.html` には無効*） | `true`                      |

### Directory セクション

```yaml
# Directory
source_dir: source
public_dir: public
tag_dir: tags
archive_dir: archives
category_dir: categories
code_dir: downloads/code
i18n_dir: :lang
skip_render:
```

| 設定           | 説明                                                         | デフォルト値     |
| :------------- | :----------------------------------------------------------- | :--------------- |
| `source_dir`   | ソースフォルダ。コンテンツを格納するディレクトリ             | `source`         |
| `public_dir`   | 静的ファイルフォルダ。ビルド済みファイルを出力するディレクトリ | `public`         |
| `tag_dir`      | タグディレクトリ                                             | `tags`           |
| `archive_dir`  | アーカイブディレクトリ                                       | `archives`       |
| `category_dir` | カテゴリディレクトリ                                         | `categories`     |
| `code_dir`     | Include code 用ディレクトリ                                  | `downloads/code` |
| `i18n_dir`     | 国際化（i18n）ディレクトリ                                   | `:lang`          |
| `skip_render`  | レンダリングをスキップするファイルの指定。[glob 式](https://github.com/micromatch/micromatch#extended-globbing)でパスをマッチできます |                  |

### Writing セクション

```yaml
# Writing
new_post_name: :title.md
default_layout: post
titlecase: false
external_link:
  enable: true
  field: site
  exclude: ''
filename_case: 0
render_drafts: false
post_asset_folder: false
relative_link: false
future: true
highlight:
  enable: true
  line_number: true
  auto_detect: false
  tab_replace: ''
  wrap: true
  hljs: false
prismjs:
  enable: false
  preprocess: true
  line_number: true
  tab_replace: ''
```

| 設定                    | 説明                                                         | デフォルト値 |
| :---------------------- | :----------------------------------------------------------- | :---------- |
| `new_post_name`         | 新規記事のファイル名                                         | `:title.md` |
| `default_layout`        | デフォルトレイアウト                                         | `post`      |
| `auto_spacing`          | 欧文文字と和文・中文文字の間に空白を挿入する                 | `false`     |
| `titlecase`             | タイトルを title case に変換する                             | `false`     |
| `external_link`         | 外部リンクを新しいタブで開く                                 | `true`      |
| `external_link.enable`  | 新しいタブでリンクを開く                                     | `true`      |
| `external_link.field`   | `site` 全体または `post` のみに適用                          | `site`      |
| `external_link.exclude` | 除外するホスト名。必要に応じて `www` を含むサブドメインを指定 | `[]`        |
| `filename_case`         | ファイル名の大文字・小文字変換：`1` で小文字、`2` で大文字   | `0`         |
| `render_drafts`         | 下書きを表示する                                             | `false`     |
| `post_asset_folder`     | [Asset フォルダ](https://hexo.io/zh-tw/docs/asset-folders)を有効にする | `false`     |
| `relative_link`         | リンクをルートディレクトリからの相対パスに変更する           | `false`     |
| `future`                | 未来の日付の記事を表示する                                   | `true`      |
| `highlight`             | コードブロックの設定。使い方は [Highlight.js](https://hexo.io/docs/syntax-highlight#Highlight-js) セクションを参照 |             |
| `prismjs`               | コードブロックの設定。使い方は [PrismJS](https://hexo.io/docs/syntax-highlight#PrismJS) セクションを参照 |             |

### Homepage セクション

```yaml
# Home page setting
```

### Pagination セクション

```yaml
# Pagination
per_page: 10
pagination_dir: page
```

| 設定             | 説明                                              | デフォルト値 |
| :--------------- | :------------------------------------------------ | :----------- |
| `per_page`       | 1 ページあたりの表示記事数（`0` = ページネーション無効） | `10`         |
| `pagination_dir` | ページネーション用ディレクトリ                    | `page`       |

### Include / Exclude セクション

```yaml
# Include / Exclude file(s)
## include:/exclude: options only apply to the 'source/' folder
include:
exclude:
ignore:
```

| 設定      | 説明                                                         |
| :-------- | :----------------------------------------------------------- |
| `include` | Hexo はデフォルトで隠しファイルや隠しフォルダを無視しますが、このフィールドに列挙したファイルは処理対象になります |
| `exclude` | ここに列挙したファイルは Hexo によって無視されます           |
| `ignore`  | 無視するファイル／フォルダ                                   |

### Extension セクション

```yaml
# Extensions
## Plugins: https://hexo.io/plugins/
## Themes: https://hexo.io/themes/
theme: next

# Deployment
## Docs: https://hexo.io/docs/one-command-deployment
deploy:
  type: git
  repo: https://github.com/Kiwi0093/Kiwi0093.github.io
  branch: master
```

| 設定     | 説明                                                         |
| :------- | :----------------------------------------------------------- |
| `theme`  | 使用するテーマ名。`false` にするとテーマ機能を無効化します   |
| `deploy` | デプロイ設定                                                 |

### Update 2021-08-16

GitHub のポリシー変更により HTTPS モードでのユーザー名／パスワード認証が直接使えなくなったため、`deploy` の設定を以下のように変更する必要があります：

```yaml
# Deployment
## Docs: https://hexo.io/docs/one-command-deployment
deploy:
  type: git
  repo: https://<token>@github.com/Kiwi0093/Kiwi0093.github.io
  branch: master
```

この設定にすれば `hexo d -g` の際に username/password の入力が不要になりますが、この token が流出すると大きな問題になるため、最も簡単な対策としてはリポジトリ全体を private に変更しておくとリスクをある程度抑えられます。

> [!info] Updated 2026-11-27
> GitHub は HTTPS パスワード認証を全面廃止しており、Personal Access Token を `_config.yml` に平文で書き込む方法（`https://<token>@github.com/...`）にも認証情報漏洩のリスクがあります。現在では SSH デプロイキー（`git@github.com:...`）、OS の資格情報マネージャー、または GitHub Actions と組み込みの `GITHUB_TOKEN` を組み合わせて GitHub Pages へ自動デプロイする方法が推奨されます。

## Hexo の使い方

```bash
# ビルド済みデータを削除
hexo clean
# 静的ページを生成
hexo g
# ローカルサーバーを起動
hexo s
# サーバーへデプロイ
hexo d
```

### Hexo 構築直後に手動で作成が必要なページ

- カテゴリ一覧ページを追加：`hexo new page categories`

- タグ一覧ページを追加：`hexo new page tags`

  `source/tags/index.md` を編集します：

  ```yaml
  ---
  type: "tags"
  ---
  ```

### Hexo で別の `config.yml` を使用する方法

```bash
# デフォルトの '_config.yml' の代わりにカスタムの 'custom.yml' を使用
$ hexo server --config custom.yml

# 複数の設定ファイルを使用し、競合時は 'custom2.json' を優先
$ hexo server --config custom.yml,custom2.json
```

このエラーが出た場合の解決策は以下のとおりです：

```yaml
# /under/your/web/_config.yml
---------------------------------------------------------------------------------------------------------------------------------
....
html_minifier:  
  collapseBooleanAttributes: true
  collapseWhitespace: true
  # Ignore '<!-- more -->' https://hexo.io/docs/tag-plugins#Post-Excerpt
  #ignoreCustomComments: [ !!js/regexp /^\s*more/]		# この行をコメントアウトすれば OK
  removeComments: true
  removeEmptyAttributes: true
  removeScriptTypeAttributes: true
  removeStyleLinkTypeAttributes: true
  minifyJS: true
  minifyCSS: true
...
```

> [!info] Updated 2026-11-27
> このエラーの主な原因は、Hexo が `js-yaml` v4 へアップグレードされた際に、安全でない `!!js/regexp` YAML タグのパースサポートがデフォルトで削除されたためです（新しいバージョンの Hexo／NexT ではこの記述は削除されています）。
