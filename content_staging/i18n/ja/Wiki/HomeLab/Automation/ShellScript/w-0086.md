## 1. 基本概念：フロー制御ジャンプキーワード

あらゆるループ構造（`while`、`until`、`for`）の内部で処理の流れを制御する主なキーワードは以下のとおりです：

| **キーワード** | **主な挙動** | **典型的な利用シーン** |
| --- | --- | --- |
| **`break`** | **ループ全体を抜け**、直ちにループの `done` 以降の次の行を実行する | ユーザーがメニュー操作を完了したとき、または目的のファイルが見つかったとき |
| **`continue`** | **今回の反復処理をスキップ**し、残りのコードを実行せずにループ先頭の判定へ戻る | 入力ミス時に警告を出して再入力させるとき、または一時ファイルをスキップするとき |
| **`exit`** | **スクリプトプロセス全体を直ちに終了**し、親プロセスへ指定した終了ステータスコード（デフォルト 0）を返す | ユーザーが明示的に終了を選んだとき、または回復不能な致命的エラーが発生したとき |

## 2. 標準的な While + Case 対話型メニュー構成

対話型メニューの用途向けに、プロンプト入力（`read -r -p`）と `case` による不正入力ガードを備えた標準テンプレートを以下に示します：

```bash
#!/usr/bin/env bash

while true; do
    echo "=================================="
    echo "  HomeLab 運用管理メニュー"
    echo "=================================="
    echo "  a) Docker コンテナの状態を確認"
    echo "  b) Nextcloud サービスを再起動"
    echo "  c) データベースのバックアップを実行"
    echo "  q) メニューを終了"
    echo "=================================="
    
    # -r はバックスラッシュのエスケープを防止、-p はプロンプト文字列を表示
    read -r -p "選択肢を入力してください [a-c, q]: " CHOICE

    case "${CHOICE}" in
        a|A)
            echo "--> 実行中のコンテナを一覧表示しています..."
            docker ps --format "table {{.Names}}\t{{.Status}}\t{{.Ports}}"
            break  # 実行完了後にメニューを抜ける
            ;;
        b|B)
            echo "--> Nextcloud を再起動しています..."
            docker compose -f /opt/nextcloud/docker-compose.yml restart
            echo "再起動が完了しました。"
            continue  # メニューの先頭へ戻る
            ;;
        c|C)
            echo "--> バックアップタスクを実行中..."
            /opt/scripts/backup.sh
            continue
            ;;
        q|Q)
            echo "プログラムを終了します。"
            exit 0  # スクリプトを正常終了
            ;;
        *)
            echo "エラー：無効な選択肢 [${CHOICE}] です。再入力してください！" >&2
            sleep 1
            continue
            ;;
    esac
done

echo "メニューを終了し、後続の自動化処理を続行します..."
```

> **構文の細かな注意点**：
> 
> - `case` は複数値マッチに対応しています：パイプ `|` を使うと大文字・小文字を同時に捕捉できます（例：`a|A)`）。
> - 各条件分岐ブロックの末尾には必ずセミコロン 2 つ `;;` を記述し、その分岐処理の終了を示します。
> - `*)` はワイルドカードを表し、それまでの条件に一致しなかったすべての文字にマッチするデフォルトのフォールバック分岐（Default Fallback）として機能します。

## 3. Bash の 3 大定番ループ構文

`case` と組み合わせたメニュー作成のほか、日常的なスクリプトでのデータ処理で最もよく使われるのは以下の 3 種類のループです：

### 3.1 For ループ（固定リスト / 配列 / 範囲反復）

処理対象の数が明確に決まっているシーン（例：複数の Docker Compose プロジェクトの一括点検）に適しています：

```bash
# 1. リストの反復処理
STACKS=("nextcloud" "bookstack" "gitea" "wireguard")

for stack in "${STACKS[@]}"; do
    echo "スタックを確認中: ${stack}..."
    docker compose -f "/opt/${stack}/docker-compose.yml" ps
done

# 2. 数値シーケンス (C 言語スタイル)
for ((i=1; i<=5; i++)); do
    echo "${i} 回目のリトライ..."
done
```

### 3.2 While ループ（条件が真の間、継続実行）

**サービスのヘルスチェックをポーリング待機**し、特定の状態になるまで待つ用途でよく使われます：

```bash
# MariaDB コンテナが完全に起動するまで待機 (Health Check ポーリング)
CONTAINER="gitea_db"

while ! docker inspect --format='{{.State.Health.Status}}' "${CONTAINER}" 2>/dev/null | grep -q "healthy"; do
    echo "${CONTAINER} データベースの初期化を待機中 (2 秒ごとに確認)..."
    sleep 2
done

echo "${CONTAINER} の準備が完了しました。メインアプリを起動します！"
```

### 3.3 ファイルの 1 行ずつ読み込み（While Read パターン）

設定ファイル、ホスト一覧、ログなどを処理する際、**絶対に `for line in $(cat file)` を使ってはいけません**（空白による単語分割でバグの原因になります）。標準的な書き方は `while IFS= read -r line` を使用します：

```bash
# ホスト IP リストを安全に 1 行ずつ読み込み、Ping テストを実行
HOSTS_FILE="/opt/network/hosts.txt"

if [[ -f "${HOSTS_FILE}" ]]; then
    while IFS= read -r host || [[ -n "${host}" ]]; do
        # 空行および # で始まるコメント行をスキップ
        [[ -z "${host}" || "${host}" =~ ^# ]] && continue
        
        if ping -c 1 -W 1 "${host}" >/dev/null 2>&1; then
            echo "[OK] ${host} 接続正常"
        else
            echo "[FAIL] ${host} 接続不可" >&2
        fi
    done < "${HOSTS_FILE}"
fi
```

## 4. 応用テクニック：組み込み Select メニュー構文

番号付きメニューを素早く表示してユーザーに選択させたいだけであれば、Bash 標準の非常に簡潔な `select` 構文が利用できます。番号が自動で描画され、手動レイアウトの煩雑なコードを省けます：

```bash
#!/usr/bin/env bash

PS3="メンテナンスするサービスの番号を選択してください: "  # プロンプト文字列を定義

SERVICES=("Nextcloud" "BookStack" "Gitea" "終了")

select srv in "${SERVICES[@]}"; do
    case "${srv}" in
        "Nextcloud")
            echo "Nextcloud をメンテナンス中..."
            break
            ;;
        "BookStack")
            echo "BookStack をメンテナンス中..."
            break
            ;;
        "Gitea")
            echo "Gitea をメンテナンス中..."
            break
            ;;
        "終了")
            echo "プログラムを終了します。"
            exit 0
            ;;
        *)
            echo "入力エラーです。1 から 4 の数字を入力してください。"
            ;;
    esac
done
```
