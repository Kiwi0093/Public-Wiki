## 1. コア実装：堅牢版 矢印キーメニュー関数 (`select_option`)

この改良版は**相対カーソル位置制御（Relative Cursor Movement）**を採用しており、ターミナルのスクロールの影響を受けやすい `\E[6n` による座標問い合わせに依存しません。そのため動作がより安定しており、主要なターミナル環境（macOS Terminal、Windows Terminal、iTerm2、Linux Console）で幅広く互換性があります。

```bash
#!/usr/bin/env bash

# ==============================================================================
# インタラクティブ矢印キーメニュー関数
# 引数: 選択肢リスト (文字列または配列展開)
# 戻り値: ユーザーが選択した項目のインデックス値 (0, 1, 2...)
# ==============================================================================
select_option() {
    local -a options=("$@")
    local num_options=${#options[@]}

    # 選択肢が1つも渡されない場合はエラーを返す
    [[ $num_options -eq 0 ]] && return 1

    # ANSI エスケープシーケンス定義
    local ESC=$'\033'
    local CURSOR_OFF="${ESC}[?25l"
    local CURSOR_ON="${ESC}[?25h"
    local CLEAR_LINE="${ESC}[2K"
    local TEXT_INVERT="${ESC}[7m"
    local TEXT_RESET="${ESC}[0m"

    # 割り込みシグナル (Ctrl+C) を捕捉し、ターミナルのカーソルと属性を正常に復元する
    trap 'printf "${CURSOR_ON}"; stty echo; printf "\n"; exit 130' INT TERM

    # カーソル表示をオフにする
    printf "%s" "${CURSOR_OFF}"

    local selected=0

    # 初回リスト描画
    local i
    for ((i=0; i<num_options; i++)); do
        if [[ $i -eq $selected ]]; then
            printf "  ${TEXT_INVERT} > %s ${TEXT_RESET}\n" "${options[i]}"
        else
            printf "    %s \n" "${options[i]}"
        fi
    done

    # キーボード入力監視ループ
    while true; do
        # 矢印キーのエスケープシーケンス (\033[A, \033[B) を捕捉するため 3 文字読み取る
        IFS= read -rsn1 key
        if [[ $key == "${ESC}" ]]; then
            read -rsn2 -t 0.1 rest
            key="${key}${rest}"
        fi

        case "$key" in
            "${ESC}[A"|k|K) # 上矢印キー (または Vim キーバインドの k)
                ((selected--))
                [[ $selected -lt 0 ]] && selected=$((num_options - 1))
                ;;
            "${ESC}[B"|j|J) # 下矢印キー (または Vim キーバインドの j)
                ((selected++))
                [[ $selected -ge $num_options ]] && selected=0
                ;;
            "") # Enter キーで選択確定
                break
                ;;
        esac

        # カーソルをリストの先頭まで上に戻し、メニュー全体を上書き再描画する
        printf "${ESC}[%dA" "${num_options}"
        for ((i=0; i<num_options; i++)); do
            printf "${CLEAR_LINE}"
            if [[ $i -eq $selected ]]; then
                printf "  ${TEXT_INVERT} > %s ${TEXT_RESET}\n" "${options[i]}"
            else
                printf "    %s \n" "${options[i]}"
            fi
        done
    done

    # カーソルと環境を復元する
    printf "%s" "${CURSOR_ON}"

    # 選択されたインデックス値を出力する
    echo "$selected"
}
```

## 2. 基本的な使用例：固定オプションメニュー

```bash
echo "[上下矢印キー] で移動し、[Enter] で選択を確定してください："
echo

MENU_ITEMS=("すべての Docker コンテナを起動" "Nextcloud サービスを停止" "データベースのバックアップを実行" "スクリプトを終了")

# 関数を呼び出して選択されたインデックスを受け取る
CHOICE_INDEX=$(select_option "${MENU_ITEMS[@]}")

echo "----------------------------------------"
echo "選択された項目のインデックス: ${CHOICE_INDEX}"
echo "選択された項目の内容: ${MENU_ITEMS[CHOICE_INDEX]}"

case "${CHOICE_INDEX}" in
    0) echo "コンテナを起動しています..." ;;
    1) echo "サービスを停止しています..." ;;
    2) echo "バックアップを実行しています..." ;;
    3) echo "プログラムを終了します。"; exit 0 ;;
esac
```

> [!info] Updated 2026-11-27
> 上記の `select_option` では、メニュー画面の `printf` と最終的なインデックスの `echo "$selected"` の両方を標準出力（`stdout`）に出力しています。そのため、`CHOICE_INDEX=$(select_option ...)` のようなコマンド置換と併用すると、メニューの ANSI 制御コードまで変数に吸い込まれてしまい、ターミナル上に正常に表示されなくなります。実運用では関数内のメニュー描画とカーソル制御を `>&2`（`stderr`）または `/dev/tty` にリダイレクトし、最後の `echo "$selected"` のみを `stdout` に出力するようにしてください。また、メインスクリプト側の `trap` を上書きしないよう、`trap '...' RETURN` を併用するか、関数終了前に `INT TERM` シグナルハンドラを復元することをおすすめします。

## 3. 動的ディレクトリの空行問題の解消：動的配列との組み合わせ

元のメモでは `DATE1=$(ls ... | sed -n '1p')` のように 5 つの変数をハードコーディングしていたため、実際のディレクトリ数が 5 未満のときに空白行が生じていました。

**標準的な解決策**：`mapfile`（または `readarray`）を使って実在するディレクトリを**配列へ動的に読み込み**、最後に `終了 (Exit)` 選択肢を動的に追加します：

```bash
#!/usr/bin/env bash

BACKUP_DIR="/storage/backup"

# 1. ディレクトリの存在確認
if [[ ! -d "${BACKUP_DIR}" ]]; then
    echo "エラー：バックアップディレクトリ ${BACKUP_DIR} が存在しません！" >&2
    exit 1
fi

# 2. 該当ディレクトリ配下のすべての「サブディレクトリ名」を配列へ動的に読み込む
# 方法 A：find を使用 (最も正確で通常ファイルを除外できる)
mapfile -t BACKUP_LIST < <(find "${BACKUP_DIR}" -mindepth 1 -maxdepth 1 -type d -exec basename {} \; | sort -r)

# 3. バックアップデータの有無を確認
if [[ ${#BACKUP_LIST[@]} -eq 0 ]]; then
    echo "通知：現在利用可能なバックアップディレクトリはありません。"
    exit 0
fi

# 4. 配列の末尾に「終了」オプションを動的に追加
BACKUP_LIST+=("キャンセルして終了 (Exit)")

# 5. メニューを描画
echo "復元するバックアップスナップショットディレクトリを選択してください："
SELECTED_IDX=$(select_option "${BACKUP_LIST[@]}")

# 6. ユーザーの選択を判定
LAST_IDX=$((${#BACKUP_LIST[@]} - 1))

if [[ "${SELECTED_IDX}" -eq "${LAST_IDX}" ]]; then
    echo "ユーザーにより操作がキャンセルされました。スクリプトを安全に終了します。"
    exit 0
fi

CHOSEN_BACKUP="${BACKUP_LIST[SELECTED_IDX]}"
echo "--------------------------------------------------"
echo "バックアップディレクトリを選択しました: ${CHOSEN_BACKUP}"
echo "フルパス: ${BACKUP_DIR}/${CHOSEN_BACKUP}"
echo "復元プロセスを準備しています..."
```

## 4. 主要な技術ポイントと注意点まとめ

|**項目**|**従来のハードコーディング方式**|**動的配列のベストプラクティス (Best Practice)**|
|---|---|---|
|**ディレクトリ取得**|`DATE1=$(ls \| sed -n '1p')`|`mapfile -t LIST < <(find ... -type d)`|
|**空白の選択肢**|宣言した変数よりディレクトリが少ないと必ず空白が出る|配列の要素数分だけ描画されるため、空白ゼロ|
|**異常終了 (Ctrl+C)**|カーソルが消えたままになり、端末に文字がエコーバックされない|`trap` を追加し、割り込み時に `stty echo` とカーソルを復元|
|**カーソル上書き機構**|`\E[6n` は端末の絶対座標に依存（スクロール時に表示崩れしやすい）|`\033[NA` の相対行数戻りと `\033[2K` による行全体消去を組み合わせ|
