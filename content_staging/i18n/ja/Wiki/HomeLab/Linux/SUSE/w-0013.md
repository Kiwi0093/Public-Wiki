## 1. はじめに：Zypper と強力な依存関係リゾルバーを知る

Zypper は SUSE ファミリー（安定版の openSUSE Leap、ローリングリリースの Tumbleweed、およびエンタープライズ版の SLES を含む）のコマンドライン・パッケージ管理ツールです。

2 つの大きな看板機能があります：

1. **最強クラスの依存関係リゾルバー (SAT Solver)：** パッケージの競合が発生した際、Zypper は単にエラーを出して停止するのではなく、複数の解決策（例：A をダウングレード、B を削除、または現状維持など）を提示し、選択肢を選ぶ感覚で競合を解消できます。
2. **徹底した短縮コマンド対応：** ほぼすべてのコマンドに短縮形が用意されており（例：`install` = `in`、`search` = `se`）、非常に高速に入力できます。

## 2. 基本メンテナンス：日常アップデート（Leap と Tumbleweed の違い）

ここには極めて重要な概念があります！openSUSE には 2 つのエディションがあり、アップデートコマンドが**まったく異なります**。間違ったコマンドを実行するとシステムが不整合に陥る可能性があります。

**1. openSUSE Leap（固定リリース版、Ubuntu/Debian に近い）** セキュリティ更新とバグ修正のみを行うため、以下を使用します：

```bash
sudo zypper update
# 短縮形：
sudo zypper up
```

**2. openSUSE Tumbleweed（ローリングリリース版、Arch に近い）** カーネルを含めすべてのパッケージが継続的に刷新されるため、ディストリビューション・アップグレードコマンドを使用する必要があります。パッケージのダウングレード、削除、依存関係の再構築を自動的に処理します：

```bash
sudo zypper dist-upgrade
# 短縮形：
sudo zypper dup
```

## 3. パッケージのインストール・検索・クリーンアップ

Zypper の短縮コマンドは非常に直感的で、日常操作のほとんどが 2〜3 文字で済みます。

**1. 検索とインストール**

```bash
# パッケージを検索 (Search)
zypper se <キーワード>

# パッケージの詳細情報を表示 (Info)
zypper info <パッケージ名>

# パッケージをインストール (Install)
sudo zypper in <パッケージ名>
```

**2. クリーンアンインストールと孤立パッケージの削除** `apt` と同様に、単に `zypper rm` を実行しただけでは依存パッケージがシステムに残ります。

```bash
# パッケージをきれいに削除し、「そのパッケージのために導入され、現在は他から使われていない依存パッケージ」も併せて削除 (-u = clean-deps)
sudo zypper rm -u <パッケージ名>

# システム内のすべての孤立パッケージ (不要になった依存パッケージ) を一覧表示
zypper packages --unneeded

# 実用テクニック：すべての孤立パッケージを一括削除
sudo zypper rm -u $(zypper packages --unneeded | awk -F'|' 'NR>4 {print $3}')
```

## 4. キラー機能：Btrfs + Snapper によるシステムスナップショットのシームレス復元

これは SUSE ファミリーが他を圧倒している機能です。インストール時にデフォルトの Btrfs ファイルシステムを選択していれば、**手動でスナップショットを取る必要すらありません。**

`zypper in`（インストール）や `zypper dup`（大型アップデート）を実行すると、Zypper が裏で自動的に Snapper を呼び出し、「更新前」と「更新後」のスナップショットを作成してくれます。

**アップデートでシステムが壊れて起動しなくなったら？**

1. 再起動し、GRUB ブートメニューで `Start bootloader from a read-only snapshot` を選択します。
2. メニューに直近の Zypper 操作履歴と日時が一覧表示されます。
3. 更新前の正常に動作していたスナップショットを選び、Enter キーを押して起動します。
4. この読み取り専用の「タイムマシンシステム」で起動したら、ターミナルを開いて問題がないことを確認し、次のコマンドを実行します：

   ```bash
   sudo snapper rollback
   ```

5. 現在の状態が即座にデフォルトとして設定されるため、再起動すれば完全に元通りになります！ハイパーバイザー側で仮想マシン（VM）のスナップショットを操作する必要は一切ありません。

## 5. 応用テクニック：Patterns（パターン）とパッケージロック

**1. Patterns（パッケージグループ）** Zypper は単体パッケージだけでなく、関連するソフトウェア一式を `Pattern` としてまとめています（例：KDE デスクトップ環境全体、LAMP サーバー環境全体、C/C++ 開発環境など）。

```bash
# システム内のすべての Pattern を一覧表示
zypper patterns
# 短縮形：
zypper pt

# 特定の Pattern をインストール (例：KVM 仮想化ホスト環境)
sudo zypper in -t pattern kvm_server
```

**2. パッケージのロック (Locks)** 特定のソフトウェア（例：特定バージョンの Docker）をアップグレードさせたくない場合は、ロックをかけることができます。

```bash
# ロックを追加 (Add Lock)
sudo zypper al <パッケージ名>

# 現在ロックされているすべてのパッケージを一覧表示 (List Locks)
zypper ll

# ロックを解除 (Remove Lock)
sudo zypper rl <パッケージ名>
```

**3. キャッシュのクリーンアップ** ディスク容量を解放したいときに使います：

```bash
# ダウンロード済みのパッケージファイルとメタデータキャッシュをすべて削除
sudo zypper clean -a
# 短縮形：
sudo zypper cc -a
```
