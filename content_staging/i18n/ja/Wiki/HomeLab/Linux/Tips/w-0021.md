# Linux デスクトップ環境で GUI アプリを root 権限で実行する方法

一部のグラフィカルユーザーインターフェース（GUI）アプリケーション（例：SonicWall NetExtender）は操作画面を備えているものの、バックグラウンドでシステムの低レイヤーツール（`pppd` やネットワークルーティング設定など）を呼び出す際に root 権限を必要とします。一般ユーザー権限のまま直接起動すると、権限不足により接続に失敗することがよくあります。

> [!warning] Updated 2026-11-27
> 現代の Linux デスクトップ環境で以下の方法を使用する場合は、次の互換性上の制限にご注意ください：
> 1. **Wayland 環境での制限**：KDE Plasma 6 や GNOME など現代の Wayland デスクトップでは、`su`、`sudo`、または `pkexec` で GUI アプリを直接起動しても、ユーザーの Wayland ソケットにアクセスできず失敗するのが一般的です。アプリが XWayland 経由で動作する場合は、事前に `xhost +SI:localuser:root` を実行する必要が生じることがあります（使用後は `xhost -SI:localuser:root` で元に戻すことを推奨します）。
> 2. **`pkexec` による GUI 起動**：`pkexec` はデフォルトで `DISPLAY` や `XAUTHORITY` などの環境変数をクリアするため、`/usr/share/polkit-1/actions/` に対応する `.policy` 設定ファイルを作成し、`<annotate key="org.freedesktop.policykit.exec.allow_gui">true</annotate>` を追加しないと正常にウィンドウを開けません。
> 3. **`kdesu` のパス差異**：多くの現代の KDE ディストリビューションでは、`kdesu` が `$PATH` に含まれなくなっています（通常は `/usr/lib/kf6/kdesu` や `/usr/lib/kf5/kdesu` に配置されています）。
> 4. **Polkit グループ名**：以下のサンプルにある `subject.isInGroup("wheel")` は Arch／Fedora／RHEL 系向けです。Debian／Ubuntu 系を使用している場合は `"sudo"` グループに変更する必要があります。

## コマンドライン端末からの実行方法 (CLI)

- **`su` でユーザーを切り替える：** 直接 root アカウントへ切り替えてからアプリケーションを起動します。

  ```bash
  su -
  netExtenderGui
  ```

- **`sudo` で一時的に権限昇格する：** 現在のユーザーが `sudoers` リストに追加されている必要があります。

  ```bash
  sudo netExtenderGui
  ```

## デスクトップショートカットとメニューの修正方法 (.desktop)

アプリケーションメニューやデスクトップショートカットをクリックした際に、自動でパスワード入力ダイアログが表示され root 権限で起動するようにしたい場合は、対応する `.desktop` ファイル（通常は `/usr/share/applications/` または `~/.local/share/applications/` にあります）を編集する必要があります。

- **KDE デスクトップ環境 (`kdesu`)** テキストエディタで `.desktop` ファイルを開き、`Exec=` フィールドを `kdesu` を使うように書き換えます：

  ```ini
  # 変更前
  Exec=/usr/bin/netExtenderGui

  # 変更後
  Exec=kdesu /usr/bin/netExtenderGui
  ```

- **GNOME / XFCE / 汎用デスクトップ環境 (`pkexec`)** 非 KDE 環境では、現代の Linux 標準である PolicyKit 権限昇格ツール `pkexec` の使用を推奨します：

  ```ini
  # 変更後
  Exec=pkexec /usr/bin/netExtenderGui
  ```

  _変更完了後、システムに即座に反映されない場合は、以下のコマンドを実行してデスクトップデータベースを更新してください：_

  ```bash
  update-desktop-database ~/.local/share/applications/
  ```

## 応用：Polkit によるパスワードなし実行の実現

毎回その GUI ソフトを起動するたびに手動で root パスワードを入力したくない場合は、PolicyKit ルールを使って許可ホワイトリストを作成できます。

1. `/etc/polkit-1/rules.d/` ディレクトリ配下に設定ファイルを作成します（例：`49-netextender.rules`）：

   ```bash
   sudo nano /etc/polkit-1/rules.d/49-netextender.rules
   ```

2. 以下のルール内容を記述します（`wheel` または `sudo` グループに属するユーザーに対してパスワードなし実行を許可）：

   ```javascript
   polkit.addRule(function(action, subject) {
       if (action.id == "org.freedesktop.policykit.exec" &&
           action.lookup("program") == "/usr/bin/netExtenderGui" &&
           subject.isInGroup("wheel")) {
           return polkit.Result.YES;
       }
   });
   ```
