## chage コマンドとオプション詳細

Linux システムのアカウントパスワード有効期限は `shadow` ファイルで管理されており、主に `chage` コマンドを使って調整します。以下は主要なオプションと実際の使用例です。

- **アカウントの現在の状態を一覧表示する (`-l`)**

    ```bash
    sudo chage -l john
    ```

    出力内容には、最終パスワード変更日、パスワード有効期限、期限切れ前の警告日数、アカウント無効化日、およびパスワード変更の最小/最大間隔が含まれます。

- **パスワードの最大有効日数を設定する (`-M`)**

    ```bash
    sudo chage -M 90 john
    ```

    ユーザーに対して 90 日ごとのパスワード変更を強制します。`-1` を設定すると、そのユーザーのパスワードは無期限になります。

- **パスワード変更の最小間隔日数を設定する (`-m`)**

    ```bash
    sudo chage -m 7 john
    ```

    パスワードを変更した後、少なくとも 7 日間は再変更できないように制限します。連続してパスワードを変更することでパスワード履歴の制限を回避する行為を防止できます。

- **パスワード期限切れ前の警告日数を設定する (`-W`)**

    ```bash
    sudo chage -W 14 john
    ```

    パスワードの有効期限まで残り 14 日を切ると、ユーザーがターミナルへログインするたびに警告メッセージが表示されます。

- **アカウント自体の絶対有効期限を設定する (`-E`)**

    ```bash
    sudo chage -E 2026-12-31 john
    ```

    そのアカウントを利用できる最終期限を指定します（書式は `YYYY-MM-DD`）。この日付を過ぎると、パスワードの有効期限にかかわらずアカウントが直接ロックされます。

## パスワード複雑性の設定 (pwquality.conf)

近年の Linux ディストリビューションでは、通常 `libpwquality` を用いてパスワード強度を検証します。`/etc/security/pwquality.conf` ファイルを編集してパスワード強度ポリシーを定義します。

| **設定パラメータ** | **デフォルトまたは推奨値** | **説明** |
| --- | --- | --- |
| `minlen` | `12` | 許可されるパスワードの最小文字数。 |
| `minclass` | `3` | 含める必要がある文字種の数（大文字、小文字、数字、記号）。 |
| `dcredit` | `-1` | 負の値は最低限含めるべき数字の個数を表します（例：`-1` は最低 1 文字）。 |
| `ucredit` | `-1` | 最低限含めるべき大文字アルファベットの個数。 |
| `lcredit` | `-1` | 最低限含めるべき小文字アルファベットの個数。 |
| `ocredit` | `-1` | 最低限含めるべき記号の個数。 |
| `maxrepeat` | `3` | 同じ文字の連続使用を許可する最大回数。 |
