## Archinstall：現代における Arch Linux インストールの標準

もし今でも手作業で `pacstrap` を叩いたり `fstab` を手書きしたりしているなら、本当にお疲れ様です。今の Arch Linux のインストールに必要な前提条件はただ一つ、ネットワークが通ることだけです。ネットワークさえ繋がれば、`archinstall` コマンド一発で「自動インストールの快感」を味わえます。

これは単なるスクリプトではなく、メニューベースの対話型インストーラー（TUI）です。Ubuntu や Manjaro のような重たい Calamares GUI インターフェースと比べて、`archinstall` ははるかに高速で安定しており、何より「システムに対する完全な制御権を手元に残しつつ、繰り返しの単純作業に時間を取られない」という点が最大の強みです。

### 🛠 基本フロー：起動、ネット接続、実行

Arch Live 環境に入ったら、焦ってパーティションを切る前にこの 3 ステップを進めます：

1. **ネットワークの確認**：`ping google.com` で確認します。Wi-Fi の場合は `iwctl` で接続しておきます。ここを通らないと先へ進めません。

2. **神ツールの起動**：Shell 上でそのまま以下を入力します：

   ```bash
   archinstall
   ```

3. **穴埋め問題タイム**：画面に一連のメニューが表示されます。テストではないので直感に沿って選んでいけば大丈夫です（詳細は下の高度な設定ポイントを参照）。

### ⚡ 高度な設定ポイント（適当に選ばず、ここをチェック）

自動化されているとはいえ、要所の選択肢を正しく選んでこそ、あなたの Arch は真価を発揮します：

#### 1. ディスク構成（Disk Layout）—— Btrfs を推奨

従来の ext4 を使い続けるのはもうやめましょう。「Wipe all selected drives」を選び、ファイルシステムに Btrfs を指定します。圧縮やサブボリューム（Subvolumes）に対応しているため、後からスナップショットバックアップ（Timeshift など）を組むのが非常に楽になります。

<img src='https://img.shields.io/badge/Kiwi-%E4%BD%86%E6%98%AF%E6%88%91%E9%83%BD%E7%94%A8ext4-A8FF24?style=social&logo=kiwix&logoColor=EA7500' height='40' />

#### 2. カーネル（Kernels）—— パフォーマンス重視なら必見

- 安定重視なら：`linux`。
- 爆速重視なら：`linux-zen`。デスクトップ用途では、Zen カーネルのレスポンス速度やスケジューリング最適化は体感できるレベルで違います。

#### 3. プロファイル（Profiles）—— ズボラ勢の福音

ここが一番気持ちいいところです。Desktop を選んだあと、KDE、GNOME、Sway、Hyprland などを直接選べます。対応するディスプレイマネージャ（SDDM や GDM など）と基本ドライバも自動でまとめて補完してくれます。

#### 4. グラフィックスドライバ（Graphics Driver）

ハードウェアを自動検出してくれます。NVIDIA ユーザーならプロプライエタリドライバ（Proprietary）を、AMD や Intel ならオープンソースドライバを選べば OK です。自分で手探りするより正確に入れてくれます。

### 💾 神ワザ：設定ファイルの「家宝」モード

個人的に `archinstall` が `Calamares` を完全に圧倒していると感じるのがこの機能です。

インストールの最後に、User Configuration を保存するかどうか聞いてきます。これを選ぶと JSON ファイルが生成されます。絶対に保存しておきましょう！

- **メリット：** 今後新しい PC に買い替えたり、別の仮想マシンにまったく同じ環境を構築したりする際、メニューをポチポチ操作する必要すらなくなります。

使い方：その JSON を USB メモリなどに放り込み、起動後に以下を実行するだけです：

```bash
archinstall --config my_favorite_setup.json
```

> [!info] Updated 2026-11-27
> 新しいバージョンの `archinstall` では、アカウントとパスワードの設定が `user_credentials.json` に分離されています。完全に無人で自動デプロイしたい場合は、設定ファイルと認証情報ファイルの両方を渡す必要があります：`archinstall --config user_configuration.json --creds user_credentials.json`。

あとはコーヒーを淹れに行くだけです。これこそ本当の「Infrastructure as Code」であり、自分のインストール習慣そのものをコード化するアプローチです。

### ⚖️ なぜ GUI インストーラーを使わないのか？

- **速度：** Calamares は GUI の読み込みや謎の展開処理で引っかかることがよくあります。`archinstall` は裏側が Python ロジックで動いており、純粋なテキスト UI のためレスポンスが極めて高速です。
- **クリーンさ：** 多くの GUI インストーラーはデフォルトで不要なソフトを大量に詰め込んできます。`archinstall` が提供してくれるのは公式の純粋な Arch であり、自分が選んだものだけが入ります。
- **自動化の柔軟性：** 生成された `config.json` をいつでも開いて書き換えられます。このレベルのカスタマイズ性は GUI インターフェースでは決して得られないものです。
