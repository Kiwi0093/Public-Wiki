> 3. **パッケージ更新と入力メソッド**：`pacman -Syyuu` はデータベースの強制再ダウンロードとパッケージのダウングレードを許可するため、日常のシステム更新では `pacman -Syu` を使用してください。また、比較的新しいシステムでは中国語入力メソッドに `fcitx5` の利用を推奨します。
> 4. **クロスファイルシステム I/O**：Windows 側ディレクトリ（`/mnt/c/...`）配下で `git` やビルドコマンドが遅くなるのは、WSL2 が 9P プロトコル経由で NTFS にアクセスする既知の特性によるものです。プロジェクトを Linux ネイティブの ext4 ディレクトリ（`~/` など）へ移動することで大幅に改善します。

# ManjaroWSL2（wsldl ベース）のインストールと使用記録

[GitHub - sileshn/ManjaroWSL2: Manjaro for WSL2 using wsldl](https://github.com/sileshn/ManjaroWSL2)

このプロジェクトは基本的に前のバージョンと同じく [wsldl: Advanced WSL launcher](https://github.com/yuk7/wsldl) を利用した実装になっているため、自分でカスタマイズして構築したい方は `wsldl` を使って自作することもできます。

## Install

ダウンロードしたファイルを好きな場所に展開し、展開された `Manjaro.exe` を実行して案内に従って進めるだけで完了します。

## 基本設定

```bash
# make sure you're root
# Set your mirrorlist to what you like
pacman-mirrors -c tw
# system full update
pacman -Syyuu
# Install basic tools
pacman -S yay neovim zsh noto-fonts-cjk .......etc 
# completed
```

上の内容を見て「えっ、これだけ？」と驚かれたでしょうか？見た目としては普通の `Manjaro` のセットアップとまったく同じですよね……。

その通りで、基本的には同じです（だからこそ最高なのです）。

ただし、以前のバージョンの説明と比べると少し違う点があります：

* DE をインストールしなくても普通に GUI アプリが動く

例えば `pacman -S brave-browser` を実行すればそのまま Brave がインストールされ、さらに不思議なことに何もしなくても Windows 側に自動でショートカットが作成されます：

![](https://raw.githubusercontent.com/Kiwi0093/graph/master/img/start_manu_wsl.png)

このように、インストールしたものがすべて自動でショートカットとして登録されます。

これにより、`wslg` を別途立ち上げなくても Windows から直接起動できるようになります。

## 注意点

WSL はやはり一種の VM（特に WSL2）であるため、Linux の GUI アプリを直接実行できるとはいえ、Windows 側の英語以外の入力メソッドをそのまま Linux GUI アプリへ入力することはできません。そのため、`fcitx` や関連する入力方式（`chewing` など）を別途インストールする必要があります。

### 中国語入力メソッド

```bash
# /etc/profile に以下を追加
# Add Chinese Input Support
export GTK_IM_MODULE=fcitx
export XMODIFIERS=@im=fcitx
export QT_IM_MODULE=fcitx
export DefaultIMModule=fcitx
fcitx-autostart &>/dev/null
```

その後、`powershell` で `wsl --shutdown` を実行して WSL を一度終了させてから、再度 `wsl` で起動します。

DE を入れていないためマウスクリックで入力メソッドを切り替えられないので、グローバルホットキー（global hot key）を設定して起動できるようにしておくのを忘れないでください。

### I/O が遅い問題

I/O 部分が改善されているかと期待していたのですが、`Windows` 配下のフォルダで `git clone`、`git push`、`hexo g -d` といったよく使うコマンドを実際に試してみると、やはりこの I/O は厳しいなとはっきり分かります……。

# まとめ

WSL1.0 は systemd に対応していて GUI アプリも wslg なしで問題なく動かせるのは魅力的ですが、中国語入力メソッドがときどき不安定になったり、I/O がまだ遅かったりと、まだ改善の余地がある部分も見えてきます。

とはいえ、ライトユース（あるいはミドルユース）程度であれば十分に扱いやすい環境です。
