# 基本的な手順

## `xrdp` & `xorgxrdp` のインストール

```bash
yay -S xrdp xorgxrdp
```

その後、サービスを起動します：

```bash
sudo systemctl enable --now xrdp.service
sudo systemctl enable --now xrdp-sesman.service
```

これで使えるようになります。基本的に他の設定は一切変更しなくて大丈夫です。

> [!info] Updated 2026-11-27
> 本記事は初期 X11 時代の KDE Plasma 5 と `~/.xinitrc` アーキテクチャ向けに書かれたものです。現在の KDE Plasma 6 では標準で Wayland が採用されているため、従来の X11 ベースである `xrdp` + `xorgxrdp` と `~/.xinitrc` を使う手法はそのままでは適用できません（Wayland 環境の KDE Plasma 6 では、代わりに公式の `krdp` / KRdp を使用して RDP リモートデスクトップサービスを提供できます）。
