## Tweak

### 環境条件

* Manjaro KDE 21.0.7

#### Mirror-list の変更

Manjaro が Arch より親切な点のひとつは、設定ファイルを直接編集しなくても専用ツールで Mirror-list を変更できることです（人によっては設定ファイルを直接編集する方がシンプルで速いと感じるかもしれませんが）。

```bash
# 国別に選択
sudo pacman-mirrors --country <Country Name>
# 速度順に選択
sudo pacman-mirrors --fasttrack <数>
```

以前は中国に住んでいたため、GFW 回避のために Mirror-list を中国に設定するのが習慣になっていました。

今は台湾に戻ったので、基本的には速度優先で選ぶか、そもそも特に指定しなくても問題ないはずです。

#### VGA Driver のインストール

```bash
sudo mhwd -a [pci or usb connection] [free or nonfree drivers] 0300
```

これで自動検出からダウンロード・インストールまで一括で行えます。

#### VM Guest OS

##### インストール ISO から起動できない

21.0.6 で発生した問題です。おそらく Manjaro 側で VM ゲスト向けドライバーの調整が入った影響で、デフォルト起動の `driver=free` では正しく画面出力を駆動できず、mhwd の検出処理で止まってしまうようでした。

対処法として、起動メニューで GRUB の起動パラメータを手動で書き換えます。

```bash
# デフォルトパラメータの
driver=free
# を以下に変更
driver=mesa
```

`mesa` に切り替えることで起動できるようになりましたが、21.0.7 ではこの問題自体が修正されていました。

##### VM 起動後に解像度のリサイズや画面サイズへの自動フィットができない

21 系になってからの不具合です（以前の 20 や 19 では起きなかったので、今後のバージョンで直るかもしれません）。原因は VM 用のディスプレイドライバー不足です。

```bash
# 必要なパッケージをインストール
sudo pacman -S open-vm-tools virtualbox-guest-utils
```

`video-virtualmachine` ドライバーは何度試してもインストールに失敗したため（そのうち直るでしょう）、厳密には正規の解決策ではありません。

ただ、これを入れておけば画面のリサイズ自体は動くようになるので、ひとまずこれで良しとしました。

##### yakuake

ドロップダウン式のコンソールです。以前はアンインストールしていましたが、最近になって意外と便利なことに気づいたので残しています。特別な設定はなく、基本は以下の通りです。

* ドロップダウン時の横幅を調整（自分は 90% が好み）
* ドロップダウン時の高さを調整（自分は 80% が好み）
* 使用するシェルを `/bin/zsh` に設定（`chsh` でデフォルトシェルを変更しておいても OK）

使いたいときに `F12` を押すだけで呼び出せます（キー割り当ては変更できそうですが、個人的には `F12` で十分使いやすいです）。他の GUI アプリを操作すると自動で引っ込んで邪魔になりません。

`exit` しない限り、もう一度 `F12` を押せば実行中のコンソールがそのまま戻ってくるのがとても便利です。

## Application

Manjaro は基本的にデスクトップ用としてしか使っていないため、それほど凝ったアプリは入れていません。

### ネットワーク関連

#### Browser

現在のメインブラウザは Brave ですが、AUR にあるため `yay` でインストールします。

```bash
yay -S brave-bin
```

コンパイル待ちで時間が溶けるのを防ぐため、`brave-bin` を指定します。
これで完了です。普段は使わないので、標準の Firefox はついでに削除することが多いです。

#### FTP client

```bash
yay -S filezilla
```

FileZilla は SFTP や ppk ファイルにも対応していて便利ですが、最近は Web クラウド経由でファイルをやり取りすることが増え、従来の FTP/SFTP を使う機会が減ってきたので無理に入れなくてもよいかもしれません。

#### RDP

```bash
yay -S remmina freerdp
```

これで他の Windows マシンを RDP でリモート操作できます。

#### GitHub Desktop (Optional)

```bash
yay -S github-desktop
```

コンソールから git を使えますが、~~時には GUI の方が便利なこともあります~~ やはり CLI の方が使いやすいです。

#### Hexo (Optional)

```bash
yay -S nodejs npm
```

私の場合は自分の Blog/Wiki 用に Hexo を入れています。そうでない場合でも、適当なディレクトリで以下を実行すれば使い始められます。

```bash
sudo npm install -g hexo-cli
```

> [!info] Updated 2026-11-27
> 実務上、`sudo npm install -g` でグローバルインストールを行うことは権限トラブルの原因になりやすいため推奨されません。現在は NVM や fnm などのバージョン管理ツールの利用が推奨されます。また、本サイトも Hexo から Docusaurus へ移行済みです。
