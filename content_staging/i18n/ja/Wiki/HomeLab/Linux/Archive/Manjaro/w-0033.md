> - `pacman-mirrors` は Manjaro 専用ツールであり、標準の Arch Linux では使用できません。Arch Linux 環境では代わりに `reflector` を使用してください（例：`sudo reflector --country Taiwan,Japan --latest 10 --sort rate --save /etc/pacman.d/mirrorlist`）。

##### 国別（Country）で選択

```Bash
sudo pacman-mirrors --country <County Name>
```

このコマンドは、指定した Country のサーバーリストに対して速度計測を行い、mirror-list を作成します。

##### 速度で選択

```Bash
sudo pacman-mirrors --fasttrack <數量>
```
