> [!tip]
> Manjaro 21 KDE が何を血迷ったのか、VMware Workstation にインストールした際に以下の 2 つの問題が発生していました：
> * ~~Free driver および non-free driver のどちらでも起動できない~~（21.0.7 で修正済み）
> * インストール後に VM 用の Display driver が入っておらず、表示に問題が出る

# Boot from USB/ISO

すでに問題は解消されていますが、当時の対策を補足として残しておきます：

```bash
# 開機的時候進入grub editor把
driver=free 改成 driver=mesa
```

これで起動できるようになりました。

# Display issue fix

基本的には、VMware と VirtualBox の両方で使える汎用ドライバ `video-virtualmachine` が不足しているのが原因です：

```
#先安裝上需要的package
sudo pacman -S virtualbox-guest-utils open-vm-tools
sudo mhwd -i pci video-virtualmachine
sudo systemctl enable vmtoolsd.service
sudo systemctl start vmtoolsd.service
```

理論上はこれで解決します。

> [!info] Updated 2026-11-27
> Manjaro 21 はすでに旧バージョンとなっています（`driver=mesa` の起動問題は 21.0.7 以降で修正済みです）。また、VMware 仮想マシンでは `open-vm-tools` のみをインストールすればよく（VirtualBox 専用の `virtualbox-guest-utils` は不要です）、`vmtoolsd.service`（および必要に応じて `vmware-vmblock-fuse.service`）を有効化すれば十分です。現在の Linux／Manjaro カーネルと Mesa にはすでに `vmwgfx` サポートが標準で組み込まれているため、上記の古い GRUB パラメータや `mhwd` による回避手順を適用する必要はありません。
