### 内容紹介

このスクリプトは、自分が使っている **Manjaro** 環境を新しくセットアップしたマシンや VM 上へ素早く移植し、作業環境の再設定や調整の手間を減らすためのものです。この記事ではまず全体として何がインストールされ、どんな環境ができるかを説明し、スクリプトの詳細は後ろでセクションごとに解説します

- **_Terminator_** :

  タブ分割に対応したコンソールアプリです。以前 Garuda に搭載されているターミナルを見かけたときになかなか格好良かったので、他に使い勝手の良さそうなものが見つかれば乗り換えるかもしれません

- **_PowerLevel10k_** :

  基本的にはターミナルの見た目カスタマイズツールですが、Linux 環境でターミナルを使う頻度は非常に高いので、見栄えを綺麗にしておいたほうが気分良く作業できますよね？基本構成は **powerlevel10k** にいくつかの Nerd Font を組み合わせ、おまけで **neofetch** を入れる程度です

- **_V2ray シリーズ_** :

  ~~壁の国~~天朝に暮らしているため、これは必須のプログラムになっています（もっとも寮内だけで使うマシンなら gateway 側で処理済みなので入れなくても済みますが）。主には **Qv2ray** と **V2ray** を入れて GUI で操作できるようにしています

  - 本当にもう少しオタクっぽく突き詰めるなら GUI を捨てて、純粋に v2ray + `config.json` と `systemd` だけで動かすこともできます……ただデスクトップ環境なので……やはり GUI があったほうが雰囲気に合います

  もっともここ数回のテスト実行では **Qv2ray** のインストールにかなり時間がかかるうえ……エラーも頻発するので……あと何度か我慢の限界が来たら外すかもしれません（あるいは選択式のオプションにするかも！？）

- **_Rambox_** :

  友人がいる身としては（これは疑いようのない事実……）、やはり IM やメールクライアントが必要になります。Rambox は今のところ各 Web サービスをまとめて扱えて非常に使いやすい統合型クライアントです（そう、実態は各種 Web インターフェースをひとまとめにしただけのツールです）

- **_Brave_** :

  **Firefox** があまり好みではないので、代わりに **Brave** を使っています

- **_Blog/Wiki 執筆シリーズ_** :

  ここには **Typora**（現時点で一番気に入っている Markdown エディタ）、**Git & GitHub Desktop**（CLI の **git** だけで十分なのは分かっていますが、GUI の **GitHub Desktop** も実はかなり便利で、特に **git** の CLI コマンドをそこまで熟知していない私にとっては助かります……）、さらに **Typora** から画像をアップロードするのに必要な **PicGo** が含まれています

- **_PuTTY_** :

  実のところ、SSH クライアントを動かすだけなら Linux 版の **PuTTY** よりターミナルから直接使ったほうが便利な面もありますが、それだと `.ppk` 形式の鍵がそのまま使えません。加えて SSH トンネルを張るなら設定を保存しておける **PuTTY** のほうが手軽なので一応入れています。とはいえ使うのは実家に繋ぐときくらいですが

- **_Remmina_** :

  これを使って RDP を直接動かすには **freerdp** も併せて入れる必要があります。私は基本的にこれと SSH トンネルを組み合わせて実家の P2P Windows に接続しています

- **_FileZilla_** :

  実を言うとこのツールは今やあまり出番がなく、**FTP/SFTP** でファイル転送する機会も減りました……ただ念のためという習慣で一応インストールしています

- **_gnome-pie_** :

  これはランチャーなのですが、見た目がかなり派手で格好良く気に入っているので、必須インストールリストに入れて使っています

- **_fcitx シリーズ_** :

  英語が母語ではない人間にとって、英語以外の入力メソッドは絶対に欠かせません……そのため通常はこれで **Chewing（新酷音）** と **Mozc** を入れて、中国語と日本語の入力環境を整えています……

- **_TeamViewer_** :

  実は **TeamViewer** もそこまで頻繁には使いませんが、いざというときのために習慣的に入れています

- **_VMware Workstation Pro (optional)_** :

  これはオプション扱いにしています。VM 上に構築しているマシンもあるため、VM の中にさらに VM を立てるような真似はしないようにするためです……

- **_KDE 個人向けのお楽しみ小物 (optional)_** :

  これはウィジェットや起動アニメーションなどを入れるためのものです……後々マルチブートのテーマなども含めるかもしれません……
