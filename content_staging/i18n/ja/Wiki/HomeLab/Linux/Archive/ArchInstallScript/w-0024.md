# はじめに

Linux の世界の中で私が一番好きなのは Arch 系のディストリビューションですが、Arch Linux のインストールはあまりユーザーフレンドリーではないため、自分でスクリプトを書いてインストールできるようにしようと考えました。

## 適用範囲

これは **_VMware ESXi_** 上で使用する汎用 **Arch Linux** インストールスクリプトで、基本的な前提条件は以下のとおりです。

* ~~Intel CPU~~（スクリプト内には AMD-ucode も含まれています）
* 1〜2GB の RAM
* 20GB 以上の HDD 容量

このバージョンでは以下の選択項目が用意されています。

*Update 2021/06/15：台湾へ戻って使う機会がなくなったため、Ver.K を削除し同項目のメンテナンスを終了しました*

* Simple Arch Linux
  - 基本構成の Arch Linux。最小限のシステムツールのみをインストール
  - シングル NIC（固定 MAC アドレス & Static IP）
  - Live CD 内の zsh 設定をコピー
* V2Ray Server
  - Arch Linux with V2Ray（V2Ray 設定なし）
  - シングル NIC（固定 MAC アドレス & Static IP）
  - Live CD 内の zsh 設定をコピー
* V2Ray Client Gateway
  - Arch Linux with V2Ray（V2Ray 設定なし）
  - iptables 設定なし
  - デュアル NIC（固定 MAC アドレス）
  - WAN 側は PPPoE または Static IP を選択可能
  - LAN 側は固定 IP
  - Live CD 内の zsh 設定をコピー
* ~~V2Ray Client Gateway Kiwi private version~~
  - ~~Arch Linux with V2Ray with 既存の Kiwi 関連設定（暗号化済み・個人用）~~
  - ~~Kiwi 既存の iptables を直接適用（暗号化済み・個人用）~~
  - ~~デュアル NIC（固定 MAC アドレス）~~
  - ~~WAN 側は PPPoE または Static IP を選択可能~~
  - ~~LAN 側は固定 IP~~
  - ~~Live CD 内の zsh 設定をコピー~~
* Nextcloud Server（後から実は Docker を使った方が早いと気づきました）
  - Arch Linux With Nextcloud from package
  - シングル NIC（固定 MAC アドレス & Static IP）
  - Live CD 内の zsh 設定をコピー

## 使用方法

Live CD で起動した後、ネットワークが疎通していることを確認した状態で以下を実行します。

```bash
zsh <(curl -L -s https://Kiwi0093.gitub.io/script/Arch/arch.sh)
```

> [!info] Updated 2026-11-27
> 上記の過去コマンド内の URL にはタイプミスが含まれており（`gitub.io` は本来 `github.io`）、この自作インストールスクリプトも現在はメンテナンスを終了しています。現在、Arch Linux 公式 Live ISO にはガイド付きインストーラー `archinstall` が標準搭載されているため、`archinstall` を直接使用してインストールすることを推奨します。

* ~~壁の向こうの国~~中国本土では DNS 汚染によって `https://raw.githubusercontent.com/` がブロックされるため、現地から使用する場合は先に `/etc/hosts` を設定して回避できるか試してみてください。
