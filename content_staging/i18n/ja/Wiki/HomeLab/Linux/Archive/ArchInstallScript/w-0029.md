> [!info] Updated 2026-11-27
> 以下は歴史的背景を残すための元のスクリプト内容であり、古い手法や構文上の問題が複数含まれています。**現代の環境でそのまま実行しないでください**：
> 1. **Shebang の位置とシェル**：完全版スクリプトでは `#` コメントが `#!/bin/zsh` より前に置かれているため、Linux カーネルが shebang を無視してしまいます（`#!` は 1 行目にある必要があります）。また Arch ISO / chroot のデフォルト環境には `zsh` がプリインストールされていないため、通常は `#!/bin/bash` を使用すべきです。
> 2. **タイムゾーン略称の誤記**：コメントの `CTS(Taipei)` は誤記であり、台湾標準時の正しい略称は `CST`（UTC+8）です。
> 3. **ネットワーク管理ツール**：`netctl` と udev によるネットワークインターフェース名の `EXT0` への固定は初期の手法であり、現代の Arch Linux では `systemd-networkd` または `NetworkManager` の使用が推奨されます。
> 4. **アカウントと sudo 権限**：`useradd -m -g root` は一般ユーザーのプライマリグループを `root` に設定してしまい、さらに `/etc/sudoers` へ直接追記するのは設定破損のリスクがあります。標準的な手法は `useradd -m -G wheel` を使用し、`visudo` 経由で `%wheel` グループを有効化することです。
> 5. **危険な部分アップグレード（Partial Upgrade）**：`pacman -Sy <パッケージ>` はデータベースのみを同期して既存パッケージを更新しないため、Arch Linux ではシステムライブラリの不整合による破損を極めて引き起こしやすいです。パッケージのインストールには `pacman -Syu <パッケージ>` を使用してください。また実運用では旧版の `v2ray` や `screen` に代わり `xray` / `sing-box` や `tmux` が使われることが一般的です。
> 6. **ブートローダーの起動モード**：`grub-install --target=i386-pc /dev/sda` は従来の BIOS / MBR 環境専用であり、現代の UEFI ホストでは ESP パーティションをマウントした上で `--target=x86_64-efi` を指定する必要があります。

## Script 内容

### Script 内容の説明

#### 基本定義

```bash
#!/bin/zsh
#Parmeter Pre-Define
COLOR1='\e[94m'
COLOR2='\e[32m'
NC='\e[0m'
```

スクリプト内で文字列を出力する際の端末文字色を定義しています。

#### タイムゾーンとハードウェアクロックの設定

```bash
#change Timezone to CTS(Taipei)
echo -e "${COLOR1}Please select your time zone\n1)Taipei\n2)Shanghai\n*)Whatever..I don't care\n${NC}"
while :
do
	read ZONE
	case $ZONE in
		1)
			echo -e "${COLOR1}Set Time Zone to Asia/Taipei${NC}"
			ln -sf /usr/share/zoneinfo/Asia/Taipei /etc/localtime
			hwclock --systohc --utc
			break
			;;
		2)
			echo -e "${COLOR1}Set Time Zone to Asia/Shanghai${NC}"
			ln -sf /usr/share/zoneinfo/Asia/Shanghai /etc/localtime
			hwclock --systohc --utc
			break
			;;
		*)
			echo -e "${COLOR1}Nobody cares the local time!!${NC}"
			hwclock --systohc --utc
			break
			;;
	esac
done
echo -e "${COLOR2}Completed${NC}"
```

#### ネットワーク設定

```bash
#Hostname
echo -e "${COLOR1}Please input your hostname\n${NC}"
read HOSTNAME
echo ${HOSTNAME} > /etc/hostname
echo "127.0.0.1 localhost ${HOSTNAME}" >> /etc/hosts
echo -e "${COLOR2}Completed${NC}"

echo -e "${COLOR1}Define your NIC by Mac address${NC}"
echo -e "${COLOR1}Please input your MAC Address:\n${NC}"
read OUTSIDE
echo 'SUBSYSTEM=="net", ACTION=="add", ATTR{address}=="'${OUTSIDE}'", NAME="EXT0"' > /etc/udev/rules.d/10-network.rules
echo -e "${COLOR2}Completed${NC}"

echo -e "${COLOR1}Define your IP for EXT0:${NC}"
echo "Description='EXT0 IP SETTING'" > /etc/netctl/EXT0.service
echo "Interface=EXT0" >> /etc/netctl/EXT0.service
echo "Connection=ethernet" >> /etc/netctl/EXT0.service
echo "IP=static" >> /etc/netctl/EXT0.service
echo -n "${COLOR1}Please input your IP address:\n${NC}"
read EXT_IP
echo "Address=('${EXT_IP}/24')" >> /etc/netctl/EXT0.service
echo -n "${COLOR1}Please input your Gateway IP address:\n${NC}"
read GATE_IP
echo "Gateway='${GATE_IP}'" >> /etc/netctl/EXT0.service
echo -n "${COLOR1}Please input your DNS IP address:\n${NC}"
read DNS_IP
echo "DNS=('${DNS_IP}')" >> /etc/netctl/EXT0.service
echo -e "${COLOR2}Enable EXT0${NC}"
netctl enable EXT0.service
echo -e "${COLOR2}Finished.${NC}"
```

- この設定は固定の **MAC Address** によってネットワークインターフェース名を **`EXT0`** として定義します。
- この設定は `netctl` を使用して静的 IP 管理を行います。

#### root パスワードの変更と他アカウントの作成

```bash
#Root Password
echo -e "${COLOR1}Set your root password${NC}"
passwd
chsh -s /bin/zsh
echo -e "${COLOR2}Completed${NC}"

#add User
echo -e "${COLOR1}Add user account:${NC}"
echo -n "${COLOR1}What ID you want:${NC}"
read YOURID
useradd -m -g root -s /bin/zsh ${YOURID}
passwd ${YOURID}
echo -e "${COLOR2}Completed${NC}"

echo -e "${COLOR1}Add $YOURID into sudo list${NC}"
pacman -Syu sudo
echo "${YOURID} ALL=(ALL) ALL" >> /etc/sudoers
echo -e "${COLOR2}Completed${NC}"
```

#### パッケージのインストール

```bash
#install Tools
echo -e "${COLOR1}Install Packages${NC}"
echo -e "${COLOR1}screen${NC}"
pacman -Sy screen v2ray certbot certbot-nginx nginx
echo -e "${COLOR2}Completed${NC}"
```

`screen`、`v2ray`、`certbot`、`certbot-nginx`、および `nginx` をインストールします。当時は `config.json` を直接置きたくなく、他人の*ワンクリックインストール*スクリプトをそのまま流用したくもなかったため、ベースパッケージのみをインストールし、残りの設定は他の資料を参照して手動で仕上げる形にしていました。

#### ブートローダーのインストール

```bash
#install Bootloader
echo -e "${COLOR1}Install grub Boot Loader into /dev/sda${NC}"
grub-install --target=i386-pc /dev/sda
grub-mkconfig -o /boot/grub/grub.cfg
echo -e "${COLOR2}Completed${NC}"
```

#### sync 後に Arch-chroot を終了

sync
