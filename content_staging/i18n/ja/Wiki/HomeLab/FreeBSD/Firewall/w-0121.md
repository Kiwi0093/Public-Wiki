# FreeBSD PF と dnctl（Dummynet）による帯域制御設定ガイド

> <img src='https://img.shields.io/badge/Status-WIP-yellow?style=for-the-badge&labelWidth=100' height='38' />

![FreeBSD](https://img.shields.io/badge/FreeBSD-Supported-green?style=plastic&logo=freebsd)

:::tip
NIC が ALTQ に対応していない場合でも、FreeBSD では `pf` と `dnctl`（Dummynet）を組み合わせて帯域制御を実現できます。
:::

> [!info] Updated 2026-11-27
> `pf` で `dnctl` / `dnpipe` をネイティブ利用するには **FreeBSD 14.0 以降**が必要です（FreeBSD 13 以前は [IPFW + Dummynet](./w-0046) を使用してください）。NAT ゲートウェイを兼ねる場合は、`/etc/pf.conf` のフィルタリングルール（`block all` / `pass ...`）より前に `nat on $EXT_IF ...` ルールを記述してください。

## 1. カーネルモジュールの読み込み

ファイアウォールには `pf` を使用しますが、帯域制限の制御自体は `dummynet` が担うため、両方のモジュールを読み込む必要があります。

### 手動読み込み

```bash
kldload pf
kldload dummynet
```

### 起動時の自動読み込み

再起動後も有効にするため、`/boot/loader.conf` を編集します：

```bash
# /boot/loader.conf
pf_load="YES"
dummynet_load="YES"
```

## 2. システム設定（`/etc/rc.conf`）

サービスを起動する前に、`/etc/rc.conf` で `pf` と `dnctl` を有効化します：

```bash
# /etc/rc.conf
pf_enable="YES"
pf_rules="/etc/pf.conf"
dnctl_enable="YES"    # dummynet コントローラを有効化
```

## 3. 帯域パイプの設定（`/etc/dnctl.conf`）

`ipfw pipe` と同じ構文で、各「パイプ（Pipe）」の帯域上限を定義します：

```bash
# /etc/dnctl.conf
# 古い設定をフラッシュ
flush

# パイプごとの帯域幅を定義
pipe 1 config bw 500KBytes/s    # VPN
pipe 2 config bw 100KBytes/s    # P2P
pipe 3 config bw 500KBytes/s    # RDP
pipe 4 config bw 350KBytes/s    # Server
pipe 5 config bw 30KBytes/s     # Guest
```

## 4. ファイアウォールフィルタと誘導（`/etc/pf.conf`）

PF 側で `dnpipe` を使い、条件に一致するパケットを先ほど定義した `dnctl` パイプへ誘導します：

```bash
# --- インターフェースとマクロ定義 ---
EXT_IF = "ext0"
INT_IF = "int0"

DMZ_NET = "192.168.0.0/24"
GUEST_NET = "192.168.2.0/24"
VPN_NET = "10.8.0.0/24"
P2P1_IP = "192.168.0.100"

# --- ルール設定 ---

# 1. Loopback をスキップ
set skip on lo0

# 2. デフォルト拒否
block all

# 3. 帯域制御（dnpipe へ誘導）

# VPN トラフィック
pass out quick on $EXT_IF to $VPN_NET dnpipe 1

# RDP 特定トラフィック（P2P1 専用）
pass in quick on $INT_IF proto tcp from $P2P1_IP to any port 3389 dnpipe 3

# P2P トラフィック
pass in quick on $INT_IF from $P2P1_IP to any dnpipe 2

# Guest ネットワーク帯域制限
pass in quick on $INT_IF from $GUEST_NET to any dnpipe 5
pass out quick on $INT_IF from any to $GUEST_NET dnpipe 5

# DMZ 送信トラフィック
pass out quick on $EXT_IF from $DMZ_NET to any dnpipe 4

# 4. 基本的な送信許可
pass out quick on $EXT_IF proto { tcp, udp, icmp } all keep state
```

## 5. 2026/04 メモまとめ・よく使うコマンド

- **この構成のメリット**：PF はルール記述が直感的で強力（`set skip on lo0` など）であり、Dummynet（`dnctl`）は FreeBSD の中で帯域制限の互換性が最も優れています。
- **状態確認コマンド**：
  - ファイアウォールルール確認：`pfctl -sr`
  - 帯域パイプの状態確認：`dnctl pipe show`
- **遅延改善のヒント**：制限中にレイテンシが増加する場合は、`/etc/dnctl.conf` の `pipe` 設定末尾に `codel` または `fq_codel` を追加してください：

  ```bash
  pipe 2 config bw 100KBytes/s fq_codel
  ```
