# FreeBSD システムパスワードと有効期限管理

## `login.conf` と `pw` コマンド群

FreeBSD の仕組みは Linux とは異なり、ログインクラス（Login Classes）とアカウント管理コマンドを使ってライフサイクルを制御します。

1. **ログインクラスによる有効期限の設定 (`/etc/login.conf`)**
   `/etc/login.conf` ファイルを編集し、対象のグループセクション（通常は `default:\`）に有効期限パラメータを追加します：

   ```bash
   default:\
       :passwdtime=90d:\
       :passwordlength=12:\
       :tc=std-default:
   ```

   > [!info] Updated 2026-11-27
   > 上記の `login.conf(5)` フィールド名には誤りがあります：FreeBSD における正しいパスワード有効期限と最小長のパラメータはそれぞれ `passwordtime`（`passwdtime` ではない）と `minpasswordlen`（`passwordlength` ではない）であり、標準の `/etc/login.conf` の `default:` セクションには組み込みの `tc=std-default:` は存在しません。正しい記述例：
   > ```text
   > default:\
   >     :passwordtime=90d:\
   >     :minpasswordlen=12:
   > ```

   - <span style="color:#e06c75"><del>`:passwdtime=90d:`</del></span> *(Updated 2026-11-27: 正しいパラメータ名は `:passwordtime=90d:`)* は、このクラスに属するユーザーのパスワードが 90 日後に期限切れになることを意味します。

   - 編集後は、コマンドを実行してデータベースを再コンパイルしないと反映されません：

     ```bash
     sudo cap_mkdb /etc/login.conf
     ```

2. **`pw` コマンドによる単一アカウントの制限変更**
   クラス全体に一律適用したくない場合は、特定のユーザーに対して直接操作できます：

   - **パスワード有効期限の設定：**

     ```bash
     sudo pw usermod john -p 2026-12-31
     ```

     > [!info] Updated 2026-11-27
     > FreeBSD の `pw(8)` の `-p` 引数は `YYYY-MM-DD` 形式を受け付けず、`dd-mmm-yyyy`（例：`31-Dec-2026`）、相対時間オフセット（例：`+90d`）、または UNIX Epoch 秒数のみをサポートします。正しい例：`sudo pw usermod john -p 31-Dec-2026` または `sudo pw usermod john -p +90d`。

   - **アカウントのロックまたはロック解除：**

     ```bash
     sudo pw lock john
     sudo pw unlock john
     ```

## パスワードの複雑さ設定 (`pam_passwdqc`)

FreeBSD は Pluggable Authentication Modules (PAM) 機構を採用しており、`pam_passwdqc` モジュールを通じてパスワード強度を制限します。

- `/etc/pam.d/passwd` ファイルを編集し、チェックルールを調整または追加します：

  ```bash
  password required pam_passwdqc.so min=disabled,disabled,12,8,6
  ```

- 引数の 5 つの数値はそれぞれ次の意味を持ちます：<span style="color:#e06c75"><del>パスワードがパスフレーズ（passphrase）、長い単語、短い単語、一般的な混合文字列、および極端に短い文字列である場合の最小文字数制限</del></span> *(Updated 2026-11-27: `pam_passwdqc(8)` の仕様に基づき、`min=N0,N1,N2,N3,N4` は順に「1 種類の文字クラス」「2 種類の文字クラス」「Passphrase パスフレーズ」「3 種類の文字クラス」「4 種類の文字クラス」に対する最小文字数制限に対応します。`disabled,disabled,12,8,6` を例にすると、1〜2 種類の文字クラスのみのパスワードを禁止し、パスフレーズは最低 12 文字、3 種類の文字クラスは最低 8 文字、4 種類の文字クラスは最低 6 文字を要求します)*。これにより、単純すぎる弱いパスワードを除外できます。

## 運用上のヒントと緊急時の対策

- **パスワード期限切れで SSH ログインが詰まった場合の対処法：**
  該当マシンの `root` 権限、または `sudo` 権限を持つ別アカウントがある場合（あるいはクラウドホストのシリアルコンソール / Recovery モード経由で）、以下のコマンドを直接実行して制限を解除すれば、再度ログインしてパスワードを再設定できます：

  ```bash
  sudo chage -M -1 <Username>
  ```

  > [!info] Updated 2026-11-27
  > `chage` は Linux（`shadow-utils`）専用のコマンドであり、FreeBSD システムにはこのツールが存在しません。FreeBSD 上でアカウントのパスワード有効期限制限をクリアまたは解除する場合は、代わりに `sudo pw usermod <Username> -p 0`（または `chpass -p 0 <Username>`）を使用してください。
