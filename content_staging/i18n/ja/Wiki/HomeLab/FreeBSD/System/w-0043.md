# 基本概念

単一のパッケージマネージャでシステム全体とソフトウェアを更新できる `Linux` とは異なり、FreeBSD ではシステムの更新とパッケージの更新で異なるコマンドを使用します。

### Linux でのやり方

```bash
# Debian/Ubuntu
apt update && apt upgrade
# Arch
pacman -Syu
```

コマンド 1 つですべて片付きます。

# FreeBSD システムの更新

## システムを更新する

```bash
# 現行バージョンへのパッチ適用
freebsd-update fetch && freebsd-update install
# x.y-RELEASE 版へのアップグレード
freebsd-update upgrade -r x.y-RELEASE && freebsd-update install
```

> [!info] Updated 2026-11-27
> `freebsd-update upgrade -r x.y-RELEASE` を用いてメジャー／マイナーバージョン間をアップグレードする場合、最初の `freebsd-update install` では新しいカーネルのみがインストールされます。一度再起動（`shutdown -r now`）してから、2 回目の `freebsd-update install` を実行してユーザーランド（userland）の更新を完了させる必要があります。また、古い共有ライブラリを削除してサードパーティ製パッケージを再構築した場合は、最後にもう一度 `freebsd-update install` を実行してください。

## パッケージの更新 - pkg

自分でコンパイル（compile）する必要がなければ、`pkg` を使う方が手軽です。

<img src="https://img.shields.io/badge/Kiwi-%E7%B0%A1%E5%96%AE%E7%9A%84%E8%AA%AA%E5%B0%B1%E6%98%AF%E6%87%B6%E7%9A%84%E7%AD%89port%20make%20install-A8FF24?style=social&logo=kiwix&logoColor=EA7500" height="40" />

```bash
# インストール
pkg install <pkg_name>

# 削除
pkg delete <pkg_name>

# 不要な依存パッケージの自動削除
pkg autoremove

# パッケージのバージョン確認
pkg version

# リポジトリの更新
pkg update

# パッケージの更新
pkg upgrade
```

## Port の更新

以前の FreeBSD では必要なソフトウェアのほとんどを port から自前でコンパイルしていましたが、現在では特殊なコンパイルオプションが必要な場合を除き、基本的に `pkg` でインストールします。

### Port Tree の更新

```bash
cd /usr/ports
# 初回使用時
portsnap fetch && portsnap extract && portsnap update
# 2回目以降
portsnap fetch && portsnap update
```

> [!info] Updated 2026-11-27
> `portsnap` ツールは FreeBSD 13 から非推奨（deprecated）となり、**FreeBSD 14.0 で正式に削除されました**（Ports Tree の管理も全面的に Git へ移行しています）。現代の FreeBSD 環境では、`git` をインストール（例：`pkg install git`）した上で、初回は `git clone https://git.FreeBSD.org/ports.git /usr/ports` で Ports Tree を取得し、以降は `git -C /usr/ports pull` で更新してください。

### Port ソフトウェアの更新

```bash
portmaster -a
```
