# キーを持っていない場合

新しくキーを生成します：

```bash
ssh-keygen -t rsa -C "your@mail.for.github"
```

> [!info] Updated 2026-11-27
> OpenSSH 8.8 以降は旧式の SHA-1 ベースの `ssh-rsa` 署名がデフォルトで無効化されており、GitHub でもより安全で鍵長も短い **Ed25519** アルゴリズムの使用が推奨されています：
> ```bash
> ssh-keygen -t ed25519 -C "your@mail.for.github"
> ```

次に、生成された <span style="color:#e06c75"><del>id_rsa.pub</del></span> *(Updated 2026-11-27: Ed25519 を採用した場合は `~/.ssh/id_ed25519.pub`)* の中身を GitHub の **Settings → SSH and GPG keys → New SSH key** に貼り付ければ準備完了です。

# すでに秘密鍵（Private Key）がある場合

```bash
eval `ssh-agent -s`
ssh-add /location/to/your/key
```

*(注：現在のシェルではバッククォート構文の代わりに `eval "$(ssh-agent -s)"` を使うことが推奨されます。)*

# リポジトリの接続方式を変更する

```bash
vi /location/to/repo/.git/config
# 中の記述を
url = https://github.com/<USER>/Repo.git
# から以下に変更
url = git@github.com:<USER>/Repo.git
```

> [!tip] Updated 2026-11-27
> 実際には `.git/config` を手動で編集しなくても、リポジトリディレクトリ内で直接 Git コマンドを実行してリモート URL を切り替えることができます：
> ```bash
> git remote set-url origin git@github.com:<USER>/<Repo>.git
> ```

これで快適に接続できるようになります。

# 追記

`ssh-add` を使ってキーを登録して利用することもできますが、毎回再登録が必要になる問題がよく起きがちです；<span style="color:#e06c75"><del>根本的な解決策は、キーファイル名をデフォルトの id_rsa のままにしておいて直接使えるようにすることです……</del></span> *(Updated 2026-11-27: デフォルトのファイル名（`id_ed25519` など）を維持するか、`~/.ssh/config` に `Host github.com` 向けの `IdentityFile` と `IdentitiesOnly yes` を設定し、必要に応じて `AddKeysToAgent yes` を追加しておくのが推奨されます。)*
