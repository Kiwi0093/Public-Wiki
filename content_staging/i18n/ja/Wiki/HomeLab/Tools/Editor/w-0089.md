Docusaurus や Obsidian、Typora などで技術ブログやナレッジベースを執筆する際、Markdown は記述の中核となる構文です。標準的な書式だけでなく、HTML タグを組み合わせることでさらに多彩な表現が可能になります。本記事では基本構文から HTML 併用の応用テクニックまで一通り整理します。

## 1. 基本構文編 (Basic Syntax)

近年の Markdown エディタ（Typora など）の多くはリアルタイムプレビューやショートカットに対応していますが、素の記法を押さえておけばどの Wiki 環境でも安定してレンダリングできます。

### 1. 見出し (Headings)

HTML の `<h1>`〜`<h6>` に対応する 6 段階の見出し階層があります：

# `#` H1 見出し

## `##` H2 見出し

### `###` H3 見出し

#### `####` H4 見出し

##### `#####` H5 見出し

###### `######` H6 見出し

### 2. 水平線 (Dividers)

3 つ以上のアスタリスク、ハイフン<span style="color:#e06c75"><del>、またはプラス記号</del></span> *(Updated 2026-11-27: CommonMark 標準ではアンダースコア `_` が規定されており、`+++` は標準の水平線構文ではありません)* を並べて水平線を作成できます：

```markdown
---
***
+++
```

> [!info] Updated 2026-11-27
> 標準の CommonMark / GFM でサポートされているのは 3 つ以上のハイフン（`---`）、アスタリスク（`***`）、またはアンダースコア（`___`）のみです。`+++` は静的サイトジェネレータにおいて主に TOML Frontmatter の区切りに使われ、水平線としてはレンダリングされません。

### 3. ハイパーリンク (Links)

標準的なアンカーテキストと URL リンクの書き方です：

```markdown
[タイトル](http URL)
```

_表示例：_ [Kiwi's Wiki](https://blog.kiwireich.com/docs "WIKIナレッジベース")

### 4. 文字装飾 (Text Styles)

斜体、太字、打ち消し線およびそれらの組み合わせに対応しています：

|構文1|構文2|表示結果|
|:-:|:-:|:-:|
|\*斜体\*|\_斜体\_| *斜体*|
|\**太字\**|\__太字\__|**太字**|
|\***太字斜体\***|\___太字斜体\___|***太字斜体***|
|\~~打ち消し\~~||~~打ち消し~~|

### 5. リスト (Lists)

- **箇条書きリスト**（`*`、`-`、`+` のいずれも同じ結果になります）：

    ```markdown
    * 項目1
    * 項目2
    * 項目3
    ```

- **番号付きリスト**：

    ```markdown
    1. 項目1
    2. 項目2
    3. 項目3
    ```

    _(注：番号が順番通りでなくても、多くのエディタが自動で連番に補正します)_

### 6. 画像とメディアリンク

- **通常の画像：**

    ```markdown
    ![Alt text](/path/to/img.jpg)
    ```

- **入れ子の動画リンク（例：YouTube サムネイルをクリック可能なリンクにする場合）：**

    ```markdown
    [![動画タイトル](http://img.youtube.com/vi/SlzBMJvtGHo/0.jpg)](https://www.youtube.com/watch?v=SlzBMJvtGHo "動画のツールチップ")
    ```

    _表示例（YouTube の例）：_

    [![Dr.Bergの断食解説](http://img.youtube.com/vi/SlzBMJvtGHo/0.jpg)](https://www.youtube.com/watch?v=SlzBMJvtGHo "断食中の体内変化")

> [!info] Updated 2026-11-27
> 上記のサムネイル URL は HTTPS（`https://img.youtube.com/vi/SlzBMJvtGHo/0.jpg`）への変更を推奨します。現代の HTTPS サイトでは HTTP 画像が混合コンテンツ（Mixed Content）としてブロックや警告の対象になる場合があります。

## 2. 応用編：Markdown と HTML の組み合わせテクニック

Markdown は仕様上、文中に **HTML タグ** を直接埋め込むことができます。より細かなレイアウトや文字色、特殊な装飾を行いたい場合は HTML タグを併用します。

> **⚠️ 注意事項：** HTML の `<>` タグ内でマークアップを記述する場合は、パーサーによる競合を防ぐため、内部でもすべて HTML タグ（`**` の代わりに `<strong>`、あるいは `<font>` や `<del>` など）を使うことを推奨します。

### 1. 文字装飾と下線

素の Markdown には下線構文が存在しないため（リンクとの混同を避けるため）、HTML の `<u>` タグで実現します：

| 構文 | 表示結果 |
| :---: | :---: |
| \<u>下線\</u> | <u>下線</u> |
| \<del>打ち消し\</del> | <del>打ち消し</del> |

### 2. 文字色のカスタマイズ (`<font>`)

`<font color="...">` を使うと文字色を自由に変更でき、技術メモでの強調に便利です：

| 構文 | 表示結果 | 構文 | 表示結果 |
| :---: | :---: | :---: | :---: |
| `<font color="#800000">ワインレッド</font>` | <font color="#800000">ワインレッド</font> | `<font color="#FF0000">赤</font>` | <font color="#FF0000">赤</font> |
| `<font color="#FF6600">オレンジ</font>` | <font color="#FF6600">オレンジ</font> | `<font color="#FFD700">ゴールド</font>` | <font color="#FFD700">ゴールド</font> |
| `<font color="#FFFF00">黄</font>` | <font color="#FFFF00">黄</font> | `<font color="#00FF00">緑</font>` | <font color="#00FF00">緑</font> |
| `<font color="#008000">深緑</font>` | <font color="#008000">深緑</font> | `<font color="#00FFFF">シアン</font>` | <font color="#00FFFF">シアン</font> |
| `<font color="#0000FF">青</font>` | <font color="#0000FF">青</font> | `<font color="#FF00FF">マゼンタ</font>` | <font color="#FF00FF">マゼンタ</font> |
| `<font color="#800080">紫</font>` | <font color="#800080">紫</font> | `<font color="#808080">グレー</font>` | <font color="#808080">グレー</font> |

> [!info] Updated 2026-11-27
> `<font>` タグは HTML5 仕様では非推奨（Deprecated）となっています。現代の標準的な記法では CSS インラインスタイルの `<span style="color: #FF0000">テキスト</span>`（Docusaurus MDX v2/v3 では `style={{color: '#FF0000'}}`）の使用が推奨されます。

### 3. 上付き文字と下付き文字 (`<sup>` / `<sub>`)

数式や化学式、バージョン表記などに適しています：

| 構文 | 表示結果 |
| :---: | :---: |
| 3\<sup>2\</sup>=9 | 3<sup>2</sup>=9 |
| H\<sub>2\</sub>O | H<sub>2</sub>O |

### 4. 特殊な数学記号とよく使う文字実体参照

HTML の文字実体参照（Entity References）を使って特殊記号を直接挿入できます：

| 目的 | 構文 | 表示結果 |
| :---: | :---: | :---: |
| 登録商標 | \&reg; | 登録商標&reg; |
| 関数 ƒ(x) | \&fnof;(X)=X+1 | &fnof;(X)=X+1 |
| 平方根 | \&radic;2 | &radic;2 |
| 角度 | 45\&deg; | 45&deg; |

### 5. 漢字のルビ（ふりがな・注音）表記 (`<ruby>`)

HTML5 の `<ruby>`、`<rt>`（ルビ・読み仮名）、および `<rp>`（未対応ブラウザ向けの括弧）タグを使ってルビを振ることができます：

```markdown
<ruby>
注<rp>(</rp><rt>ㄓㄨˋ</rt><rp>)</rp>
音<rp>(</rp><rt>ㄧㄣˉ</rt><rp>)</rp>
</ruby>
```

_表示例：_ <ruby>注<rp>(</rp><rt>ㄓㄨˋ</rt><rp>)</rp>音<rp>(</rp><rt>ㄧㄣˉ</rt><rp>)</rp></ruby>

**実践応用例（二重の意味を持たせる技術表現）：** 文字色や打ち消し線と組み合わせることで、裏の意味やツッコミを重ねた表現も作れます：

```markdown
私は <ruby><font color="blue"><del>我が家の艦隊</del></font><rp>(</rp><rt><font color="red">VMware ESXi</font></rt><rp>)</rp></ruby> が大好きです
```

_表示例：_ 私は <ruby><font color="blue"><del>我が家の艦隊</del></font><rp>(</rp><rt><font color="red">VMware ESXi</font></rt><rp>)</rp></ruby> が大好きです
