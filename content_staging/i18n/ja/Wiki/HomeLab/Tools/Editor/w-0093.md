## 一、 NeoVim の基本インストール

NeoVim は高い拡張性と非同期処理能力を備えており、主要な Linux ディストリビューションではネイティブのパッケージマネージャーから直接インストールできます。

- **Arch Linux / Manjaro：**
    
   ```bash
    sudo pacman -S neovim
   ```
    
- **Debian / Ubuntu / Linux Mint：**
    
   ```bash
    sudo apt install neovim
   ```
    
- **Fedora / RHEL：**
    
   ```bash
    sudo dnf install neovim
   ```
    
- _基本設定ファイルパス：_ `~/.config/nvim/`

## 二、 NvChad フレームワークのデプロイ

**NvChad** はあらかじめ構成され、全面的に Lua 言語で記述された Neovim 向けのカスタマイズ＆オールインワン統合パッケージです。非常に高い軽量性とモジュール化されたアーキテクチャを維持しています。

### 1. インストールと初期化

Git を使用して公式 Starter プロジェクトをユーザーの `.config/nvim` ディレクトリ配下にクローンします。

```bash
git clone https://github.com/NvChad/starter ~/.config/nvim && nvim
```

_(注：Neovim を初回起動すると、プラグインのダウンロードとインストール画面が自動的に起動します。)_

### 2. パーソナライズされたカスタムプロジェクト構造管理 (`custom` ディレクトリ)

NvChad のコア設計では、個人的なカスタマイズ内容をすべて `~/.config/nvim/lua/custom/` ディレクトリ配下に配置することが推奨されています。このディレクトリはデフォルトで `.gitignore` に含まれているため、独自の Git リポジトリとして管理し、複数ホスト間で同期するのに非常に適しています。

- **完全上書き（Full Override）：** `custom` 配下に `init.lua` を配置すると、NvChad のデフォルト動作を直接上書きして置き換えます。
- **部分上書き（Partial Override / 推奨）：** `custom` 配下に `chadrc.lua` を配置し、`core/default_config.lua` の構造に従って部分的な上書きや拡張を行います。

> [!info] Updated 2026-11-27
> **NvChad v2.5**（上記でクローンした `NvChad/starter`）以降、旧版 v2.0 の `lua/custom/` ディレクトリおよび `core/default_config.lua` は廃止されました。新構造ではユーザーの `~/.config/nvim/lua/` 直下で `chadrc.lua`、`options.lua`、`mappings.lua`、`plugins/init.lua` を直接メンテナンスします（`NvChad/NvChad` 自体は `lazy.nvim` のプラグインとして読み込まれます）。以下の章にある `lua/custom/` の例は、旧版 v2.0 の概念を理解するための参考としてご覧ください。

## 三、 カスタム設定例 (`chadrc.lua` と Lua の統合)

### 1. `~/.config/nvim/lua/custom/chadrc.lua` の例

すべての UI テーマやカスタムモジュールの読み込みはこのファイルで定義します。

```lua
---@type ChadrcConfig
local M = {}

-- 設定預設佈景主題
M.ui = {
  theme = "onedark",
}

-- 掛載自訂的程式碼摺疊模組 (對應 custom/folder.lua)
M.folder = require "custom.folder"

return M
```

- **モジュール読み込みロジックの説明：** `M.XXX = require "custom.XXX"` という構文は、`custom/XXX.lua` ファイルを読み込むことを意味します。公式の `core/` にある対応ファイルをコピーして編集すると、最も高い互換性を保てます。
    

### 2. `~/.config/nvim/lua/custom/folder.lua` (コード折りたたみ設定の例)

```lua
-- 語法高亮（Neovim 預設開啟，若需強制執行可保留 vim.cmd）
vim.cmd('syntax on')

-- 使用 vim.opt 設定選項 (等同於 Vimscript 的 set)
vim.opt.foldmethod = 'marker'
vim.opt.foldmarker = '{{{,}}}'
vim.opt.foldlevel = 0
vim.opt.foldnestmax = 3

-- 設定全域變數 (等同於 Vimscript 的 let，用來處理舊式外掛變數)
vim.g.php_folding = 1
```

#### コア対応原則の説明：

- **`vim.opt`**：各種 Vim オプション（`foldmethod`、`number`、`shiftwidth` など）を設定するために使用し、自動補完や型処理に対応しています。
- **`vim.g`**：グローバル変数（Global Variables）を設定するために使用します。たとえば従来の `let php_folding = 1` は `vim.g.php_folding = 1` に対応させる必要があります。

また、Lua から `vim.cmd()` を呼び出すことで、従来の Vimrc の各種設定をそのままシームレスに引き継ぐことも可能です。

```lua
vim.cmd('syntax on')
vim.cmd('set foldmarker={{{,}}}')
vim.cmd('set foldmethod=marker')
vim.cmd('set foldlevel=0')
vim.cmd('let php_folding = 1')
vim.cmd('set foldnestmax=3')
```

#### Vim で折りたたみ状態を操作する際によく使うショートカットキー：

|**ショートカットコマンド**|**効果と説明**|
|---|---|
|`zi`|ファイル全体の折りたたみ機能を **有効化 / 無効化** する|
|`zo`|現在のカーソル位置にある折りたたみブロックを **開く (Open)**|
|`zc`|現在のカーソル位置にある折りたたみブロックを **閉じる (Close)**|
|`zO`|現在のカーソル位置の階層以下にあるすべての折りたたみブロックを **再帰的に開く**|
|`zC`|現在のカーソル位置の階層以下にあるすべての折りたたみブロックを **再帰的に閉じる**|
|`zm`|`foldlevel` を 1 減らす（全体の折りたたみレベルを一段階締める）|
|`zM`|`foldlevel` を 0 に設定する（**すべてのブロックを強制的に折りたたむ**）|
|`zr`|`foldlevel` を 1 増やす（全体の折りたたみレベルを一段階緩める）|
|`zR`|`foldlevel` を最大に設定する（**すべてのブロックを完全に展開する**）|
|`zx`|折りたたみ状態を更新する（カーソル位置のブロック以外に対してルールを再適用する）|
|`zf`|ビジュアルモードで選択した範囲に開始・終了の折りたたみマーカーを動的に作成する|


## 四、 NvChad の主要ショートカットキーと操作ガイド (Key Mappings)

NvChad のショートカットキーの多くは **Leader Key（リーダーキー）** を起点とします。デフォルトのリーダーキーは **`Space`（スペースキー）** です。押下するとキーヒントメニュー（Which-Key）が自動的にポップアップ表示されます。

### 1. インターフェースとナビゲーションでよく使うショートカットキー

|**キーの組み合わせ (先に Leader Space を押下)**|**機能説明**|**備考**|
|---|---|---|
|`Space` + `ch`|内蔵チートシートを呼び出す|すべてのショートカットキーの確認・検索に便利な機能|
|`Space` + `th`|テーマスイッチャー (Theme Switcher)|好みのカラーテーマをリアルタイムにプレビューして切り替え|
|`Space` + `ff`|ファイル検索 (Find Files)|プロジェクト全体のファイルを高速にあいまい検索（ファイル内の文字列検索ではない）|
|`Space` + `b`|新しい Buffer (タブ) を開く|空のバッファ（タブ領域）を新規追加|
|`Space` + `x`|現在の Buffer を閉じる|使用中のバッファを閉じる（直接 `:q!` を使うより安全）|
|`矢印キー` または `h/j/k/l`|使用中の Buffer を切り替える|開いている複数のタブ間を素早く移動|

### 2. NvimTree ファイルツリー用ショートカットキー

|**キーの組み合わせ (先に Leader Space を押下)**|**機能説明**|**備考**|
|---|---|---|
|`Space` + `e`|左側のファイルツリーを開く / 閉じる|閉じている場合は自動的に展開し、左側の Tree にフォーカスを移動|
|`Space` + `q`|左側のファイルツリーを閉じる|サイドバーを折りたたむだけ|
|`:cd <パス>`|作業ディレクトリを変更|ファイルツリーのルートディレクトリを指定した場所へ切り替え（コマンド）|
|`L` (大文字)|右側のエディタ領域へ移動|カーソルフォーカスをファイルツリーから編集中のコードへ戻す|
|`H` (大文字)|左側のファイルツリーへ移動|カーソルフォーカスをファイルツリーのサイドバーへ戻す|

## 五、 Mason パッケージマネージャー (LSP / DAP / Linters 管理)

モダンな Neovim 開発環境において、**Mason.nvim** は Language Server (LSP)、Debugger (DAP)、Linter および Formatter を管理するための中核プラグインです。統一された UI を通じて、各プログラミング言語の開発ツールを簡単にインストール・更新できます。

### 1. よく使うコマンドと操作

NvChad または Neovim 上で以下の Ex コマンドを入力すると Mason を呼び出せます。

|**コマンド**|**効果の説明**|**備考**|
|---|---|---|
|`:Mason`|Mason メインコンソール画面を開く|対話式のダッシュボードが表示され、上下キーで各種ツールの閲覧・インストール・アンインストールが可能|
|`:MasonInstall <package>`|指定したツールをインストール|コマンドラインから特定の Linter や LSP を直接インストール（例：`:MasonInstall pyright`、`:MasonInstall typescript-language-server`）|
|`:MasonUninstall <package>`|指定したツールを削除|不要になった Language Server やフォーマッタをアンインストール|
|`:MasonUpdate`|インストール済みの全ツールを更新|Mason が管理するすべての外部バイナリツールを確認し、最新バージョンへアップグレード|

### 2. NvChad と連携した LSP 統合設定

NvChad では通常、Mason を `mason-lspconfig.nvim` と組み合わせて使用し、Mason 経由でインストールした Language Server が Neovim 組み込みの LSP と自動的に連携するようにします。特定の LSP をカスタマイズまたはあらかじめ自動インストールしたい場合は、`~/.config/nvim/lua/custom/plugins.lua` で拡張設定を行えます。

```lua
-- 範例：透過 NvChad 的 plugins 覆寫機制擴充 Mason 自動安裝清單
local plugins = {
  {
    "williamboman/mason.nvim",
    opts = {
      ensure_installed = {
        "lua-language-server",
        "pyright",
        "typescript-language-server",
        "gopls",
      },
    },
  },
}

return plugins
```

> [!info] Updated 2026-11-27
> - **NvChad v2.5**（`NvChad/starter`）では、プラグインの上書きファイルが `lua/custom/plugins.lua` から `~/.config/nvim/lua/plugins/init.lua` に変更されています。また、`lua/chadrc.lua` 内で `M.mason = { pkgs = { ... } }` を定義し、`:MasonInstallAll` で一括インストールすることも可能です。
> - `williamboman/mason.nvim` のアップストリームリポジトリは `mason-org/mason.nvim` へ移行しています（旧パスからもリダイレクトされますが、新規設定では `mason-org/mason.nvim` の使用を推奨します）。

## 六、 おすすめの主要 LSP (Language Server Protocol) 一覧

Mason を通じて Language Server をインストールすることで、Neovim にコード補完、構文チェック、定義ジャンプ（Go to Definition）、リアルタイムエラー表示といった IDE クラスの機能を追加できます。以下は主要なプログラミング言語ごとにおすすめの LSP サーバー一覧です。

|**プログラミング言語 / 技術**|**Mason パッケージ名 (Package Name)**|**主な機能と特徴**|
|---|---|---|
|**Python**|`pyright` または `basedpyright`|Microsoft が開発した強力な型チェック・自動補完 LSP。リアルタイムのエラー表示とコードナビゲーションに対応。|
|**Lua**|`lua-language-server`|Neovim のカスタム設定や Lua スクリプト開発に必須。Neovim の `vim` グローバル変数へのサポートが非常に優秀。|
|**TypeScript / JavaScript**|`typescript-language-server`|フロントエンド開発の要。TS/JS の型推論、リファクタリング、自動補完を提供。|
|**HTML / CSS / JSON**|`vscode-langservers-extracted`|Web 基本 3 技術の標準 LSP。高精度なタグやスタイルの補完ヒントを提供。|
|**Go**|`gopls`|Go 言語公式メンテナンスの LSP。優れたパフォーマンスと最も充実した機能を提供。|
|**Rust**|`rust-analyzer`|Rust 開発に欠かせない強力なコアツール。高度なマクロ展開と型解析を提供。|
|**Bash / Shell**|`bash-language-server`|シェルスクリプト向けの構文チェックと基本的な自動補完を提供。|
|**C / C++**|`clangd`|LLVM/Clang ベースで、極めて高速かつ高精度な C/C++ ナビゲーションと補完を提供（ccls より推奨）。|

### 一括自動インストールの記述例

起動時に Mason 経由で上記の主要な LSP を自動インストールしたい場合は、`~/.config/nvim/lua/custom/plugins.lua`（NvChad v2.5 では `lua/plugins/init.lua`）の `ensure_installed` 配列に直接追記します。

```lua
ensure_installed = {
  "lua-language-server",
  "pyright",
  "typescript-language-server",
  "gopls",
  "clangd",
  "bash-language-server",
}
```

## 七、 おすすめの主要 Formatter (コードフォーマッタ)

LSP による構文チェックや定義ジャンプに加えて、Neovim では専用の Formatter（フォーマッタ）を組み合わせてチームや個人のコードスタイルを一貫して保つのが一般的です。Mason でインストールし、`conform.nvim` や `none-ls.nvim`（メンテナンス終了した `null-ls.nvim` のコミュニティ後継フォーク）と連携させることで、保存時の自動フォーマットを実現できます。

|**プログラミング言語 / 対象範囲**|**Mason パッケージ名 (Package Name)**|**主な機能と特徴**|
|---|---|---|
|**Python**|`black` または `ruff`|`black` は Python 界隈で標準的な迷いのない整形ツール。`ruff` は近年急速に普及している Rust 製の超高速 Linter 兼 Formatter。|
|**JavaScript / TypeScript / JSON / HTML / CSS / Markdown**|`prettier`|フロントエンド開発における万能フォーマッタ。各種 Web 技術やマークアップ言語のインデントと改行を綺麗に整形。|
|**Lua**|`stylua`|Lua 言語専用に設計された強力なフォーマッタ（Neovim / NvChad エコシステムで非常に一般的）。|
|**Go**|`gofmt` または `goimports`|Go 言語公式標準のフォーマッタ（通常は `gopls` や Go SDK 本体に同梱されており、Mason 経由での管理も可能）。|
|**C / C++ / Java / Rust (など多言語)**|`clang-format`|Clang ベースの強力なフォーマッタ。プロジェクトルートにある `.clang-format` ファイルでフォーマット規約を厳密に制御可能。|
|**Shell Script**|`shfmt`|Bash / シェルスクリプトのインデント整形に特化した標準ツール。|

### Mason 自動インストールリストへの統合例

同様に、よく使う Formatter も `~/.config/nvim/lua/custom/plugins.lua`（NvChad v2.5 では `lua/plugins/init.lua`）の `ensure_installed` 配列に含めておくことで、新規環境構築時に自動で揃うようになります。

```lua
ensure_installed = {
  -- LSP
  "lua-language-server",
  "pyright",
  "typescript-language-server",
  "gopls",
  -- Formatter
  "prettier",
  "stylua",
  "black",
  "shfmt",
}
```
