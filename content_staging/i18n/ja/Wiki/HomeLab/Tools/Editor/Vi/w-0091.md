## 一、基本操作と保存・終了

<span style="color:#e06c75"><del>すべてのコマンドは **Command Mode（コマンドモード）** で入力します</del></span> *(Updated 2026-11-27: 厳密には、`i`、`a`、`o`、`dd`、`u`、`p` などの操作は **Normal Mode（ノーマルモード）** に属し、`:w`、`:q`、`:%s/...` などコロンで始まるコマンドのみが **Command-line Mode（コマンドラインモード）** に属します)*。`Esc` キーを押すといつでもノーマルモードに戻れます。

| **コマンド** | **効果・説明** |
|---|---|
| `:q` | 保存せずに終了（未保存の変更がある場合はブロックされます） |
| `:q!` | 保存せずに強制終了（未保存の変更をすべて破棄） |
| `:w` | 現在のファイルに書き込んで保存 |
| `:wq` または `ZZ` | 保存して終了 |
| `:wq!` | 強制的に保存して終了（権限が許可されている場合の上書きに有効） |

## 二、キーボード編集・ナビゲーションショートカット

ノーマルモードから挿入モードへの切り替えや、ブロック操作を行う際によく使うショートカットキーです。

| **コマンド / キー操作** | **効果・説明** |
|---|---|
| `i` | カーソルの現在位置で挿入モード (Insert) に入る |
| `a` | カーソルの**後ろ**の位置で挿入モードに入る |
| `o` | 現在行の**下**に空行を挿入して挿入モードに入る |
| `dd` | 行全体を削除（切り取り） |
| `[数字]dd` | 現在行から指定した「[数字]」行分を削除（例：`5dd`） |
| `u` | 直前の操作を取り消す (Undo) |
| `p` | 貼り付け（`dd` または `yy` でヤンク・切り取りした内容） |

## 三、検索と一括置換の応用コマンド

コマンドラインモードの Ex コマンドを活用して、強力な文字列検索や一括置換を行います。

### 1. 基本検索

- ノーマルモードで `/` に続けてキーワードを入力すると下方向へ検索できます（`n` で次を検索、`N` で前を検索）。

### 2. 一括文字列置換の構文

- **ファイル全体を一括置換：**

  ```vim
  :%s/search_from/replace_to/g
  ```

- **置換前に 1 件ずつ確認（Interactive）：**

  ```vim
  :%s/search_from/replace_to/gc
  ```

  _(確認プロンプトが出たら、`y` で置換実行、`n` でスキップ、`a` で残りすべて置換、`q` で終了)_

- **大文字・小文字の区別を無視して置換：**

  ```vim
  :%s/search_from/replace_to/gi
  ```

- **「現在行」のみ置換：**

  ```vim
  :s/search_from/replace_to/g
  ```

- **特定の行範囲を指定して置換：**

  ```vim
  :[行數起點],[行數終點]s/search_from/replace_to/gc
  ```

  _(例：`:10,50s/foo/bar/gc` は 10 行目から 50 行目の間のみ確認付きで置換します)_
