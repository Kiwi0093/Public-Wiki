## 二、 現在の主流：`tmux` と `oh-my-tmux` の実践

### 1. 基本インストール

- **Arch Linux:**

  ```bash
  sudo pacman -S tmux
  ```

- **Debian / Ubuntu:**

  ```bash
  sudo apt install tmux
  ```

- **FreeBSD:**

  ```bash
  sudo pkg install tmux
  ```

### 2. oh-my-tmux の設定（見た目の改善とクイックセットアップ）

有名な設定プロジェクトを利用して、洗練された美しいインターフェースを素早く構築します：

```bash
cd
git clone https://github.com/gpakosz/.tmux.git
ln -s -f .tmux/.tmux.conf
cp .tmux/.tmux.conf.local .
```

### 3. tmux のよく使うショートカットキー対照表 (Prefix のデフォルトは `Ctrl+a` または `Ctrl+b`)

_(注：`oh-my-tmux` を使用している場合、デフォルトの Prefix は通常 `Ctrl+a` に割り当てられます)_

|**機能の説明**|**キー操作 (Prefix の後に続けて押す)**|
|---|---|
|**新規 Session 作成**|`Prefix` + `C-c`|
|**Pane を垂直分割（上下分割）**|<span style="color:#e06c75"><del>`Prefix` + `-` または `%`</del></span> *(2026-11-27 更新: `oh-my-tmux` では `Prefix` + `-`、素のデフォルトでは `Prefix` + `"`)*|
|**Pane を水平分割（左右分割）**|<span style="color:#e06c75"><del>`Prefix` + `_` または `"`</del></span> *(2026-11-27 更新: `oh-my-tmux` では `Prefix` + `_`、素のデフォルトでは `Prefix` + `%`)*|
|**マウスモード切り替え**|`Prefix` + `m`|
|**Session 名を変更**|`Prefix` + `,`|
|**他のペインへフォーカス移動**|`Prefix` + `方向キー`|
|**一覧からウィンドウを選択**|`Prefix` + `w`|
|**タブ（ウィンドウ）の高速切り替え**|`Prefix` + `数字キー`|
|**Session の切り離し (Detach)**|`Prefix` + `d` (screen と同様)|

### 4. 起動と接続管理コマンド

- **実行中のすべての Session を一覧表示：**

  ```bash
  tmux ls
  ```

- **指定した Session に再接続：**

  ```bash
  tmux attach -t $數字
  # 或簡寫
  tmux at -t 0
  ```

- **スマート起動コマンド（自動接続と新規作成の組み合わせ）：**

  ```bash
  tmux -u attach || tmux -u
  ```

### 5. 高度な設定：デフォルト Shell と WSL での自動アタッチ

- **デフォルト Shell を zsh に設定：**

  `~/.tmux.conf` に以下を追加します：

  ```bash
  set -g default-shell /usr/bin/zsh
  ```

- **WSL 自動 Session 引き継ぎ：**

  以下のスニペットを `~/.zshrc` または `~/.bashrc` に追加します。WSL 環境で非常に便利で、ターミナルウィンドウを閉じて開き直しても元の Session に自動でアタッチされます：

  ```bash
  if command -v tmux &> /dev/null && [ -z "$TMUX" ]; then
    tmux attach-session -t default || tmux new-session -s default
  fi
  ```

## 三、 古典の元祖：GNU `screen`

`tmux` がすでに主流となっていますが、多くの軽量コンテナ（Docker image）や古いサーバーでは、今でも `screen` がデフォルトで内蔵された最良のレスキューツールとなっています。

### よく使うコマンド

- **新規 Session の起動：**

  ```bash
  screen -S mysession
  ```

- **バックグラウンドの Screen Sessions を一覧表示：**

  ```bash
  screen -ls
  ```

- **指定した Screen に再接続：**

  ```bash
  screen -r mysession
  ```

- **キーボードショートカット：**
  - Detach（切り離してバックグラウンドへ）：`Ctrl+a` を押してから `d`
  - 新規ウィンドウ作成：`Ctrl+a` を押してから `c`
  - ウィンドウ切り替え：`Ctrl+a` を押してから `n` (Next) または `p` (Previous)

## 四、 モダン Rust 製ターミナルの新星：`zellij`

`zellij` は Rust で書かれたターミナルマルチプレクサです。レイアウトの概念を極限までシンプルにしており、デフォルトで下部のステータスバーやペインメニューを提供し、マウス操作への対応も極めて優れています。

### 1. インストール方法

- **Arch Linux:**

  ```bash
  sudo pacman -S zellij
  ```

- **Cargo (Rust パッケージマネージャ)：**

  ```bash
  cargo install zellij
  ```

### 2. 基本的な使い方と操作

- **新しいセッションを起動：**

  ```bash
  zellij
  ```

- **Sessions の一覧表示と管理：**

  ```bash
  zellij list-sessions
  ```

- **指定した Session に再接続：**

  ```bash
  zellij attach <SESSION_NAME>
  ```

- **主な操作の特徴：**
  - 起動すると画面の最下部に黄・青のメニューガイド（Shortcut Bar）が常駐し、`Ctrl+p`（ペイン制御）や `Ctrl+n`（新規ペイン作成）から方向キーやマウスで直感的に操作できるため、複雑な Prefix キーの組み合わせを丸暗記する必要がありません。
