## Zsh のインストール

これは非常に簡単で、基本的にはシステムのパッケージマネージャーを使ってインストールするだけです：

```shell
# Arch Linux 系
sudo pacman -S zsh
または
yay -S zsh
# yum 系
yum install zsh
# FreeBSD
pkg install zsh
```

> [!info] Updated 2026-11-27
> 現代の RHEL、Rocky Linux、AlmaLinux、Fedora ディストリビューションでは `yum` が `dnf` に置き換わっているため、`sudo dnf install zsh` を使用してください。FreeBSD でも `sudo pkg install zsh`（または `root` 権限）で実行する必要があります。

## Manjaro-zsh-config @ Arch Linux

`manjaro-zsh-config` は AUR 内にあるため、このパッケージをインストールするだけで関連する依存関係もすべて自動で導入され、特に問題はありません：

```shell
# Arch Linux 系
# AUR 内にあるため
git clone https://aur.archlinux.org/manjaro-zsh-config.git
cd manjaro-zsh-config && makepkg -si
あるいはさらに簡単に
yay -S manjaro-zsh-config
```

<span style="color:#e06c75"><del>`/etc/zsh/zshrc-manjaro/.zshrc` を `~/.zshrc` にコピーするのを忘れないようにしないと有効になりません</del></span> *(Updated 2026-11-27: AUR パッケージ `manjaro-zsh-config` が提供するテンプレートは `/etc/skel/.zshrc` に配置されており（`/usr/share/zsh/manjaro-zsh-config` を読み込みます）、下記の手動スクリプトに従ってコピーする場合は `/etc/zsh/zshrc-manjaro` を `~/.zshrc` としてコピーしてください。)*

## その他の OS

### zsh-theme-powerlevel10k のインストール

```shell
# Arch Linux 系
sudo pacman -S zsh-theme-powerlevel10k
or
yay -S zsh-theme-powerlevel10k
# その他のシステム - Manual Installation
sudo git clone --depth=1 https://github.com/romkatv/powerlevel10k.git /usr/share/
# 後で manjaro の設定ファイルと組み合わせるため、インストール先は固定
```

> [!info] Updated 2026-11-27
> すでに存在し空ではない `/usr/share/` へ直接 `git clone` すると失敗するため、手動インストール時は保存先ディレクトリ名を指定する必要があります：
> ```shell
> sudo git clone --depth=1 https://github.com/romkatv/powerlevel10k.git /usr/share/zsh-theme-powerlevel10k
> ```
> なお、`romkatv/powerlevel10k` のアップストリームは現在限定的なメンテナンス状態に入っており、機能は概ね凍結されていますが引き続き正常に利用できます。

### gitstatus のインストール

```shell
sudo git clone --depth=1 https://github.com/romkatv/gitstatus.git /usr/share/zsh-theme-powerlevel10k/
# 後で manjaro の設定ファイルと組み合わせるため、インストール先は固定
```

> [!info] Updated 2026-11-27
> `/usr/share/zsh-theme-powerlevel10k/` ディレクトリがすでに存在する場合は、サブディレクトリ名 `gitstatus` を指定する必要があります（すなわち `/usr/share/zsh-theme-powerlevel10k/gitstatus`）。なお、`powerlevel10k` はデフォルトで対応する `gitstatusd` バイナリも自動ダウンロードします。

### Manjaro-zsh-config の設定ファイル

直接インストールできるパッケージがないため、以下のスクリプトを実行してください：

```shell
git clone https://github.com/Chrysostomus/manjaro-zsh-config
sudo cp -Rv manjaro-zsh-config/manjaro-zsh-prompt /usr/share/zsh/
sudo cp -Rv manjaro-zsh-config/zsh-maia-prompt /usr/share/zsh/
sudo cp -Rv manjaro-zsh-config/p10k.zsh /usr/share/zsh/
sudo cp -Rv manjaro-zsh-config/p10k-portable.zsh /usr/share/zsh/
sudo cp -Rv manjaro-zsh-config/command-not-found.zsh /usr/share/zsh/functions/
sudo cp -Rv manjaro-zsh-config/.zshrc /etc/zsh/zshrc-manjaro
sudo cp -r manjaro-zsh-config/base16-shell /usr/share/zsh/scripts/
sudo chmod a+x /usr/share/zsh/scripts/base16-shell/
```

> [!info] Updated 2026-11-27
> 元の GitHub リポジトリ `Chrysostomus/manjaro-zsh-config` は移行・アーカイブされているため、Manjaro 公式リポジトリまたは AUR から取得することを推奨します。また、非 Arch 系システムで上記のコピーコマンドを実行する前に、`sudo mkdir -p /usr/share/zsh/functions /usr/share/zsh/scripts /etc/zsh` を実行してコピー先ディレクトリを作成しておく必要があります。

その後、`manjaro-zsh-config/.zshrc`（または `/etc/zsh/zshrc-manjaro`）を `~/.zshrc` にコピーしてから `zsh` を再起動すれば完了です。
