## 1. CJK（日中韓）共通フォントのインストール (Fonts)

どのシステムを使用する場合でも、最初のステップは日本語・中国語・韓国語の文字を正しく描画できる共通フォントをインストールすることです。

- **Arch Linux / Manjaro：**

    ```bash
    sudo pacman -S noto-fonts-cjk
    ```

- **Debian / Ubuntu / Linux Mint：**

    ```bash
    sudo apt install fonts-noto-cjk
    ```

- **RHEL / CentOS / Fedora：**

    ```bash
    sudo dnf install google-noto-sans-cjk-fonts
    ```

- **FreeBSD：**

    ```bash
    sudo pkg install noto-fonts-cjk
    ```

> [!info] Updated 2026-11-27
> FreeBSD の `pkg` リポジトリには `noto-fonts-cjk` というパッケージ名は存在しません。用途に応じて言語別フォント（繁体字中国語の `noto-tc`、日本語の `noto-jp` など）またはメタポートの `noto` をインストールしてください（例：`sudo pkg install noto-tc noto-jp`）。

## 2. 入力メソッドフレームワークおよびエンジンのインストール（各システム向けコマンド）

優れたパフォーマンス、Wayland 互換性、そして日本語や注音（ボポモフォ）の変換精度を得るため、モダンな **Fcitx5** シリーズの採用を強く推奨します。

### 1. Arch Linux 系

```bash
sudo pacman -S fcitx5 fcitx5-mozc fcitx5-chewing fcitx5-configtool fcitx5-qt fcitx5-gtk
```

### 2. Debian / Ubuntu 系

```bash
sudo apt install fcitx5 fcitx5-frontend-qt5 fcitx5-frontend-gtk3 fcitx5-module-quickphrase fcitx5-config-qt fcitx5-mozc fcitx5-chewing
```

> [!info] Updated 2026-11-27
> 比較的新しい Ubuntu 24.04+ / Debian 13+ では `fcitx5-module-quickphrase` がコアパッケージ `fcitx5-modules` に統合されています。パッケージが見つからないエラーが出る場合は `fcitx5-modules` を代わりにインストールし、デスクトップ環境に応じて `fcitx5-frontend-gtk4` や `fcitx5-frontend-qt6` を追加してください。

### 3. RHEL / Fedora 系 (Fedora 34+)

```bash
sudo dnf install fcitx5 fcitx5-gtk fcitx5-qt fcitx5-config-qt fcitx5-mozc fcitx5-chewing
```

> [!info] Updated 2026-11-27
> Fedora 公式リポジトリにおける設定 GUI パッケージ名は（Debian 系の `fcitx5-config-qt` ではなく）`fcitx5-configtool` です。また必要に応じて `fcitx5-gtk4`、`fcitx5-qt6`、`fcitx5-autostart` を追加インストールできます。

### 4. FreeBSD

```bash
sudo pkg install fcitx5 fcitx5-configtool fcitx5-gtk4 fcitx5-gtk3 fcitx5-qt fcitx5-chewing fcitx5-mozc
```

> [!info] Updated 2026-11-27
> FreeBSD の `pkg` では実際のパッケージ名に言語や共通コンポーネントの接頭辞・接尾辞が付きます。新酷音（Chewing）は `zh-fcitx5-chewing`、GTK 共通は `fcitx5-gtk-common`、Qt 共通は `fcitx5-qt-common`（または対応する Qt5/Qt6 パッケージ）です。また公式バイナリリポジトリでは通常 `fcitx5-mozc` が直接提供されていないため、日本語入力には `ja-fcitx5-anthy` をインストールするか、Ports から Mozc をビルドしてください。

## 3. システム環境設定と動作シナリオ

使用する「デスクトップ環境」と「ディスプレイサーバー（X11 vs Wayland）」によって設定方法が異なります。

### シナリオ A：モダンな Wayland + KDE Plasma（Arch Linux + Plasma 5.27/6 など）

この組み合わせでは Fcitx5 の統合度が非常に高く、**手動で環境変数を設定する必要はほぼありません**：

1. 上記パッケージのインストールが完了したら再ログイン（Re-login）します。
2. システムが XDG 経由で自動的に `fcitx5` をバックグラウンド起動します。
3. KDE のシステム設定（**Regional Settings -> Input Method**）を開き、新酷音（Chewing）と Mozc をリストに追加するだけでそのまま利用できます。

### シナリオ B：従来の X11 または XFCE / GNOME / フルデスクトップ環境なし（WSL など）

Wayland + KDE 環境以外、またはシステムがモジュールを自動読み込みできない場合は、環境変数を手動で設定する必要があります。

- **グローバル環境変数 (`/etc/environment`)：**

    ```bash
    GTK_IM_MODULE=fcitx
    QT_IM_MODULE=fcitx
    XMODIFIERS=@im=fcitx
    SDL_IM_MODULE=fcitx
    GLFW_IM_MODULE=fcitx
    ```

- **FreeBSD 環境変数と自動起動：**

    - シェル設定ファイル（`~/.xprofile` または `~/.bashrc`）に以下を追記します：

        ```bash
        export GTK_IM_MODULE=fcitx5
        export QT_IM_MODULE=fcitx5
        export XMODIFIERS=@im=fcitx5
        ```

        > [!info] Updated 2026-11-27
        > Fcitx5 では互換性維持のため、GTK/Qt IM モジュールおよび XIM 識別名は（`fcitx5` ではなく）引き続き `fcitx` を使用します。正しい設定は `export GTK_IM_MODULE=fcitx`、`export QT_IM_MODULE=fcitx`、`export XMODIFIERS=@im=fcitx` です。

    - ウィンドウマネージャーの起動スクリプト（`~/.xinitrc`）にバックグラウンド起動コマンドを追記します：

        ```bash
        fcitx5 -d &
        ```
