## 1. 伝統的なコアツール：`du` (Disk Usage)

`du` はすべての Unix 系システム（Linux、FreeBSD、macOS）に標準で組み込まれている POSIX 準拠の標準ツールです。ファイルシステムのメタデータを順次読み取って使用容量を計算するため、標準的なシェルスクリプトによる自動調査に適しています。

### プラットフォーム対応状況

- **対応状況：** 両方対応（Linux / FreeBSD いずれも標準搭載）。

### 主要コマンドと実践例

- **表示するディレクトリの深さを制限する（容量調査で最もよく使われる）：**

    ```bash
    du -h --max-depth=1
    # または短縮形
    du -h -d 1
    ```

- **MB 単位で出力し、指定ディレクトリの合計サイズを表示する：**

    ```bash
    du -m -s /var/log/
    ```

- **実践の定番：カレントディレクトリ配下で容量が大きい上位 5 件のサブディレクトリまたはファイルを特定する**

    ```bash
    du -m --max-depth=1 | sort -nr | head -n 5
    ```

> [!info] Updated 2026-11-27
> `--max-depth=1` は GNU coreutils 版 `du`（Linux）専用のロングオプションです。FreeBSD や macOS の BSD 版 `du` は `--max-depth` に対応していないため、クロスプラットフォームで共通して使える `-d 1`（例：`du -m -d 1 | sort -nr | head -n 5`）を使用してください。

## 2. ターミナル対話型ツールの先駆け：`ncdu` (NCurses Disk Usage)

プレーンテキスト出力の `du` では階層を掘り下げて調査しづらいという欠点を補うために開発されたツールです。`ncurses` ベースのテキスト UI を備えており、ターミナル上でファイルマネージャーのように直感的な操作ができます。

### プラットフォーム対応状況

- **対応状況：** 両方対応（各システムのパッケージリポジトリからインストール可能）。

### インストールと操作方法

- **インストールコマンド：**

    ```bash
    # Linux (Ubuntu / Debian / RHEL)
    sudo apt install ncdu

    # FreeBSD (pkg または Ports 経由)
    sudo pkg install ncdu
    ```

- **起動と対話操作：**

    ```bash
    # カレントディレクトリをスキャンして対話 UI を起動
    ncdu

    # 指定したディレクトリをスキャン
    ncdu /var/log
    ```

- **操作ショートカット：** 上下キーで移動し、`Enter` でサブディレクトリに入ります。対象を選択した状態で `d` キーを押すと、容量を圧迫している不要なファイルをその場で削除できます。

## 3. モダンなパーティションビューア：`duf` (Disk Usage/Free Utility)

名前に `du` が付いていますが、実質的には従来の `df` コマンドを置き換えることに特化したツールです。見やすいレイアウトで各ディスクパーティション（マウントポイント）の健全性と空き容量を視覚的に表示します。

### プラットフォーム対応状況

- **対応状況：** 両方対応（クロスプラットフォーム対応）。

### インストールと使用方法

- **インストールコマンド：**

    ```bash
    # パッケージリポジトリまたはバイナリからインストール
    sudo apt install duf  # 一部の Linux ディストリビューション
    ```

- **実行方法：**

    ```bash
    duf
    ```

## 4. 超高速・並列処理の注目株：`gdu` (Go Disk Usage)

Go 言語で記述された高性能なディスク解析ツールです。最新の SSD とマルチコア CPU アーキテクチャ向けに最適化されており、ハードウェア性能を最大限に引き出して並列スキャンを行います。

### プラットフォーム対応状況

- **対応状況：** 両方対応（クロスプラットフォーム対応）。

### メリットと基本操作

- **圧倒的な高速性：** 従来の `du` や `ncdu` と比較して、`node_modules` のように数百万個の小さなファイルを含むディレクトリをスキャンする際、数倍高速に処理できます。

- **よく使う操作コマンド：**

    ```bash
    # カレントディレクトリを対話形式でスキャン
    gdu

    # すべてのマウントポイントの容量状況のみを表示
    gdu -d

    # Web サーバーモードを起動し、ブラウザ経由でリモートからスキャン結果を確認
    gdu --web /path/to/scan
    ```
