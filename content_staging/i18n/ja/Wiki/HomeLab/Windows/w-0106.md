# Duo Stream (Moonlight + Sunshine) マルチユーザーゲームストリーミング構成

> <img src='https://img.shields.io/badge/Status-Active-A8FF24?style=for-the-badge&labelWidth=100' height='38' />

![Windows](https://img.shields.io/badge/Windows-Supported-green?style=plastic&logo=windows)

これは Windows 11 とハードウェア仮想化技術をベースにした、マルチユーザー独立並列ゲームストリーミング構成です。従来のストリーミング方式（標準の Sunshine など）では現在の単一フォアグラウンドデスクトップしかキャプチャできず、複数人による同時操作には対応できませんでした。本構成では **Duo** と仮想ディスプレイおよび仮想ゲームパッドドライバを組み合わせることで、仮想マシン（VM）を起動することなく、1 台の物理ホストから入力フォーカスが互いに干渉しない完全に独立した 2 系統の 1080p 60fps ゲーム画面を同時に出力できます。

## 2. Software Requirement (ソフトウェア要件)

- **メインソフトウェア**：

    - **[Duo (Multi-user Sunshine Fork)](https://github.com/DuoStream/Duo)**（<span style="color:#e06c75"><del>https://www.google.com/search?q=https://github.com/giggio/duo</del></span> *(Updated 2026-11-27: 元のリンクは検索リダイレクトかつ誤ったリポジトリを指していたため、公式リポジトリ DuoStream/Duo に修正しました)*）：複数の Windows アカウント、仮想ディスプレイ、仮想入力デバイスを割り当てるためのコア管理ツールです。

    - **Sunshine**：オープンソースの低遅延ゲームストリーミング Host ソフトウェアです。

    - **Moonlight**：ストリーミング受信クライアント（Windows / macOS / Linux / Android / iOS / tvOS 対応）です。

- **下位依存ドライバ**：

    - **IddSampleDriver (Virtual Display Driver)**：Windows 用仮想ディスプレイドライバ。物理 HDMI ダミープラグ（Dummy Plug）を挿さずに拡張仮想ディスプレイを生成します。

    - **ViGEmBus (Virtual Gamepad Emulation Bus)**：仮想ゲームパッドドライバ。各クライアントからのコントローラー入力信号を分離し、指定されたセッションへ注入します。

- **周辺管理（オプション）**：

    - **EmuDeck for Windows**：レトロゲームエミュレータ統合スイート。

    - **RomM**：集中型ゲーム ROM / BIOS 管理プラットフォーム（NAS またはバックエンドサーバーから NFS/SMB マウントで提供）。

## 3. Setting (設定手順)

### ステップ A：基本環境とドライバ構成

1. **クリーンなドライバのインストール**：最新版の NVIDIA GeForce Game Ready または Studio ドライバをインストールします。

2. **ViGEmBus のインストール**：最新版の ViGEmBus ドライバをダウンロードしてインストールし、仮想コントローラー機能を有効にします。

3. **IddSampleDriver（仮想ディスプレイ）の構成**：

    - 仮想ディスプレイドライバをインストール後、システム設定の「ディスプレイ」で仮想ディスプレイ（Display）が追加されていることを確認します。

    - 仮想ディスプレイの解像度を **1920x1080**、リフレッシュレートを **60Hz** に設定します（高リフレッシュレート端末へ配信する場合は 120Hz に設定可能）。

    - マルチディスプレイのモードを「表示画面を拡張する (Extend these displays)」に設定します。

### ステップ B：分離されたユーザーアカウントの作成

複数ユーザーが接続した際にマウス・キーボード操作やアクティブウィンドウのフォーカス（Active Focus）を奪い合わないようにするため、Windows 側で独立したユーザー環境を作成します：

1. ローカルの標準ユーザーアカウントを 2 つ作成します（例：`Player1` と `Player2`）。

2. 自動サインインを設定するか、両アカウントがバックグラウンドセッションで実行できる権限を持っていることを確認します。

### ステップ C：Duo と Sunshine の構成

1. **Duo のインストール**：

    - Duo インストーラを実行すると、Sunshine の実行ファイルと IddSampleDriver が自動的に検出・紐付けされます。

    - Duo の設定パネルで 2 つの「Seat（シート）」を作成します：

        - **Seat 1**：ユーザー `Player1` を紐付け、仮想ディスプレイ `Display 1` と仮想コントローラー 1 を割り当てます。

        - **Seat 2**：ユーザー `Player2` を紐付け、仮想ディスプレイ `Display 2` と仮想コントローラー 2 を割り当てます。

2. **Sunshine エンコーダのチューニング**：

    - Sunshine WebUI（`https://localhost:47990`）を開きます。

    - **Configuration ➔ Audio/Video**：

        - **Encoder**：`NVENC` を明示的に指定します。

        - **NVENC Preset**：`P1` または `P2`（Performance、エンコード遅延を極限まで低減）に設定します。

        - **Capture Method**：`Desktop Duplication API (DXGI)` を選択します。

3. **Moonlight のペアリング**：

    - ユーザー A（リビングのテレビ用 Shield TV など）で Moonlight を開き、Duo の Seat 1 のポートとペアリングします。

    - ユーザー B（ノート PC や別室の端末など）で Moonlight を開き、Duo の Seat 2 のポートとペアリングします。

## 4. Tips (運用上の注意点と最適化テクニック)

- **1 人のシャットダウン操作によるホスト全体の電源断を防ぐ (Shutdown Prevention)**：

    - リビングの Moonlight クライアントからメニューの「Quit / Turn Off PC」を選択すると、デフォルトでは Windows 本体の物理シャットダウンが実行される可能性があります。

    - **対処法**：`Win + R` を押して `gpedit.msc`（ローカル グループ ポリシー エディター）を開き、`コンピューターの構成 ➔ Windows の設定 ➔ セキュリティの設定 ➔ ローカル ポリシー ➔ ユーザー権利の割り当て` へ移動して「システムのシャットダウン」を編集します。標準の Users グループを削除し、**Administrators のみを残す**ことで、リモートプレイヤーの誤操作によるシャットダウンを防止します。

- **Wake-on-LAN 失敗の切り分け (Wake-on-LAN 最適化)**：

    - Windows 11 でデフォルト有効になっている「高速スタートアップ (Fast Startup)」は、待機時の NIC への電源供給を遮断するため、Magic Packet を受信できなくなります。

    - 「電源オプション」から**「高速スタートアップを有効にする」のチェックを外し**、「デバイス マネージャー」のネットワークアダプタのプロパティで「シャットダウン Wake-On-Lan (Shutdown Wake-On-Lan)」を **Enabled**、「省電力型イーサネット (Energy Efficient Ethernet)」を **Disabled** に設定します。

- **ゲームセーブデータ（Save Data）のローカル分離と ROM / BIOS の共有**：

    - EmuDeck やエミュレータを併用する場合、ゲームの ROM と BIOS は NAS から SMB ネットワークドライブとして集中マウントするのがおすすめです。ただし、**ゲームのセーブデータ（Saves / States）は必ずローカルの各ユーザーの `%APPDATA%` または各 Windows ユーザーディレクトリ配下に保存**してください。Duo で同じゲームを二重起動した際に、ファイル書き込みロック（File Lock）やセーブデータの上書き事故が発生するのを防ぎます。

- **ノート PC 常時稼働時のバッテリー膨張対策 (Battery Care)**：

    - ゲーミングノート PC を Duo ホストとして運用する場合、長時間の常時給電による高温でリチウムイオンバッテリーが膨張しやすくなります。メーカー純正の管理ソフト（MSI Center / Dragon Center など）で充電上限を **50%〜60%** に制限するか、内蔵バッテリーを取り外して AC アダプタのみで運用してください。

- **同一セグメント L2 直通によるゲートウェイ負荷の軽減**：

    - 1080p 60fps の 2 系統同時ストリーミングでは、瞬間帯域幅が 80〜100 Mbps に達します。ストリーミングホストと主要クライアント（Shield TV など）は必ず同一 LAN スイッチ（同一 VLAN / サブネット）に接続し、パケットをハードウェアのワイヤスピードでスイッチングさせて、ソフトウェアルータ経由による不要な遅延やジッター（Jitter）を回避してください。
