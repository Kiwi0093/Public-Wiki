# 『BattleTech』弾薬システム構造とカスタム弾薬箱 JSON 編集ガイド

> <img src='https://img.shields.io/badge/Status-Active-A8FF24?style=for-the-badge&labelWidth=100' height='38' />

:::tip
弾薬もまた編集する価値のあるポイントです。少なくとも携行弾数は非常に重要です。
:::

BattleTech の内部アーキテクチャにおいて、弾薬システムは厳格な「3 層式」の対応ロジックを採用しています。弾丸を 1 発正常に発射するためには、**武器 (Weapon)**、**弾薬箱 (AmmunitionBox)**、**弾薬本体 (Ammunition)** の 3 つの JSON 設定が完璧に連携している必要があります。

## 1. 弾薬のマッチングと発射ロジック (System Logic)

メックが戦闘中に射撃を試みると、システムは以下の順序で検証を行います：

1. **第 1 層【武器側】**：`Weapon` JSON 内の `AmmoCategory` パラメータ（例：`"AC20"`）を読み取り、その武器がどの口径の弾薬を使うかを確認します。
2. **第 2 層【メックの搭載装備】**：メックに搭載されている全装備をスキャンし、`ComponentType` が `AmmunitionBox` である実体の弾薬箱を探し出して、その箱が `"AC20"` カテゴリの弾薬を供給できるかを照合します。
3. **第 3 層【弾薬定義】**：弾薬箱内の `AmmoID` は、独立した `Ammunition` JSON ファイル（例：`Ammunition_AC20.json`）を指しています。この下層ファイルこそが、その弾丸の属性（徹甲弾か焼夷弾かなど）を実際に定義しています。

> 💡 **最も安全な編集方法 (Safe Modding Rule)**
>
> 目的が単に「携行弾数を増やすこと」だけであれば、**弾薬箱 (AmmunitionBox) の `Capacity` パラメータのみを編集し**、`AmmoID` は標準のデフォルト弾薬ファイルを指したままにしておいてください。これにより、ゲーム側で読み込みエラーが発生するのを確実に防げます。

## 2. 弾薬箱 (`AmmunitionBox`) 主要パラメータ辞書

弾薬箱は、プレイヤーが実際にメックラボ（改造画面）でメックに搭載する「実体装備」です。

| **パラメータ名 (Key)** | **設定の影響と説明** |
| :--- | :--- |
| `AmmoID` | **中核の接続ポイント**：この弾薬箱に装填されている弾薬の種類を指定します。下層の Ammunition ファイル名（例：`"Ammunition_AC20"`）と完全に一致している必要があります。**絶対に間違えてはならず、誤ると武器が弾切れ表示になります。** |
| `Capacity` | **携行弾数**：この弾薬箱が供給する総発射回数です。例えば `100` に設定すると、1 発あたり弾薬を 1 消費する武器で 100 回射撃できるようになります。 |
| `ComponentType` | **コンポーネント主分類**：必ず `"AmmunitionBox"` に設定します。これによりシステムが武器やヒートシンクではなく弾薬コンテナとして判定します。 |
| `ComponentSubType` | **コンポーネント副分類**：必ず `"Ammunition"` に設定します。 |
| `InventorySize` | **占有スロット数 (Slots)**：メックの部位（脚部、胴体など）で占有するスペースの大きさです。標準の弾薬は通常 1 スロットを占めます。 |
| `Tonnage` | **装備重量 (トン)**：メックの総積載量から消費する重量です。標準の弾薬は通常 1 トンです。 |
| `Description.Id` | **オブジェクト ID**：この弾薬箱の JSON ファイル名と完全に同一でなければなりません。 |

## 3. 弾薬本体 (`Ammunition`) 主要パラメータ辞書（上級編）

特殊な弾薬（例：命中時に熱量を増加させる高爆焼夷弾や、より高ダメージの劣化ウラン徹甲弾など）を作成したい場合は、新しい `Ammunition` JSON ファイルを作成し、弾薬箱の `AmmoID` がそれを指すように設定する必要があります。

_ファイル例：純正の `Ammunition_AC20.json` をコピーして編集できます。_

| **パラメータ名 (Key)** | **設定の影響と説明** |
| :--- | :--- |
| `AmmoCategory` | **弾薬口径カテゴリ**：武器の `AmmoCategory` と一致させる必要があります（例：`"AC20"`）。システムに対し、この弾薬がどの武器用かを伝えます。 |
| `WeaponEffectID` | **専用ビジュアルエフェクト**：任意項目。特殊な弾薬であれば、異なる発射エフェクトや弾道カラーを指定できます。 |
| `HeatGeneratedModifier` | **発熱補正倍率**：この弾薬を発射した際の発熱量を変化させます。例えば `1.2` の場合、この弾薬での射撃時に武器の発熱が 20% 増加します。 |
| `ArmorDamageModifier` | **装甲ダメージ補正倍率**：装甲に対する破壊力を変化させます。例えば `1.5` の場合、敵の装甲に対して 1.5 倍の追加ダメージを与えます。 |
| `ISDamageModifier` | **内部構造ダメージ補正倍率**：無装甲部位（Internal Structure）に対する破壊力を変化させます。例えば `2.0` の場合、敵メックの内部構造を極めて破壊しやすくなります。 |
| `InstabilityModifier` | **不安定値補正倍率**：命中時にターゲットの安定度を削る倍率を変化させます。 |
