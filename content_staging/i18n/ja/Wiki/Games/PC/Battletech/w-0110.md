# BattleTech 武器・装備 JSON パラメータ解説

> <img src='https://img.shields.io/badge/Status-Active-A8FF24?style=for-the-badge&labelWidth=100' height='38' />

> [!tip]
> この記事では、PC ゲーム **BattleTech** の武器・装備 JSON ファイルにおける各パラメータの定義と実際の挙動への影響を 4 つのカテゴリに分けてまとめています。

## 1. 基本武器ステータス (Base Weapon Stats)

武器のハードウェア分類、射程、および動作の基本を制御します。

| **パラメータ名 (Key)** | **設定の影響と説明** |
|---|---|
| `Category` | 武器の大分類：`Ballistic`（実弾）、`Energy`（エネルギー）、`Missile`（ミサイル）など。対応するメックのハードポイント (Hardpoint) を決定します。 |
| `Type` | 武器タイプ：`Autocannon`、`Laser` など。システム内部のロジック判別に使用されます。 |
| `WeaponSubType` | 武器サブタイプ：`UAC20` など。種類をさらに細分化し、弾薬庫の適合やパイロットスキルのボーナスに影響します。 |
| `RangeSplit` | 射程しきい値：書式は `[短, 中, 長]`。各距離帯における命中率減衰の判定ポイントを定義します。 |
| `AmmoCategory` | 弾薬カテゴリ：`AC20` など。メックに対応するカテゴリの弾薬箱を搭載しないと発砲できません。 |
| `HeatGenerated` | 発射発熱量：1 回の発砲ごとにメックへ加算される熱量です。 |

## 2. ダメージと戦闘判定 (Damage Mechanics)

武器の発砲時に与える破壊力や追加の戦闘効果を定義します。

| **パラメータ名 (Key)** | **設定の影響と説明** |
|---|---|
| `Damage` | 単発基本ダメージ：弾丸・ビーム 1 発が命中した際に削る装甲または内部構造の値です。 |
| `ShotsWhenFired` | 1 回の攻撃での発射数：1 回の攻撃コマンドで発射される回数です。総ダメージ = 基本ダメージ × 発射数（`ProjectilesPerShot > 1` の場合、総ダメージは `Damage × ShotsWhenFired × ProjectilesPerShot` となります）。 |
| `ProjectilesPerShot` | 1 発あたりの弾丸数：散弾 (LBX) やミサイルにおいて、1 発の弾薬が何個の独立して命中判定される弾丸・弾頭に分裂するかを指定します。 |
| `Instability` | 不安定値ダメージ：命中時に目標の安定度を削る値です。一定値蓄積すると敵メックが転倒します。 |
| `AccuracyModifier` | 命中率補正：**負の値**が命中率上昇、正の値が命中率低下を意味します。 |
| `AttackRecoil` | 攻撃反動：連続ターンで発砲した際に発生する命中ペナルティです（UAC 系は通常高めに設定されています）。 |
| `IndirectFireCapable` | 間接射撃能力：ブール値 (`true`/`false`)。射線 (LoS) が通っていなくても障害物を越えて攻撃できるかどうかを指定します。 |

## 3. メック搭載・物理仕様 (Mech Specs)

メックラボ画面におけるスロット占有数や搭載制限を定義します。

| **パラメータ名 (Key)** | **設定の影響と説明** |
|---|---|
| `InventorySize` | 占有スロット数 (Critical Slots)：メックの部位に搭載する際に占有するスペースの大きさです。 |
| `Tonnage` | 装備重量 (トン)：メックの総積載重量から消費するトン数です。 |
| `AllowedLocations` | 搭載可能部位：`All` は全部位に搭載可能。`MechHead` などのように限定することもできます。 |

## 4. UI 表示と設定 (UI & Description)

| **パラメータ名 (Key)** | **設定の影響と説明** |
|---|---|
| `Description.Id` | **最重要パラメータ**。JSON ファイル名と完全に一致している必要があります。 |
| `BonusValueA / B` | 特殊効果の表示テキスト：緑色のボーナス表記（例：`+ 50 Dmg.`）。*注意：これはあくまで UI 上の表示文字列であり、実際の効果は Damage や statusEffects で変更する必要があります。* |
| `ComponentTags` | コンポーネントタグ：ショップでの出現に影響します。`BLACKLISTED` を付けるとショップや戦利品に出現しなくなります。 |
