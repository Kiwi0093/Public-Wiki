## コアコンセプト

『BattleTech』の装備・武器システムは完全に JSON ファイルによって駆動しています。すべての武器、弾薬ボックス、装備、さらには弾丸本体に至るまで、それぞれ独立した JSON 定義ファイルを持っています。改変における中核原則は、**ID の一意性を確保すること**と**論理的な関連性を正しく保つこと**です。

## 改変と適用の手順 (SOP)

### 1. ファイルの準備と編集

- **必須ツール**：Notepad++ などのプレーンテキストエディタを使用して JSON ファイルを編集し、書式エラーや文字化けが起きないようにします。
- **複製と命名**：オリジナルのファイル（例：`Weapon_Autocannon_UAC20.json`）をそのままコピーして編集します。**ファイル名は絶対に重複させてはいけません**。独自のサフィックス（例：`_VerK`）を付与することをおすすめします。
- **ID の一致**：JSON ファイル内の `"Id"` パラメータは、変更後の新しいファイル名と**完全に一致**させる必要があります。一致しない場合、ゲーム起動時に読み込みエラーが発生します。

> [!info] Updated 2026-11-27
> オリジナルのファイルを直接上書きするのではなく、複製して**新規に**カスタムファイル名を作成した場合、『BattleTech』のバニラエンジンは未登録の新しい JSON ファイルを自動的にはスキャンしません。実用上は **ModTek** を併用してカスタム Mod フォルダ内に `mod.json` マニフェストを記述するか、`VersionManifest.csv` に新しいエントリを登録することで、ゲーム側が該当装備を正しく読み込むようになります。

### 2. ゲーム内への実装方法

- **ショップ出現方式（通常ルート）**：`Description` 内の `"Cost"`、`"Rarity"`（テストしやすいよう低めに設定するのがおすすめ）、および `"Purchasable"`（`true` に設定）を変更し、さらに `"ComponentTags"` から `"BLACKLISTED"` タグを削除します。これにより、ゲーム内の星系ショップで装備がランダムに販売されるようになります。
- **Save Editor 方式（簡易テスト向け）**：コミュニティ製の `BattleTech Save Editor` を利用し、新しく作成した装備 ID を既存のセーブデータのインベントリへ直接書き込みます。そのままゲームを起動すれば、すぐに機体へ搭載してテストできます。
