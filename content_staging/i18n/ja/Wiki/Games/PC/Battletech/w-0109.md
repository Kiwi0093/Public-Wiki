# BattleTech ステータス効果とバフ設定

> <img src='https://img.shields.io/badge/Status-Active-A8FF24?style=for-the-badge&labelWidth=100' height='38' />

:::tip
BattleTech において、`statusEffects` は非常に奥深いシステムです。「パッシブ装備の強化効果（Passive）」だけでなく、「命中時に発動するマイナス効果（OnHit）」も作成できます。各ステータス効果は、主に 4 つの JSON ブロックで構成されています。
:::

## 1. 発動条件とターゲット設定 (Duration & Targeting)

これら 2 つのブロックは、「効果が何ターン続くか」および「誰に作用するか」を決定します。

| **パラメータ名 (Key)** | **設定の影響と説明** |
| --- | --- |
| `durationData.duration` | **持続ターン数**：`-1` に設定すると永続効果（装備している限り有効）になります。正の整数（例：`2`）に設定すると効果が 2 ターン持続します（通常は敵に命中させた際に付与するデバフに使用します）。 |
| `targetingData.effectTriggerType` | **発動タイミング**：<br />• `Passive`：パッシブ常時発動。装備している限り有効になります。<br />• `OnHit`：武器が目標に命中したときに発動します。 |
| `targetingData.effectTargetType` | **作用対象**：<br />• `Creator`：この武器/コンポーネントを装備しているメック自身に作用します（バフ）。<br />• `Target`：この武器が命中した敵メックに作用します（デバフ）。 |
| `targetingData.showInStatusPanel` | **UI 表示**：`true` または `false`。戦闘画面のステータスバーにこのバフ/デバフのアイコンを表示するかどうか。隠しパッシブ能力は UI が煩雑にならないよう通常 `false` にします。 |

## 2. 表示と説明 (Description)

ゲーム UI 上でその効果をクリック・確認した際に表示される情報を制御します。

| **パラメータ名 (Key)** | **設定の影響と説明** |
| --- | --- |
| `Description.Id` | **効果の一意な識別子**：ゲーム全体で重複不可。`StatusEffect-装備名-効果名` という形式を強く推奨します。 |
| `Description.Name` | **効果名**：UI 上に表示されるバフ/デバフの名前。 |
| `Description.Details` | **詳細説明**：UI 上に表示されるその効果のテキスト説明。 |
| `Description.Icon` | **UI アイコン**：呼び出す SVG ベクター画像ファイル名（例：`uixSvgIcon_equipment_TTS`）。 |

## 3. コア演算エンジン (Statistic Data)

最も重要なブロックであり、基盤となる数値の加減乗除を実行します。

| **パラメータ名 (Key)** | **設定の影響と説明** |
| --- | --- |
| `statisticData.targetCollection` | **作用範囲**：<br />• `Weapon`：このバフを提供する武器本体のみに効果が限定されます。<br />• `StatCollection`：メック全体のすべてのコンポーネントおよび基本ステータスに効果が及びます。 |
| `statisticData.statName` | **変更する属性対象**：どのシステム数値を変更するか（下記の「よく使われる属性名リファレンス」を参照）。 |
| `statisticData.operation` | **演算ロジック**：<br />• `Float_Add` / `Int_Add`：加算演算（負の数を入力すると減算になります）。<br />• `Float_Multiply`：乗算演算。倍率の計算に使用します（例：`1.1` は 10% 増加）。 |
| `statisticData.modValue` | **変更値**：変更する具体的な数値。**注意：JSON 内では必ず二重引用符で囲んで文字列として記述する必要があります**（例：`"-1.0"` や `"15"`）。 |
| `statisticData.modType` | **データ型**：<br />• `System.Single`：浮動小数点数（小数点付きの数値）に対応。<br />• `System.Int32`：整数（小数点なしの数値）に対応。 |

## 📖 よく使われる属性名 (statName) リファレンス

特殊装備を作成する際は、以下の文字列を `statisticData.statName` に入力することで対応するメックや武器の能力を変更できます。

### 📌 武器専用強化 (範囲：`Weapon`)

_`targetCollection` を `"Weapon"` に設定した場合に適用され、その武器にのみ影響します。_

| **属性名 (statName)** | **推奨演算** | **実際の効果説明** |
| --- | --- | --- |
| `AccuracyModifier` | Float_Add | **命中率補正**。負の値（例：`-1.0`）を入力すると命中率が上がり、射撃難易度が下がります。 |
| `DamagePerShot` | Float_Add | **単発ダメージ増加**。弾丸またはレーザー 1 発あたりの基本ダメージ値を直接増加させます。 |
| `HeatGenerated` | Float_Add | **発射発熱補正**。負の値（例：`-5.0`）を入力すると武器発射時の発熱量が減少します。 |
| `EvasivePipsIgnored` | Int_Add | **回避ピップ無視**。敵の Evasion ピップを無視する能力を高めます（例：`1` は追加で 1 つ多く無視）。 |
| `MaxRange` | Float_Add | **最大射程延長**。武器の限界射撃距離を直接延長します。 |

### 📌 メック全体強化 (範囲：`StatCollection`)

_`targetCollection` を `"StatCollection"` に設定した場合に適用され、メック全体の性能と移動に影響します。_

| **属性名 (statName)** | **推奨演算** | **実際の効果説明** |
| --- | --- | --- |
| `MaxHeat` | Int_Add | **オーバーヒート閾値上限**。メックが許容できる熱量の総容量を引き上げます。 |
| `HeatSinkCapacity` | Int_Add | **基礎放熱能力**。各ターン終了時に追加で排出される熱量値（内蔵ヒートシンクのような効果）。 |
| `WalkSpeed` | Float_Add | **歩行距離**。戦闘マップ上でメックが 1 回に移動できる歩行範囲を増やします。 |
| `RunSpeed` | Float_Add | **スプリント距離**。メックが Sprint を実行した際の最大移動範囲を増やします。 |
| `JumpDistanceMultiplier` | Float_Multiply | **ジャンプ距離倍率**。ジャンプジェット（Jump Jets）を装備している場合のみ有効で、ジャンプの限界距離を伸ばします。 |
| `DamageReductionMultiplierAll` | Float_Multiply | **全体被ダメージ軽減倍率**。例えば `0.9` の場合、あらゆる攻撃からの被ダメージが 10% 減少します（非常に強力な防御属性）。 |
| `SensorSignatureModifier` | Float_Add | **センサーシグネチャ補正**。負の値（例：`-0.2`）を入力すると、敵が遠距離からこのメックをロックオン・探知しにくくなります（ステルス効果）。 |

## ステータス効果 JSON 例 (命中 +1 と熱量上限 +15)

```json
"statusEffects": [
    {
        "durationData": { "duration": -1 },
        "targetingData": {
            "effectTriggerType": "Passive",
            "effectTargetType": "Creator",
            "showInStatusPanel": true
        },
        "effectType": "StatisticEffect",
        "Description": {
            "Id": "StatusEffect-UAC20K-Accuracy",
            "Name": "精準火控系統",
            "Details": "命中率 +1。",
            "Icon": "uixSvgIcon_equipment_TTS"
        },
        "nature": "Buff",
        "statisticData": {
            "statName": "AccuracyModifier",
            "operation": "Float_Add",
            "modValue": "-1.0",
            "modType": "System.Single",
            "targetCollection": "Weapon"
        }
    },
    {
        "durationData": { "duration": -1 },
        "targetingData": {
            "effectTriggerType": "Passive",
            "effectTargetType": "Creator",
            "showInStatusPanel": false
        },
        "effectType": "StatisticEffect",
        "Description": {
            "Id": "StatusEffect-UAC20K-HeatCap",
            "Name": "冷卻管線擴充",
            "Details": "最大熱量容量增加 15 點。",
            "Icon": "uixSvgIcon_equipment_Heatsink"
        },
        "nature": "Buff",
        "statisticData": {
            "statName": "MaxHeat",
            "operation": "Int_Add",
            "modValue": "15",
            "modType": "System.Int32",
            "targetCollection": "StatCollection"
        }
    }
]
```
