# ManjaroWSL（WSL2）安裝與桌面環境設定（已封存）

> <img src='https://img.shields.io/badge/Status-Obsolete-red?style=for-the-badge&labelWidth=100' height='38' />

![WSL](https://img.shields.io/badge/WSL-Supported-green?style=plastic&logo=linux)
![Manjaro](https://img.shields.io/badge/Manjaro-Supported-green?style=plastic&logo=manjaro)

> [!tip]
> 現在最新的做法是完全透過 Microsoft Store 安裝 WSL2 搭配 ArchWSL，步驟簡化許多。

> [!info]
> 因為手上有台 Windows 機器取得安裝權限可以使用 WSL，所以記錄當時加裝 ManjaroWSL 的過程。

## Pre-Start

首先要先把 WSL / WSL2 環境準備好：

- 用系統管理員權限開啟 `PowerShell`，執行下列指令開啟 Windows Subsystem for Linux：

```powershell
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
```

- 用系統管理員權限開啟 `PowerShell`，執行下列指令開啟 Virtual Machine Platform：

```powershell
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
```

- 下載並安裝 [WSL-Kernel](https://www.catalog.update.microsoft.com/Search.aspx?q=wsl)
- 將預設版本設為 WSL2：

```powershell
wsl --set-default-version 2
```

> [!info] Updated 2026-11-27
> 現代 Windows 10（2004+）與 Windows 11 已支援直接使用 `wsl --install`（及 `wsl --update`）一鍵安裝並啟用所需元件，不需手動執行 `dism.exe` 或另外下載 WSL2 Kernel 更新包。

## Install & Initialize ManjaroWSL

### Download

[ManjaroWSL](https://github.com/sileshn/ManjaroWSL) 已經預先打包完成，當時可直接到 [Releases 頁面](https://github.com/sileshn/ManjaroWSL/releases)下載最新的 zip 檔。

> [!info] Updated 2026-11-27
> `sileshn/ManjaroWSL` 專案目前已停止維護／封存。現代 WSL2 若需要使用 Arch 系環境，建議改用官方支援的 `wsl --install -d archlinux` 或新版 `.wsl` 映像匯入機制。

### 放置＆安裝

將下載好的 zip 檔放到預計存放整個 ManjaroWSL 系統的目錄並解壓縮後，開啟 PowerShell 執行：

```powershell
./Manjaro.exe
```

待其自動完成解壓初始化後，再執行一次：

```powershell
./Manjaro.exe
```

### Initialize

依畫面提示決定是否要 Resize 及建立 New User，當時建議皆選 `No`，原因如下：

- 不會用到 250GB 以上空間（且 WSL 預設會自動將 Windows 磁碟掛載至 `/mnt/`）。
- 使用者帳號由後續腳本統一建立，能順便套用完整的 Zsh 終端機與 Xfce 環境設定。

## Configure System

以 `root` 身份執行初始化腳本：

```bash
bash <(curl -L -s https://kiwi0093.github.io/script/WSL/manjaro.sh)
```

### Script 使用注意

- 一開始手動指定國家代碼通常比自動測速挑選鏡像站更快。
- 中途跳出 `vi` 編輯 `/etc/wsl.conf` 的介面時，加入以下設定：

```ini
[Users]
# 加入以下資訊
default = <User Name you created and wish to be default>
```

編輯完成後輸入 `:wq` 存檔離開。

### Script 說明

以下節錄腳本中主要執行的設定段落：

#### Mirrorlist & System Upgrade

```bash
# Basic system configuration
echo -e "${color1}Basic system configuration started${NC}"
echo -e "${color1}Setting your Repo${NC}"
echo -e "${color2}Do you want to set location for the mirror-list?(Y for Location, others for fastest 3 location)${NC}"
while :
do
        read LT
        case $LT in
                Y)
                        echo -e "${color2}Please input location you want(EX, tw for Taiwan, us for USA)\n${NC}"
                        read LT2
                        pacman-mirrors -c $LT2
                        break
                        ;;
                *)
                        pacman-mirrors --fasttrack 3
                        break
                        ;;
        esac
done
echo -e "${color1}Update system${NC}"
pacman -Syyu
```

主要是提供互動選項執行 `pacman-mirrors` 與 `pacman -Syyu`。

#### Basic Tools Install

```bash
echo -e "${color1}Install Basic tools${NC}"
pacman -S git yay wget curl rsync sshpass zsh manjaro-zsh-config \
ttf-nerd-fonts-symbols ttf-meslo-nerd-font-powerlevel10k \
ttf-meslo-nerd-font-powerlevel10k powerline-fonts \
nerd-fonts-noto-sans-mono vim wireguard-tools systemd-resolvconf htop --noconfirm
```

在此區段安裝 `zsh` 與美化相關字型／設定，以及 `git`、`yay`、`rsync`、`wireguard` 等常用工具。

#### Xfce4 及 Manjaro Theme

```bash
echo -e "${color1}Install Xfce4 for GUI${NC}"
pacman -S xfce4-gtk3 xfce4-goodies xfce4-terminal network-manager-applet \
xfce4-notifyd-gtk3 xfce4-whiskermenu-plugin-gtk3 tumbler engrampa lightdm \
lightdm-gtk-greeter lightdm-gtk-greeter-settings manjaro-xfce-gtk3-settings \
manjaro-settings-manager --noconfirm
```

這段主要是參照 Manjaro 官方文件安裝 Xfce4 與佈景主題套件。

#### GUI Tools & 中文環境

```bash
echo -e "${color1}Install GUI$ tools${NC}"
pacman -S terminator brave-browser tigervnc gnome-pie --noconfirm
echo -e "${color1}Install Chinese Environment${NC}"
pacman -S adobe-source-han-serif-tw-fonts adobe-source-han-serif-hk-fonts \
adobe-source-han-serif-cn-fonts adobe-source-han-sans-tw-fonts \
adobe-source-han-sans-hk-fonts adobe-source-han-sans-cn-fonts \
adobe-source-han-serif-jp-fonts adobe-source-han-sans-jp-fonts \
fcitx fcitx-chewing fcitx-configtool fcitx-mozc fcitx-configtool --noconfirm
```

這部分就是安裝基本瀏覽器、終端機與中文字型、輸入法套件；其餘則是一些個人設定檔匯入與帳號建立。

> [!info] Updated 2026-11-27
> 上述歷史腳本中，`ttf-meslo-nerd-font-powerlevel10k` 與 `fcitx-configtool` 有重複列出；此外，傳統 `fcitx`（v4）在 Arch / Manjaro 生態系中已被 `fcitx5`（`fcitx5-im`、`fcitx5-chewing`、`fcitx5-mozc`）全面取代。

#### Systemd on WSL

```bash
echo -e "${color1}Change your root password & shell to zsh${NC}"
sudo -u $USERN yay -S genie-systemd-git
echo 'genie -i' > /etc/init.wsl
chmod +x /etc/init.wsl
genie -i
genie -c systemctl disable auditd.service
genie -c systemctl disable multipathd.service
genie -c systemctl disable systemd-modules-load.service
genie -c systemctl enable systemd-resolved.service
genie -c systemctl start systemd-resolved.service
```

當時實測後，能較簡單正常運作的方案只有 `genie-systemd-git`：裝好後先以 `genie -i` 初始化瓶子環境，再透過 `genie -c` 執行指令或進入新的 shell。

> [!info] Updated 2026-11-27
> 自 WSL 0.67.6 起，WSL2 已原生支援 systemd。現代環境只需在 `/etc/wsl.conf` 加入 `[boot]` 與 `systemd=true` 並重啟 WSL（`wsl --shutdown`）即可，已不再需要安裝 `genie-systemd-git` 或套用上述停用服務的 workaround。

#### 建立 Desktop Shortcut

使用 [GWSL](https://opticos.github.io/gwsl/) 進行設定：

- 開啟 `GWSL Distro Tools` → `Display/Audio auto exporting`
- 開啟 `GWSL Distro Tools` → `LibGL Indirect`
- 接著打開 `Shortcut Creator`：

![](https://raw.githubusercontent.com/Kiwi0093/graph/master/2022/03/16-15-22-35-gwsl-shortcut.PNG)

- **Shortcut Label**：Windows 開始功能表顯示的捷徑名稱，可自訂。
- **Shortcut Command**：使用 Xfce4 時固定填寫 `startxfce4`。
- **Display Mode**：若要顯示完整桌面環境，需選擇 `Single Window` 或 `Fullscreen`。
- **Keep Xserver Instance**：若 Display Mode 選 `Fullscreen`，此項必須設為 `true`，否則容易閃退。

設定完成後可先按 `Test Configuration` 測試，確認沒問題再點選 `Add to Start Menu`。

> [!info] Updated 2026-11-27
> Windows 11 內建的 WSLg 已原生提供 Linux GUI（X11 / Wayland）與音訊、中文輸入法整合，一般圖形化應用已不再需要搭配 GWSL 等第三方 X Server。

## 結語

老實說一開始看到 `WSL` 時覺得很驚喜，發現有 `Manjaro` 社群發行版更讓人期待，但實際安裝使用後感受卻有些落差，原因如下：

- 執行速度不如預期流暢，尤其是開啟完整桌面環境運作時。
- 多螢幕環境下執行的程式常常無法正常切換輸入法（或許只能試著預設改用 Chewing 並以 `Shift` 切換）。
- Desktop 模式閒置一段時間後容易直接當掉，連帶裡面的程式也一起終止。
- `systemd` 雖然透過第三方工具勉強能跑，但整體穩定度與原生環境仍有明顯差距。

因此，如果只是需要一個 Linux shell 執行工具，或因特殊需求必須同時在 Windows 與 Linux 下作業，WSL 會是不錯的選擇；但若要拿來與真正的 Linux Desktop 相比就顯得力不從心，甚至連遠端 VNC 連線另一台 Linux 桌機的體驗都比不上。不過這本來就是針對特定情境才採用的權宜方案。
