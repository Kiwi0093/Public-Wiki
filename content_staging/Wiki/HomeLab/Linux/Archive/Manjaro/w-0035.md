# 基本作法

## 安裝 `xrdp` & `xorgxrdp`

```bash
yay -S xrdp xorgxrdp
```

然後啟動服務：

```bash
sudo systemctl enable --now xrdp.service
sudo systemctl enable --now xrdp-sesman.service
```

然後就可以用了，基本上什麼其他設定都不用改。

# 注意事項

```bash
#記得把--exit-with-session拿掉不然會卡住
```

> [!info] Updated 2026-11-27
> 本篇針對早期 X11 時代的 KDE Plasma 5 與 `~/.xinitrc` 架構撰寫；現今 KDE Plasma 6 已預設改用 Wayland，傳統 X11 的 `xrdp` + `xorgxrdp` 與 `~/.xinitrc` 做法已不再直接適用（Wayland 環境下的 KDE Plasma 6 可改用官方的 `krdp` / KRdp 提供 RDP 遠端桌面服務）。
