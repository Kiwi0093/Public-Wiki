> [!tip]
> Manjaro 21 KDE 不知道發了什麼瘋，安裝到 VMware Workstation 裡面的時候會有下面兩個問題：
> * ~~用 Free driver & non-free driver 無法開機~~（21.0.7 已修復）
> * 安裝後沒有 VM 用的 Display driver，導致顯示有問題

# Boot from USB/ISO

雖然問題解決了，但是補充一下當時的對策：

```bash
# 開機的時候進入grub editor把
driver=free 改成 driver=mesa
```

就可以了。

# Display issue fix

基本上就是缺安裝 `video-virtualmachine` 這個 VMware 跟 VirtualBox 通吃的 driver：

```
#先安裝上需要的package
sudo pacman -S virtualbox-guest-utils open-vm-tools
sudo mhwd -i pci video-virtualmachine
sudo systemctl enable vmtoolsd.service
sudo systemctl start vmtoolsd.service
```

理論上這樣就好了。

> [!info] Updated 2026-11-27
> Manjaro 21 已屬過時版本（`driver=mesa` 開機問題於 21.0.7 後即已修正）。此外，在 VMware 虛擬機中僅需安裝 `open-vm-tools`（不需安裝僅供 VirtualBox 使用的 `virtualbox-guest-utils`）並啟用 `vmtoolsd.service`（及視需求啟用 `vmware-vmblock-fuse.service`）；現代 Linux／Manjaro 核心與 Mesa 已內建 `vmwgfx` 支援，無須再套用上述舊版 GRUB 參數或 `mhwd` 繞道步驟。
