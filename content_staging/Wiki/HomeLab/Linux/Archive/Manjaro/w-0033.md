> [!info] Updated 2026-11-27
> 本文為早期使用 Manjaro Linux 的歷史封存筆記：
> - `pacman-mirrors` 為 Manjaro 專用工具，不適用於標準 Arch Linux。若在 Arch Linux 環境請改用 `reflector`（例如 `sudo reflector --country Taiwan,Japan --latest 10 --sort rate --save /etc/pacman.d/mirrorlist`）。
> - 原文指令中的 `<County Name>` 應為 `<Country Name>`；在 Manjaro 變更鏡像站後，亦建議搭配執行 `sudo pacman -Syyu` 強制同步套件庫索引。

##### By Country選擇

```Bash
sudo pacman-mirrors --country <County Name>
```

這個指令會依照選定的Country的server列表進行速度確認建立mirror-list

##### By 速度選擇

```Bash
sudo pacman-mirrors --fasttrack <數量>
```
