# 前言

其實不用搞成這麼複雜，但是寫的時候想說寫得細一點，順便拿來練習寫 Shell Script。

## 架構說明

因為 **_Arch Linux_** 的安裝邏輯如下：

> 先在 Live CD 的 OS 內對 HDD 進行處理，然後透過網路把新的 Arch Linux 系統裝進 HDD 內，接著 chroot 到新的系統內，利用新系統的環境進行初步設定與開機引導設定等動作，最後再完全退出並重新開機，改以 HDD 開機，這樣才算完成一個新系統的安裝。

因此在腳本的設計上，是把所有選項在 `arch-chroot` 後都做成獨立的 script 來執行，如同下面的架構圖：
