## 基本需求

* 建立額外帳號：作為備援／救援用帳號。
* 擴容：將系統映像檔分割區擴大至實際的 Boot Volume 大小（預設映像檔僅約 50 GB，但單台免費實例最高可配置到 100 GB 的 Boot Volume，因此需要擴容）。
* 更新系統套件。
* 基本安裝：安裝 `docker-ce`、<span style="color:#e06c75"><del>docker-compose</del></span> *(Updated 2026-11-27: Docker Compose v1 已停止維護，新版應改為安裝 `docker-compose-plugin` 並使用 `docker compose` v2 指令)* 等工具。
* 基本設定：透過 `git clone` 拉取設定檔並完成系統初始化。

> - **Docker Compose v1 淘汰**：腳本透過 GitHub Releases 下載已停止維護的 `docker-compose` `1.29.2` 並執行 `docker-compose`；現代應改為安裝 `docker-compose-plugin` 並使用 `docker compose`（v2）指令。同時 Compose YAML 內的 `version: '3'` / `version: '3.3'` 與 `links:` 在 v2 皆已廢棄（同網路內可直接以服務名稱互通）。
> - **腳本語法與設定錯誤**：
>   - 第 46–47 行等處誤用了未定義的小寫 `${nc}`（上方宣告為大寫 `NC='\e[0m'`），會導致終端機顏色重設失效。

### 改版說明

因為這些 Oracle Linux 8 主機若是我自己使用，通常都是直接 `git clone` 我的私人 Repo 來建立服務；但考量到也會有其他人拿去用，且大多有跑 V2Ray 的需求（唉……GFW 呀……），所以才把直接部署 V2Ray 相關的程式加進去：

* WebSocket + TLS 需要 SSL 憑證，因此把 `Traefik` 作為基礎元件打包進去。
* 因為前端改用 Traefik，所以不直接使用 V2Ray 預設的 HTTP 處理功能來承接封包，而是再包一層 Nginx 做反向代理轉發。
* 因為 `Traefik` 的特性，請務必先設定好 DNS 再啟動服務，否則服務起來卻還沒對應到正確解析時，就會收到 <span style="color:#e06c75"><del>let's encryption的Error然後把這個DN卡住至少30天</del></span> *(Updated 2026-11-27: 應為 Let's Encrypt；且驗證失敗的速率限制為每小時每主機名稱最多 5 次、約鎖定 1 小時，並非 30 天)*……。
* 因為我懶得寫複雜驗證，只要沒有正確輸入 `Yes` 或 `No` 就會陷入無限迴圈（大小寫也要完全一致唷\~\~\~\~）。
