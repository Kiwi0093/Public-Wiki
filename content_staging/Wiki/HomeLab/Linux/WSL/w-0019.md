## 一、Host Setting（Windows 宿主機設定）

**1. 更新 WSL 核心**

確保你的 WSL 是最新版本，在 Windows 的 PowerShell 中執行：

```powershell
wsl --update
```

**2. 開啟 Nested Virtualization**

> **⚠️ 易錯提醒：** 巢狀虛擬化的設定是針對整個 WSL2 虛擬機引擎的，所以必須寫在 Windows 端的全域設定檔 `.wslconfig` 中，**不能**寫在 WSL 內部的 `/etc/wsl.conf`。

開啟 Windows 的檔案總管，編輯或建立 `C:\Users\<你的帳號>\.wslconfig`，加上以下這段：

```ini
[wsl2]
nestedVirtualization=true
```

完成後，在 PowerShell 強制重啟 WSL 讓設定生效：

```powershell
wsl --shutdown
```

## 二、ArchWSL 安裝 QEMU/KVM 與 Virt-Manager

> [!info] Updated 2026-11-27
> 1. 除第三方 `ArchWSL` 外，Arch Linux 現已提供官方 WSL2 映像檔（`archlinux-wsl`），可直接在 Windows 透過 `wsl --install archlinux` 安裝。
> 2. 執行下方 `systemctl enable --now libvirtd` 前，須先確認 WSL 內部的 `/etc/wsl.conf` 已設定 `[boot]` 區段的 `systemd=true` 並以 `wsl --shutdown` 重啟，否則 `systemctl` 無法運作。

重新啟動並進入 WSL（Arch Linux）後，開始安裝虛擬化相關工具。

**1. 安裝核心與網路套件**

```bash
sudo pacman -S archlinux-keyring qemu-full virt-manager virt-viewer edk2-ovmf dnsmasq vde2 bridge-utils openbsd-netcat libguestfs ebtables iptables virglrenderer
```

> [!info] Updated 2026-11-27
> 1. `ebtables` 已自 Arch Linux 官方套件庫移除，其功能已由支援 `nftables` 後端的 `iptables` 取代，實際執行 `pacman -S` 時請移除 `ebtables` 以免發生 `target not found` 錯誤。
> 2. 若需使用第四節的 VirtioFS 共享資料夾功能，請一併安裝 `virtiofsd` 套件（已從 QEMU 拆分為獨立套件）。

**2. 安裝 TPM 2.0 模擬套件（若需要跑 Windows 11 Guest）**

```bash
sudo pacman -S swtpm
```

**3. 啟動與設定 Libvirt 服務**

```bash
# 啟動並設定開機自啟 libvirtd
sudo systemctl enable --now libvirtd

# 啟動預設的虛擬網路 (NAT)
sudo virsh net-start default

# 設定虛擬網路開機自動啟動
sudo virsh net-autostart default
```

**4. 調整帳號權限**

為了讓你不用每次開啟 Virt-Manager 都要輸入 root 密碼，需將目前使用者加入相關群組：

```bash
sudo usermod -a -G libvirt $USER
sudo usermod -a -G libvirt root
sudo usermod -a -G kvm $USER
sudo usermod -a -G kvm root
```

> [!info] Updated 2026-11-27
> `root` 帳號本身即具備完整系統權限，不需執行 `usermod -a -G libvirt root` 與 `usermod -a -G kvm root`；僅需將一般使用者 `$USER` 加入 `libvirt` 與 `kvm` 群組並重新登入（或重啟 WSL）即可。

**5. 設定 Polkit 規則（免密碼管理）**

編輯 `/etc/polkit-1/rules.d/50-libvirt.rules`：

```javascript
/* Allow users in kvm group to manage the libvirt daemon without authentication */
polkit.addRule(function(action, subject) {
    if (action.id == "org.libvirt.unix.manage" &&
        subject.isInGroup("kvm")) {
            return polkit.Result.YES;
    }
});
```

都修改完成後，重開服務套用權限（最保險是直接登出 WSL 再登入，或執行 `wsl --shutdown`）：

```bash
sudo systemctl restart libvirtd
```

## 三、Guest OS 設定（以第二層的 Arch Linux 為例）

當你在 Virt-Manager 裡面裝好了一台 Guest OS（虛擬機）後，需要安裝類似 VMware Tools 的增強套件，才能實現畫面自動縮放與剪貼簿共用。

**1. 安裝 QEMU 與 SPICE 客體代理程式**

在 **Guest OS（虛擬機內部）** 執行：

```bash
sudo pacman -S spice-vdagent qemu-guest-agent xf86-video-qxl
```

若你是使用 X11 桌面環境，為了讓視窗可以自動縮放，可透過 AUR 安裝 `x-resize`：

```bash
yay -S x-resize
```

> **💡 關於 Service Enable 的疑惑：** 網路上很多舊教學會說要 `systemctl enable` 這些服務。但其實現在的 `spice-vdagent` 通常是由桌面環境（如 GNOME / KDE / XFCE 的 autostart）自動啟動，而 `qemu-guest-agent` 則是透過 socket 觸發。所以找不到對應的 service 檔案或不需要手動 enable 是正常的，只要重新開機後功能正常生效即可。

## 四、加掛 Shared Folder（VirtioFS）

透過 VirtioFS，可以讓 Guest OS 原生且高效地存取 Host（此處指 WSL）的資料夾。

**1. Virt-Manager 硬體設定**

1. 先將 Guest OS 關機。
2. 點擊 Virt-Manager 視窗上方那排的「燈泡」圖示（顯示虛擬硬體詳細資料）。
3. 點擊左下角的 **Add Hardware（新增硬體）**。
4. 選擇 **Filesystem（檔案系統）**：
   - **Driver:** 選擇 `virtiofs`
   - **Source path:** 填入 WSL 裡的目錄，例如 `/home/kiwi/host`（記得先在 WSL 建立好這個資料夾）
   - **Target path:** 這是標籤名稱（Mount Tag），可自行命名，例如 `host`
5. 點擊完成並啟動虛擬機。

> [!info] Updated 2026-11-27
> 使用 VirtioFS 前，須同時於 Virt-Manager 虛擬機設定的 **Memory** 頁面勾選 **Enable shared memory**，否則啟動虛擬機時會出現 `virtiofs requires shared memory` 錯誤。

**2. 在 Guest OS 中掛載**

**手動掛載測試：**

```bash
# -t virtiofs <Target Path 標籤> <Guest OS 內的掛載點>
sudo mount -t virtiofs host /home/kiwi/host
```

**寫入 `/etc/fstab` 開機自動掛載：**

確認手動掛載沒問題後，編輯 Guest OS 內的 `/etc/fstab`，加上這行：

```text
# Shared Folder with HOST (WSL)
# <Target標籤>  <掛載點>           <格式>      <參數>                       <dump> <pass>
host            /home/kiwi/host   virtiofs   rw,noatime,_netdev           0      2
```

> **注意：** 加上 `_netdev` 參數可以確保系統在載入網路與外部設備模組後才執行掛載，避免開機卡住。

> [!info] Updated 2026-11-27
> 第六欄的 `pass`（`fsck` 檢查順序）建議設為 `0`（即 `0 0`）而非 `2`，因為 `virtiofs` 為虛擬共享檔案系統，系統內並不存在對應的 `fsck.virtiofs` 檢查工具。
