# Manjaro Linux 桌面特色與遷移至 Arch Linux 的使用心得

:::tip
Manjaro 不僅是我 Arch 系 Desktop 的啟蒙，甚至是我整個 Linux Desktop 的啟蒙；曾經帶給我許多美好，直到我發現直接用 Arch 就好。

## 現狀

現狀就是我沒有任何一個系統在跑 Manjaro，但是我的每個 Arch Linux Desktop 上都有 `manjaro-zsh-config` 這個已經從 AUR 下架、但仍有保留 Git repo 的套件⋯⋯
Manjaro 對我的影響是很深遠的，尤其是讓我對於 Linux Desktop 該長什麼樣子做了定型，就跟很多人年輕的時候第一次用電腦就接觸 Windows 98，從此留下了電腦作業系統就該長那個樣的印象。

## 特徵

Manjaro 是最早一個為了桌面特化的 Arch 系發行版（distro），也有許多好用的小工具跟介面美化。我個人覺得比起後來的其他 Arch 系發行版，它還是很優秀的，所以有放進 AUR 的好用工具我也會想引進 Arch 裡面。

## 問題點

其實也不是什麼問題，之前網路上說什麼內鬨、吵架，所以支持者流失，我只能說，不愛了就是不愛，不用這麼多藉口，而且就算不愛了也要公平地評價它的好與壞。
在我的角度來看，我只能說，改用 Arch Linux 為的是更加乾淨的系統。這個其實很矛盾：新人的時候熱愛 Manjaro 包山包海都幫我照顧得好好的，熟悉後卻又嫌它管太多、預設安裝太多不需要的東西……
實在是很渣男行徑的感覺。

所以為了紀念曾經使用 Manjaro 的美好，我把以前相關的筆記全數留下，也算是一種懷念。
