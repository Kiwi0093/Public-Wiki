# Hexo：GitHub Pages 部落格架設架構簡介

> <img src='https://img.shields.io/badge/Status-Obsolete-red?style=for-the-badge&labelWidth=100' height='38' />

## 目標

利用 [Hexo](https://hexo.io/zh-tw/) + [GitHub Pages](https://pages.github.com/) 實現個人 Blog + Wiki 的架設。

## 基本架構

![Construction](https://raw.githubusercontent.com/Kiwi0093/graph/master/img/Blog_wiki_construction.PNG)

### 說明

這裡利用了 GitHub Pages 的幾個特性：

- 在 `<Username>.github.io` 這個 repo 的 <span style="color:#e06c75"><del>master</del></span> *(Updated 2026-11-27: GitHub 預設主分支現已改為 `main`，且新版 GitHub Pages 亦可指定任意分支或透過 GitHub Actions 直接部署)* 內的 `index.html` 會產生 `https://<Username>.github.io/` 這個有效網址
- 在其他 repo 中，GitHub Pages 會把 branch：`gh-pages` 內的 `index.html` 產生出 `https://<username>.github.io/<其他repo>/` 這個有效網址

所以可以將 Blog 的網頁產生到 `<username>.github.io` 這個 repo 的主分支裡面作為主網頁，將其他想要的 theme 的網頁產生到其他 repo 的 `gh-pages` 內作為其他子網站使用。

雖然可以利用 Hexo 指令指定特定 `_config.yml` 的方法把兩個放在一起，但是其實原理上跟上表是一樣的，只是可以把 Hexo Wiki 跟 Hexo Blog 存在同一個目錄裡面，將 Git 同步管理這點整合起來。
