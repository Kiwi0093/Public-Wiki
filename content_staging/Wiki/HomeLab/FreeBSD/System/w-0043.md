# 基本概念

與 `Linux` 使用單一套件管理器即可更新整個系統與套件不同，FreeBSD 更新系統與套件使用不同的指令。

### Linux 的作法

```bash
# Debian/Ubuntu
apt update && apt upgrade
# Arch
pacman -Syu
```

一個指令搞定全世界。

# FreeBSD 系統更新

## 更新系統

```bash
# 現有版本更新 patch
freebsd-update fetch && freebsd-update install
# 更新到 x.y-Release 版
freebsd-update upgrade -r x.y-RELEASE && freebsd-update install
```

> [!info] Updated 2026-11-27
> 使用 `freebsd-update upgrade -r x.y-RELEASE` 進行跨版本升級時，第一次執行 `freebsd-update install` 只會安裝新核心，必須先重新開機（`shutdown -r now`），再執行第二次 `freebsd-update install` 完成使用者空間（userland）更新；若有移除舊版函式庫並重建第三方套件，最後還須再執行一次 `freebsd-update install`。

## 更新 Package - pkg

其實不需要自己編譯（compile）的話，用 `pkg` 比較方便。

<img src="https://img.shields.io/badge/Kiwi-%E7%B0%A1%E5%96%AE%E7%9A%84%E8%AA%AA%E5%B0%B1%E6%98%AF%E6%87%B6%E7%9A%84%E7%AD%89port%20make%20install-A8FF24?style=social&logo=kiwix&logoColor=EA7500" height="40" />

```bash
# Install
pkg install <pkg_name>

# Remove
pkg delete <pkg_name>

# Autoremove
pkg autoremove

# Check pkgs version
pkg version

# 更新 repo
pkg update

# 更新 pkg
pkg upgrade
```

## Port 更新

以前 FreeBSD 大多數都是用 port 自己編譯所需的套件，但是到了現在，除了需要特殊編譯參數的條件以外，基本上都用 `pkg` 來安裝。

### Port Tree 更新

```bash
cd /usr/ports
# 第一次使用
portsnap fetch && portsnap extract && portsnap update
# 之後使用
portsnap fetch && portsnap update
```

> [!info] Updated 2026-11-27
> `portsnap` 工具已自 FreeBSD 13 起列為過時（deprecated），並於 **FreeBSD 14.0 起正式移除**（Ports Tree 亦已全面改由 Git 託管）。現代 FreeBSD 環境應安裝 `git`（例如 `pkg install git`）後，初次使用 `git clone https://git.FreeBSD.org/ports.git /usr/ports` 取得 Ports Tree，日後透過 `git -C /usr/ports pull` 更新。

### Port Software 更新

```bash
portmaster -a
```
