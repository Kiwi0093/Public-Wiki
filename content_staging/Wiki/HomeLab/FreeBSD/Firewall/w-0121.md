# FreeBSD PF 與 dnctl（Dummynet）流量控制實戰設定

> <img src='https://img.shields.io/badge/Status-WIP-yellow?style=for-the-badge&labelWidth=100' height='38' />

![FreeBSD](https://img.shields.io/badge/FreeBSD-Supported-green?style=plastic&logo=freebsd)

:::tip
即使網路卡不支援 ALTQ，FreeBSD 依然可以透過 `pf` 搭配 `dnctl`（Dummynet）達成流量控制。
:::

> [!info] Updated 2026-11-27
> `pf` 原生整合 `dnctl` / `dnpipe` 語法需 **FreeBSD 14.0 以上版本**（FreeBSD 13 及更早版本須改用 [IPFW + Dummynet](./w-0046)）。若主機同時擔任 NAT 閘道，請記得在 `/etc/pf.conf` 的過濾規則（`block all` / `pass ...`）之前加入 `nat on $EXT_IF ...` 轉譯規則。

## 1. 核心模組載入

雖然我們使用 `pf` 作為防火牆，但限速邏輯依然由 `dummynet` 驅動，因此必須載入兩個核心模組。

### 手動載入

```bash
kldload pf
kldload dummynet
```

### 開機自動載入

修改 `/boot/loader.conf` 以確保重啟後限速模組依然自動載入：

```bash
# /boot/loader.conf
pf_load="YES"
dummynet_load="YES"
```

## 2. 系統設定（`/etc/rc.conf`）

在啟動服務前，需在 `/etc/rc.conf` 啟用 `pf` 與 `dnctl`：

```bash
# /etc/rc.conf
pf_enable="YES"
pf_rules="/etc/pf.conf"
dnctl_enable="YES"    # 啟動 dummynet 控制器
```

## 3. 設定流量水管（`/etc/dnctl.conf`）

這部分與 `ipfw pipe` 語法一致，專門定義「水管（Pipe）」的頻寬上限：

```bash
# /etc/dnctl.conf
# 清除舊設定
flush

# 定義水管頻寬
pipe 1 config bw 500KBytes/s    # VPN
pipe 2 config bw 100KBytes/s    # P2P
pipe 3 config bw 500KBytes/s    # RDP
pipe 4 config bw 350KBytes/s    # Server
pipe 5 config bw 30KBytes/s     # Guest
```

## 4. 防火牆過濾與導流（`/etc/pf.conf`）

在 PF 中，使用 `dnpipe` 將符合條件的封包導向剛才定義好的 `dnctl` 水管：

```bash
# --- 定義介面與變數 ---
EXT_IF = "ext0"
INT_IF = "int0"

DMZ_NET = "192.168.0.0/24"
GUEST_NET = "192.168.2.0/24"
VPN_NET = "10.8.0.0/24"
P2P1_IP = "192.168.0.100"

# --- 規則設定 ---

# 1. 略過 Loopback
set skip on lo0

# 2. 預設阻斷
block all

# 3. 流量限速 (導向 dnpipe)

# VPN 流量
pass out quick on $EXT_IF to $VPN_NET dnpipe 1

# RDP 特定流量 (P2P1 專用)
pass in quick on $INT_IF proto tcp from $P2P1_IP to any port 3389 dnpipe 3

# P2P 流量
pass in quick on $INT_IF from $P2P1_IP to any dnpipe 2

# Guest 網路限速
pass in quick on $INT_IF from $GUEST_NET to any dnpipe 5
pass out quick on $INT_IF from any to $GUEST_NET dnpipe 5

# DMZ 出口流量
pass out quick on $EXT_IF from $DMZ_NET to any dnpipe 4

# 4. 基礎放行
pass out quick on $EXT_IF proto { tcp, udp, icmp } all keep state
```

## 5. 2026/04 筆記小結與常用指令

- **為什麼這樣配？**：PF 的規則管理相當直覺且強大（例如 `set skip on lo0`），而 Dummynet（`dnctl`）則是 FreeBSD 中頻寬限制相容性最好的機制。
- **常用狀態檢查指令**：
  - 查看防火牆狀態：`pfctl -sr`
  - 查看限速水管狀態：`dnctl pipe show`
- **延遲優化建議**：若發現限速後延遲明顯升高，可在 `/etc/dnctl.conf` 的 `pipe` 設定最後加上 `codel` 或 `fq_codel`，例如：

  ```bash
  pipe 2 config bw 100KBytes/s fq_codel
  ```
