# 沒有 Key 的狀態

就產生新的 Key：

```bash
ssh-keygen -t rsa -C "your@mail.for.github"
```

> [!info] Updated 2026-11-27
> 自 OpenSSH 8.8 起預設停用舊式 SHA-1 的 `ssh-rsa` 簽章，GitHub 亦建議優先使用更安全且較短的 **Ed25519** 金鑰演算法：
> ```bash
> ssh-keygen -t ed25519 -C "your@mail.for.github"
> ```

然後把產生的 <span style="color:#e06c75"><del>id_rsa.pub</del></span> *(Updated 2026-11-27: 若採用 Ed25519 則為 `~/.ssh/id_ed25519.pub`)* 裡的資料貼到 GitHub 的 **Settings → SSH and GPG keys → New SSH key**，這樣就可以了。

# 已經有現成的 Private Key

```bash
eval `ssh-agent -s`
ssh-add /location/to/your/key
```

*(註：現代 Shell 建議改用 `eval "$(ssh-agent -s)"` 取代反引號語法。)*

# 變更 Repo 連線方式

```bash
vi /location/to/repo/.git/config
把裡面的
url = https://github.com/<USER>/Repo.git
改成
url = git@github.com:<USER>/Repo.git
```

> [!tip] Updated 2026-11-27
> 實務上也可直接於 Repo 目錄內執行 Git 指令切換遠端位址，無須手動編輯 `.git/config`：
> ```bash
> git remote set-url origin git@github.com:<USER>/<Repo>.git
> ```

然後就可以快樂地連線了。

# 追加

雖然可以用 `ssh-add` 把 Key 加入使用，但常常會有需要一直重新加入的問題；<span style="color:#e06c75"><del>根本的解決方案就是讓key file為維持檔名id_rsa就可以直接用了....</del></span> *(Updated 2026-11-27: 建議維持預設檔名（如 `id_ed25519`），或於 `~/.ssh/config` 為 `Host github.com` 設定 `IdentityFile` 與 `IdentitiesOnly yes`，並視需求加上 `AddKeysToAgent yes`。)*
