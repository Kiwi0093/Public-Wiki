Apache Guacamole 網頁遠端桌面 Docker 部署封存筆記

提示

其實這個用很長一段時間了，但是到了最近重新整理的時候才發現我沒有寫成筆記。

參考資料​

  • Apache Guacamole and docker-compose – systems.dance

基本流程​

前提​

這是一個把 DB 與 AP 放在同一個 docker-compose.yml 內的作法；也的確後來發現不要刻意去整合 DB 可能對於容器化後比較方便，而且要像這次一樣切分也比較簡單。

流程​

  1. 先用 docker run 跑 Image 內的 script 來產生 initial DB。
  2. 用 compose file 先單獨建立 DB（並且要定義 volumes 來保留資料）。
  3. 在 DB container 內把 initial DB 匯入 DB container 的資料庫內（透過 volumes 保留成果）。
  4. 移除單獨的 DB container（其實不移除也可以，只不過後面的調整比較囉唆）。
  5. 利用 docker-compose.yml 直接建立相關的 container（包含 DB container）。

實際指令與文件​

Pull Image​

docker pull guacamole/guacamole
docker pull guacamole/guacd
docker pull mariadb/server
Updated 2026-11-27

mariadb/server 為已停止維護的舊版映像，現代部署應改用官方映像 mariadb:lts（環境變數前綴亦建議使用 MARIADB_*）。

Create Initial DB​

docker run --rm guacamole/guacamole /opt/guacamole/bin/initdb.sh --mysql > guac_db.sql

Create Initial DB Container/Volume​

initial.yml​

version: '3'
services:
  guacdb:
    container_name: guacdb
    image: mariadb/server:latest
    restart: unless-stopped
    environment:
      MYSQL_ROOT_PASSWORD: '<PASSWD_YOU_WANT>'
      MYSQL_DATABASE: 'guacamole_db'
      MYSQL_USER: 'guacamole_user'
      MYSQL_PASSWORD: '<PASSWD_YOU_WANT>'
    volumes:
      - /var/lib/docker/volumes/<Dir_you_want>:/var/lib/mysql

指令​

# Establish initial DB Container
docker-compose up -d

# Copy initial sql into db container
docker cp guac_db.sql guacdb:/guac_db.sql

# Opening a shell and initializing the db:
docker exec -it guacdb bash
cat /guac_db.sql | mysql -u root -p guacamole_db
exit

# Remove initial DB OS
docker-compose -f /where/is/your/docker-compose down
Updated 2026-11-27
  1. docker-compose v1 已終止支援，現代環境請改用 docker compose v2（例如 docker compose -f initial.yml up -d 與 docker compose -f initial.yml down，原指令末行亦漏了 .yml 副檔名）。
  2. Compose YAML 頂層的 version: '3' 欄位在 Compose v2 已屬過時屬性，建議直接省略。

Service Up​

docker-compose.yml​

version: '3'
services:
  guacdb:
    container_name: guacdb
    image: mariadb/server:latest
    restart: unless-stopped
    networks:
      - traefik
    environment:
      MYSQL_ROOT_PASSWORD: '<PASSWD_YOU_WANT>'
      MYSQL_DATABASE: 'guacamole_db'
      MYSQL_USER: 'guacamole_user'
      MYSQL_PASSWORD: '<PASSWD_YOU_WANT>'
    volumes:
      - /var/lib/docker/volumes/guacamole/db:/var/lib/mysql
  guacd:
    container_name: guacd
    image: guacamole/guacd
    restart: unless-stopped
    networks:
      - traefik
  guacamole:
    container_name: guacamole
    image: 'guacamole/guacamole:latest'
    restart: unless-stopped
    networks:
      - traefik
 #   ports:
 #     - '8080:8080'
    environment:
      GUACD_HOSTNAME: "guacd"
      MYSQL_HOSTNAME: "guacdb"
      MYSQL_DATABASE: "guacamole_db"
      MYSQL_USER: "guacamole_user"
      MYSQL_PASSWORD: "<PASSWD_YOU_WANT>"
    depends_on:
      - guacdb
      - guacd
    labels:
      traefik.enable: true
      traefik.http.routers.guacamole.rule: Host(`<hostname.you.want>`)
      traefik.http.routers.guacamole.tls: true
      traefik.http.routers.guacamole.tls.certresolver: myresolver
      traefik.http.services.guacamole.loadbalancer.server.port: 8080

networks:
  traefik:
    external: true
    name: web-service
Updated 2026-11-27

同上，Compose v2 不需 version: '3'，且 mariadb/server:latest 應改為 mariadb:lts（官方新映像中連線工具為 mariadb CLI）。

廢棄原因​

  • 安全性不佳，這個作法等於在防火牆上打個洞。
  • 改用 WireGuard + VNC 的方式代替，相對更安全簡單。
