Docker部署Node-RED：流程自動化引擎

提示

本來我只是想弄個類似 IFTTT 的東西，結果一踏進去才發現這玩意根本不是那麼單純呀～～

Updated 2026-11-27

本篇為早期實驗 Node-RED 的封存筆記，以下為現代 Docker 與 Node-RED 對照說明：

  1. Docker Compose v2 已捨棄頂層 version: '3.3' 欄位，並建議改用 compose.yaml 與 docker compose 指令。
  2. 不建議直接對掛載目錄執行 chmod 777；較安全的做法是執行 chown -R 1000:1000 /var/lib/docker/volumes/node-red 對齊容器預設 UID 1000。
  3. Node-RED 設定檔正確檔名為小寫複數的 settings.js（非 Setting.js）；新版官方容器內建指令為 node-red admin hash-pw，無須另裝全域 node-red-admin。

參考資料

  • Node-RED Official Website

安裝

其實安裝這部分是最簡單的一部分了⋯⋯

docker-compose.yml​

version: '3.3'
services:
  node-red:
    image: nodered/node-red
    container_name: node-red
#    ports:
#      - '1880:1880'
    environment:
      - TZ=Asia/Taipei
    volumes:
      - /var/lib/docker/volumes/node-red:/data
    restart: unless-stopped
    labels:
      traefik.enable: true
      traefik.http.routers.node-red.rule: Host(`<Domain>`)
      traefik.http.routers.node-red.tls: true
      traefik.http.routers.node-red.tls.certresolver: myresolver
      traefik.http.services.node-red.loadbalancer.server.port: 1880

networks:
  default:
    external: true
    name: traefik_backend

注意要點​

  • Volumes 權限 因為預設的 UID 權限是 1000，所以用 root 建立 container 後會因為寫入權限不能正常執行，解決方案是定義為 root 或是直接把目錄權限改了（我是改成 777）。

  • settings.js（原文寫作 Setting.js）設定 因為我是用 Traefik 來處理 SSL，所以只剩下登入權限的部分需要注意。 基本上登入設定開啟很容易：

    adminAuth: {
     type: "credentials",
     users: [
         {
             username: "admin",
             password: "$2a$08$zZWtXTja0fB1pzD4sHCMyOCMYz2Z6dNbM6tl8sJogENOMcxWV9DN.",
             permissions: "*"
         },
         {
             username: "george",
             password: "$2b$08$wuAqPiKJlVN27eF5qJp.RuQYuy6ZYONW7a/UWYxDTtwKFCdB8F19y",
             permissions: "read"
         }
     ]
    }

    只要把 username 的部分改成你喜歡的 ID， 然後透過 docker exec -it <NodeRed_container_name> bash 執行 node-red-admin hash-pw， 它就會讓你輸入你想要的密碼後把 hash 字串產出來，複製貼到上面的設定裡面去就好了。
