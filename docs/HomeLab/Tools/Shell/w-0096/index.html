Linux 與 FreeBSD 中／日文輸入法設定指南（Fcitx5）

一、 中日韓通用字型安裝 (Fonts)​

無論使用哪種系統，首要步驟是安裝能正確渲染中日韓字符的通用字型：

  • Arch Linux / Manjaro：

    sudo pacman -S noto-fonts-cjk

  • Debian / Ubuntu / Linux Mint：

    sudo apt install fonts-noto-cjk

  • RHEL / CentOS / Fedora：

    sudo dnf install google-noto-sans-cjk-fonts

  • FreeBSD：

    sudo pkg install noto-fonts-cjk
Updated 2026-11-27

FreeBSD pkg 套件庫中並無 noto-fonts-cjk 這個套件名稱，請依需求安裝語系字型（如 noto-tc 繁中、noto-jp 日文）或完整 meta-port noto：例如 sudo pkg install noto-tc noto-jp。

二、 輸入法框架與引擎安裝 (各大系統指令)​

強烈建議全面採用現代化的 Fcitx5 家族，以獲得最佳的效能、Wayland 相容性與日文/注音選字體驗。

1. Arch Linux 家族​

sudo pacman -S fcitx5 fcitx5-mozc fcitx5-chewing fcitx5-configtool fcitx5-qt fcitx5-gtk

2. Debian / Ubuntu 家族​

sudo apt install fcitx5 fcitx5-frontend-qt5 fcitx5-frontend-gtk3 fcitx5-module-quickphrase fcitx5-config-qt fcitx5-mozc fcitx5-chewing
Updated 2026-11-27

較新的 Ubuntu 24.04+ / Debian 13+ 已將 fcitx5-module-quickphrase 整併進 fcitx5-modules 核心套件；若遇到找不到套件錯誤可改裝 fcitx5-modules，並可視桌面環境補裝 fcitx5-frontend-gtk4、fcitx5-frontend-qt6。

3. RHEL / Fedora 家族 (Fedora 34+)​

sudo dnf install fcitx5 fcitx5-gtk fcitx5-qt fcitx5-config-qt fcitx5-mozc fcitx5-chewing
Updated 2026-11-27

Fedora 官方套件庫的設定介面套件名稱為 fcitx5-configtool（而非 Debian 系的 fcitx5-config-qt），另可視需求補裝 fcitx5-gtk4、fcitx5-qt6 與 fcitx5-autostart。

4. FreeBSD​

sudo pkg install fcitx5 fcitx5-configtool fcitx5-gtk4 fcitx5-gtk3 fcitx5-qt fcitx5-chewing fcitx5-mozc
Updated 2026-11-27

FreeBSD pkg 實際套件名稱帶有語系與共用元件前／後綴：新酷音為 zh-fcitx5-chewing、GTK 共用為 fcitx5-gtk-common、Qt 共用為 fcitx5-qt-common（或對應 Qt5/Qt6 套件）；另官方二進位套件庫通常不直接提供 fcitx5-mozc，日文輸入可改裝 ja-fcitx5-anthy 或經由 Ports 編譯 Mozc。

三、 系統環境設定與運行情境​

根據你使用的「桌面環境」與「顯示伺服器（X11 vs Wayland）」，設定方式有所不同：

情境 A：現代 Wayland + KDE Plasma (如 Arch Linux 搭配 Plasma 5.27/6)​

在這種組合下，Fcitx5 具備極高的整合度，幾乎不需要手動設定任何環境變數：

  1. 確保安裝完成上述套件後重新登入（Re-login）。
  2. 系統會透過 XDG 自動在背景啟動 fcitx5。
  3. 直接進入 KDE 的系統設定（Regional Settings -> Input Method），將新酷音（Chewing）與 Mozc 加入清單即可開箱使用。

情境 B：傳統 X11 或 XFCE / GNOME / 無完整桌面環境 (如 WSL)​

若非運作於 Wayland + KDE，或系統無法自動帶入模組，則需手動配置環境變數：

  • 全域環境變數 (/etc/environment)：

    GTK_IM_MODULE=fcitx
    QT_IM_MODULE=fcitx
    XMODIFIERS=@im=fcitx
    SDL_IM_MODULE=fcitx
    GLFW_IM_MODULE=fcitx

  • FreeBSD 環境變數與自動啟動：

    • 在 Shell 設定檔（~/.xprofile 或 ~/.bashrc）中加入：

      export GTK_IM_MODULE=fcitx5
      export QT_IM_MODULE=fcitx5
      export XMODIFIERS=@im=fcitx5
      Updated 2026-11-27

      Fcitx5 為了相容性，GTK/Qt IM module 與 XIM 識別名稱仍維持 fcitx（而非 fcitx5），正確設定應為 export GTK_IM_MODULE=fcitx、export QT_IM_MODULE=fcitx、export XMODIFIERS=@im=fcitx。

    • 在視窗管理器啟動腳本（~/.xinitrc）中加入背景啟動指令：

      fcitx5 -d &

系統 / 桌面情境建議輸入法架構中文引擎日文引擎設定與啟動特性

Debian / Ubuntufcitx5fcitx5-chewingfcitx5-mozc企業與伺服器桌面常用，多數 X11 環境需配置環境變數。
