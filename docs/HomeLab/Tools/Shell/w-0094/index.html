Zsh 與 Powerlevel10k 終端機美化跨平台設定

提示

自從用過 Manjaro KDE 後被它的 Zsh console 風格吸引，接著就繼續無性繁殖同樣的設定。

Zsh 安裝​

這個很簡單，基本上依靠系統的套件管理器安裝就好了：

# Archlinux系
sudo pacman -S zsh
或
yay -S zsh
# yum系
yum install zsh
# FreeBSD
pkg install zsh
Updated 2026-11-27

現代 RHEL、Rocky Linux、AlmaLinux 與 Fedora 發行版已由 dnf 取代 yum，請改用 sudo dnf install zsh；FreeBSD 亦須以 sudo pkg install zsh（或 root 身分）執行。

Manjaro-zsh-config @ Arch Linux​

因為 manjaro-zsh-config 在 AUR 內，只要安裝這個套件就會自動把相關依賴都裝上，所以問題不大：

# Archlinux系
# 這個在AUR內所以
git clone https://aur.archlinux.org/manjaro-zsh-config.git
cd manjaro-zsh-config && makepkg -si
或是更簡單的
yay -S manjaro-zsh-config

記得要把 /etc/zsh/zshrc-manjaro/.zshrc 複製到 ~/.zshrc 這樣才會生效 (Updated 2026-11-27: AUR 套件 manjaro-zsh-config 提供的範本位於 /etc/skel/.zshrc（會載入 /usr/share/zsh/manjaro-zsh-config）；若是照下方手動腳本複製，則應複製 /etc/zsh/zshrc-manjaro 為 ~/.zshrc。)

其他作業系統​

packages for manjaro-zsh-config​

  • zsh-completions
  • zsh-autosuggestions
  • zsh-history-substring-search
  • zsh-syntax-highlighting
  • zsh-theme-powerlevel10k
  • ttf-noto-nerd (Noto Nerd Fonts)

zsh-theme-powerlevel10k 安裝​

# Archlinux系
sudo pacman -S zsh-theme-powerlevel10k
or
yay -S zsh-theme-powerlevel10k
# 其他系統 - Manual Installation
sudo git clone --depth=1 https://github.com/romkatv/powerlevel10k.git /usr/share/
# 因為後面要搭配manjaro的設定檔,所以安裝位置固定
Updated 2026-11-27

直接 git clone 至已存在且非空的 /usr/share/ 會失敗，手動安裝須指定目標資料夾名稱：

sudo git clone --depth=1 https://github.com/romkatv/powerlevel10k.git /usr/share/zsh-theme-powerlevel10k

另須注意 romkatv/powerlevel10k 上游目前已進入有限度維護狀態，功能大致凍結但仍可正常使用。

gitstatus 安裝​

sudo git clone --depth=1 https://github.com/romkatv/gitstatus.git /usr/share/zsh-theme-powerlevel10k/
# 因為後面要搭配manjaro的設定檔,所以安裝位置固定
Updated 2026-11-27

若 /usr/share/zsh-theme-powerlevel10k/ 目錄已存在，須加上子目錄名稱 gitstatus（即 /usr/share/zsh-theme-powerlevel10k/gitstatus）；其實 powerlevel10k 預設亦會自動下載對應的 gitstatusd 二進位檔。

Manjaro-zsh-config 的設定檔​

因為沒有可直接安裝的套件，所以請用以下的腳本執行：

git clone https://github.com/Chrysostomus/manjaro-zsh-config
sudo cp -Rv manjaro-zsh-config/manjaro-zsh-prompt /usr/share/zsh/
sudo cp -Rv manjaro-zsh-config/zsh-maia-prompt /usr/share/zsh/
sudo cp -Rv manjaro-zsh-config/p10k.zsh /usr/share/zsh/
sudo cp -Rv manjaro-zsh-config/p10k-portable.zsh /usr/share/zsh/
sudo cp -Rv manjaro-zsh-config/command-not-found.zsh /usr/share/zsh/functions/
sudo cp -Rv manjaro-zsh-config/.zshrc /etc/zsh/zshrc-manjaro
sudo cp -r manjaro-zsh-config/base16-shell /usr/share/zsh/scripts/
sudo chmod a+x /usr/share/zsh/scripts/base16-shell/
Updated 2026-11-27

原 GitHub 倉庫 Chrysostomus/manjaro-zsh-config 已移轉／封存，建議改由 Manjaro 官方倉庫或 AUR 取得；此外在非 Arch 系統執行上述複製指令前，需先執行 sudo mkdir -p /usr/share/zsh/functions /usr/share/zsh/scripts /etc/zsh 建立目標目錄。

然後把 manjaro-zsh-config/.zshrc（或 /etc/zsh/zshrc-manjaro）複製為 ~/.zshrc 後重新執行 zsh 就好了。

Windows Terminal Nerd Fonts Display​

安裝 Nerd Fonts​

但是因為是 WSL，所以除了裡面的系統要安裝 Noto Nerd Font 以外，外面的 Windows 也是要安裝 Nerd Font，不然無法正確顯示。

Nerd Fonts 收集各種 Nerd Font 的網頁：

到 Download 內挑自己喜歡的版本下載。

我個人喜歡用 noto-nerd-font (Updated 2026-11-27: v3.1.1 為舊版連結，建議改至 Nerd Fonts 最新版本 Noto.zip 下載)

下載後請記得解開 Zip 檔後安裝字型。

設定 Windows Terminal 字型​

在設定內選擇你的 ArchWSL 選項然後選擇外觀：

將字型改成你下載的 Nerd Font 然後記得保存你的變更就好了。
