基礎設施架構白皮書 (Infrastructure Blueprint)

"Perfection is achieved, not when there is nothing more to add, but when there is nothing left to take away."
本基礎設施是一套歷經長期迭代、在極致能耗與硬體約束下打磨而成的微型私有雲系統。
其核心聚焦於邊界防禦純粹化、確定性網路拓撲、冷熱儲存分級與跨國混成雲互聯。

1. 架構核心原則 (Design Tenets)​

  • 預設阻斷與單向信任鏈 (Default-Deny & Asymmetric Trust)：嚴格劃分安全域，所有流量跨網段轉發均需狀態審查，核心服務與 IoT 網段絕對物理/邏輯隔離。
  • 核心級流量調度 (Kernel-Level Traffic Engineering)：引入主動式佇列管理（AQM），在邊界消除 Bufferbloat，確保控制面連線在任何突發負載下具備確定性的微秒級響應。
  • 資料與運算完全解耦 (Decoupled Compute & Storage)：運算節點維持輕量化與暫態化，資料依讀寫頻率與可靠度需求收斂至專屬的分級儲存池。
  • 零公網暴露面 (Zero Attack Surface)：外部管理通道全數收斂至加密專線，公網僅維持最低限度的反向代理與必要端點。

3. 系統分層設計 (Layer Specifications)​

3.1 邊界安全與流量調度 (Edge & Traffic Control)​

  • 狀態化防火牆：以 FreeBSD 核心級 Packet Filter (PF) 為邊界，建立嚴格的進出站狀態過濾機制。

  • 主動佇列管理 (CoDel)：透過多級優先佇列（Queue 70 至 Queue 10）實施流量工程，保障 TCP ACK、DNS 解析與加密隧道傳輸永遠具備零排隊優先權，並將大流量背景傳輸強制降階調度。

  • 多公網 IP SNAT 策略：針對家用網段、雲端運算網段及外部 IoT 流量分配獨立公網 IP 進行源地址轉換，徹底杜絕單一服務異常引發的全網連線信譽污染。

3.2 跨國混成雲骨幹 (Hybrid-Cloud Backbone)​

  • Mesh 專線互聯：與海外雲端運算實例（OCI）建立全天候 WireGuard 加密骨幹，打通跨地域私有子網。

  • 流量借道與出站隔離：特定高頻或非核心業務封裝於虛擬通道內，借道遠端節點出站，本機邊界對相關業務達成「零開孔、零暴露」。

3.3 儲存分級體系 (Tiered Storage Architecture)​

系統在底層以全 10GbE 骨幹與 MTU 9000 巨型訊框（Jumbo Frame）連結，將儲存池依 I/O 特性嚴格分級：

  • 長效媒體池 (Tier 1)：大容量 ZFS 儲存池，具備端到端資料校驗與自癒能力，服務高吞吐串流與重要冷資料。

  • 核心資料庫與備份池 (Tier 2)：承載微服務資料庫實例，並作為每日快照與備份槽。

  • 中轉快取池 (Tier 3)：採用無快取開銷的輕量檔案系統（UFS），專職吸收高頻下載與暫存讀寫，徹底隔離並保護主力 ZFS 儲存池免受 I/O 磨損。

3.4 運算與容器編排 (Compute & Microservices)​

  • 微服務邊界劃分：運算節點依安全層級拆分為基礎維運、公開服務與內部受限節點。公開節點透過 Traefik 統一進行 SNI 路由與安全憑證生命週期管理。

  • 現代化資料堆疊：核心資料庫採用 PostgreSQL 16 搭配高效能向量延伸模組，全面支撐次世代相簿感知與語意檢索等微服務。

  • 自動化維運閉環：透過宣告式 Compose 與排程器執行每日容器狀態打包與遠端備份，達成隨時可遷移的暫態架構。
