Bash / Shell ターミナルのカラーとテキストスタイル

参考資料​

FLOZz’ MISC の解説ページを参照しています。

1. 基本構文​

制御コードの基本形式は次のとおりです。

\e[<樣式/顏色代碼>m
  • \e[（または \033[、\x1b[）：CSI（Control Sequence Introducer）プレフィックス。
  • <コード>：スタイルコード。複数のコードはセミコロン ; で連結できます（例：\e[1;31;40m は太字＋赤文字＋黒背景を意味します）。
  • m：Select Graphic Rendition（SGR）の終端記号。
  • \e[0m：リセット制御コード。最後にリセットしないと、それ以降のターミナル全体の文字がその色のままになってしまいます。

基本的な使用例​

# 使用 echo (需加上 -e)
echo -e "\e[1;31m[ERROR]\e[0m 伺服器連線失敗"

# 更加推薦的 POSIX 標準寫法 (printf，免 -e 且各平台完全通用)
printf "\033[1;32m[SUCCESS]\033[0m 部署完成\n"

3. 応用：256 色と 24-bit True Color (RGB)​

iTerm2、Windows Terminal、Alacritty、Kitty などの最新ターミナルでは、より豊かな 256 色および RGB トゥルーカラーに対応しています。

  • 256 色モード：
    • 前景色：\e[38;5;<0-255>m
    • 背景色：\e[48;5;<0-255>m
    • 例：echo -e "\e[38;5;208m這是漂亮的橘色\e[0m"
  • 24-bit True Color (RGB)：
    • 前景色：\e[38;2;<R>;<G>;<B>m
    • 背景色：\e[48;2;<R>;<G>;<B>m
    • 例：echo -e "\e[38;2;255;100;0m自定義 RGB 珊瑚色\e[0m"

4. 実践テクニック：可読性の高いログ関数のラッパー (Script Boilerplate)​

Shell Script 内に難解な \e[31m を散在させるのは避けましょう。スクリプトの先頭で定数変数を統一的に定義するか、ヘルパー関数としてラップするのが業界標準のプラクティスです。

#!/bin/bash

# --- 定義色彩變數 ---
C_RESET="\033[0m"
C_BOLD="\033[1m"
C_RED="\033[1;31m"
C_GREEN="\033[1;32m"
C_YELLOW="\033[1;33m"
C_BLUE="\033[1;34m"
C_CYAN="\033[1;36m"

# --- 日誌函式 ---
log_info() {
    printf "${C_BLUE}[INFO]${C_RESET} %s\n" "$*"
}

log_success() {
    printf "${C_GREEN}[SUCCESS]${C_RESET} %s\n" "$*"
}

log_warn() {
    printf "${C_YELLOW}[WARN]${C_RESET} %s\n" "$*"
}

log_error() {
    printf "${C_RED}[ERROR]${C_RESET} %s\n" "$*" >&2
}

# --- 測試呼叫 ---
log_info "正在啟動 Docker Compose 服務..."
log_warn "記憶體剩餘不足 512MB"
log_success "Nextcloud 備份成功完成"
log_error "無法連接 MariaDB 資料庫"
