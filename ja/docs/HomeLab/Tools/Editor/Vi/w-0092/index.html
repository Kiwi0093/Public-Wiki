Vim ターミナル装飾と高度なコード折りたたみテクニック

ヒント

Linux をメインのコンソールとして使い始めてから、見栄えを気にして大量に Powerline を導入し始めました

本記事では従来から現代のコマンドライン環境まで使われる定番の Vim に焦点を当て、Powerline を使って見た目の優れたステータスラインを構築する方法と、Marker 折りたたみ機構および効率的なショートカットキーを組み合わせて、プレーンテキストエディタに視覚的な美しさと構造管理の両面で最高の体験をもたらす方法を解説します（注：Neovim と NvChad のモダンな Lua アーキテクチャについては別記事を参照してください）。

一、 事前準備：Powerline フォントとコアのインストール​

ステータスラインに特殊なアイコンや矢印を正しく描画させるには、ターミナルのフォントとパッケージを揃えておく必要があります。

1. Powerline 専用のパッチ済みフォント (Patched Fonts) をインストール​

  • Arch Linux / Manjaro：

    sudo pacman -S powerline-fonts ttf-jetbrains-mono-nerd

  • Debian / Ubuntu：

    sudo apt install fonts-powerline

  • FreeBSD：

    sudo pkg install powerline-fonts

(インストール後は、ターミナルエミュレータのフォント設定を JetBrainsMono Nerd Font など Powerline 対応フォントに切り替えるのを忘れないでください)

2. Vim と Powerline コアをインストール​

Arch Linux / Manjaro 環境を例にとると以下の通りです：

sudo pacman -S vim powerline python-powerline
Updated 2026-11-27

Arch Linux 公式リポジトリでは Vim 連携プラグインが vim-powerline（powerline-vim を提供）に分離されているため、sudo pacman -S vim powerline vim-powerline のインストールが推奨されます。vim-powerline をインストールすると Vim の runtime path へ自動的にマウントされるため、通常は set laststatus=2 を設定するだけで済み、手動で python3 ロードスクリプトを書く必要はありません。

二、 Powerline ステータスラインの装飾設定​

組み込み Python モジュール経由で動的なステータスラインを駆動します。

1. 設定ファイルの初期化​

システム同梱の Vim サンプル設定をホームディレクトリへコピーします：

cp /usr/share/vim/vim90/vimrc_example.vim ~/.vimrc

(注：実際の Vim バージョンによって、パス中の vim90 は vim91 などのバージョン番号になる場合があります)

2. Powerline 起動設定を追記​

エディタで ~/.vimrc を開き、末尾に以下の設定を追加します：

" Powerline ステータスライン装飾
set laststatus=2           " 下部ステータスラインを常時表示

" 組み込み Python 3 経由で Powerline フレームワークを読み込む
python3 from powerline.vim import setup as powerline_setup
python3 powerline_setup()
python3 del powerline_setup

三、 コード折りたたみ (Code Folding) と Marker 設定​

数百行にも及ぶコードを前にしたとき、Marker 記号と foldmethod を使えば、今見なくてよいロジックブロックをすっきり折りたたむことができます。

1. ~/.vimrc に折りたたみ設定を追記​

同じ ~/.vimrc ファイルに以下の折りたたみパラメータを追加します：

syntax on
set foldmarker={{{,}}}
set foldmethod=marker
set foldlevel=0          " デフォルトでは起動時にすべてのブロックを折りたたむ
let php_folding = 1      " PHP 構文向けの追加折りたたみサポート
set foldnestmax=3        " 入れ子の折りたたみ最大階層を 3 階層に制限

2. 実際の記述例​

設定後、コードのコメント内に {{{ と }}} を書くだけで折りたたみブロックを作成できます：

// データベース接続および初期化モジュール {{{
function init_connection() {
    // 実装の詳細...
}
// }}}

四、 折りたたみ操作の頻出ショートカット一覧 (Folding Commands)​

Vim で折りたたみ状態を操作する際によく使うショートカットキー：

ショートカットコマンド効果と説明
ziファイル全体の折りたたみ機能を 有効化 / 無効化
zo現在のカーソル位置にある折りたたみブロックを 開く (Open)
zc現在のカーソル位置にある折りたたみブロックを 閉じる (Close)
zO現在のカーソル位置より下の階層にある折りたたみブロックを 再帰的に開く
zC現在のカーソル位置より下の階層にある折りたたみブロックを 再帰的に閉じる
zmfoldlevel を 1 減らす（全体の折りたたみレベルを一段階締める）
zMfoldlevel を 0 に設定（すべてのブロックを強制的に折りたたむ）
zrfoldlevel を 1 増やす（全体の折りたたみレベルを一段階緩める）
zRfoldlevel を最大に設定（すべてのブロックを完全に展開する）
zx折りたたみ状態を更新（カーソル位置のブロック以外、ルールを再適用する）
zfビジュアルモード（Visual Mode）で範囲を選択し、開始・終了の折りたたみマーカーを動的に作成
