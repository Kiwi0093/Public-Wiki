Hexo ブログの基本設定（_config.yml）とデプロイメモ

Updated 2026-11-27

本記事はアーカイブ済みの Hexo 静的ブログ設定メモです（当サイトは現在 Docusaurus へ移行済みです）。以下は歴史的参考として当時の設定とトラブルシューティング記録を残したものです。

Hexo 本体の設定​

Hexo 本体の設定はすべて <folder>/_config.yml に記述されており、ほとんどの項目はデフォルトのまま流用できて非常に便利です。必要に応じて一部の項目のみ調整します。

詳細な Hexo Configuration

Site セクション​

# Site
title: Kiwi's Blog
subtitle: 中年大叔的自言自語
description: ''
keywords:
author: Kiwi 
language: zh_TW
timezone:
設定説明
titleサイトタイトル
subtitleサイトサブタイトル
descriptionサイトの説明
keywordsサイトのキーワード（複数指定に対応）
author著者名
languageサイトで使用する言語。2-letter ISO-639-1 code を参照。デフォルトは en
timezoneサイトのタイムゾーン。Hexo のデフォルトは使用中の PC のタイムゾーンです。タイムゾーン一覧から America/New_York、Japan、UTC などを指定できます

URL セクション​

サイトをサブディレクトリ（例：http://example.org/blog）に配置する場合は、url を http://example.org/blog に、root を /blog/ に設定してください。

# URL
url: https://kiwi0093.github.io/
root: /
permalink: :year/:month/:day/:title/
permalink_defaults:
pretty_urls:
  trailing_index: true
  trailing_html: true
設定説明デフォルト値
urlサイトの URL。http:// または https:// で始まる必要があります
rootサイトのルートディレクトリ
permalink記事のパーマリンク形式:year/:month/:day/:title/
permalink_defaultspermalink 内の各セグメントのデフォルト値
pretty_urlspermalink の値を書き換えて URL を整形します
pretty_urls.trailing_indexパーマリンク末尾に index.html を残すかどうか。false にすると除去されますtrue
pretty_urls.trailing_htmlパーマリンク末尾に .html を残すかどうか。false にすると除去されます（末尾の index.html には無効）true

Directory セクション​

# Directory
source_dir: source
public_dir: public
tag_dir: tags
archive_dir: archives
category_dir: categories
code_dir: downloads/code
i18n_dir: :lang
skip_render:
設定説明デフォルト値
source_dirソースフォルダ。コンテンツを格納するディレクトリsource
public_dir静的ファイルフォルダ。ビルド済みファイルを出力するディレクトリpublic
tag_dirタグディレクトリtags
archive_dirアーカイブディレクトリarchives
category_dirカテゴリディレクトリcategories
code_dirInclude code 用ディレクトリdownloads/code
i18n_dir国際化（i18n）ディレクトリ:lang
skip_renderレンダリングをスキップするファイルの指定。glob 式でパスをマッチできます

Writing セクション​

# Writing
new_post_name: :title.md
default_layout: post
titlecase: false
external_link:
  enable: true
  field: site
  exclude: ''
filename_case: 0
render_drafts: false
post_asset_folder: false
relative_link: false
future: true
highlight:
  enable: true
  line_number: true
  auto_detect: false
  tab_replace: ''
  wrap: true
  hljs: false
prismjs:
  enable: false
  preprocess: true
  line_number: true
  tab_replace: ''
設定説明デフォルト値
new_post_name新規記事のファイル名:title.md
default_layoutデフォルトレイアウトpost
auto_spacing欧文文字と和文・中文文字の間に空白を挿入するfalse
titlecaseタイトルを title case に変換するfalse
external_link外部リンクを新しいタブで開くtrue
external_link.enable新しいタブでリンクを開くtrue
external_link.fieldsite 全体または post のみに適用site
external_link.exclude除外するホスト名。必要に応じて www を含むサブドメインを指定[]
filename_caseファイル名の大文字・小文字変換：1 で小文字、2 で大文字0
render_drafts下書きを表示するfalse
post_asset_folderAsset フォルダを有効にするfalse
relative_linkリンクをルートディレクトリからの相対パスに変更するfalse
future未来の日付の記事を表示するtrue
highlightコードブロックの設定。使い方は Highlight.js セクションを参照
prismjsコードブロックの設定。使い方は PrismJS セクションを参照

Homepage セクション​

# Home page setting
# path: Root path for your blogs index page. (default = '')
# per_page: Posts displayed per page. (0 = disable pagination)
# order_by: Posts order. (Order by date descending by default)

  path: ''
  per_page: 10
  order_by: -date

tag_map:

Date & Time セクション​

# Date / Time format
## Hexo uses Moment.js to parse and display date
## You can customize the date format as defined in
## http://momentjs.com/docs/#/displaying/format/
date_format: YYYY-MM-DD
time_format: HH:mm:ss
## updated_option supports 'mtime', 'date', 'empty'
updated_option: 'mtime'

Pagination セクション​

# Pagination
per_page: 10
pagination_dir: page
設定説明デフォルト値
per_page1 ページあたりの表示記事数（0 = ページネーション無効）10
pagination_dirページネーション用ディレクトリpage

Include / Exclude セクション​

# Include / Exclude file(s)
## include:/exclude: options only apply to the 'source/' folder
include:
exclude:
ignore:
設定説明
includeHexo はデフォルトで隠しファイルや隠しフォルダを無視しますが、このフィールドに列挙したファイルは処理対象になります
excludeここに列挙したファイルは Hexo によって無視されます
ignore無視するファイル／フォルダ

Extension セクション​

# Extensions
## Plugins: https://hexo.io/plugins/
## Themes: https://hexo.io/themes/
theme: next

# Deployment
## Docs: https://hexo.io/docs/one-command-deployment
deploy:
  type: git
  repo: https://github.com/Kiwi0093/Kiwi0093.github.io
  branch: master
設定説明
theme使用するテーマ名。false にするとテーマ機能を無効化します
deployデプロイ設定

Update 2021-08-16​

GitHub のポリシー変更により HTTPS モードでのユーザー名／パスワード認証が直接使えなくなったため、deploy の設定を以下のように変更する必要があります：

# Deployment
## Docs: https://hexo.io/docs/one-command-deployment
deploy:
  type: git
  repo: https://<token>@github.com/Kiwi0093/Kiwi0093.github.io
  branch: master

この設定にすれば hexo d -g の際に username/password の入力が不要になりますが、この token が流出すると大きな問題になるため、最も簡単な対策としてはリポジトリ全体を private に変更しておくとリスクをある程度抑えられます。

Updated 2026-11-27

GitHub は HTTPS パスワード認証を全面廃止しており、Personal Access Token を _config.yml に平文で書き込む方法（https://<token>@github.com/...）にも認証情報漏洩のリスクがあります。現在では SSH デプロイキー（git@github.com:...）、OS の資格情報マネージャー、または GitHub Actions と組み込みの GITHUB_TOKEN を組み合わせて GitHub Pages へ自動デプロイする方法が推奨されます。

Hexo の使い方​

# ビルド済みデータを削除
hexo clean
# 静的ページを生成
hexo g
# ローカルサーバーを起動
hexo s
# サーバーへデプロイ
hexo d

Hexo 構築直後に手動で作成が必要なページ​

  • カテゴリ一覧ページを追加：hexo new page categories

  • タグ一覧ページを追加：hexo new page tags

    source/tags/index.md を編集します：

    ---
    type: "tags"
    ---

Hexo で別の config.yml を使用する方法​

# デフォルトの '_config.yml' の代わりにカスタムの 'custom.yml' を使用
$ hexo server --config custom.yml

# 複数の設定ファイルを使用し、競合時は 'custom2.json' を優先
$ hexo server --config custom.yml,custom2.json
