Hexo NexT テーマ設定とコメントシステム（アーカイブ）

Updated 2026-11-27

本サイトはすでに Hexo + NexT から Docusaurus アーキテクチャへ移行済みです。以下の内容（旧版 kiwi0093.github.io/Wiki-site/ リンク、hexo-next-darkmode プラグイン、および Disqus／DisqusJS 設定を含む）は歴史的記録の参考としてのみ残しています。

はじめに​

NexT テーマはデザインが非常に美しい Blog テーマ／スタイルで、インストールも非常に簡単です。npm で直接コマンドを実行するだけで導入できます。

インストール​

NexT Theme 公式サイトでは 2 通りのインストール方法が案内されています：

  • npm を使って直接インストール（Hexo 5.0 以上が必要）

    # Hexo ディレクトリ配下で実行
    npm install hexo-theme-next

    インストール後、Hexo ディレクトリの _config.yml 内の theme 項目を変更するだけですぐに利用できます：

    theme: next

  • Git コマンドでテーマ全体を Hexo の theme ディレクトリへ直接 clone する V8 以降は基本的に npm でインストールします

    # Hexo ディレクトリ配下で実行
    git clone https://github.com/next-theme/hexo-theme-next themes/next

    インストール後は同様に Hexo ディレクトリの _config.yml を変更します：

    theme: next

設定​

Theme Setting​

テーマ側の _config.yml を _config.[Theme_name].yml（例：_config.next.yml）としてコピーします。

詳細な説明は公式ドキュメントを参照してください。

基本的には以下の主要なパラメータをいくつか変更するだけで十分です：

Choosing Scheme​

# ---------------------------------------------------------------
# Scheme Settings
# ---------------------------------------------------------------

# Schemes
#scheme: Muse
scheme: Mist
#scheme: Pisces
#scheme: Gemini

# Dark Mode
darkmode: true

4 種類の scheme から選ぶことができ、公式サイトにサンプルが用意されています：Muse、Mist、Pisces、Gemini。好みのものを選んで設定を変更し有効化してください。

また、現在の NexT は公式でネイティブに Dark Mode をサポートしています。デフォルトは false なので、true に変更するとダークモードが有効になります。

Dark Mode の手動切り替え​

参考資料​

Clay の技術ブログ

設定方法​
プラグインのインストール​
$ npm install hexo-next-darkmode --save
設定​
#_config.next.yml
---------------------------------------------------------------------------------------------------------------------------------
# disable default Darkmode
darkmode: false
# add below

# Darkmode JS
# For more information: https://github.com/rqh656418510/hexo-next-darkmode, https://github.com/sandoche/Darkmode.js
darkmode_js:
  enable: true
  bottom: '64px' # default: '32px'
  right: 'unset' # default: '32px'
  left: '32px' # default: 'unset'
  time: '0.5s' # default: '0.3s'
  mixColor: 'transparent' # default: '#fff'
  backgroundColor: 'transparent' # default: '#fff'
  buttonColorDark: '#100f2c' # default: '#100f2c'
  buttonColorLight: '#fff' # default: '#fff'
  isActivated: false # default false
  saveInCookies: true # default: true
  label: '🌓' # default: ''
  autoMatchOsTheme: true # default: true
  libUrl: # Set custom library cdn url for Darkmode.js
  • isActivated: true：デフォルトで Dark Mode を使用します。saveInCookies: false、autoMatchOsTheme: false との併用をおすすめします。

Menu​

# ---------------------------------------------------------------
# Menu Settings
# ---------------------------------------------------------------

menu:
  home: / || fa fa-home
  #about: /about/ || fa fa-user
  tags: /tags/ || fa fa-tags
  categories: /categories/ || fa fa-th
  archives: /archives/ || fa fa-archive
  #schedule: /schedule/ || fa fa-calendar
  #sitemap: /sitemap.xml || fa fa-sitemap
  #commonweal: /404/ || fa fa-heartbeat
  wiki: https://kiwi0093.github.io/Wiki-site/ || fa fa-sitemap

# Enable / Disable menu icons / item badges.
menu_settings:
  icons: true
  badges: false

この部分を編集することで、Blog フレームワーク内のメニューを簡単に作成できます。公式ドキュメントでは、以下のように階層化された Menu の書き方も紹介されています：

menu:
  home: / || fa fa-home
  archives: /archives/ || fa fa-archive
  Docs:
    default: /docs/ || fa fa-book
    Getting Started:
      default: /getting-started/ || fa fa-flag
      Installation: /installation.html || fa fa-download
      Configuration: /configuration.html || fa fa-wrench
    Third Party Services:
      default: /third-party-services/ || fa fa-puzzle-piece
      Math Equations: /math-equations.html || fa fa-square-root-alt
      Comment Systems: /comments.html || fa fa-comment-alt

その他の細かな設定については公式ドキュメントを参照してください。

当時の構成では必ず以下を追加する必要がありました：

wiki: https://kiwi0093.github.io/Wiki-site/ || fa fa-sitemap

これにより Wiki へのリンクが生成されます。

Disqus アカウントの申請​

これは公式サイトから申請するだけでOKです。申請後は忘れずに API の設定も済ませておきます（DisqusJS Github の手順を参照）

設定ファイル​

#_config.next.yml
---------------------------------------------------------------------------------------------------------------------------------
# Disqus
disqus:
  enable: true
  shortname: ${your_shortname}
  count: true

# DisqusJS
# Alternative Disqus - Render comment component using Disqus API.
# Demo: https://suka.js.org/DisqusJS/
# For more information: https://github.com/SukkaW/DisqusJS
disqusjs:
  enable: true
  # API Endpoint of Disqus API (https://disqus.com/api/).
  # Leave api empty if you are able to connect to Disqus API. Otherwise you need a reverse proxy for it.
  # For example:
  # api: https://disqus.skk.moe/disqus/
  api:
  apikey: ${Your_API_KEY} # Register new application from https://disqus.com/api/applications/
  shortname: ${your_shortname} # See: https://disqus.com/admin/settings/general/
設定できたら hexo clean、hexo d -g を実行するだけです
