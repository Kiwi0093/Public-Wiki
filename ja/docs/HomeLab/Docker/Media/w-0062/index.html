Calibre-Web によるプライベート電子書籍ライブラリ構築とクロスデバイス読書管理

1. アーキテクチャの核心概念とハマりポイント対策​

1.1 ライブラリ構造と metadata.db への必須依存​

  • Calibre-Web は 何もない状態から新規ライブラリを単独で作成することはできません。必ず すでに metadata.db を含む Calibre ライブラリディレクトリ をマウントする必要があります。
  • 初回構築時に指定したディレクトリが空の場合、システムはエラーを返して初期化を拒否します。あらかじめデスクトップ版の Calibre でライブラリを作成しておくか、空でも有効な状態の metadata.db を配置しておく必要があります。

1.2 ストレージ分離の鉄則：ローカル SSD vs. NAS ネットワークマウント​

Navidrome や Nextcloud の運用経験と同様、ネットワークファイルシステム上での SQLite データベース運用には重大な落とし穴があります。

  • ライブラリ本体ディレクトリ (/books)： 書籍本体（EPUB、MOBI、PDF、表紙画像）を保存する領域であり、NAS へのマウントを強く推奨します（SMB/CIFS または高パフォーマンスな NFS に対応）。
  • 設定ファイルおよびアプリデータベース (/config)： Calibre-Web 自身のユーザー権限、読書進捗、ブックマーク用データベース（app.db）が含まれます。高頻度のロック競合による SQLite 破損を防ぐため、CIFS/NFS ネットワークドライブには絶対に置かず、必ずホストマシンのローカル SSD に配置してください。

1.3 USE_CONFIG_DIR=true の役割​

LinuxServer.io 版の Calibre-Web イメージにおいて USE_CONFIG_DIR=true を指定すると、Calibre-Web 自身のシステムデータベース app.db が強制的に /config 内に保存され、/books 内の Calibre ライブラリ metadata.db と物理的に分離されます。これにより、マルチユーザー運用やバックアップ管理がより安全になります。

2. 事前準備：Photon OS での NAS ライブラリマウント (CIFS vs. NFS)​

案 A：CIFS / SMB マウントを使用​

NAS 側がネイティブで Windows ACL 寄り、または ID／パスワード認証でアクセスする場合：

# 1. 確保已安裝 cifs-utils
tdnf -y install cifs-utils

# 2. 建立掛載點
sudo mkdir -p /mnt/nas/books

# 3. 編輯 /etc/fstab 自動掛載
# //192.168.1.50/Books /mnt/nas/books cifs credentials=/root/.smbcredentials/nas,uid=1000,gid=1000,rw,iocharset=utf8,_netdev,nofail 0 0

案 B：NFSv4.1 マウントを使用（推奨・高パフォーマンス）​

NAS 側で NFS エクスポートと許可 IP ホワイトリストを設定し、Photon OS 側でマウントします。

# 1. 安裝 NFS 工具
tdnf -y install nfs-utils
systemctl enable --now rpcbind

# 2. 建立掛載點
sudo mkdir -p /mnt/nas/books

# 3. 編輯 /etc/fstab
# 192.168.1.50:/volume1/Books /mnt/nas/books nfs nfsvers=4.1,rw,_netdev,nofail,hard,intr,rsize=1048576,wsize=1048576 0 0

# 4. 測試掛載
sudo mount -a
ls -la /mnt/nas/books

(注意：Web インターフェースから書籍のアップロードやメタデータ編集を行いたい場合は、マウント権限が読み書き可能な rw である必要があります。)

Updated 2026-11-27

現在の Linux カーネル（2.6.25 以降）では NFS マウントオプションの intr は非推奨となり無視されるため、通常の設定ではこのオプションを省略し、hard のみを残せば問題ありません。

3. Docker Compose 完全デプロイ設定（Traefik v3 統合）​

この構成では /config をローカル SSD（/opt/calibre-web/config）に保持し、書籍ライブラリは NAS の /mnt/nas/books をマウントした上で、Traefik に SSL 終端を任せています。

ステップ 1：ローカル専用ディレクトリの作成と権限設定​

sudo mkdir -p /opt/calibre-web/config
sudo chown -R 1000:1000 /opt/calibre-web/config

ステップ 2：docker-compose.yml の設定​

services:
  calibre-web:
    image: lscr.io/linuxserver/calibre-web:latest
    container_name: calibre-web
    restart: unless-stopped
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=Asia/Taipei
      # 關鍵：將 app.db 隔離儲存在 /config 內
      - USE_CONFIG_DIR=true
      # 預先指定轉檔工具目錄（若有安裝 kepubify 或 Calibre 轉換二進位檔）
      - DOCKER_MODS=linuxserver/mods:universal-calibre # 可選：啟用後端格式轉檔支援
    volumes:
      - /opt/calibre-web/config:/config
      - /mnt/nas/books:/books
    networks:
      - proxy-network
    labels:
      - "traefik.enable=true"
      - "traefik.http.routers.calibre-web.rule=Host(`books.example.com`)"
      - "traefik.http.routers.calibre-web.entrypoints=websecure"
      - "traefik.http.routers.calibre-web.tls=true"
      - "traefik.http.routers.calibre-web.tls.certresolver=myresolver"
      # 轉發至容器內部的 8083 連接埠
      - "traefik.http.services.calibre-web.loadbalancer.server.port=8083"

networks:
  proxy-network:
    external: true

サービスを起動します。

docker compose up -d

4. Nginx / Nginx Proxy Manager（サブパスとサブドメイン設定）​

4.1 案 A：サブパスリバースプロキシ (/book)​

Calibre-Web をサブパス配下に配置する必要がある場合、Nginx は X-Script-Name ヘッダーを付与する必要があります（パスの末尾にスラッシュを付けないよう注意してください）。

location /book {
    proxy_pass http://calibre-web:8083;
    proxy_set_header Host $http_host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Scheme $scheme;
    # 核心：通知後端應用子路徑基底
    proxy_set_header X-Script-Name /book;
    
    # 支援大容量電子書（如掃描版 PDF/漫畫）上傳
    client_max_body_size 500M;
}

4.2 案 B：独立サブドメイン (books.example.com)​

NPM で新しい Proxy Host を追加します。

  • Forward Hostname / IP：calibre-web
  • Forward Port：8083
  • Websockets Support と Block Common Exploits にチェックを入れます。
  • Advanced タブに client_max_body_size 500M; を追記し、大容量ファイルのアップロードがブロックされないようにします。

5. 初回初期化と主要機能の設定​

  1. ブラウザで https://books.example.com を開きます。
  2. デフォルトの最高権限アカウント・パスワード：
    • ユーザー名：admin
    • パスワード：admin123
  3. ライブラリパスの指定：

    • 初回セットアップ画面に進み、Location of Calibre database 欄に以下を入力します。

      /books

    • Save をクリックします。システムが自動的に /books/metadata.db の存在を検証します。

  4. セキュリティ変更：
    • すぐに右上の admin をクリックし、パスワードを変更してメールアドレスを紐づけます。

5.1 「Web アップロード」と「形式変換」機能の有効化​

デフォルト状態では、Calibre-Web は閲覧とダウンロードのみ許可されています。Web インターフェースから直接電子書籍をアップロードしたい場合は以下を設定します。

  1. admin でログイン → Admin → Edit Basic Configuration へ進みます。
  2. Feature Configuration を展開します。
    • Enable Uploads にチェックを入れます（アップロードボタンを有効化）。
    • Enable Anonymous Browsing にチェックを入れます（ログインなしのゲスト閲覧を許可するかどうか、要件に応じて選択）。
  3. Edit User へ進み → 対象ユーザーを編集 → Upload allowed にチェックを入れます。

6. クロスデバイス読書と OPDS ライブラリ直接接続​

Calibre-Web は強力な OPDS (Open Publication Distribution System) プロトコルを内蔵しており、タブレットや電子書籍リーダーからブラウザでダウンロードすることなく、アプリ内で直接ライブラリを閲覧しワンタップでダウンロードして読むことができます。

6.1 OPDS 接続 URL​

  • グローバル OPDS URL： https://books.example.com/opds
  • サブパスを使用している場合： https://example.com/book/opds

6.2 各プラットフォーム向け推奨リーダーアプリ​

プラットフォーム / デバイス推奨リーダーソフト主な特徴と接続方法
Android / 汎用 E-Ink 端末 (BOOX / Moaan など)KOReader（第一推奨） / Moon+ ReaderOPDS 直接接続、カスタムレイアウト、自動余白カットに対応し、EPUB/PDF の読書体験が最も優れています。ライブラリ管理から OPDS を追加し、URL と認証情報を入力します。
iOS / iPadOSKyBook 3 / Marvin / YomuOPDS カタログ同期機能を内蔵し、緻密な組版やクラウドフォントに対応しています。
Kindle（クローズド端末）Send-to-Kindle（メール配信）Calibre-Web で SMTP とユーザーの @kindle.com メールアドレスを設定し、書籍横の「Send to Kindle」をクリックするだけでワンクリック送信できます。
Windows / macOSCalibre デスクトップ版 / Web 内蔵リーダー高度なメタデータ編集、レイアウト修正、バックアップ作業に適しています。

Kindle 配信の重要ポイント：

  1. Amazon 公式は .mobi 形式での配信を完全に廃止しており、現在の Send to Kindle は .epub 形式が標準となっています。
  2. Calibre-Web では 1 つのユーザーアカウントにつき 1 つの Kindle 受信メールアドレスしか紐づけられません。手元に 2 台以上の Kindle（例：Oasis と Paperwhite）がある場合は、管理画面で 2 つの独立したアカウントを作成し、それぞれに異なる @kindle.com アドレスを紐づける必要があります。

7. メンテナンスとデータバックアップ​

ストレージ分離アーキテクチャのおかげで、バックアップは非常にシンプルです。

# 1. 備份 Calibre-Web 系統設定與使用者進度 (SSD 本機端)
sudo tar -czvf /opt/backups/calibre-web-config-$(date +%F).tar.gz -C /opt/calibre-web config

# 2. 書庫本體 (/books)
# 書籍本體與 metadata.db 已在 NAS 上，直接納入 NAS 本身的快照 (Snapshot) 或 Hyper Backup 排程即可。

# 還原方式
sudo tar -xzvf /opt/backups/calibre-web-config-*.tar.gz -C /opt/calibre-web/
docker compose restart calibre-web
