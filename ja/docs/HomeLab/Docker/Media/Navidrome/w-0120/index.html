4. なぜ Ultrasonic で問題が起きやすいのか？Subsonic 認証メカニズムの解説​

多くのユーザーが Ultrasonic などの古いクライアントで接続した際、401 Unauthorized エラーや繰り返しのパスワード入力要求に直面します：

  • 主な原因（平文トークン vs. MD5 Salt ハッシュ）：

    • 初期の Subsonic API はパスワードを直接送信するか、時代遅れの SHA1 認証 (Updated 2026-11-27: 初期の Subsonic API は平文の p= または簡易的な Hex エンコード p=enc:... でパスワードを送信しており、SHA1 ではありませんでした) を採用していましたが、現代の Subsonic / OpenSubsonic API 仕様では Token + Salt（token=md5(password+salt)）方式が要求されます。

    • Ultrasonic プロジェクトはメンテナンス頻度が低く、OpenSubsonic 拡張仕様や特定の URL エスケープ（Escaping）処理に互換性の問題があるため、Navidrome へ送信される認証ヘッダーが期待通りに機能しないことがあります。

  • トラブルシューティング方法：

    • クライアントの接続設定から 「Token 認証を使用 (Use Token Authentication)」 を探してチェックを入れるか、Subsonic API 1.16+ を強制指定してください。

    • 近年コミュニティでより活発にメンテナンスされている最新のクライアントを選ぶことを推奨します。

6. 音楽ライブラリのタグ付け (Tagging)、Lidarr 自動管理と歌詞ダウンロード整理​

Navidrome は ID3 音声タグに強く依存する サーバーであり、内部的にはフォルダ構造による分類ではなく音声メタデータを直接読み取ります。Lidarr 自体には歌詞取得モジュールが組み込まれていませんが、Lidarr 自動化フック (Custom Script) または 独立した Sidecar コンテナ を組み合わせることで、「ダウンロード -> 自動タグ修正 -> 同期動的歌詞 (.lrc) 自動取得 -> Navidrome スキャン即時トリガー」という完全な自動化サイクルを構築できます。

6.1 Lidarr バックエンド自動標準化設定 (手動タグ編集の代替)​

Lidarr は MusicBrainz データベースと連携しており、音楽のインポート時に標準化されたタグ付けとファイル名変更を自動で完了できます：

  1. 音声ファイルへのタグ書き込みを有効化 (Media Management)：

    • Lidarr の Settings -> Media Management へ進みます。

    • Write Audio Tags にチェックを入れ、Sync または Scrub and Sync に設定します。

    • 重要チェック項目：Write Embedded Cover Art（高画質カバーアートをファイルに埋め込む）と Save Artwork to Album Folder（folder.jpg / cover.jpg を生成し、Navidrome がサムネイルキャッシュとして優先的に読み込むようにする）にチェックを入れます。

  2. 標準化されたリネーム構造 (Naming)：

    • Rename Tracks をオンにします。

    • Artist Folder Format：{Artist CleanName}

    • Album Folder Format：{Artist CleanName} - {Release Year} - {Album CleanTitle}

    • Track File Format：{Track:00} - {Track CleanTitle}

6.2 動的歌詞の自動取得と整理プラン (2 大主流手法)​

手法 A：Lidarr 連携 Custom Script (最もスマート：インポート時に全自動トリガー)​

コミュニティのオープンソースツール（synclyr2metadata など）は単一の静的バイナリとしてビルドできるため、Lidarr コンテナにシームレスに組み込めます：

  1. ツールの配置： ビルド済みの静的実行ファイルを Lidarr のマウントディレクトリ（例：/opt/appdata/lidarr/scripts/synclyr2metadata）に配置します。

    chmod +x /opt/appdata/lidarr/scripts/synclyr2metadata

  2. Lidarr でカスタムスクリプトを設定：

    • Lidarr の Settings -> Connect -> + をクリックして Custom Script を追加します。

    • Name：Auto Sync Lyrics

    • Triggers：On Release Import と On Upgrade にチェックを入れます。

    • Path：コンテナ内部のパス /config/scripts/synclyr2metadata を入力します。

  3. 動作メカニズム： Lidarr が新しいアルバムをダウンロードして整理するたびに、スクリプトが自動的にその曲の Artist/Title/Duration を用いて現在最大のオープン歌詞データベース LRCLIB へ同期歌詞を問い合わせ、音声ファイルの埋め込み LYRICS / SYLT タグに直接書き込みます（または同名の .lrc を出力します）。

手法 B：独立した歌詞取得コンテナのデプロイ (LRCGET-CLI / LyricFlow)​

Lidarr 内部にスクリプトを置きたくない場合は、Docker Compose に専用の歌詞取得 Sidecar サービス（LRCLIB 公式ベースの lrcget-cli など）をマウントできます：

docker-compose.yml に以下を追加します：

  lrcget:
    image: diegoninja/lrcget-cli:latest
    container_name: lrcget-cli
    restart: unless-stopped
    environment:
      - TZ=Asia/Taipei
    volumes:
      - /mnt/nas/music:/music:rw  # .lrc 歌詞ファイルを保存するため書き込み権限が必要
    # 定時 scan スケジュールの設定も可能

これにより /music ディレクトリ配下の新しい音声ファイルを自動監視し、同じディレクトリに同名の Song.lrc スクロール歌詞ファイルを自動生成します。

6.3 閉ループ自動化：Lidarr ダウンロード完了時に Navidrome の更新を自動通知​

Navidrome はデフォルトで ND_SCANSCHEDULE に従って定期スキャン（例：1 時間ごと）を行いますが、Lidarr の Webhook 連携を使うことで、新しいアルバムのダウンロード・整理完了と同時に Navidrome の部分スキャンを即座にトリガー できます：

  1. Lidarr の Settings -> Connect -> + をクリックして Webhook を追加します。

  2. URL：

    http://navidrome:4533/rest/startScan?u=<admin_user>&t=<token>&s=<salt>&v=1.16.1&c=Lidarr

  3. Triggers：On Download と On Upgrade にチェックを入れます。(Token と Salt の生成方法は Subsonic API 標準に従います：token=md5(password+salt))。

6.4 過去のレガシーファイル補完ツール (MusicBrainz Picard)​

Lidarr の監視対象外にある古いローカルコレクションや珍しい自己録音ファイルについては、NAS に投入する前に MusicBrainz Picard を使用して手動で整理し、標準的な Title、Artist、Album Artist、Track Number、Date フィールドを整えてからアーカイブすることをおすすめします。

7. メンテナンスとデータバックアップ​

/music（NAS リモートライブラリ）と /data（ローカル SSD）を分離しておけば、データバックアップはローカルの軽量ディレクトリのみを対象とするだけで済みます：

# Navidrome データベースと再生履歴のバックアップ
sudo tar -czvf /opt/backups/navidrome-$(date +%F).tar.gz -C /opt/navidrome data

# リストア方法
sudo tar -xzvf /opt/backups/navidrome-*.tar.gz -C /opt/navidrome/
sudo chown -R 1000:1000 /opt/navidrome/data
docker compose restart navidrome
