FreeBSD SNMP（bsnmpd）と Checkmk Agent 監視設定

備考

LibreNMS で監視するには SNMP が必要ですが、補助として check_mk_agent も利用できます​

ただし現在はもう LibreNMS を使っていないので、また気が向いて使いたくなったときに導入するかもしれません

参考資料​

柯仓无居所 (Updated 2026-11-27: 元の Leanote 外部リンクは多くがリンク切れとなっているため、履歴参考としてのみ残しています)

bsnmp​

FreeBSD には標準で bsnmp が組み込まれています

  1. vi /etc/rc.conf
# /etc/rc.conf
--------------------------------------------------------------------------------------------------------------------------------
bsnmpd_enable="YES"
  1. pkg install bsnmp-ucd
  2. vi /etc/snmpd.conf
# /etc/snmpd.conf 加上以下內容
--------------------------------------------------------------------------------------------------------------------------------
begemotSnmpdModulePath."ucd" = "/usr/local/lib/snmp_ucd.so"
%ucd
updateInterval = 500
extCheckInterval = 100
extUpdateInterval = 3000
extTimeout = 60

memMinimumSwap = 1600
memSwapErrorMsg = "No free swap!"

laConfig.1 = "6.0"
laConfig.2 = "5.0"
laConfig.3 = "4.0"

laErrMessage.1 = "1min load average is high!"
laErrMessage.2 = "5min load average is high!"
laErrMessage.3 = "15min load average is high!"

# Process table

prNames.0 = "httpd"
prMin.0 = 3
prMax.0 = 100

prErrFix.0 = 1
prErrFixCmd.0 = "/usr/local/etc/rc.d/apache22 restart"

# Extension commands (extTable)

extNames.0 = "uname"
extCommand.0 = "/usr/bin/uname -a"

extNames.1 = "uptime"
extCommand.1 = "/usr/bin/uptime"

# example of extension with fix command
extNames.2 = "apache"
extCommand.2 = "/usr/local/etc/rc.d/apache status"
extErrFix.2 = 1
extErrFixCmd.2 = "/usr/local/etc/rc.d/apache restart"
  1. /etc/rc.d/bsnmpd restart
  2. bsnmpwalk -v 2c -c public

データが取得できていれば OK です

Updated 2026-11-27
  1. 例中の apache22 はすでに FreeBSD Ports から退役しています（現在のバージョンは apache24 です）。
  2. 近年の FreeBSD では /etc/rc.d/bsnmpd restart を直接実行する代わりに service bsnmpd restart の使用が推奨されます。
  3. FreeBSD 組み込みの bsnmpwalk(1) は net-snmp の -c オプションに対応しておらず、コミュニティ名と対象ホストの指定には -s を使用する必要があります：bsnmpwalk -v 2c -s public@localhost（デフォルトが v2c のため bsnmpwalk -s public@localhost と省略も可能です）。

check_mk_agent​

事前インストールが必要なパッケージ​

pkg install bash ipmitool libstatgrab git

check_mk_agent の実行には bash が必要なため、bash がないと動作しません

インストールとセットアップ​

  1. check_mk_agent の取得と実行権限の付与
git clone https://github.com/librenms/librenms-agent.git
cp librenms-agent/check_mk_agent_freebsd /usr/local/bin/check_mk_agent
chmod +x /usr/local/bin/check_mk_agent

上記の方法はもう古いです..というのも、現在は ports 内にすでに収録されているからです

/usr/ports/net-mgmt/check_mk_agent/

cd /usr/ports/net-mgmt/check_mk_agent/
make install clean
Updated 2026-11-27

Ports からのコンパイル以外にも、近年の FreeBSD ではバイナリパッケージを直接インストールできます：pkg install check_mk_agent（bash や libstatgrab などの依存パッケージも自動でインストールされます）。

  1. vi /etc/services
# /etc/services
--------------------------------------------------------------------------------------------------------------------------------
check_mk        6556/tcp   #check_mk agent

これは追記する設定です

  1. vi /etc/inetd.conf
#/etc/inetd.conf
--------------------------------------------------------------------------------------------------------------------------------
check_mk  stream  tcp nowait  root  /usr/local/bin/check_mk_agent check_mk_agent

これも追記する設定です

  1. vi /etc/rc.conf
#/etc/rc.conf
--------------------------------------------------------------------------------------------------------------------------------
inetd_enable=yes
inetd_flags=-wW

これも追記する設定です

  1. vi /etc/hosts.allow
#/etc/hosts.allow
--------------------------------------------------------------------------------------------------------------------------------
# Allow nagios server to access us
check_mk_agent : 192.168.56.3 : allow
check_mk_agent : ALL : deny

これも追記します

  1. /etc/rc.d/inetd start
  2. telnet で動作確認
telnet bsdhost 6556
<<<check_mk>>>
Version: 1.1.13i1
AgentOS: freebsd

これで完了です

Updated 2026-11-27

/etc/rc.conf の標準的な記述としてはダブルクォートを付けること（inetd_enable="YES"、inetd_flags="-wW"）が推奨され、サービスの起動には service inetd start の使用が推奨されます。また、ポートの疎通確認には telnet の代わりに nc bsdhost 6556 を使用できます。

まとめ​

あまり inetd を開けて動かしたくはないのですが、これらのマシンとポートは基本的にファイアウォールで接続元をしっかり制限しており、さらに LibreNMS も内部に構築しているため、そこまで大きな問題にはならないはずです

ひとまずこの構成でも運用は可能です
