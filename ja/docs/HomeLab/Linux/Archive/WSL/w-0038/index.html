ArchWSL と WSLg の初期環境構築およびよくある問題のアーカイブメモ

ヒント

現在 WSLg は基本的に WSL のインストールに標準で組み込まれているため、わざわざ GWSL を入れて設定する必要はなくなりました。 忘れないように ArchWSL まわりの設定もあわせてメモしておきます。

Updated 2026-11-27

本記事は初期のサードパーティ製 yuk7/ArchWSL に関するアーカイブメモです。現在、Microsoft と Arch Linux は公式の WSL イメージを提供しています（wsl --install archlinux でインストール可能）。

Basic Setting​

GUI を使う予定がない場合は、基本的にこの部分だけ設定すれば十分です：

Archlinux-keyring​

# keyring を初期化
sudo pacman-key --init
# keyring を登録
sudo pacman-key --populate
# 適用および更新（mirrorlist を調整したい場合は先に /etc/pacman.d/mirrorlist を編集）
sudo pacman -Syu

この手順は ArchWSL において必須です。正しい keyring がないと何もインストールできません。

/etc/wsl.conf​

# systemd を使用
[boot]
systemd=true
# デフォルトユーザーを設定
[users]
default=<username>
Updated 2026-11-27

上記設定ファイル内の [users] は誤ったセクション名であり、WSL に無視されます。正しい記述は単数形の [user] です：

[user]
default=<username>

yay​

# 事前に go, git, base-devel のインストールが必要
cd <what ever you like>
git clone https://aur.archlinux.org/yay.git
cd yay
makepkg -si

yay は現在 AUR をインストールする上で最も便利なツールなので、強くインストールをおすすめします。

GUI (WSLg)​

X server​

参考資料：

  • Bug of WSL Preview - Empty /mnt/wslg/.X11-unix & /tmp/.X11-unix Directory
# Display が :0 であることを確認
echo $DISPLAY
:0

# /mnt/wslg/.X11-unix が存在するか、および /tmp/.X11-unix -> /mnt/wslg/.X11-unix になっているか確認
ls -la /mnt/wslg
ls -la /tmp

# /mnt/wslg/.X11-unix は存在するが /tmp/.X11-unix へリンクされていない場合
sudo rm -r /tmp/.X11-unix
ln -s /mnt/wslg/.X11-unix /tmp/.X11-unix

その後、GUI ソフトが正常に起動するかテストします。起動できれば次のステップへ進みます。起動できない場合は……ドキュメントを調べてください……。

/etc/tmpfiles.d/wslg.conf
---

# TYPE    PATH        Mode    UID    GID Age    Argument
L+    /tmp/.X11-unix    -        -    -    -    /mnt/wslg/.X11unix
Updated 2026-11-27
  1. 手動でシンボリックリンクを作成する際は sudo を付ける必要があります（sudo ln -s /mnt/wslg/.X11-unix /tmp/.X11-unix）。
  2. 上記 wslg.conf の最後の列にあるターゲットパスはドットが 1 つ抜けており、正しくは /mnt/wslg/.X11-unix です（.X11unix ではありません）。また、ファイル内容には先頭のファイル名と --- を含めないでください。
  3. 新しいバージョンの WSL / WSLg では systemd 起動時に /tmp/.X11-unix がクリーンアップされる問題が修正されているため、通常はこの設定ファイルを手動で作成する必要はありません。

PowerShell で wsl --shutdown を実行してから、再度 WSL に入れば完了です。

dolphin + breeze (Optional)​

Dolphin は KDE のファイルマネージャー（Windows のエクスプローラーに相当）です。Dolphin だけを入れるとアイコンが欠ける問題が発生するため、KDE のテーマ breeze もあわせてインストールすると正常に表示されます：

yay -S breeze dolphin

Remmina + freerdp (Optional)​

とても使いやすい RDP クライアントですが、Remmina 自体はフロントエンド UI にすぎないため、他の RDP サーバーに接続するには freerdp もインストールする必要があります：

yay -S remmina freerdp

Brave (Optional)​

ブラウザがないと……何のために GUI を入れたのかわからないので：

yay -S brave-bin

Fcitx (Optional)​

基本的に WSL 内には完全なデスクトップ環境をインストールしないため、Fcitx を選ぶ際は Fcitx4 系しか使えません。下手に知ったかぶりをして Fcitx5 を入れないように…… (Updated 2026-11-27: Fcitx 4 はすでにメンテナンスが終了し、多くのディストリビューションのリポジトリから削除されました。現在の WSLg 環境では Fcitx 5 を問題なく利用できます。) 詳細な内容は別の wiki に記載しているので、そちらを参照してください (Updated 2026-11-27: 中国語／日本語入力メソッド設定)
