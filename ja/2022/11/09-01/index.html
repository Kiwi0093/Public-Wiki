最近少し時間を作って基礎的なものをいろいろ見直したり調べたりしていたのですが……まさか vim にこんなに素晴らしい後継者がいたとは思いませんでした。

NeoVim というフォークは多種多様なプラグインや機能に対応していて、他の人が作ってくれた NvChad と組み合わせるだけでもう本当に最高です。

NeoVim + NvChad

Neovim​

Official Neovim Website

これ自体は実際のところ Vim とほとんど変わりませんが、lua の設定ファイルに対応しており、数多くのプラグインをサポートしている点が異なります。

ただ、これだけたくさんの新しい機能に対応しているというだけでも、長年使ってきた vim から乗り換える価値は十分にあります。

NvChad​

NvChad · Neovim with lua is cool

正直なところ、これは本当にヤバいくらいすごいです……。

Lua の構文を使って Neovim がサポートする Vim プラグインを基本的な形で記述するだけで、もはや別のエディタのような見た目と使い勝手を実現してくれます（そう、基本的には VS Code のような見た目に仕上げることができます）。

自分でカスタマイズすれば、Markdown エディタの代わりにすら使えます……（しかも picgo 用のプラグインまで見かけました……画像ホスティングへのアップロード機能まで揃っているなら、もう他のエディタなんて要らないのでは……）。

カスタマイズ​

正直、カスタマイズするには多少の知識が必要になります。

  • Lua の構文

  • Vim プラグインの導入と設定方法

基本的には、NvChad が用意してくれているフレームワークの下で override 機能を使っていくつかの定義を差し替える形になります……（もちろんリポジトリを fork してゼロから作り直すこともできますが……）。

今のところ私が独自にカスタマイズしているのは Key mapping の部分だけですが（元の機能だと少し物足りなかったので）、今後はこれを Ansible に組み込んで自分のすべてのクライアント環境に適用していく予定です。
