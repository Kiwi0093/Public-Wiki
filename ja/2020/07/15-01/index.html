備考

本記事は旧サイトからの転載アーカイブです。

長年パソコンを使っていると、使用しているソフトウェアも時代の変化とともに少しずつ変わっていきます。これまで Manjaro のインストールや使い方、Gaming 関連の記事などを書いてきましたが、このあたりで一度、今の時点から使い始めたものや何年使っても飽きない定番ソフト、そして普段の習慣的な設定方法などをまとめたごった煮統合記事を書いて記録に残しておこうと思いました。興味がある方の参考になれば幸いです。

基本方針

今年からおじさんも少しずつマルチプラットフォーム環境（主に Windows / Linux のデスクトップ）に慣れてきたため、ソフトウェアを選ぶ際もできるだけ以下の特徴を満たすものを選ぶようにしています。

  • Freeware または Open-Source のソフトウェアであること
  • マルチプラットフォームに対応していること
  • 環境間で相互に sync でき、プラットフォームや端末を変えても作業を途切れなく続けられること
  • ネットワークに依存せずオフラインでも操作できること

これらの条件は、要するに海賊版ソフトの使用をできるだけ避け、Web app（大量の Chrome 拡張機能など）への依存を減らすためのものです。

Markdown Editor​

Typora - Windows & Linux​

  • Windows
#Powershell as Administrator with Chocolatey
choco upgrade typora -y
  • Linux(Manjaro)
#None root account & yay installed
yay -S typora

これは一度使うと手放せなくなる超優秀なエディタです。おじさんが別の記事 *(Updated 2026-11-27: 別の記事)*でも触れたとおり、GitHub を画像ホスティング先として連携し、画像を自動アップロードすることもできます。Hot-key に慣れてしまえばブログ執筆の作業効率が格段に上がるため、とてもおすすめの Markdown Editor です。

ついでにメモしておくと、Markdown 内に YouTube 動画を埋め込みたい場合はこちらの方法を使います。

基本語法
[![alt text](http://example.com/exampl.png)](http://example.com/link "title")

封面的圖
http://img.youtube.com/vi/{video-id}/0.jpg

所以範例就是
[![Audi R8](http://img.youtube.com/vi/KOxbO0EI4MA/0.jpg)](https://www.youtube.com/watch?v=KOxbO0EI4MA "Audi R8")

ここで KOxbO0EI4MA の部分が Video-id であり、動画の URL から確認できます。ただしプレイリストにはサムネイル画像がありません。

Player - Audio​

foobar2000 - Windows​

  • Windows
#Powershell as Administrator with Chocolatey
choco upgrade foobar2000 -y

ただ、このソフトについてはインストール版ではなく portable 版を使うことをおすすめします。理由は、インストール版だと毎回 UI を調整し直す羽目になるうえ、本体アップデートが正直あまり必要ないからです。そもそも codec の大半は plugin 依存であり、その plugin もめったに更新されないので……。

使用する際は Lame MP3 Encoder を組み合わせると、音楽ファイルの変換や整理がとても便利になります。

Platform​

Steam - Windows & Linux​

  • Windows
#Powershell as Administrator with Chocolatey
choco upgrade steam -y
  • Linux(Manjaro)

最初からインストールされているため、特別な変更は不要です。

これはまさに神ツールと言えます。特に Linux においては Gaming のための最重要ソフトウェアです。

最近は年を取ったこともあり、あちこちから拾ってきた ISO や得体の知れないバージョンを探す手間と労力をかけるくらいなら、セールの時にクレジットカードでサクッと買った方がよほど手っ取り早く確実だと感じるようになりました。

Steam library にあるゲームは遊びたいときにインストールすればいいだけですし、元のファイルとの整合性チェックを使っていじり倒して壊れたゲームを正常な状態に戻すこともできます。Workshop や Nexus Mod と組み合わせれば、PC ゲームの体験と快適さ（はい、おじさんは Mod 派かつ cheat 愛好家です）はかなり高いレベルになります。

さらに今では Steam Link や Remote Play Together などの新機能も Linux 上で非常にスムーズに動作するため、AMD の教えに従う Linux 仲間がストリーミング環境を組む際にも良い選択肢になります。

GOG Glaxy - Windows​

  • Windows
#Powershell as Administrator with Chocolatey
choco upgrade goggalaxy -y

これは GOG 版のSteamゲームダウンロード／インストール管理クライアントです。GOG 最大のメリットは DRM free である点ですが、一般のプレイヤーにはあまりピンと来ないかもしれません。簡単に言えば著作権保護の縛りが緩いため、古い名作ゲームを遊ぶのにとても都合が良いのです（何しろ Good Old Game という名前ですからね）。

Lutris - Linux​

  • Linux(Manjaro)
sudo pacman -Sy lutris

Lutris もまた神ツールです。世界中の猛者たちが書いたゲームインストール用スクリプトが集まっており、それを自動実行してくれる優れものだからです（もっとも、おじさん自身はこれでゲームを動かすのに成功したことがありませんが）。ただし動作のベースが各種バージョンの Wine とその設定に大きく依存しているため、使う前にハードウェア側の設定をしっかり整える必要があり、実行中もトラブルが起きたら自力で対処するという Linux らしい付き合い方が求められます。こちらの簡単な Manjaro Lutris Install Guide がありますが、要点をまとめると以下のようになります。

  1. Linux を使うなら CPU と GPU は AMD を買うこと。Nvidia は人生に絶望する羽目になります。
  2. 遊びたいゲームが Steam にあるなら、素直に Steam を使いましょう。ゲームは楽しんでこそであり、ゲーム以外の設定で自分を苦しめる必要はありません。

GameSteam​

Moonlight - Steam - Windows & Linux & macOS & Android & iOS​

上記リンクの一番下に綺麗で分かりやすいインストールリンクが一式そろっているので、ここでは文字数を節約します。

これは基本的にはサードパーティ製の Nvidia Shield クライアント＆サーバー構成のツールで、推奨される構成イメージは以下の通りです。

このツール自体は非常に優秀ですが、以下のような制約があります。

  1. 同じサブネット内にある Server しか自動検出できないため、外部から接続して遊びたい場合はゲートウェイに穴を開ける（ポート開放する）必要がある Moonlight Internet Hosting Tool を利用することで実現できます。

  2. ストリーミング方式のため、1 台の Server に同時接続できる Client は 1 台のみです。また Client 側で行った操作はそのまま Server 側で実行されるため、ある意味 Remote Desktop としても使えます。

  3. Server 側は基本的に Nvidia 環境に限定されており、レンダリング機能も Nvidia の GeForce Experience 純正機能を利用します。その代わり、Host 側の設定が非常に簡単というメリットがあります。

構成図のように、将来おじさんが思い切って作業用コンソールをすべて Linux に移行したとしても、ゲーム専用の Windows Server を 1 台別に用意し、モニターも繋がずに部屋の隅へ置いておく運用にぴったりです。

WOL（Wake-on-LAN）機能と組み合わせれば、遊びたいときだけ電源を入れ、終わったらリモートでシャットダウンできるので省電力かつ省スペースです。TV ボックスと繋いで大画面テレビで遊ぶこともできます。もし将来これが X Window のように、画面のレンダリング結果を送るのではなく直接クライアント側へ出力できるようになり、1 台のサーバーで複数のクライアントが別々の処理を実行できるようになったら最高ですね（まあ夢物語ですが）。

追伸：AMD も同じようなことができる AMD Link という仕組みを出していますが、おじさんはまだ試していません。

  • Windows インストール方法

choco upgrade brave -y

もちろん昔ながらの方法で公式サイトからインストーラーをダウンロードしてダブルクリックしても構いませんが、package manager でアップデートを管理する方が今の気分に合っている気がします。

  • Linux(Manjaro) インストール方法

  • Android インストール方法

Chromium ベースで開発されているため、基本的には Google Chrome と非常に高い互換性があります。Sync の仕組みはアカウントログイン方式ではなく、同期用のテキスト文字列（Sync Code）を使って同期する方式です。今のところ特別な設定をしなくても快適に使えています。

  • Windows インストール方法

    Portable Version
