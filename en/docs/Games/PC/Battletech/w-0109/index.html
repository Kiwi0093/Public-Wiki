BattleTech Status Effects and Buff Configuration

tip

In BattleTech, statusEffects is a very deep system. It can handle both "passive equipment bonuses (Passive)" and "negative effects triggered on hit (OnHit)". Every status effect consists of four main JSON blocks.

1. Duration and Targeting​

These two blocks determine "how long the effect lasts" and "who it applies to".

Parameter Name (Key)Settings Impact and Description
durationData.durationDuration in turns: Set to -1 for permanent effect (as long as the equipment remains equipped). If set to a positive integer (like 2), it means the effect lasts for 2 turns (usually used for debuffs applied when hitting enemies).
targetingData.effectTriggerTypeTrigger timing:
• Passive: Passive constant, active as long as equipped.
• OnHit: Triggered when weapon hits the target.
targetingData.effectTargetTypeTarget:
• Creator: Applies to the mech equipping this weapon/component itself (Buff).
• Target: Applies to the enemy mech hit by this weapon (Debuff).
targetingData.showInStatusPanelUI display: true or false. Whether to show the icon of this buff/debuff in the combat screen status bar. Hidden passive abilities are usually set to false to avoid interface clutter.

2. Description​

Controls information displayed when this effect is clicked in the game interface.

Parameter Name (Key)Settings Impact and Description
Description.IdUnique effect identifier: Must be unique across the game. Strongly recommended to use the format StatusEffect-EquipmentName-EffectName.
Description.NameEffect Name: Buff/Debuff name displayed on the UI.
Description.DetailsDetailed Description: Text description for the effect on the UI.
Description.IconInterface Icon: Name of the SVG vector icon invoked (e.g., uixSvgIcon_equipment_TTS).

3. Core Computation Engine (Statistic Data)​

This is the most critical block, responsible for executing underlying numerical additions, subtractions, multiplications, and divisions.

Parameter Name (Key)Settings Impact and Description
statisticData.targetCollectionScope:
• Weapon: Effect is limited to the weapon providing this buff itself.
• StatCollection: Effect extends to all components and base stats of the entire mech.
statisticData.statNameTarget property: Which system statistic you want to modify (refer to the "Common Property Name Dictionary" below).
statisticData.operationOperation logic:
• Float_Add / Int_Add: Addition operation (input negative numbers for subtraction).
• Float_Multiply: Multiplication operation, used for multipliers (e.g., 1.1 means a 10% increase).
statisticData.modValueModification value: Specific number to change. Note: Must be wrapped in double quotes as a string in JSON (e.g., "-1.0" or "15").
statisticData.modTypeData type:
• System.Single: Corresponds to float (numbers with decimals).
• System.Int32: Corresponds to integer (numbers without decimals).

📖 Common Property Name (statName) Dictionary​

When building special equipment, fill the following strings into statisticData.statName to modify corresponding mech or weapon capabilities.

📌 Weapon-Exclusive Enhancements (Scope: Weapon)​

Applicable when targetCollection is set to "Weapon", affecting only that specific weapon.

Property Name (statName)Operation RecommendationActual Effect Description
AccuracyModifierFloat_AddAccuracy modifier. Input negative values (like -1.0) to increase accuracy and lower shooting difficulty.
DamagePerShotFloat_AddDamage per shot increase. Directly increases the base damage of each bullet or laser.
HeatGeneratedFloat_AddHeat generation modifier. Input negative values (like -5.0) to reduce heat generated when the weapon fires.
EvasivePipsIgnoredInt_AddEvasive pips ignored. Improves weapon's ability to ignore enemy Evasion points (e.g., 1 means ignoring 1 additional grid).
MaxRangeFloat_AddMax range extension. Directly increases the maximum firing distance of the weapon.

📌 Full Mech Enhancements (Scope: StatCollection)​

Applicable when targetCollection is set to "StatCollection", affecting the entire mech's physique and movement.

Property Name (statName)Operation RecommendationActual Effect Description
MaxHeatInt_AddOverheat threshold cap. Increases the total slot quantity of heat the mech can tolerate.
HeatSinkCapacityInt_AddBase heat dissipation capacity. Extra heat dissipated at the end of each turn (similar to built-in heat sinks).
WalkSpeedFloat_AddWalking distance. Increases the single movement range of the mech on the combat map.
RunSpeedFloat_AddSprint distance. Increases the maximum movement range of the mech when performing a Sprint.
JumpDistanceMultiplierFloat_MultiplyJump distance multiplier. Only effective if equipped with Jump Jets, increasing the limit of jump distance.
DamageReductionMultiplierAllFloat_MultiplyGlobal damage reduction multiplier. E.g., 0.9 means damage from any source is reduced by 10% (extremely powerful defensive attribute).
SensorSignatureModifierFloat_AddRadar signature modifier. Input negative values (like -0.2) to make it harder for enemies to lock onto and discover this mech at a distance (stealth effect).

Status Effect JSON Example (Accuracy +1 & Heat Cap +15)​

"statusEffects": [
    {
        "durationData": { "duration": -1 },
        "targetingData": {
            "effectTriggerType": "Passive",
            "effectTargetType": "Creator",
            "showInStatusPanel": true
        },
        "effectType": "StatisticEffect",
        "Description": {
            "Id": "StatusEffect-UAC20K-Accuracy",
            "Name": "Precision Fire Control System",
            "Details": "Accuracy +1.",
            "Icon": "uixSvgIcon_equipment_TTS"
        },
        "nature": "Buff",
        "statisticData": {
            "statName": "AccuracyModifier",
            "operation": "Float_Add",
            "modValue": "-1.0",
            "modType": "System.Single",
            "targetCollection": "Weapon"
        }
    },
    {
        "durationData": { "duration": -1 },
        "targetingData": {
            "effectTriggerType": "Passive",
            "effectTargetType": "Creator",
            "showInStatusPanel": false
        },
        "effectType": "StatisticEffect",
        "Description": {
            "Id": "StatusEffect-UAC20K-HeatCap",
            "Name": "Cooling Pipeline Expansion",
            "Details": "Maximum heat capacity increased by 15 points.",
            "Icon": "uixSvgIcon_equipment_Heatsink"
        },
        "nature": "Buff",
        "statisticData": {
            "statName": "MaxHeat",
            "operation": "Int_Add",
            "modValue": "15",
            "modType": "System.Int32",
            "targetCollection": "StatCollection"
        }
    }
]
