Neovim and NvChad Installation, Configuration, and Keybinding Reference

1. Basic NeoVim Installation​

NeoVim offers high extensibility and asynchronous processing, and can be installed directly via native package managers across major Linux distributions:

  • Arch Linux / Manjaro:

     sudo pacman -S neovim

  • Debian / Ubuntu / Linux Mint:

     sudo apt install neovim

  • Fedora / RHEL:

     sudo dnf install neovim

  • Default configuration directory: ~/.config/nvim/

2. Deploying the NvChad Framework​

NvChad is a pre-configured, out-of-the-box Neovim distribution and theming setup written entirely in Lua. It maintains a lightweight footprint and a modular architecture.

1. Installation and Initialization​

Clone the official Starter repository to the user's .config/nvim directory using Git:

git clone https://github.com/NvChad/starter ~/.config/nvim && nvim

(Note: On first launch, Neovim will automatically trigger the plugin download and installation interface.)

2. Managing Custom Configuration Structure (custom Directory)​

NvChad's core design recommends placing all personal customizations inside ~/.config/nvim/lua/custom/. Since this directory is included in .gitignore by default, it is well-suited to being maintained as its own independent Git repository for cross-host synchronization:

  • Full Override: Placing init.lua inside custom directly overrides and replaces NvChad's default behavior.
  • Partial Override (Recommended): Placing chadrc.lua inside custom allows local overrides or extensions based on the structure of core/default_config.lua.
Updated 2026-11-27

Starting from NvChad v2.5 (the NvChad/starter cloned above), the legacy v2.0 lua/custom/ directory and core/default_config.lua have been deprecated. The new structure maintains chadrc.lua, options.lua, mappings.lua, and plugins/init.lua directly under ~/.config/nvim/lua/ (with NvChad/NvChad itself loaded as a lazy.nvim plugin). The lua/custom/ examples in the sections below are kept only for understanding legacy v2.0 concepts.

3. Custom Configuration Examples (chadrc.lua and Lua Integration)​

1. ~/.config/nvim/lua/custom/chadrc.lua Example​

All UI themes and custom module mounts are defined in this file:

---@type ChadrcConfig
local M = {}

-- 設定預設佈景主題
M.ui = {
  theme = "onedark",
}

-- 掛載自訂的程式碼摺疊模組 (對應 custom/folder.lua)
M.folder = require "custom.folder"

return M
  • Module loading explanation: The syntax M.XXX = require "custom.XXX" loads the custom/XXX.lua file. Copying the corresponding file from the official core/ directory before editing offers the best compatibility.

2. ~/.config/nvim/lua/custom/folder.lua (Code Folding Configuration Example)​

-- 語法高亮（Neovim 預設開啟，若需強制執行可保留 vim.cmd）
vim.cmd('syntax on')

-- 使用 vim.opt 設定選項 (等同於 Vimscript 的 set)
vim.opt.foldmethod = 'marker'
vim.opt.foldmarker = '{{{,}}}'
vim.opt.foldlevel = 0
vim.opt.foldnestmax = 3

-- 設定全域變數 (等同於 Vimscript 的 let，用來處理舊式外掛變數)
vim.g.php_folding = 1

Core Mapping Principles:​

  • vim.opt: Dedicated to setting various Vim options (such as foldmethod, number, shiftwidth, etc.), supporting autocompletion and type handling.
  • vim.g: Used to set global variables; for example, the traditional let php_folding = 1 must be mapped to vim.g.php_folding = 1.

You can also call vim.cmd() from Lua to seamlessly carry over traditional .vimrc settings:

vim.cmd('syntax on')
vim.cmd('set foldmarker={{{,}}}')
vim.cmd('set foldmethod=marker')
vim.cmd('set foldlevel=0')
vim.cmd('let php_folding = 1')
vim.cmd('set foldnestmax=3')

Common Keybindings for Managing Code Folding in Vim:​

zoOpen the folded block under the cursor

Most NvChad keybindings start with the Leader Key. The default Leader Key is Space. Pressing it automatically brings up the keybinding hint menu (Which-Key).

5. Mason Package Manager (LSP / DAP / Linters Management)​

In modern Neovim development environments, Mason.nvim is the core plugin for managing Language Servers (LSP), Debug Adapters (DAP), Linters, and Formatters. Through a unified graphical interface, developers can easily install and update development tools across major programming languages.

1. Common Commands and Operations​

Run the following Ex commands in NvChad or Neovim to invoke Mason:

CommandEffect DescriptionNotes
:MasonOpen Mason DashboardDisplays an interactive UI where you can browse, install, or uninstall tools using arrow keys.
:MasonInstall <package>Install Specific ToolDirectly installs a specific Linter or LSP from the command line (e.g., :MasonInstall pyright, :MasonInstall typescript-language-server).
:MasonUninstall <package>Remove Specific ToolUninstalls language servers or formatters you no longer need.
:MasonUpdateUpdate All Installed ToolsChecks and upgrades all external binaries managed by Mason to their latest versions.

2. LSP Integration with NvChad​

In NvChad, Mason is typically paired with mason-lspconfig.nvim to ensure language servers installed via Mason automatically integrate with Neovim's built-in LSP. If you need to customize or pre-install specific LSPs, extend the configuration in ~/.config/nvim/lua/custom/plugins.lua:

-- 範例：透過 NvChad 的 plugins 覆寫機制擴充 Mason 自動安裝清單
local plugins = {
  {
    "williamboman/mason.nvim",
    opts = {
      ensure_installed = {
        "lua-language-server",
        "pyright",
        "typescript-language-server",
        "gopls",
      },
    },
  },
}

return plugins
Updated 2026-11-27
  • In NvChad v2.5 (NvChad/starter), the plugin override file has moved to ~/.config/nvim/lua/plugins/init.lua (instead of lua/custom/plugins.lua). You can also use M.mason = { pkgs = { ... } } in lua/chadrc.lua paired with :MasonInstallAll for batch installation.
  • The upstream repository williamboman/mason.nvim has migrated to mason-org/mason.nvim (the old path still redirects, though mason-org/mason.nvim is recommended for new configurations).

6. Recommended Common LSPs (Language Server Protocol)​

Installing language servers through Mason equips Neovim with IDE-grade features such as autocompletion, syntax checking, Go to Definition, and real-time diagnostics. Below is a recommended list of LSP servers for major programming languages:

Language / TechnologyMason Package NameCore Features & Highlights
Pythonpyright or basedpyrightPowerful type-checking and autocompletion LSP developed by Microsoft, supporting real-time error diagnostics and code navigation.
Lualua-language-serverEssential for writing Neovim custom configs and Lua scripts, with excellent support for Neovim's vim global variables.
TypeScript / JavaScripttypescript-language-serverCore frontend development server providing type inference, refactoring, and autocompletion for TS/JS.
HTML / CSS / JSONvscode-langservers-extractedStandard LSPs for the core web trio, delivering accurate tag and style completion.
GogoplsThe official LSP maintained by the Go team, offering top performance and the most complete feature set.
Rustrust-analyzerAn indispensable powerhouse for Rust development, offering strong macro expansion and type analysis.
Bash / Shellbash-language-serverProvides syntax checking and basic autocompletion for shell scripts.
C / C++clangdBased on LLVM/Clang, providing blazingly fast and accurate navigation and completion for C/C++ (generally preferred over ccls).

Quick One-Click Installation Example​

To have Mason automatically install these common LSPs at startup, add them directly to the ensure_installed array in ~/.config/nvim/lua/custom/plugins.lua (lua/plugins/init.lua in NvChad v2.5):

ensure_installed = {
  "lua-language-server",
  "pyright",
  "typescript-language-server",
  "gopls",
  "clangd",
  "bash-language-server",
}

7. Recommended Common Formatters​

In addition to handling syntax checking and navigation via LSP, Neovim is usually paired with dedicated Formatters to keep code formatting consistent across teams or personal projects. By installing them via Mason and hooking them up with conform.nvim or none-ls.nvim (the community-maintained fork after null-ls.nvim was archived), you can achieve automatic formatting on save.

Language / ScopeMason Package NameCore Features & Highlights
Pythonblack or ruffblack is the standard zero-config formatter in Python; ruff is a rapidly rising, ultra-fast Rust-based linter and formatter combo.
JavaScript / TypeScript / JSON / HTML / CSS / MarkdownprettierAll-around frontend formatter that cleanly handles indentation and line wrapping across web and markup languages.
LuastyluaA powerful formatter designed specifically for Lua (very common in the Neovim / NvChad ecosystem).
Gogofmt or goimportsOfficial standard Go formatters (typically bundled with gopls or the Go SDK itself, and also manageable via Mason).
C / C++ / Java / Rust (and more)clang-formatA powerful Clang-based formatter that strictly enforces layout rules via a .clang-format file in the project root.
Shell ScriptshfmtThe standard indentation tool dedicated to formatting Bash / Shell scripts.

Example of Integrating into Mason's Auto-Install List​

Similarly, you can include commonly used Formatters in the ensure_installed array in ~/.config/nvim/lua/custom/plugins.lua (lua/plugins/init.lua in NvChad v2.5) to ensure they are automatically provisioned on every fresh setup:

ensure_installed = {
  -- LSP
  "lua-language-server",
  "pyright",
  "typescript-language-server",
  "gopls",
  -- Formatter
  "prettier",
  "stylua",
  "black",
  "shfmt",
}
