Basic Approach

Install xrdp & xorgxrdp​

yay -S xrdp xorgxrdp

Then start the services:

sudo systemctl enable --now xrdp.service
sudo systemctl enable --now xrdp-sesman.service

After that, it is ready to use, and basically no other settings need to be changed.

Updated 2026-11-27

This article was written for early X11-era KDE Plasma 5 and the ~/.xinitrc architecture. Today, KDE Plasma 6 defaults to Wayland, and traditional X11 xrdp + xorgxrdp alongside ~/.xinitrc practices are no longer directly applicable (in Wayland environments, KDE Plasma 6 can use the official krdp / KRdp for RDP remote desktop services).
