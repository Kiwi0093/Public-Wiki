Manjaro KDE 環境自動安裝腳本 Ver.2

tip

This series is no longer applicable and is kept purely as a memento.

Just like the automated installation scripts, this script isn't actually very useful in practice—it was mainly written as shell scripting practice.

Updated 2026-11-27

This article is an archived record of an early personal Manjaro Linux setup script. Several packages and tools in the script (such as neofetch, fcitx 4, Qv2ray, the legacy Hexo setup, and KDE Plasma 5's plasmapkg2) are unmaintained or superseded by newer tools, the external static asset URLs (Kiwi0093.github.io/script/Manjaro/...) are retired legacy paths, and parts of the script contain syntax bugs. Please treat this strictly as historical reference.

This time I split the colors into five different definitions (pretty elaborate, right?) and added a warning banner right at the top. Going forward, I'll probably rewrite all of my scripts to start with this header so they look a bit more legit.

Mirrorlist Definition and Application (Plus System Update)​

# Choose Country for pacman-mirrors
echo -e "${COLOR1}Please choose the loaction you want to set for Mirror\n ${COLOR_H}C) China\n T) Taiwan\n L) Let me type what I want\n F) Fastest Mirror from all country\n Any other) Use Manjaro Default\n >${NC}"
while :
do
	read COUNTRY
	case $COUNTRY in
		C)
			echo -e "${COLOR2}Using China Mirrors${NC}"
			sudo pacman-mirrors -c China
			break
			;;
		T)
			echo -e "${COLOR2}Using Taiwan Mirrors${NC}"
			sudo pacman-mirrors -c Taiwan
			break
			;;
		L)
			echo -e "${COLOR2}Please input coutry you want (ie:United_States)\n${NC}"
			read COUNTRY_INPUT
			sudo pacman-mirrors -c $COUNTRY_INPUT
			break
			;;
		F)
			echo -e "${COLOR2}Use All Country for Fastest Mirror${NC}"
			sudo pacman-mirrors --fasttrack 3
			break
			;;
		*)
			echo -e "${COLOR2}Use Default setting${NC}"
			break
			;;
	esac
done

# Apply Mirrorlist and update system
echo -e "${COLOR1}Update your system${NC}"
sudo pacman -Syyu
Updated 2026-11-27

On line 2 of the script, ${COLOR_H} in the prompt string is undefined (the earlier definitions are COLOR_H1 and COLOR_H2), which causes color formatting to fail; additionally, $COUNTRY_INPUT in sudo pacman-mirrors -c $COUNTRY_INPUT is not quoted.

Since Manjaro provides pacman-mirrors, it works differently from the Arch Linux script and can be configured directly via commands. Here I also added four options (plus keeping the default):

  • The Walled Country The Celestial Empire (physically staying here right now, so this option is a must)
  • Taiwan (home sweet home, had to include it)
  • Custom input (for anyone else who might use this, or when I feel like typing it manually...)
  • Sort the top 3 fastest mirrors worldwide by speed (theoretically the best option without needing to pick a country, though... running through the full benchmark takes quite a while...)
  • Keep the original settings without changing anything

Next is a simple sudo pacman -Syyu, using -Syy to update the Mirrorlist—even if you don't want to upgrade the system, you still have to run sudo pacman -Syy, otherwise configuring the mirrorlist beforehand was a waste of time (Updated 2026-11-27: pacman -Syy forces a re-download of the package repository sync databases rather than updating the Mirrorlist; the Mirrorlist was already updated by pacman-mirrors in the previous step. Furthermore, on Arch/Manjaro you should avoid running pacman -Syy and then installing packages without upgrading the system (partial upgrade); instead, run sudo pacman -Syu for a full sync and system upgrade).

Updated 2026-11-27
  • neofetch was discontinued and archived in 2024; fastfetch is recommended for modern environments.
  • The fcitx (Fcitx 4) package group (fcitx, fcitx-qt5, fcitx-configtool, fcitx-chewing, fcitx-mozc) is now legacy; switching to the fcitx5 family (such as fcitx5-im, fcitx5-chewing, fcitx5-mozc) is recommended.

Updated 2026-11-27

mkdir ~/.cache/yay/ttf-meslo-nerd-font-powerlevel10k lacks -p, so it will fail if ~/.cache/yay does not yet exist; moreover, the external font download URLs point to an archived legacy path. On modern systems, you can directly install Nerd Fonts packages from the official repositories such as ttf-meslo-nerd.

Normally, a simple yay -S ttf-meslo-nerd-font-powerlevel10k should handle this, but due to the special network conditions in the Walled Country the Celestial Empire, downloading the required ttf files during installation often fails.

That's why I used a pre-download approach, fetching them from the script hosting location first (and if that location isn't reachable, you wouldn't be able to fetch this script to run in the first place).

As for what this Nerd Font is used for: Powerlevel10k uses various glyph icons to prettify the prompt, so these font files are needed for them to render properly.

I also mischievously made a custom zeon.ttf containing only two glyphs—the emblems of the glorious Principality of Zeon and Neo Zeon. Since it's just for personal use, I didn't worry too much about image licensing.

Qv2ray​

# Install Qv2ray
echo -e "${COLOR1}Do you want to install ${COLOR_H2}Qv2ray${NC}?\nIt should spend much time\n ${COLOR_H1}Y) Yes install via yay\n A) Using AppImage version\n N)No Need\n >${NC}"
while :
do
	read QV2RAY
	case $QV2RAY in
		Y)
			echo -e "${COLOR2}Install QV2Ray via yay${NC}"
			yay -S --noconfirm qv2ray
			break
			;;
		A)
			echo -e "${COLOR_H1}Please enter Qv2ray Version(ie:2.6.3)${NC}"
			read Q_VERSION
			echo -e "${COLOR2}Download QV2Ray AppImage from Github${NC}"
			mkdir ~/Applications
			wget https://github.com/Qv2ray/Qv2ray/releases/download/v${Q_VERSION}/Qv2ray.v${Q_VERSION}.linux-x64.AppImage
			mv ./Qv2ray.v* ~/Applications/Qv2ray.v${Q_VERSION}.linux-x64.AppImage
			break
			;;
		N)
			echo -e "${COLOR2}Skip Qv2ray Installation${NC}"
			break
			;;
		*)
			echo -e "${COLOR_H1}Please enter your choice Y or A or N${NC}"
			;;
	esac
done
Updated 2026-11-27

The upstream Qv2ray project ceased development and was archived in 2021; it is no longer recommended for installation or use in new environments.

From experience, Qv2ray builds very easily get stuck and are painful to install, so I added an extra option to download the AppImage version instead.

Restore Qv2ray Settings​

# Restore Qv2ray Setting
echo -e "${COLOR1}Are you Kiwi?\nIf you are, do you need to restore your private ${COLOR_H2}Qv2ray${NC} setting\n ${COLOR_H1}Y) Yes\n N) No I don't need\n >${NC}"
while :
do
	read Q_SET
	case $Q_SET in
		Y)
			echo -e "${COLOR1}Check QV2ray installed${NC}"
			if [ -f "~/Applications/Qv2ray*AppImage" ]; then
				echo -e "${COLOR2}AppImage Version Installed${NC}"
				curl -o qv2ray.e.tar.gz https://Kiwi0093.github.io/script/Manjaro/qv2ray.e.tar.gz
				openssl enc -d -aes256 -in qv2ray.e.tar.gz -out qv2ray.tar.gz
				tar zxvf qv2ray.tar.gz
				rm -rf ~/.config/qv2ray
				mv ./qv2ray ~/.config/
				rm -rf ./qv2ray.*
			else
				echo -e "${COLOR2}No Qv2ray AppImage found${NC}"
			fi
			if [ -f "/usr/bin/qv2ray" ]; then
				echo -e "${COLOR2}Qv2ray Installed${NC}"
				curl -o qv2ray.e.tar.gz https://Kiwi0093.github.io/script/Manjaro/qv2ray.e.tar.gz
				openssl enc -d -aes256 -in qv2ray.e.tar.gz -out qv2ray.tar.gz
				tar zxvf qv2ray.tar.gz
				rm -rf ~/.config/qv2ray
				mv ./qv2ray ~/.config/
				rm -rf ./qv2ray.*
			else
				echo -e "${COLOR2}No Qv2ray found${NC}"
				fi
			break
			;;
		N)
			echo -e "${COLOR2}Skip QV2Ray Setting${NC}"
			break
			;;
		*)
			echo -e "${COLOR_H1}Please enter your choice Y or A or N${NC}"
			;;
	esac
done
Updated 2026-11-27
  • [ -f "~/Applications/Qv2ray*AppImage" ] places ~ and the wildcard * inside double quotes, preventing shell expansion and causing the condition to always fail.
  • openssl enc -d -aes256 omits -pbkdf2, which is a deprecated key derivation method in modern OpenSSL versions and may fail to decrypt older files due to changes in the default digest algorithm.
  • Qv2ray itself ceased maintenance in 2021.

Here I added a check to see if Qv2ray is installed—if not, it won't restore anything. Also, because these are private settings, my config archives are encrypted with OpenSSL, so they're useless without the password.

Restore Gnome-Pie​

# Restore Gnome-pie Setting
echo -e "${COLOR1}Are you Kiwi?\nIf you are, do you need to restore your ${COLOR_H2}gnome-pie${NC} setting\n ${COLOR_H1}Y) Yes\n N) No I don't need\n >${NC}"
while :
do
        read P_SET
        case $P_SET in
                Y)
                        echo -e "${COLOR1}Check Gnome-Pie installed${NC}"
                        if [ -f "/usr/bin/gnome-pie" ]; then
                        	echo -e "${COLOR2}Gnome-pie Installed${NC}"
				curl -o gnome-pie.tar.gz https://Kiwi0093.github.io/script/Manjaro/gnome-pie.tar.gz
				tar zxvf gnome-pie.tar.gz
				rm -rf ~/.config/gnome-pie
				mv ./gnome-pie ~/.config
                        else
                        	echo -e "${COLOR2}No Gnome-pie found${NC}"
                        	echo -e "${COLOR2}Skip Gnome-pie Setting${NC}"
                        fi
			break
			;;
                N)
                        echo -e "${COLOR2}Skip Gnome-pie Setting${NC}"
                        break
                        ;;
                *)
			echo -e "${COLOR_H1}Please enter your choice Y or A or N${NC}"
                        ;;
        esac
done

Gnome-Pie doesn't hold anything sensitive, so it just copies over the plaintext config files directly to restore it.

KDE Plasmoid​



# Install Kde Plasmaoid
echo -e "${COLOR1}Install KDE plasma Widget & Splash\n${NC}"
if [ -d "/usr/include/plasma" ];then
	echo -e "${COLOR2}KDE Plasma Found${NC}"
	curl -o plasma-simpleMonitor-v0.6.plasmoid https://Kiwi0093.github.io/script/Manjaro/plasma-simpleMonitor-v0.6.plasmoid
	plasmapkg2 -i plasma-simpleMonitor-v0.6.plasmoid ~/.local/share/plasma/plasmoids/
	rm -f plasma-simpleMonitor-v0.6.plasmoid
	curl -o  VioletEvergarden-Splash.tar.gz https://Kiwi0093.github.io/script/Manjaro/VioletEvergarden-Splash.tar.gz
	plasmapkg2 -i VioletEvergarden-Splash.tar.gz ~/.local/share/plasma/look-and-feel/
	rm -f VioletEvergarden-Splash.tar.gz
	curl -o  plasma-org.kde.plasma.desktop-appletsrc https://Kiwi0093.github.io/script/Manjaro/plasma-org.kde.plasma.desktop-appletsrc
	mv ./plasma-org.kde.plasma.desktop-appletsrc ~/.config/
else
	echo -e "${COLOR2}KDE Plasma NOT found${NC}"
fi
Updated 2026-11-27

plasmapkg2 was the package management tool for KDE Plasma 5, and its -i flag only takes the package file path (it should not be followed by a target installation directory). In modern KDE Plasma 6 environments, it has been replaced by kpackagetool6, and legacy Plasma 5 .plasmoid widgets are incompatible with Plasma 6.

This just automatically installs my favorite simple monitor widget and a flashy boot splash, though I still have to tweak things manually afterward.
