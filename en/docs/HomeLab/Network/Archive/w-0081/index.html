Hexo NexT Theme Configuration and Comment Systems (Historical Archive)

Updated 2026-11-27

This site has migrated from Hexo + NexT to the Docusaurus architecture. The following content (including old kiwi0093.github.io/Wiki-site/ links, hexo-next-darkmode plugin, and Disqus / DisqusJS settings) is retained solely as a historical reference.

Preface​

The NexT theme is a very beautiful blog theme/style and is very simple to install. You can install it directly using npm.

Installation​

There are two installation methods on the NexT Theme Official Website:

  • Install directly via npm (requires Hexo version 5.0 or above)

    # Inside the Hexo directory
    npm install hexo-theme-next

    After installation, directly modify the theme section in the Hexo directory's _config.yml to use it:

    theme: next

  • Clone the entire theme directly into Hexo's theme directory using Git commands Since V8, npm installation is essentially used.

    # Inside the Hexo directory
    git clone https://github.com/next-theme/hexo-theme-next themes/next

    After installation, you still need to modify the Hexo directory's _config.yml:

    theme: next

Configuration​

Theme Setting​

Copy the Theme's _config.yml as _config.[Theme_name].yml (e.g., _config.next.yml).

For detailed instructions, refer to the Official Documentation.

Basically, you only need to modify the following main parameters:

Choosing Scheme​

# ---------------------------------------------------------------
# Scheme Settings
# ---------------------------------------------------------------

# Schemes
#scheme: Muse
scheme: Mist
#scheme: Pisces
#scheme: Gemini

# Dark Mode
darkmode: true

There are four schemes to choose from, with examples available on the official website: Muse, Mist, Pisces, Gemini. You can choose one and modify the configuration to enable it.

Additionally, NexT now natively supports Dark Mode. It is false by default; changing it to true enables dark mode.

Manual Toggle for Dark Mode​

References​

Clay's Technical Blog

Configuration Method​

Install Plug-in​
$ npm install hexo-next-darkmode --save
Configuration​
#_config.next.yml
---------------------------------------------------------------------------------------------------------------------------------
# disable default Darkmode
darkmode: false
# add below

# Darkmode JS
# For more information: https://github.com/rqh656418510/hexo-next-darkmode, https://github.com/sandoche/Darkmode.js
darkmode_js:
  enable: true
  bottom: '64px' # default: '32px'
  right: 'unset' # default: '32px'
  left: '32px' # default: 'unset'
  time: '0.5s' # default: '0.3s'
  mixColor: 'transparent' # default: '#fff'
  backgroundColor: 'transparent' # default: '#fff'
  buttonColorDark: '#100f2c' # default: '#100f2c'
  buttonColorLight: '#fff' # default: '#fff'
  isActivated: false # default false
  saveInCookies: true # default: true
  label: '🌓' # default: ''
  autoMatchOsTheme: true # default: true
  libUrl: # Set custom library cdn url for Darkmode.js
  • isActivated: true: Use Dark Mode by default; recommended to pair with saveInCookies: false, autoMatchOsTheme: false.

# ---------------------------------------------------------------
# Menu Settings
# ---------------------------------------------------------------

menu:
  home: / || fa fa-home
  #about: /about/ || fa fa-user
  tags: /tags/ || fa fa-tags
  categories: /categories/ || fa fa-th
  archives: /archives/ || fa fa-archive

# Enable / Disable menu icons / item badges.

  home: / || fa fa-home
  archives: /archives/ || fa fa-archive

Comment Functionality​

After trying around, I ultimately chose to use self-hosted Isso instead of Disqus+DisqusJS.

References​

  • Laoqingcai
  • DisqusJS Github

Applying for a Disqus Account​

Apply for this on the official website. After applying, remember to set up the API as well (refer to the approach in DisqusJS Github)

Configuration File​

#_config.next.yml
---------------------------------------------------------------------------------------------------------------------------------
# Disqus
disqus:
  enable: true
  shortname: ${your_shortname}
  count: true

# DisqusJS
# Alternative Disqus - Render comment component using Disqus API.
# Demo: https://suka.js.org/DisqusJS/
# For more information: https://github.com/SukkaW/DisqusJS
disqusjs:
  enable: true
  # API Endpoint of Disqus API (https://disqus.com/api/).
  # Leave api empty if you are able to connect to Disqus API. Otherwise you need a reverse proxy for it.
  # For example:
  # api: https://disqus.skk.moe/disqus/
  api:
  apikey: ${Your_API_KEY} # Register new application from https://disqus.com/api/applications/
  shortname: ${your_shortname} # See: https://disqus.com/admin/settings/general/
Once done, run hexo clean and hexo d -g
