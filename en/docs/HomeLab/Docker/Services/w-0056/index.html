Setting Up Heimdall Application Dashboard

1. Core Positioning and Architecture Planning​

  • Dashboard Portal: Consolidates cluttered intranet ports (e.g., Portainer :9443, LibreNMS :8000, Node-RED :1880, Nextcloud) into visual cards.
  • SSL Offloading Mechanism: Since frontend traffic is typically handled by NPM / Traefik for HTTPS certificates, Heimdall itself does not need port 443 exposed externally. It only needs to listen on port 80 internally, eliminating certificate management overhead.
  • Data Persistence: All user settings, card arrangements, custom icons, and the built-in SQLite database are stored in the container's /config directory.

2. Modern Deployment via Docker Compose​

Step 1: Create Persistent Directory and Permissions​

sudo mkdir -p /opt/heimdall/config
sudo chown -R 1000:1000 /opt/heimdall/config

Step 2: docker-compose.yml Configuration​

Define in /opt/heimdall/docker-compose.yml:

services:
  heimdall:
    image: ghcr.io/linuxserver/heimdall:latest
    container_name: heimdall
    restart: unless-stopped
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=Asia/Taipei
    volumes:
      - /opt/heimdall/config:/config
    # If using a reverse proxy, expose the internal port or attach directly to a shared network
    ports:
      - "8081:80"
    networks:
      - proxy-network

networks:
  proxy-network:
    external: true

Start the service:

docker compose up -d

3. Reverse Proxy Integration (NPM / Traefik)​

3.1 Using Nginx Proxy Manager (NPM) as Default Homepage​

  1. Add a Proxy Host in NPM:
    • Domain Names: home.example.com (or your main domain name)
    • Forward Hostname / IP: heimdall (use the container name directly when on the same proxy-network)
    • Forward Port: 80
    • Check Websockets Support and Block Common Exploits.
  2. Request or mount an SSL certificate and enable Force SSL.

3.2 Using Traefik v3 (Labels Declaration)​

If using Traefik, you can add labels directly to the heimdall service section in docker-compose.yml and remove the ports: mapping:

    labels:
      - "traefik.enable=true"
      - "traefik.http.routers.heimdall.rule=Host(`home.example.com`)"
      - "traefik.http.routers.heimdall.entrypoints=websecure"
      - "traefik.http.routers.heimdall.tls=true"
      - "traefik.http.routers.heimdall.tls.certresolver=myresolver"
      - "traefik.http.services.heimdall.loadbalancer.server.port=80"

4. Basic Usage and "Enhanced Apps" Features​

Heimdall cards are not just static shortcuts; they also support connecting to backend APIs to display real-time data in real time (Enhanced Apps).

4.1 Adding General Shortcut Cards​

  1. Click the "+" button (Add item) in the bottom-right corner of the homepage.
  2. Enter the service name in Application Name (e.g., Nextcloud or Portainer).
  3. The system will automatically pull from the official supported list and fill in the default icon and background color.
  4. Enter the URL (e.g., https://cloud.example.com).

4.2 Enabling Enhanced Apps Real-Time Status Display​

If the service supports API integration (such as Pi-hole, AdGuard Home, qBittorrent, Transmission, Plex, Proxmox):

  • A Config section will appear below the card settings.
  • Enter the application's API Key, Token, or username and password.
  • Effect: The card will directly display Pi-hole's "Blocked Ads / Total Queries", the downloader's "Real-Time Download / Upload Speed", or the media library's "Now Playing Count".

5. Heimdall Visual Customization (Personalization)​

The default solid color background and large block style are relatively plain, but can be upgraded via built-in features and custom CSS:

5.1 Custom High-Resolution Wallpaper and Dark Mode​

  1. Click the gear icon (Settings) in the bottom-right corner.
  2. Background Image: Upload a 4K wallpaper (or specify an Unsplash random wallpaper URL).
  3. Background Blur / Opacity: If card text is hard to read, adjust the background blur and overlay darkness in settings.
  4. Check Dark Mode.

5.2 Importing Community High-Quality Vector Icons (Dashboard Icons)​

Most of Heimdall's built-in icons are PNG raster images, which blur when enlarged. You can download corresponding SVGs / high-resolution PNGs from community-maintained open-source icon libraries (such as walkxcode/dashboard-icons) and upload custom icons directly when editing cards.

5.3 Injecting Custom CSS for Glassmorphism Cards​

Heimdall supports custom stylesheet files on the host.

Edit /opt/heimdall/config/www/custom.css (create if it doesn't exist):

/* Make cards translucent with frosted glass effect */
.item {
    background: rgba(255, 255, 255, 0.1) !important;
    backdrop-filter: blur(12px) !important;
    -webkit-backdrop-filter: blur(12px) !important;
    border: 1px solid rgba(255, 255, 255, 0.18) !important;
    border-radius: 12px !important;
    box-shadow: 0 8px 32px 0 rgba(0, 0, 0, 0.37) !important;
    transition: transform 0.2s ease, box-shadow 0.2s ease !important;
}

/* Slightly float and scale up on mouse hover */
.item:hover {
    transform: translateY(-4px) scale(1.02) !important;
    box-shadow: 0 12px 40px 0 rgba(0, 0, 0, 0.5) !important;
}

/* Hide extra edit button in bottom-right corner when not logged in (cleaner guest mode) */
body:not(.logged-in) #edit-toggle {
    display: none;
}

After editing, hard refresh your browser (Ctrl + F5) to apply the changes.

7. Data Backup and Restore​

All Heimdall configurations (including users, cards, background images, and uploaded icons) are centralized within the /config directory:

# Backup configuration
sudo tar -czvf /opt/backups/heimdall-$(date +%F).tar.gz -C /opt/heimdall config

# Restore configuration
sudo tar -xzvf /opt/backups/heimdall-*.tar.gz -C /opt/heimdall/
sudo chown -R 1000:1000 /opt/heimdall/config
docker compose restart heimdall
Updated 2026-11-27

If the wildcard heimdall-*.tar.gz in the restore command above matches multiple backup files in the directory, tar will fail; please specify a single exact filename during actual restoration (e.g., heimdall-2026-09-04.tar.gz).
