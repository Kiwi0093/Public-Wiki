Calibre-Web: Self-Hosted Private E-Book Library and Cross-Device Reading Management

1. Core Architecture Concepts and Troubleshooting Guide​

1.1 Library Structure and metadata.db Core Dependency​

  • Calibre-Web cannot create a brand-new library from scratch on its own. It requires mounting an existing Calibre library directory that already contains metadata.db.
  • During initial setup, if the specified directory is empty, the system will error out and refuse to initialize. You must first create a library using the desktop version of Calibre or place a blank yet valid metadata.db inside.

1.2 Storage Separation Golden Rule: Local SSD vs. NAS Network Mount​

Similar to the maintenance experiences of Navidrome and Nextcloud, SQLite databases have significant pitfalls on network file systems:

  • Physical Library Directory (/books): Stores actual books (EPUB, MOBI, PDF, cover images). It is strongly recommended to mount this on a NAS (supporting SMB/CIFS or high-performance NFS).
  • Configuration and Application Database (/config): Contains Calibre-Web's own user permissions, reading progress, and bookmark database (app.db). Be sure to keep this on the host's local SSD; do not mount it on a CIFS/NFS network share to avoid SQLite corruption caused by high-frequency lock contention.

1.3 The Role of USE_CONFIG_DIR=true​

In LinuxServer.io's Calibre-Web image, declaring USE_CONFIG_DIR=true forces Calibre-Web to store its own system database app.db inside /config, physically isolating it from the Calibre library's metadata.db inside /books, ensuring safer multi-user and backup management.

2. Prerequisites: Photon OS Mounting NAS Library (CIFS vs. NFS)​

Option A: Using CIFS / SMB Mount​

If your NAS naturally leans towards Windows ACL or access via credentials:

# 1. Ensure cifs-utils is installed
tdnf -y install cifs-utils

# 2. Create mount point
sudo mkdir -p /mnt/nas/books

# 3. Edit /etc/fstab for automatic mounting
# //192.168.1.50/Books /mnt/nas/books cifs credentials=/root/.smbcredentials/nas,uid=1000,gid=1000,rw,iocharset=utf8,_netdev,nofail 0 0

Option B: Using NFSv4.1 Mount (Recommended, Better Performance)​

Enable NFS export and whitelist IP on the NAS side, then mount on Photon OS:

# 1. Install NFS utilities
tdnf -y install nfs-utils
systemctl enable --now rpcbind

# 2. Create mount point
sudo mkdir -p /mnt/nas/books

# 3. Edit /etc/fstab
# 192.168.1.50:/volume1/Books /mnt/nas/books nfs nfsvers=4.1,rw,_netdev,nofail,hard,intr,rsize=1048576,wsize=1048576 0 0

# 4. Test mount
sudo mount -a
ls -la /mnt/nas/books

(Note: If you need to upload books or edit metadata via the web interface, the mount permissions must be rw read-write).

Updated 2026-11-27

Modern Linux kernels (version 2.6.25 and later) have deprecated and ignored the NFS mount parameter intr. You can safely omit this option in daily configurations, keeping hard alone.

3. Complete Docker Compose Deployment Configuration (Integrating Traefik v3)​

This configuration keeps /config on the local SSD (/opt/calibre-web/config), mounts the book library to /mnt/nas/books on the NAS, and lets Traefik handle SSL termination.

Step 1: Create Local Dedicated Directory and Fix Permissions​

sudo mkdir -p /opt/calibre-web/config
sudo chown -R 1000:1000 /opt/calibre-web/config

Step 2: docker-compose.yml Configuration​

services:
  calibre-web:
    image: lscr.io/linuxserver/calibre-web:latest
    container_name: calibre-web
    restart: unless-stopped
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=Asia/Taipei
      # Key: Isolate app.db inside /config
      - USE_CONFIG_DIR=true
      # Pre-specify conversion tool directory (if kepubify or Calibre conversion binaries are installed)
      - DOCKER_MODS=linuxserver/mods:universal-calibre # Optional: enable backend format conversion support
    volumes:
      - /opt/calibre-web/config:/config
      - /mnt/nas/books:/books
    networks:
      - proxy-network
    labels:
      - "traefik.enable=true"
      - "traefik.http.routers.calibre-web.rule=Host(`books.example.com`)"
      - "traefik.http.routers.calibre-web.entrypoints=websecure"
      - "traefik.http.routers.calibre-web.tls=true"
      - "traefik.http.routers.calibre-web.tls.certresolver=myresolver"
      # Forward to port 8083 inside the container
      - "traefik.http.services.calibre-web.loadbalancer.server.port=8083"

networks:
  proxy-network:
    external: true

Start the service:

docker compose up -d

4. Nginx / Nginx Proxy Manager (Subpath and Subdomain Setup)​

4.1 Option A: Subpath Reverse Proxy (/book)​

If Calibre-Web must be placed under a subpath, Nginx must include X-Script-Name (note: no trailing slash in the path):

location /book {
    proxy_pass http://calibre-web:8083;
    proxy_set_header Host $http_host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Scheme $scheme;
    # Core: Inform the backend application of the subpath base
    proxy_set_header X-Script-Name /book;
    
    # Support uploading large e-books (e.g., scanned PDFs/comics)
    client_max_body_size 500M;
}

4.2 Option B: Dedicated Subdomain (books.example.com)​

Add a Proxy Host in NPM:

  • Forward Hostname / IP: calibre-web
  • Forward Port: 8083
  • Check Websockets Support and Block Common Exploits.
  • In the Advanced section, add client_max_body_size 500M; to prevent upload blocks for large files.

5. Initial Setup and Core Feature Configuration​

  1. Open in browser: https://books.example.com
  2. Default Administrator Credentials:
    • Username: admin
    • Password: admin123
  3. Specify Library Location:

    • Enter the initial wizard page, and fill in the Location of Calibre database field with:

      /books

    • Click Save. The system will automatically verify if /books/metadata.db exists.

  4. Security Change:
    • Immediately click admin in the upper right corner -> Change password and bind an email.

5.1 Enable "Web Uploads" and "Format Conversion" Features​

By default, Calibre-Web only allows browsing and downloading. If you want to upload e-books directly through the web interface:

  1. Log in as admin -> Go to Admin -> Edit Basic Configuration.
  2. Expand Feature Configuration:
    • Check Enable Uploads (enable the upload button).
    • Check Enable Anonymous Browsing (decide whether to allow guest browsing without login based on your needs).
  3. Go to Edit User -> Edit the specified user -> Check Upload allowed.

6. Cross-Device Reading and OPDS Library Direct Connection​

Calibre-Web has a built-in powerful OPDS (Open Publication Distribution System) protocol, allowing tablets and e-readers to browse, borrow, and download directly within apps without using a browser.

6.1 OPDS Connection URL​

  • Global OPDS URL: https://books.example.com/opds
  • If using a subpath: https://example.com/book/opds

6.2 Recommended Reading Clients by Platform​

Platform / DeviceRecommended Reading SoftwareCore Features & Connection Method
Android / Open E-Paper (Boox/Meebook)KOReader (Preferred) / Moon+ ReaderSupports OPDS direct connection, custom typesetting, auto-cropping; best experience for reading EPUB/PDF. Add OPDS in library management with URL and credentials.
iOS / iPadOSKyBook 3 / Marvin / YomuBuilt-in OPDS catalog sync, detailed typesetting, cloud font support.
Kindle (Closed)Send-to-Kindle (Email Push)Configure SMTP and user's @kindle.com email in Calibre-Web, click "Send to Kindle" next to a book for one-click delivery.
Windows / macOSCalibre Desktop Version / Built-in Web ReaderIn-depth editing, typesetting revisions, and backups.

Kindle Push Key Tips:

  1. Amazon has officially deprecated .mobi pushes entirely; Send to Kindle now exclusively uses .epub format.
  2. Each Calibre-Web user account can only bind one Kindle receiving email address. If you have more than two Kindles (e.g., Oasis and Paperwhite), you need to create two independent accounts in the backend, each bound to a different @kindle.com email.

7. Maintenance and Data Backup​

Thanks to the storage separation architecture, backups are very easy:

# 1. Backup Calibre-Web system settings and user progress (Local SSD side)
sudo tar -czvf /opt/backups/calibre-web-config-$(date +%F).tar.gz -C /opt/calibre-web config

# 2. Library Body (/books)
# The book files and metadata.db are already on the NAS; simply include them in the NAS's own Snapshot or Hyper Backup schedule.

# Restoration method
sudo tar -xzvf /opt/backups/calibre-web-config-*.tar.gz -C /opt/calibre-web/
docker compose restart calibre-web
