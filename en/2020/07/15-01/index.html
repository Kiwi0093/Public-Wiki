Uncle's Ramblings - Windows & Linux Tool Inventory

July 15, 2020 · 16 min read

info

This article was archived from the old site.

After years of using computers, the software I rely on has gradually changed over time. Looking back at the posts I wrote earlier about installing and using Manjaro or Linux gaming, I started thinking about writing a hodgepodge consolidated post to document the software I'm currently using—or have used for years without getting tired of—along with my preferred setup methods, as a reference for anyone interested.

Basic Premises

Starting this year, I've gradually gotten used to working across multiple platforms (mainly Windows and Linux desktops), so when choosing software, I try to prioritize the following characteristics:

  • Freeware or Open-Source software
  • Cross-platform support
  • Ideally able to sync with each other, so switching platforms or devices doesn't interrupt my workflow
  • Able to operate without depending on an internet connection

Basically, these points help me avoid pirated software as much as possible and reduce reliance on web apps (such as tons of Chrome extensions).

Desktop Environment

Editor/Coding/Note tools​

Markdown Editor​

Typora - Windows & Linux​

  • Windows
#Powershell as Administrator with Chocolatey
choco upgrade typora -y
  • Linux(Manjaro)
#None root account & yay installed
yay -S typora

You only realize how amazingly good this is once you've used it. As I mentioned in another post (Updated 2026-11-27: another post), it can also integrate with GitHub as an image host to automatically upload images. Once you get used to the hotkeys, writing blog posts with it is super productive—definitely a Markdown editor worth recommending.

By the way, as a quick note, if you want to embed a YouTube video in Markdown, do it like this:

基本語法
[![alt text](http://example.com/exampl.png)](http://example.com/link "title")

封面的圖
http://img.youtube.com/vi/{video-id}/0.jpg

所以範例就是
[![Audi R8](http://img.youtube.com/vi/KOxbO0EI4MA/0.jpg)](https://www.youtube.com/watch?v=KOxbO0EI4MA "Audi R8")

Here, KOxbO0EI4MA is the Video ID, which you can find from the video URL—though playlists don't have cover thumbnails.

Editor for coding​

Notepad++ - Windows & Linux​

  • Windows
#Powershell as Administrator with Chocolatey
choco upgrade notepadplusplus -y

This editor is pretty handy on Windows. I mainly use it to edit HOI4 files (a prime example of slacking off from real work). Unfortunately, it's Windows-only; you can install it via choco, download and run the installer, or even run it as a portable app.

Notion - Browser based​

  • Windows & Linux & macOS & any device with a browser

    Search for Notion on the App Store.

    Ever since Notion changed its free-tier block limit to unlimited, it instantly became an absolute powerhouse. For anyone in the habit of taking notes, it's basically a must-sign-up (though I switched my note-taking style to blogging, so I don't use it much myself).

    Fun fact: I actually wanted to learn Markdown only after watching Notion promo videos—that shows just how tempting it is to use. Here's a related YouTube playlist link too; friends behind the Great Firewall can just pretend they didn't see it.

Player - Audio​

foobar2000 - Windows​

  • Windows
#Powershell as Administrator with Chocolatey
choco upgrade foobar2000 -y

For this program, though, I actually recommend not using the installer version—use the portable version instead. The main reason is that with the installed version you have to tweak the UI every time, and honestly its software updates aren't really necessary since almost all its codecs rely on plugins, and those plugins barely ever update...

When using it, remember to pair it with the Lame MP3 Encoder so you can easily convert and organize your music.

Game​

Platform​

Steam - Windows & Linux​

  • Windows
#Powershell as Administrator with Chocolatey
choco upgrade steam -y
  • Linux(Manjaro)

Pre-installed out of the box—no special tweaks needed.

This can only be called a godsend, especially on Linux where it is hands-down the single most important piece of gaming software.

Now that I'm older, instead of spending time and energy hunting down random ISOs or sketchy repacks online, it's much more practical and hassle-free to just whip out the credit card during a sale.

With games in your Steam library, not only can you wait until you want to play to install them, you can also verify file integrity to restore a heavily modded/broken game right back to a working state. Paired with Steam Workshop and Nexus Mods, the PC gaming experience and satisfaction (yeah, I'm a modder + cheat lover, deal with it) are sky-high.

On top of that, Steam now has new features like Steam Link and Remote Play Together, which run smoothly on Linux too—a great choice for Linux users following the teachings of AMD who want to stream games.

GOG Galaxy - Windows​

  • Windows
#Powershell as Administrator with Chocolatey
choco upgrade goggalaxy -y

This is GOG's version of a Steam game download/install manager. GOG's biggest selling point is being DRM-free. Most casual players might not notice much difference, but simply put, the copy protection isn't as strict, making it super convenient for playing old games (it's literally called Good Old Games, after all).

Lutris - Linux​

  • Linux(Manjaro)
sudo pacman -Sy lutris

Although Lutris is also an awesome tool—since it gathers tons of game install scripts written by community wizards and automates them (though I haven't personally succeeded in running any games with it yet)—because a lot of it is built on Wine (yes, all sorts of different Wine versions and configurations), you have to get your hardware setup right beforehand. And when running it, in classic Linux fashion, you still need to keep an eye out for how to troubleshoot issues if something goes wrong. Here is a simple Manjaro Lutris Install Guide. To sum up the key takeaways:

  1. If you use Linux, buy an AMD CPU & GPU—Nvidia will make you question your life choices.
  2. If your game is on Steam, just use Steam, kid. Gaming is supposed to be fun; don't torture yourself over non-game headaches.

GameSteam​

Moonlight - Steam - Windows & Linux & macOS & Android & iOS​

At the very bottom of the link above, there are clean and complete installation links, so I'll save some words here.

This is basically a third-party Nvidia Shield client-and-server architecture. The recommended way to use it is:

Great as this is, it has a few limitations:

  1. It can only discover servers on the same subnet. If you want to connect and play from outside your network, you need to poke holes in your gateway you can set it up via the Moonlight Internet Hosting Tool.

  2. Because it's streaming, one server can only accept one client connection at a time, and whatever you do on the client happens directly on the server—to some extent, it can even work as a remote desktop.

  3. The server is basically limited to Nvidia GPUs, as rendering relies on Nvidia GeForce Experience's native streaming capability. The upside, though, is that host setup is super simple.

Just like in the architecture diagram, if I ever lose my mind and decide to switch all my work consoles over to Linux in the future, this would be ideal for setting up a dedicated Windows gaming server tucked away in some corner without a monitor attached.

Paired with WOL (Wake-on-LAN), you can power it on only when you want to game and shut it down remotely when you're done—saving power and taking up no desk space. You can even hook it up to a TV box to play on a big-screen TV. If only in the future this could work more like X Window—

instead of sending over the whole rendered screen, outputting directly to the client so one server could let multiple clients run different things, that would be amazing (keep dreaming).

PS: AMD also made AMD Link which should be able to do something similar, I just haven't tried it yet.

Network​

Browser​

Brave Browser - Windows & Linux & Android

  • Windows installation
#Powershell as Administrator with Chocolatey
choco upgrade brave -y

Of course, you can also go the old-fashioned route, download it from the official site, and double-click to install—though I think letting a package manager handle updates fits modern tastes a bit better.

  • Linux(Manjaro) installation
sudo pacman -Syu brave

  • Android installation

This browser is highly compatible with Google Chrome (since it's built on Chromium, after all). Its sync method doesn't use account-based sign-in; instead, it uses a passphrase string as a Sync Code to sync data. So far, there haven't been any special settings worth mentioning.

SSH Client​

Putty - Windows & Linux​

  • Windows installation

  1. Use the Portable version

    Portable Version

  2. Install via Chocolatey

#Powershell as Administrator with Chocolatey
choco upgrade putty -y
  • Linux(Manjaro) installation
sudo pacman -Syu putty

On Windows, not having PuTTY is painful because there aren't many good SSH clients. On Linux, however, the built-in terminal or Terminator (installed later) works great, so aside from socket features or private key compatibility, there isn't really much reason to use PuTTY.

JuiceSSH - Android​

Even though touchscreen keyboards on Android are universally painful for CLI work, having a client on hand for emergencies is still pretty useful in a pinch.

SFTP/FTP Client​

Filezilla - Windows & Linux​

  • Windows
#Powershell as Administrator with Chocolatey
choco upgrade filezilla -y
  • Linux(Manjaro)
yay -S filezilla

These days I don't use FTP/SFTP nearly as much as back in college, but to some extent you still need an SFTP client. This one also supports PuTTY keys, so it's quite practical. Otherwise, the alternative is WinSCP, though in practice there isn't that big of a difference between the two.

Mail/IM​

Rambox - Windows & Linux​

  • Windows
#Powershell as Administrator with Chocolatey
choco upgrade Rambox -y
  • Linux
yay -S rambox

This is actually quite handy. We live in the smartphone era, so most IM apps—like LINE, WeChat, Telegram, etc.—are mobile-first. Rambox is essentially a wrapper that brings all IM/mailboxes with web clients together in one place, saving your desktop from the clutter of having a dozen separate apps open. The downside is there's no LINE (since it doesn't have a web client).

Remote Desktop​

Remmina - Linux​

  • Linux(Manjaro)
yay -S remmina

To use RDP, make sure to install:

yay -S freerdp

This is a great tool if you want to use RDP on Linux. I'm not a big fan of remote desktop apps like TeamViewer or VNC that rely on other proprietary/special protocols, so I prefer RDP (on Windows I just use the built-in RDP client). Apparently this can open an SSH tunnel directly without needing PuTTY, though I haven't successfully tried that myself.

Teamviewer - Windows & Linux​

  • Windows
#Powershell as Administrator with Chocolatey
choco upgrade teamviewer -y
  • Linux(Manjaro)
yay -S teamviewer

Honestly, this is a very powerful remote desktop tool—and precisely because it's too powerful, I don't really like it. My biggest mental hurdle is that a machine sitting behind NAT, without any port forwarding configured on the NAT gateway,

can still be connected to using just a code or account. Its NAT traversal and connectivity are insanely strong... which is why I'm a bit hesitant to use it.

VPN​

qv2ray - Windows & Linux​

  • Windows
#Powershell as Administrator with Chocolatey
choco upgrade qv2ray -y
  • Linux(Manjaro)
yay -S qv2ray

Needs to be used together with V2ray-Core. It's basically just a GUI frontend for V2ray-Core, works smoothly and is easy to use. Short description, but a very important "ladder" (proxy tool).

System Tools​

Launcher​

Orchis - Windows​

  • Windows

This program has been with me for a very long time. Basically, you can only download it from its website—a very classic Japanese-style approach.

Gnome Pie - Linux​

  • Linux(Manjaro)
yay -S gnome-pie

This is what I ended up with while looking for a Linux alternative to Orchis. In actual use, it feels pretty nice.

Package Manager​

Chocolatey - Windows​

  • Windows
#Powershell as Administrator with Chocolatey
Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://chocolatey.org/install.ps1'))

This is super useful, provided your internet connection cooperates.

yay - Archlinux & Manjaro​

  • Linux(Manjaro)
sudo pacman -S yay

In Manjaro, yay can be installed directly with the command above, whereas on Arch Linux that won't work—you have to install it via git.

Terminal​

Windows Terminal - Windows​

  • Windows
#Powershell as Administrator with Chocolatey
choco upgrade microsoft-windows-terminal -y

This is easily Microsoft's best terminal app—the old cmd and PowerShell don't even come close. If you have WSL installed, you can open a Linux terminal right inside it, which is super convenient.

Terminator - Linux

  • Linux(Manjaro)
yay -S terminator

Honestly, I don't have high demands for a Linux console—basic features are plenty for me—but after seeing Chris Titus recommend it as his favorite, I decided to jump on the bandwagon.

Virtual Machine​

VMware Workstation - Windows & Linux​

  • Windows
#Powershell as Administrator with Chocolatey
choco upgrade vmware-workstation -y
  • Linux(Manjaro)
yay -S vmware-workstation

VMware—the reigning king of virtual machine environments in my heart. Simple yet powerful VMs; I even run VMware ESXi on my server. The fact that it can be installed via Chocolatey on Windows was also a major reason I leaned completely into using Chocolatey.

Qemu - Windows & Linux​

  • Windows
#Powershell as Administrator with Chocolatey
choco upgrade qemu -y

For a GUI, please use

  • Linux(Manjaro)
yay -S qemu

For a GUI, please install 

yay -S libvirt

To be honest, there's really only one reason I wanted to touch QEMU: it currently looks like the only program capable of creating a Portable Virtual Machine, whereas basically everything else requires installation.
