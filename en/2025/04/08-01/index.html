Novels... I'd Die Without Light Reading...

April 8, 2025 · 6 min read

info

This article is reposted from the old site archive.

Not having novels to read, just like not having manga to read, is going to kill me.....

Japanese Light Novels

Originally, I always went to MobiNovels (魔筆小說) to grab the Japanese light novel e-books uploaded by the site owner, but later the site owner had a daughter and accidentally lost the site, so for a while I didn't update my own library... Until recently, when I discovered something great.

Tampermonkey - Greasy Fork - Wenku8 Downloader (轻小说文库下载)​

This is truly a blessing, because it can automatically convert novels on Wenku8 (輕小說文庫)—currently the site with the largest free collection—into epub format and pack the illustrations and cover image inside before downloading...

Notes

  • Brave users need to turn off Brave Shields, otherwise the script will be blocked from running
  • For those who want the filenames directly in Traditional Chinese, please click CC開啟 (Enable CC) first—it will convert the filenames to Traditional Chinese
  • Downloading all together merges all volumes into a single file for download
  • If there is a problem downloading any image, it will throw an Error instead of giving you an epub with missing images

Chinese Power-Fantasy Web Novels

Chinese power-fantasy web novels are trickier—basically you have to find websites offering full-book txt downloads. Currently, I go to Free Novel Net (免費小說網) to download the full-book txt files. Because Chinese web novels easily run into millions of words and generally only contain text anyway, I don't expect covers or illustrations...

Converting to epub​

Since I always read on a kindle, I forcibly convert txt files to epub for archiving. Also, since I work in a Linux (penguin) environment most of the time now, the conversion tool naturally has to run on Linux. You ask why not use a web-based converter? Mainly because Chinese web novels have too much text, free online converters can't handle them, and I just want to stay a freeloader..

txt2epub​

txt2epub github - There are many tools with the same name; I picked this one because it can be installed with yay, while most others are installed via pip. On Archlinux, I just run yay -S txt2epub and it's done...

~~Basic syntax

[Kiwi]#> txt2epub -o </path/filename.epub> --author <author Name> --title <book title> --cover-image <filename.jpg> chapter01.txt chapter02.txt chapter03.txt

Notes

  • This thing is purely a CLI command. If you want a GUI, use pip to install another Python txt2epub—I saw a GUI version
  • Make sure the text is unicode before converting, otherwise there will be issues

kaf-cli​

Before this, I used txt2epub for conversion, but found the text formatting of the converted files was a complete mess, so I switched to kaf-cli, which can also be installed directly with yay. The syntax is very similar to txt2epub.

An excerpt of the instructions from GitHub is as follows:

Command-line mode parameters

Usage of kaf-cli:
  -align string
        标题对齐方式: left、center、righ。环境变量KAF_CLI_ALIGN可修改默认值 (default "center")
  -author string
        作者 (default "YSTYLE")
  -bookname string
        书名: 默认为txt文件名
  -bottom string
        段落间距(单位可以为em、px) (default "1em")
  -cover string
        封面图片可为: 本地图片, 和orly。 设置为orly时生成orly风格的封面, 需要连接网络。 (default "cover.png")
  -cover-orly-color string
        orly封面的主题色, 可以为1-16和hex格式的颜色代码, 不填时随机
  -cover-orly-idx int
        orly封面的动物, 可以为0-41, 不填时随机, 具体图案可以查看: https://orly.nanmu.me (default -1)
  -filename string
        txt 文件名
  -font string
        嵌入字体, 之后epub的正文都将使用该字体
  -format string
        书籍格式: all、epub、mobi、azw3。环境变量KAF_CLI_FORMAT可修改默认值 (default "all")
  -indent uint
        段落缩进字数 (default 2)
  -lang string
        设置语言: en,de,fr,it,es,zh,ja,pt,ru,nl。环境变量KAF_CLI_LANG可修改默认值 (default "en")
  -line-height string
        行高(用于设置行间距, 默认为1.5rem)
  -match string
        匹配标题的正则表达式, 不写可以自动识别, 如果没生成章节就参考教程。例: -match 第.{1,8}章 表示第和章字之间可以有1-8个任意文字
  -max uint
        标题最大字数 (default 35)
  -out string
        输出文件名，不需要包含格式后缀
  -tips
        添加本软件教程 (default true)
  -unknow-title string
        未知章节默认名称 (default "章节正文")
  -volume-match string
        卷匹配规则 (default "^第[0-9一二三四五六七八九十零〇百千两 ]+[卷部]")
PS: 在darwin(mac、osx)上-tips参数要设置为false的方法 kaf-cli -filename 小说.txt -tips=0

Command-line mode instructions Convert 全职法师.txt and set the author name to 乱

# windows 10: win + s 搜索powershell 
cd d:/
d:/kaf-cli.exe -author 乱 -filename d:/全职法师.txt

# linux / mac下, 把kaf-cli-linux/kaf-cli-darwin重命名为kaf-cli, 放到用户目录
# 把小说和kaf-cli放到用户目录下,  打开终端执行
cd ~
./kaf-cli -author 乱 -filename ./全职法师.txt

# 如果kaf-cli放到path里了, 或者在aur安装的可以执行:
kaf-cli -author 乱 -filename ~/全职法师.txt

# 命令行的简单模式（功能和拖拽模式一样）
kaf-cli ~/全职法师.txt

Update to kindle

Basically, for Japanese light novels, I just throw them into my light novel library — Calibre-Web — and use Calibre-Web's built-in feature to send books to my Kindle, so there's no problem there. However, I haven't set up a Calibre-Web instance for Chinese web novels yet (maybe later if the collection grows, or I'll put them into my general books Calibre library). Regardless of the future, right now if I want to manually push them to Kindle, I rely on Amazon's official send to kindle, which has a web-based uploader.

Once it's done, you can download it on your Kindle and enjoy reading non-stop...
