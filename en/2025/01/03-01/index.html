It is already 2025. Although there isn't much to sigh about, I have indeed tweaked a few things recently.

BT over VPN

A colleague was sued by a copyright troll and had to pay a settlement... This incident more or less planted a seed of worry in my heart... So when I saw the introduction related to Gluetun mentioned in Ivon's Blog, I got eager to try it out.

Implementation​

I have updated it to My Wiki (Updated 2026-11-27: Automated Media Binge-Watching Wiki)! Interested folks can refer to my approach.

Thoughts​

It seems to work for now, but qBittorrent's efficiency doesn't look very good. Plus, I haven't successfully set up port forwarding yet, so I am actually considering whether to pay for ProtonVPN's service... To be honest, ProtonVPN's plans and pricing (VPN Plus 2-year plan at 4.99 USD/month) actually seem quite viable...

V2Ray on Cloudflare

After leaving China, I haven't spent much effort or skill points on anti-censorship wall-circumvention tools anymore... However, while watching YouTube last time, I discovered that you can set up a serverless V2Ray server using free Cloudflare Workers, and it even comes with multiple IPs that can be refreshed and changed... I can only say it is truly a blessing...

Edgetunnel​

Edgetunnel from cmliu

Actually, the moment I found this project, 90% of the setup was already done. The remaining part is having a Cloudflare account—though you might not even need one since CF Workers automatically generate a URL like worker_name.User_name.workers.dev for you. However... as someone who has previously set up V2Ray WebSockets over TLS myself, hosting on a custom domain under CF can be considered a standard setup... so none of these should be an issue, unless someone starts completely from scratch with nothing at all, in which case they might really need to put in some effort to get a domain...

Next, just create a free Worker project, paste the code from GitHub into the Worker editor, go to an online UUID generator to get a pleasing UUID put any arbitrary string as a token into the 4th line let userID = '<uuid you like>';, and deploy it.

Then go to the Worker's Settings -> Domains and Routes to configure your domain, or resign yourself to using the workers.dev link (though I only tested that it connects; not sure what might happen if actually used), and visit https://your.domain.or.workers.dev/UUID to see a screen similar to the one below:

Client​

Windows​

Basically V2RayN works. Just import the subscription group, refresh, and you're good to go.

Android​

Unfortunately, V2RayNG does not support group subscription features, so I had to test ClashMeta for Android instead. I installed it directly from GitHub using Obtainium... Detailed configuration methods... too lazy to write them out. Basically anyone who knows how to use V2RayNG will know how to configure it themselves from a subscription URL, just by filling in https://your.domain.or.workers.dev/UUID into the URL field.....

iOS​

No hardware... so not tested. Even friends who have hardware are far away in China, so let's skip testing... too troublesome Updated: Tested singbox app using a colleague's iOS device. It looks pretty good, but you have to comment out 127.0.0.1 in the source code first, and all nodes must be online in order to use it. Not sure if it's due to my bad configuration or what, but overall the user experience was pretty poor... Might need to spend more time looking into it.

MacOS​

Do you think someone who doesn't even have iOS hardware would have MacOS hardware??? (If I really had one, I probably would have used it to install Asahi Linux anyway...)

Reflections​

  • Indeed, being outside of China and lacking the pressure of the GFW makes it really hard to ignite my passion for testing a bunch of things Without the network environment inside China, I can't optimize IPs specifically for Jiangsu...
  • Same as above, so I actually don't know how effective the created nodes really are... can only look at user feedback Based on feedback from friends physically located in China, it's much better than my previous nodes and the speed is fast enough...
  • I used to feel that living in China required spending a bunch of skill points on tunneling tools. Although skill is skill... learning things always brings a sense of achievement, especially when they are easily applied practically. But looking back without absolute necessity, it really is a waste of skill points...
  • Looking at the VPNs sold nowadays—many using the WireGuard protocol while tunnels in China are almost all disguised as WebSocket-based SOCKS servers—I feel quite wistful, especially since I need Wireguard every day to connect back home. Feeling wistful that WireGuard is so easy to set up and extremely efficient... I suppose one can only helplessly accept that one cannot choose where they are born.
